# M10：原作者 2026-07-22 版原内核的变化与跟进方案（2026-11-16）

## 1. 版本与方法

- 原作者仓库 IMP-AVAS/AVAS 的 `dllfile/` 保存了各版 AVAS.dll／libAVAS.so。
  - 根目录的 AVAS.dll 链接时间是 **2026-07-22**，比所有带日期的文件夹都新，是最新版。
  - 根目录的 libAVAS.so 含同样的新字符串，视为同一版本的 Linux 构建。
  - M9-notes 第 6 节把 2026-05-27 当作最新，有误。
- 本项目的逐位基准仍是 **2026-04-02 版 AVAS.dll**。
- 方法：
  1. 用 07-22 版 DLL 在 XPS 上跑全部 197 个对齐算例，与基准比较；
  2. 用 04-17、04-22、04-28、05-26、05-27、07-22 六个版本跑 13 个代表算例，确定每个变化出现的版本；
  3. 用 Ghidra 反编译根目录 libAVAS.so，按函数名与已逆向的 .so 逐个对比，分区阅读所有有实质变化的函数。
     伪代码和对比笔记不进仓库，只记结论。
- 注意：已逆向的 .so 与 04-02 版 DLL 本来就有几处不同（50-distribution-rng 第 6 节）。07-22 版有些“新行为”只是 DLL 向 .so 看齐。

## 2. 结果概览

- 197 个算例中 49 个与基准逐字节相同，148 个不同（含 5 个原本就标为未定义行为的）。
- **没有改变的部分**：
  - 粒子推进：Boris、全部硬边矩阵、zTotcode；
  - 场图插值与 Ke／Kb、射频相位；
  - V3 = 0 的同步相位求解；
  - 误差抽样与误差场的算术；
  - 空间电荷求解器（PICNIC、SPICNIC、FFT）；
  - RFQ::GetField（仍不可运行，见 M9-notes）。
  - 用生成分布、经过腔体的算例，同步粒子结果与基准相同。
- **出现时间**：
  - 04-17 起：单粒子输出格式改变，新增 ConvertPlane.txt／ResetPosition.txt；
  - 04-22～05-27：superpose 与报错路径改变，其中 05-26 版的 SP2 又变回报错；
  - **其余物理与约定的变化全部只在 07-22 版**。

## 3. 变化清单

“默认模式”指新内核的默认（修正）模式。“现状”说明新内核目前怎样做。

### 3.1 束流与粒子文件

| # | 变化 | 07-22 版 | 现状 | 判断 |
|---|---|---|---|---|
| P1 | 粒子能量 W 的含义 | W = 总动能，含横向动量（x′ = px/pz）。生成分布写出的 W 因此升高 1e-7～1e-4 MeV；读粒子文件时 vz = βc/√(1+x′²+y′²) | 默认模式在 M3 已改成同样约定；兼容模式按 04-02 版不含横向 | DLL 向 .so 看齐，**已一致** |
| P2 | 读粒子文件时的参考（同步）能量 | 取 beam.txt `kneticenergy`，打印 “Syn particle energy”；只有 kneticenergy < 0 时才用按权重平均的 γβz | 取文件中粒子的平均 W | 约定改变，**待定 D1** |
| P3 | 单粒子初始偏移 | 关键字改名 `displacepos` → `initpos`、`displacedpos` → `initmom`，去掉 ×0.01（x′ 单位 mrad，δ 单位 1e-3）；**旧名字被当作未知关键字忽略**，粒子留在轴上 | 读旧名字，旧单位 | 新功能兼破坏兼容，**待定 D2** |
| P4 | 单粒子能量 | 用实际质量（原为 938.271875） | 默认模式已修正 | 已一致 |
| P5 | 二次粒子文本输入的 γ | 只用 vz 计算 | 用完整速度 | 回归，不跟 |
| P6 | GenBunch（新导出函数） | 独立的生成程序，自带解析与默认值（mc² 938.271875、N 10000、162.5 MHz、2.1 MeV），沿用旧的不含横向的约定，与正常运行的 inData.dst 不一致 | 无 | 不跟 |
| P7 | DC 束 | 能量按 `kneticenergy W ΔW` 展宽；Calculate_Weight 按 βγλ 周期折叠 z | 默认模式已支持 ΔW | 已一致；折叠见 S2 |

### 3.2 输出

| # | 变化 | 07-22 版 | 现状 | 判断 |
|---|---|---|---|---|
| O1 | 单粒子输出 | 不写 DataSet 行、不写 outData_*.dst；新增 SingleParticlePlane.txt，每个输出面一行 `z W x γβx y γβy t`；SingleParticle.txt 运行时被清空，丢了 3 行表头 | DataSet、outData、SingleParticle.txt 照旧 | **待定 D3** |
| O2 | 命名输出面 | `outputplane z NAME`，写成 `<NAME>_<z>.dst`；不写名字时为 `outData_<z>.dst` | 不支持名字 | 新功能，**待定 D4** |
| O3 | 输出面间距小于束长 | 去掉 “The output plane interval is less than the bunch length” 报错；新增 BunchSnapshotStore，可以同时有多个输出面在记录（input.txt `nplanes` 预分配，默认 3）；steerer 之后的输出面不再丢弃 | 默认模式同原内核报错 | 新功能，**待定 D4** |
| O4 | ConvertPlane.txt、ResetPosition.txt | 诊断文件：每个 superposeout 块一行（7 个数），每行 boundary.txt 一行（3 个数） | 无 | 无人读取，不跟 |
| O5 | collisionData.txt | 每行加一列：粒子穿过的 superposeout 块数 | 无此列 | 随 D5 一起定 |
| O6 | BeamSet.plt 第一个字节 | 0x00／0x01（原为 0x7D） | 0x7D | 只有界面读它，不跟 |

### 3.3 lattice、边界与场

| # | 变化 | 07-22 版 | 现状 | 判断 |
|---|---|---|---|---|
| L1 | 射频 field 行 \|Ke\| < 1e-6 | 当作漂移段，不占腔号、不读场图、不扫相位，superpose 块内同样处理；但在补齐 14 个词之前就读 `word[4]`、`word[7]`，参数不足时越界（S5c 算例因此崩溃） | 照常读场图、扫相位 | 新功能，**待定 D6**；越界不跟 |
| L2 | superpose 块内射频切片的 V3 | 用腔自己的 V3（原 .so 一律写 0） | 兼容模式已按 DLL 修正（SP8、SP9） | 已一致 |
| L3 | boundary.txt | 形状 1–4：3 为矩形管、4 为椭圆管；新增复合形状 0，各子形状都是壁，孔径取交集；`end` 停止读取；按边界行的 z 偏移求几何（原来选段用 z + 偏移、求值用 z，有误）；新增“一步越过整段短管”的检查 | 形状 1、2；默认模式 `end` 停止读取 | 新功能兼修正，**待定 D5**。新检查有两处缺陷：用全局 x、y 而非局部坐标，椭圆用 x 动量代替 y（汇编 0x4ff89 确认），实现时不照抄 |
| L4 | superpose 子场的孔径丢失 | 只在没有 boundary.txt（boundaryMode = 0）时按子场半径判丢失 | 照旧 | 修正，**待定 D5** |
| L5 | 误差场 GetErrField（superpose，类型 4） | 去掉“粒子在块外即无场”的提前返回，块外粒子也取子场并可能按子场半径丢失 | 有提前返回 | 疑似回归，不跟 |
| L6 | Field::SetParameter 的漂移子块 | 按正确步长识别（`words[20+20j]`）并登记位置 | 待核对 | 修正，实施时核对 |
| L7 | `spacechargecomp V`（lattice） | .so 也支持了（原来只有 DLL）：电荷乘 (1 − V)，V = 1 为“未设置”（不补偿），V > 1 忽略，V < 0 放大 | 默认模式截断到 [0, 1]，V = 1 为完全补偿并警告（M2 决定 4） | 不变 |

### 3.4 主循环与空间电荷

| # | 变化 | 07-22 版 | 现状 | 判断 |
|---|---|---|---|---|
| S1 | 平均 γ | `beam.gamma` = 按权重平均的 √(1 + γβz²)，只计纵向动量；影响 DataSet 第 0 列、归一化发射度、rms z 和空间电荷 | 用平均动量 | 定义改变，示例束流下小于 6 位有效数字。UpdateBeamParameters 求和不加权却除以总权重，前后不一致。不跟 |
| S2 | `lpboundary V1 [V2]` | 新的第二个值：V2 = 1 强制 FFT 并使用纵向周期盒；但纵向周期改成 βλ（原 βγλ） | 只有 V1 | 周期边界是新功能，**待定 D7**。空间电荷求解在束流静止系中，周期应为 γβλ；βλ 使网格短 γ 倍（1.5 MeV 质子差 1.6e-3，100 MeV 约 10 %），两条电荷分配路径也不一致，是回归，不跟 |
| S3 | 误差研究中的同步粒子 | t-code 段一律用无误差的场（新增 `\|\| i == N`） | 同步粒子不受误差影响（70-errors G-17） | 实施时核对默认模式在 t-code 段是否已如此 |
| S4 | 损失判据 | 停滞判丢失要求步数 > 2000；全部丢失前先写 FullParticle.txt | 照旧 | 小改动，不跟 |
| S5 | HESCFieldPre 的纵向因子 | 1/√(1 − (c5/γ)²) 改为 √(1 + c5²)，横向质心动量为零时相同 | 照旧 | 可忽略，不跟 |

### 3.5 算例差别的来源

- **读粒子文件的算例**（Z、ER、D_dst 等）：P1 与 P2，经过腔时同步相位随之变化。
- **生成分布的算例**（D_* 系列）：P1。
- **单粒子算例**：
  - P3：粒子留在轴上；
  - O1：输出改变。
  - LB1、LB3（边界碰撞）、EP_D36（t-code 起不来的检查）都是因为偏移被忽略，粒子不再撞壁或离轴，检查本身没变。
- **EP_D18**：O3。
- **S5c**：L1 的越界读取。
- **SP2**：04-22 起运行、05-26 报错、05-27 起又运行，原因未细查。

## 4. 对两个问题的回答

- **新内核要不要跟到 07-22 版？**
  - 物理核心没有变；P1 默认模式已经一致。
  - 值得跟的是几项新功能：命名输出面、多个输出面同时记录、新边界形状、射频场 Ke = 0 当漂移、纵向周期边界。
  - 约定的改变（P2、P3、O1）要由你决定。
  - 07-22 版自身的回归不跟：S5c 崩溃、二次粒子 γ、lpBoundary 的 βλ、椭圆边界判据、误差场块外取场、单粒子表头被清空。
- **随软件附带的原内核要不要换成 07-22 版？** 建议**暂不换**：
  1. 界面束流页写的是 `displacepos`／`displacedpos`，07-22 版会静默忽略，单粒子偏移失效且没有任何提示；
  2. 单粒子不再写 DataSet，界面的包络图、结果页会是空的；
  3. 有新的崩溃（参数不足的 field 行）；
  4. 已有运行记录换内核后无法复现；
  5. 兼容模式与对齐算例都以 04-02 版为基准，换基准要重新逆向 07-22 版的 DLL（静态 CRT，libm 舍入也会变）。

## 5. 待定点（推荐项列在前）

1. **D1 读粒子文件时的参考能量**：
   - **推荐**：跟随 07-22 版，以 beam.txt `kneticenergy` 为参考能量；beam.txt 写负值时用粒子平均。与粒子平均相差超过 1 % 时打印警告，界面运行前的检查同样提示。兼容模式保持平均 W。
   - 或者：保持平均 W，只在两者不同时警告。
2. **D2 单粒子初始偏移的关键字**：
   - **推荐**：新内核同时接受两套。`initpos`（mm）、`initmom`（x′、y′ 为 mrad，δ 为 1e-3）用新单位；旧名字保持旧单位。同时写了两套时以新名字为准并警告。界面暂时继续写旧名字，等附带的原内核换代时再改；schema 加入新关键字。
   - 或者：只跟新名字。旧项目的单粒子偏移会失效，不推荐。
3. **D3 单粒子输出**：
   - **推荐**：默认模式新增 SingleParticlePlane.txt（格式同 07-22 版）；DataSet 行、outData_*.dst、SingleParticle.txt 的表头照旧保留，界面靠它们画图。
   - 或者：完全照 07-22 版去掉 DataSet 行和 outData。
4. **D4 输出面**：**推荐**默认模式支持 `outputplane z NAME` 命名，并允许面间距小于束长（多个输出面同时记录）。`nplanes` 接受但不需要（新内核按需分配）。兼容模式仍报错。
5. **D5 边界**：
   - **推荐**：默认模式支持形状 3、4 与复合形状 0（局部坐标、椭圆用 y 动量），采用 z 偏移的修正和 L4 子场孔径规则。
   - collisionData.txt 加第 11 列（superposeout 块数），先查界面读取是否受影响。
   - “一步越过整段短管”的检查按正确的局部坐标实现。
6. **D6 射频 field 行 Ke ≈ 0 当作漂移**：**推荐**默认模式支持，参数不足照常报错。界面的“关闭腔体”可以直接用它，以后另议。
7. **D7 纵向周期边界 `lpboundary V1 1`**：**推荐**默认模式支持，周期用 γβλ（静止系），不照抄 βλ；连续束（DC）和长束团可用。
8. **D8 附带的原内核与兼容基准**：**推荐**都保持 04-02 版（第 4 节）。另在 docs/engine 记下 07-22 版的差别，供用户自己换用原内核时参考。

工作量估计：
- D1、D2、D3、D6 都是小改动；
- D4（多面同时记录、命名）和 D5（新几何、局部坐标）各需要新增对齐算例和单元测试；
- D7 要改空间电荷网格的纵向边界，并做物理检验。
所有改动只在默认模式中进行，兼容模式与对齐结果不变。
