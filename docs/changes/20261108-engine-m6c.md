• 内部维护：新内核（`AVAS_ENGINE=new`，尚未接入界面，软件默认仍用原内核，新内核默认也仍在 CPU 上运行）可以在 Mac 的显卡上计算空间电荷（Metal，Apple 芯片），用环境变量 `AVAS_ENGINE_DEVICE=metal` 打开，需要在构建时打开 `AVAS_WITH_METAL`，只装 Command Line Tools 即可。这一阶段只把空间电荷的网格计算（电荷分配、PICNIC / SPICNIC 求和、电场插值）放到显卡上，用单精度，粒子推进仍在 CPU 上；同一台机器重复运行结果逐位相同，没有空间电荷时结果与 CPU 完全相同。CPU 与 NVIDIA 显卡的计算结果不受影响。
