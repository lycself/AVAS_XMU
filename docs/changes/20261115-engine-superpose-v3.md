# 新内核：兼容模式下 superpose 块内射频腔的相位设置改为与原内核一致

用用户的真实项目比较两个内核时发现：射频腔放在 superpose 块中间或末尾、且 V3 = 2（给定绝对相位）时，新内核的“原版兼容”模式把它当成 V3 = 0 去扫描相位，而原 AVAS.dll 按给定的绝对相位计算，两者结果完全不同。现已改正，并新增了对应的比对算例，参考由原 AVAS.dll 生成。新内核默认模式本来就按 V3 处理，结果不变。比较工具 `tools/compare_kernels.py` 的逐字节核对改为只在 Windows 上进行。同时记录真实项目在三台机器上的比对结果：物理量全部在统计起伏内；另发现两处待查的性能问题——24 线程时新内核比原内核慢，Mac 显卡在该项目上比 CPU 慢。
