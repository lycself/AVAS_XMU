• 新计算内核（重建中，engine-rebuild 分支）完成第一个里程碑：能读入 input.txt、beam.txt、lattice.txt，处理漂移段与场图元件（射频、静电、静磁），确定同步相位（V3 = 0/1/2），跟踪单个宏粒子或从 .dst 文件读入的粒子，并写出与原内核格式相同的 DataSet.txt、synData.txt、SingleParticle.txt、outData_*.dst 等文件。
• 新内核默认修正原内核的已知缺陷：V3 = 0 腔的同步相位不再有约 +0.07° 的系统偏差，V3 = 2 腔不再影响下游腔的相位扫描，main_agent(2) 不再重新运行一次；“原版兼容”模式（AVAS_ENGINE_COMPAT=dll）在 Windows 上与原 AVAS.dll 逐字符一致。
• 从源码运行时设置环境变量 AVAS_ENGINE=new 即可让 avas run 使用新内核（需先用 CMake 编译 engine/），不设置时仍使用原内核。尚未实现的功能（空间电荷、矩阵元件、superpose、误差研究、随机分布生成等）会给出明确的“not implemented”报错。
