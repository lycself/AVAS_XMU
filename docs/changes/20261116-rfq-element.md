# 新内核支持 RFQ 元件（按 cell 计算，尚未与参考结果核对）

lattice 中的 `rfq` 元件现在可以在新内核中计算（默认模式，在 CPU 上）：语法 `rfq L R 0 1 频率 0 结构文件`，结构文件每个 cell 一行给出长度、极间电压、孔径和 8 项势系数，也可以像原程序一样由 rfqinputAnn.txt 与 rfqinputV.txt 生成 rfqinput.txt。原内核的 RFQ 从未能运行（读取 cell 表的函数从不被调用），所以这个元件没有原内核结果可比：已用数值梯度核对场公式，并用一台合成 RFQ 检查同步粒子的加速与相位、粒子的俘获，正式使用前请与其他程序核对。兼容模式和显卡不支持 rfq，“自动”会改用 CPU；线性预览把它当作漂移段并给出提示。入门的 RFQ 章节、使用说明和 README 已同步。
