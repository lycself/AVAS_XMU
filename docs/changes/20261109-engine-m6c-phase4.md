• 内部维护：新内核（`AVAS_ENGINE=new`，尚未接入界面，软件默认仍用原内核）的单精度显卡计算统一为一套设计：Mac 显卡（Metal）、NVIDIA 显卡的 fp32 档和 CPU 上的单精度参照共用同一份主机逻辑和计算代码，三者结果逐字节相同，且与显卡数量、MPI 进程数无关；CPU 单精度参照现在也能在 Linux 和不含 Metal 的 Mac 构建中使用。四极铁、螺线管、弯铁等硬边元件段（z-code）的粒子变换也移到显卡上，进出这些段不再整体转换粒子数据。NVIDIA 显卡 fp32 档的结果略有变化（与 Mac 显卡相同：一般在万分之一以内，硬边元件段的结果差别稍大，仍远小于物理上需要的精度），有空间电荷时目前比原来的 fp32 档慢；CPU 默认模式与 NVIDIA 显卡 fp64 档的结果不变。
