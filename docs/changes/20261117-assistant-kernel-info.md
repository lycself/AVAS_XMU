# AI 助手能回答各平台怎样用 CPU／GPU 计算；使用说明新增 GPU 与 Linux 两节

• AI 助手新增“查询计算内核”工具：给出本机找到的内核库、NVIDIA GPU 及其架构、Mac GPU、CPU 线程数、“自动”会选哪个设备、本项目的内核设置能否运行，以及 Windows、Linux、macOS 上用 CPU 或 GPU 计算的要求和命令。问到内核、GPU、CUDA、驱动、速度或命令行时，助手会先查询，不再凭印象回答。
• AI 助手的“搜索说明”同时搜索界面里的使用说明（操作指南、案例教程、参数与文件参考，中文或英文），新增“阅读说明”读取整节；原来只能搜索旧的 Word 手册。
• 使用说明新增两节：“在各平台上用 CPU 或 GPU 计算”（平台与安装、只需显卡驱动不需装 CUDA、支持的 NVIDIA 显卡架构、P100／V100 不支持、命令行怎样选设备）和“在 Linux 服务器或集群上运行”（源码安装、CPU 与多卡 GPU、离线集群、服务器上的图形界面）。
