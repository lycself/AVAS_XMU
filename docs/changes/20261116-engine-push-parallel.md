# 新内核：粒子数较少时也能用满多线程；Mac 显卡少提交一次；Mac“自动”设备加粒子数下限

新内核默认模式的粒子推进原来按 4096 个粒子一组分给线程，粒子少时只能用上几个线程（5000 个粒子只用 2 个）。现在改按 256 个粒子一块并行计算，统计量仍按原来的固定顺序求和，结果逐位不变；电荷分配在粒子数较少时也改为并行。HIAF 项目（15088 个粒子）在 Mac 上从 34 秒降到 20 秒。Mac 显卡把每一步的粒子推进和统计合成一次提交，快约 14 %，结果不变。实测网格较小时，Mac 显卡到约 6 万个粒子才比 CPU 快，所以 Mac 上“自动”现在要求粒子数至少 6 万、且不少于空间电荷网格单元数的一半才用显卡。
