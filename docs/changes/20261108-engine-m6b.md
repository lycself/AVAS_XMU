• 内部维护：新内核（`AVAS_ENGINE=new`，尚未接入界面，软件默认仍用原内核，新内核默认也仍在 CPU 上运行）的默认模式新增空间电荷算法 `scmethod PICNIC`，即旧 GPU 内核 libPIC.so 的直接求和算法，CPU 和显卡上都能用，双精度下两者结果逐位相同、与显卡数量无关。原库计算格林函数表时忽略了每个网格单元自身的电荷、只算到约四分之三个网格远，并以单精度保存电场，使横向空间电荷场弱约 3%；新内核已修正这些问题（与原库实测比较的结果和 libPIC.so 的完整说明见 docs/engine/65-libpic.md）。原版兼容模式仍和 AVAS.dll 一样不接受 PICNIC。另外显卡运行 SPICNIC 时，格林函数表和非对称修正改在显卡上计算，1000 万粒子时每步快约 5 ms（双卡约 6 ms）；新内核默认模式下 SPICNIC 的结果因此只在末位变化。
