# 界面与两个计算内核保持一致；新增“默认计算内核”

• 菜单“设置 → 默认计算内核”可以一次决定所有没有单独指定内核的项目用原内核还是新内核。命令行 `avas run`、研究页和 AI 助手的试算都遵守这个选择；在没有原内核的电脑（如 Mac）上选原内核时自动改用新内核并说明。模拟设置页会注明项目是“跟随默认”还是自己指定了内核，并可一键改回跟随默认。
• 模拟设置页去掉了“相位扫描”和 scanData.txt 表格：没有任何内核读取它们。input.txt 里原有的 scanphase 行会提示并在保存时删去；scanData.txt 保留，可在文件页查看。
• 用原内核或兼容模式且随机种子不为 0 时，初始分布的 x 与相位完全相关。模拟设置页的随机种子旁和研究页的扫描、响应标签会提示这一点；新内核默认模式没有这个问题。
• 二次粒子：束流页提示原内核和兼容模式只读取 beam.txt 写明的粒子文件；保存时检查 SeParticle.txt 每行至少 11 列并去掉空行；运行结束说明结果在 outData_*.txt 和 SeSynParticle.txt（不再只报“DataSet.txt 为空”），结果页注明没有包络曲线；分段运行不支持二次粒子时会直接说明。
• 运行页“与前一次运行对比”和结果页“运行对比”在两次运行所用内核或模式不同时提示“差别可能来自内核”。
• 文档：说明 spacechargecomp 的实际作用（空间电荷乘以 1 − V，以及两个内核的差别）；Linux 上旧的 `device = gpu`（libPIC.so）运行时提示已弃用，请改用新内核的 NVIDIA 显卡；删去了会让原内核重跑整个模拟的旧接口 `MultiParticle.stop()`。
