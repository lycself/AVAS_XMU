• 内部维护：新内核（`AVAS_ENGINE=new`，尚未接入界面，软件默认仍用原内核）的单精度显卡计算继续改进：FFT 空间电荷求解、`lpboundary` 与 `longlimits` 也在显卡上完成，Mac 显卡上 FFT 算例每步快 1.2～5 倍，这些算例不再每步在 CPU 与显卡之间整体转换粒子数据；NVIDIA 显卡 fp32 档的网格格林函数表、SPICNIC 修正表和电荷、场的转换移到显卡上，并改用显式显存与批量复制，不再依赖托管内存的页迁移（Windows 显卡驱动对托管内存的限制因此不再影响单卡运行），有空间电荷时的速度恢复到接近原来 fp32 档的水平。Mac 显卡、NVIDIA 显卡 fp32 档和 CPU 单精度参照三者结果仍逐字节相同，与显卡数量、MPI 进程数无关；FFT 算例的 fp32 结果因求解改在显卡上以单精度完成而略有变化（万分之一以内），CPU 默认模式与 NVIDIA 显卡 fp64 档的结果不变。
