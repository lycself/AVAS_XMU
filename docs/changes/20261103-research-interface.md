• 新增 Python 研究接口（avas.research）：在 notebook 或脚本里把项目的变体（lattice 参数、beam.txt / input.txt 关键字、随机种子、粒子数）交给线性模型或内核运行，两种结果用同样的方式读取。
• 内核在子进程中运行，内核出错不会让 notebook 崩溃；每次运行连同输入、版本和指标记录在 <项目>/Research/<研究名>/，相同输入直接复用，中断的批量运行可以续跑，也可以多个内核并行。
• 支持多维参数扫描、拉丁超立方采样、线性模型与内核的逐点对比、多种子统计、用内核计算响应矩阵，以及导出 npz / CSV 供代理模型训练；examples/research/ 下有三个示例脚本。
• 项目的输入文件和 OutputFile 不会被研究接口改动；界面暂不显示研究运行。
