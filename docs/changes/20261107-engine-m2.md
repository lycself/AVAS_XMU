• 新计算内核（重建中，engine-rebuild 分支）完成第二个里程碑：支持硬边矩阵元件 quad、solenoid、bend、edge（按 z 推进，与时间步推进自动切换）、校正铁 steerer、superpose 场叠加与 superposeout 出口偏移／转角，以及 multipole 多极场；“原版兼容”模式在 Windows 上与原 AVAS.dll 逐字符一致。
• 默认模式修正原内核在这些元件上的缺陷：含射频腔的 superpose 组能正常加速（原内核 φs 为 NaN、不加速）；漏写 superposeend 时不再吞掉后面一个元件；叠加组的长度和位置不再被舍入到 1e-6 m；矩阵元件和校正铁不再改变粒子能量（原内核在磁铁出口能量会有约 1e-4 的相对变化）；写成长度 0 的 bend 走完整个弧长（原内核只走一半），下游腔的相位也计入这段弧长的渡越时间；multipole 的场强与 G 成正比（原内核把 G 乘了两次，场强与 G² 成正比）。
• RFQ 元件原内核运行即崩溃，新内核暂不支持（明确报错）；误差研究、空间电荷等仍未实现。
