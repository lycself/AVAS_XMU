# AVAS 2.1.0：新内核正式成为默认内核

• 版本号升到 2.1.0。这一版的计算内核是重建的新内核：所有平台默认使用，可在 CPU、NVIDIA GPU（CUDA，只需显卡驱动，不需要安装 CUDA）和 Mac GPU（Metal）上计算；原内核在 Windows、Linux 上仍可选择（模拟设置 → 计算内核，或 设置 → 默认计算内核），将在以后的版本中移出发布包。
• 新内核修正了原内核的若干缺陷，所以结果会与以前略有不同：固定随机种子时初始分布中 x 与相位完全相关、多线程时矩阵元件中空间电荷偏强且每次不同、各种崩溃与挂起已修正；SPICNIC 与 PICNIC 空间电荷与解析解吻合得更好（长束团上发射度与尺寸可能相差 1–2 %）；同步相位精确求解。帮助 → 使用说明 新增“新内核与原内核的差别”一节，逐项说明差别的来源、哪些尚未验证，以及怎样在自己的项目上对比、怎样改回原内核。
