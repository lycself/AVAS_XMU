# 3D 视图弯转方向改正；打包版运行进度不再成批到达

- 用新内核的兼容模式（与原 AVAS.dll 一致）核实了二极铁的弯转方向：偏转角 α > 0 时束流向 −x（竖直弯转向 −y）偏转，与线性包络预览和元件场示意图相同。3D 视图此前把它画成向 +x 偏转，现已改正；edge 极面也按相邻二极铁的方向和入口／出口画出倾斜方向（β > 0 时外侧路程变短）。入门“二极铁”一章同步写明这个方向。
- Windows 打包版在模拟子进程里没能关闭内核标准输出的缓冲（程序误载入了包内的第二份 C 运行库），运行页的进度可能每隔数秒成批出现。现在改为使用进程中已经载入、内核实际使用的那份运行库。源码运行不受影响。
