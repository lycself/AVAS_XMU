# 新内核：空间电荷计算改为多线程，显卡 FFT 加快，结果逐位不变

新内核的空间电荷计算（FFT 求解、电荷分配、插值）原来几乎都在一个线程上，线程多的机器上反而比原内核慢。现在这些步骤按互不相关的线和网格平面分给多个线程，运算顺序不变，结果与修改前逐位相同。用户的真实项目（5000 个粒子、64³ 网格）：24 线程服务器上从 382 秒降到 110 秒（原内核 260 秒），Mac 上从 170 秒降到 73 秒。显卡上的 FFT 去掉了每一项的整数取模，Mac 显卡新增按线读取的变换，Mac 显卡从约 254 秒降到 120–140 秒，NVIDIA 显卡略快且结果不变。Mac 上粒子较少时显卡仍比 CPU 慢，自动选择设备的规则待定。
