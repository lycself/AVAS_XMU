• 加速器入门引导教程：第 4、5 步（多周期加速段、加入流强）改用更温和的默认值 Kb 0.30、Ke 0.8，每个周期的横向、纵向相移都低于 90°。原先沿用第 3 步的 0.35／1.36 时第一个周期纵向相移约 128°，内核在 8 个周期上会丢失纵向粒子。换步时只带走读者改过的参数。
