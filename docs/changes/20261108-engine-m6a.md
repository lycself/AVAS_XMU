• 内部维护：新内核（`AVAS_ENGINE=new`，尚未接入界面，软件默认仍用原内核，新内核默认也仍在 CPU 上运行）可以在 NVIDIA 显卡上计算（Windows、Linux，Pascal 1080Ti 及以后的显卡，含 CentOS 7 集群）。用环境变量 `AVAS_ENGINE_DEVICE=cuda` 打开，`AVAS_ENGINE_PRECISION` 选双精度或单精度（默认按显卡自动选择：A100 等用双精度，其他显卡用以同步粒子为参照的单精度），`AVAS_ENGINE_GPUS` 选一块或多块显卡。双精度下没有空间电荷时结果与 CPU 逐位相同；有空间电荷时每次运行、用一块或多块显卡结果都逐位相同。为此新内核默认模式（CPU）的统计量求和次序、空间电荷电荷分配和少数逐粒子函数改成了与显卡共用的固定算法，结果只在末位变化；原版兼容模式不变，只能在 CPU 上使用。
