# 内部维护：内核比对工具改进与第一批比对结果

- `tools/compare_kernels.py` 修正在中文 Windows 控制台上打印报告时的编码错误；计时加入内核自报的运行时间、线程数和中位数表；发射度改为比较相对入口的增长（初始分布的抽样差单独列出），可用 `--repeats`、`--seeds` 增加运行次数；新增新内核 GPU 与 CPU 同一种子的比较；束线起点之前的差别标为“初始分布”。
- 记录示例项目在 Windows 11 + GTX 1650 上的比对结果：新内核兼容模式与原内核逐字节相同；默认模式的物理量都在统计起伏内；新内核 CPU 比原内核快 1.0–1.5 倍，GPU 快 5–9 倍。
- AGENTS.md 第 6 节注明各条内核约定适用于原内核还是新内核：用新内核重跑核实工具，两种模式都复现了原有结论。
