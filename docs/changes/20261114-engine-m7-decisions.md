# 新内核：进度更及时、自动选设备的原因更具体，Windows 安装包更小

- 新内核在默认模式下每秒或每完成 5 % 报告一次进度（原来每 3 秒），GPU 上几秒就跑完的算例，运行页也能看到进度。兼容 AVAS.dll 模式不变。
- 新内核选“自动”却在 CPU 上运行时，由内核直接给出原因（例如没有 NVIDIA 驱动、显存不足、这一版没有该显卡的机器码），运行页、结果页和模拟设置页显示对应的中文说明。
- Windows 安装包不再带原内核只在 Linux 上用的文件（libAVAS.so、libPIC.so、fftw 的 .so）。
- CI 记录三个平台单精度结果是否逐字节相同，只作记录，不影响构建。
