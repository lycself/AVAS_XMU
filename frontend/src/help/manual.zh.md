# AVAS 使用说明

本手册可在操作软件时保持打开。拖动标题栏移动窗口，拖动边缘调整大小；最大化后可还原，按 Esc 关闭。每次重新打开恢复默认位置和大小。使用上方搜索按正文和标题筛选章节，点击目录跳转。界面语言切换时手册同步切换。

## 快速开始

1. 在项目页打开已有项目，或从文件菜单新建项目。初次使用建议复制 examples/hwr010 示例再操作。
2. 在束流页检查粒子数、能量和分布，在结构页检查元件与场图，在模拟设置页检查模拟选项。
3. 确认结构页标记为运行使用的文件正确，保存修改，然后开始运行。
4. 在运行页查看进度、日志和实时包络；结束后到结果页查看曲线和相空间。
5. 需要保留本次结果时，在运行记录中选择保留运行，再进行下一次计算。

## 项目与输入文件

项目通过 ini.ini 组织输入和输出。InputFile 保存束流、模拟设置、结构和场图等输入；OutputFile 保存最近一次完整运行。结构文件由 ini.ini 的 lattice/source 指定，文件名不一定是 lattice_mulp.txt。

文件菜单和标题栏的项目切换入口用于打开其他项目。切换或关闭时有未保存改动会询问处理方式。文件页是 InputFile 的文件浏览器：查看原始文本、场图曲线与切片、粒子文件，并进行导入、复制、重命名或移到回收站等操作。日常修改在各自的页面完成：初始粒子分布与二次粒子在束流页，boundary.txt 在模拟设置页。旧项目中的 scanData.txt 不被任何内核读取，只能在文件页查看原始文本。

运行期间输入只读。可以查看文件和结果，等待任务结束后再编辑。

## 束流设置

束流页用于设置入射束流。按界面分组调整能量、电流、粒子数和分布等参数，保存后写入 beam.txt；未由页面管理的关键字和注释会保留。撤销和重做可使用 Ctrl+Z、Ctrl+Y。

参数参考中的 beam 条目列出各关键字说明、单位和可选值。勾选“从 .dst 文件读取粒子”并选好文件后，页面下方显示该文件的粒子分布（x-x′、y-y′、φ-W，红线为按粒子计算的 rms 椭圆），可用“从文件读取参数”把质量、流强、能量和 Twiss 填入表单。

“二次粒子”区勾选后在 input.txt 写入 secondarybeam 1，并在表格中编辑 SeParticle.txt（每行一个粒子）；同步粒子仍由束流参数决定。保存时检查每行至少有 11 列（x y z vx vy vz charge mass weight time kind，前十列为数字），并去掉空行。新内核的默认模式在 beam.txt 没有 `readparticledistribution` 时读取 SeParticle.txt；原内核和新内核的兼容模式（复现 AVAS.dll）只读取 beam.txt 中 `readparticledistribution` 指定的文件，这时页面会给出提示（AVAS 不改写 beam.txt）。二次粒子运行不输出包络（DataSet.txt 为空），结果在 `outData_*.txt` 和 `SeSynParticle.txt` 中，运行日志会说明这一点；分段运行不接受 secondarybeam 1。

“历史”按钮列出 beam.txt 的保存版本，恢复的版本作为一步可撤销的修改填入表单，保存后才写入文件。

## 结构编辑

文件下拉框用于打开结构文件；打开文件不等于将其设为运行结构。使用单独的“设为运行结构”按钮选择运行输入。

“文本 + 结构”模式将文本与结构面板并排显示。选择元件可查看参数、位置和检查提示。文本、结构及可视化编辑使用同一份内容，修改可撤销。

可视化模式默认浏览，只读查看。进入编辑状态后才能修改参数和元件；点击完成时，若有未保存修改，可保存、放弃本次编辑或继续编辑。TraceWin .dat 文件目前只读。

2D 和 3D 左上角提供放大、缩小、显示全部。2D 双击视图显示全部；3D 双击空白显示全部，双击元件聚焦。手动缩放 3D 会停止漫游和束团跟随。

“文本 + 结构”模式的“周期分析”标签分析 lattice 中用 `lattice n 1` … `lattice_end` 标出的周期：零流强与有流强的相移、相移压低比、匹配 α／β、当前束流的失配因子、Floquet 稳定性和包络稳定性，以及沿线逐周期的相移曲线。分析使用编辑器中的当前文本和项目束流（线性模型，加速周期按 βγ 归一化），“把匹配的 α、β 填入束流页”只修改束流页的编辑框，保存后才写入 beam.txt。

## 模拟设置

模拟设置页管理 input.txt 中的模拟选项和 ini.ini 中的计算内核（见“计算内核”一节），支持撤销和重做。每个字段的含义以参数参考中的 input 条目为准。勾选“启用边界 (boundary.txt)”后在其下方编辑损失边界表；表格随页面一起保存，空表格不会新建文件。“历史”按钮列出 input.txt 的保存版本，恢复方式与束流页相同。

原内核和新内核都不读取 input.txt 的 `scanphase` 和 scanData.txt，射频相位只由 field 行的相位参数决定（V3 = 0 为同步相位，由内核自己扫描入口相位求出；V3 = 2 为 t = 0 时刻的绝对相位），因此页面不再提供相位扫描选项。input.txt 中有 `scanphase` 行时，页面用一行提示说明内核不读取它，保存该页时删除这一行。scanData.txt 不会被删除，仍可在文件页查看原始文本。

使用原内核或新内核的兼容模式（复现 AVAS.dll）且 `randomseed` 不为 0 时，内核生成的初始分布中 x 与相位完全相关（相关系数 −1），这是原内核的缺陷；页面会在随机种子旁给出警告。新内核的默认模式没有这个缺陷。

CPU 多线程开启时写 multithreading 1；关闭时删除该行。不要手工填写 multithreading 0，它会导致内核在起点丢失全部粒子。

运行前先检查结构问题和场图是否齐全。线性包络预览用于快速评估，最终结果以内核计算为准。

## 计算内核 {#guide-kernels}

AVAS 有两个计算内核。**新内核**是重建的内核，也是所有平台的默认内核，可在 CPU、NVIDIA GPU（CUDA）和 Mac GPU（Metal）上计算，并支持空间电荷算法 PICNIC 和按 cell 计算的 `rfq` 元件（只在 CPU 上、默认模式下计算；原内核的 rfq 从未能运行，所以它没有参考结果，正式使用前请与其他程序核对）；它修正了原内核的若干缺陷（例如固定随机种子时初始束团 x 与相位完全相关、多线程时矩阵元件中的空间电荷偏强且每次不同、SPICNIC 截断长束团的场），所以结果会与原内核略有不同。**原内核**（AVAS.dll／libAVAS.so）只有 Windows 与 Linux x86-64 版本，将在以后的版本中移除，目前仍可选择；新内核的“复现 AVAS.dll”模式可以逐位得到原内核的结果。Windows／Linux 更新到默认使用新内核的版本后，第一次启动时弹出说明，可以选择“默认使用原内核”。项目可以单独选择内核，保存在 ini.ini 的 `[engine]` 段，原内核仍能读取同一个项目（input.txt 不变）；没有单独选择的项目使用默认计算内核。

**设置 → 默认计算内核** 有“内置默认”“原内核”“新内核”三项，保存在界面偏好 gui.json 中。内置默认在所有平台上都是新内核；在没有原内核的平台（macOS、ARM）上选“原内核”时，按内置默认处理并给出说明。一次运行使用哪个内核按以下顺序决定：命令行参数 > 环境变量 `AVAS_ENGINE*` > 项目 ini.ini `[engine]` 中的 `kernel` > 默认计算内核 > 内置默认。默认计算内核同样作用于命令行 `avas run`（读取同一个 gui.json，或环境变量 `AVAS_GUI_SETTINGS` 指定的文件）、研究运行和 AI 助手的沙盒试算。

在 **模拟设置 → 计算内核** 中选择：

- **内核**：新内核或原内核（将淘汰）。项目的 `[engine]` 中没有 `kernel` 时，页面注明跟随默认（并显示当前是哪个内核）；“跟随默认”按钮删除项目的单独选择。macOS 等没有原内核的平台上，页面会注明“本平台只有新内核”。新内核的库不存在时，该选项不可选并说明如何获得。
- **设备**：自动、CPU，以及本机检测到的 NVIDIA GPU 或 Mac GPU；右上角的刷新按钮重新检测。选“自动”时，下方显示本项目的运行会用什么：有 NVIDIA 卡时用 CUDA（粒子不足 1000 个、包括单粒子跟踪时用 CPU，GPU 在粒子很少时反而更慢）；Mac 上有空间电荷、粒子数至少 6 万、且不少于空间电荷网格单元数（numofgrid 三个数之积）的一半时用 Metal，粒子更少或没有空间电荷时用 CPU（粒子少时每步的固定开销与网格计算占主导，Mac GPU 反而比 CPU 慢）；都没有时用 CPU。
- **精度**：自动、fp64、fp32。Metal 只能用 fp32，CPU 只用 fp64，不合法的组合不可选。自动精度在 CPU 和 fp64 全速的 GPU 上用 fp64，其他 GPU 和 Metal 上用 fp32。
- **GPU**：本机有多张 NVIDIA 卡时出现，不勾选具体的卡即使用全部。
- **高级**：CPU 线程数（0 = 自动，只影响速度，新内核结果与线程数无关）；兼容模式“复现 AVAS.dll”逐位复现原内核（包括它的缺陷，只能在 CPU 上），用于比对，默认“修正原内核的缺陷”。

选原内核时，设备、精度和高级选项不可用，只对新内核有效。设置随页面保存，只在改动时写入 `[engine]`，受运行锁约束。命令行 `avas run --engine … --device …` 与环境变量 `AVAS_ENGINE*` 优先于 ini.ini；设置了这些环境变量时页面会提示。

Linux 上原内核的旧 GPU 途径（ini.ini `[input] device = gpu`，调用 libPIC.so）已弃用，运行日志会给出警告，将在以后的版本中删除；请改用新内核的 NVIDIA GPU（`avas run --engine new --device cuda`，或在 模拟设置 → 计算内核 中选择）。

开始运行（运行页、分段运行、误差研究、研究页的内核扫描和响应矩阵、AI 助手的试算）之前，软件检查所选设备是否存在、组合是否合法，不可用时直接给出提示，不会悄悄改用 CPU。原内核下选择 PICNIC 时，算法选项旁会提示“只有新内核支持”，运行前也会拦下。

使用原内核或兼容模式（复现 AVAS.dll）时：启用边界且 boundary.txt 含 superpose 块的项目在运行前被拦下（AVAS.dll 读到这种块会异常退出，请改用新内核默认模式）；lattice 中位于叠加块开头（superpose 偏移为 0）的射频腔会在运行前提醒，原内核里这个腔没有场、束流不加速。Linux 上用原内核运行时，运行副本中的 boundary.txt 自动改为 LF 换行（libAVAS.so 遇到 Windows 换行会崩溃），项目文件不变。

每次运行实际使用的内核写在 avas_run.json 的 `engine` 中。运行页（运行信息、实时面板、运行记录）、状态栏、结果页的来源和运行对比都显示标签，例如“新内核 · Metal fp32”或“原内核”；自动回落到 CPU 时显示“实际：CPU（原因）”。运行中先显示按设置预计的设备，结束后换成实际值；旧记录没有这项信息时不显示标签。用运行对比可以直接比较同一项目的原内核和新内核结果；两次运行的内核或兼容模式不同时，运行页的“与前一次运行对比”和结果页的运行对比标签会注明差别可能来自内核。不同内核、不同结果档（原内核、新内核 CPU fp64、CUDA fp64、fp32、复现 AVAS.dll）的随机数与算术不同，结果会有统计范围内的差别；只有同一结果档、同一随机种子的运行可以逐项比较。

**帮助 → 关于 AVAS** 列出两个内核的版本、新内核的构建选项和本机设备，“复制版本信息”包含这些内容。

## 运行与保留结果

同一时间只允许一个运行任务。开始前软件检查并保存有修改的页面；上次结果完成但尚未保留时，会询问保留并运行、直接运行或取消。

暂停挂起运行进程，恢复后继续；停止结束任务。运行期间输入保持只读，包括暂停状态。完整运行使用输出目录中的 inputs 快照，不改写原始输入。

完整运行覆盖 OutputFile。保留运行会把结果和输入快照复制到 Runs 下的独立目录。运行记录中可回放完成的记录，也可将不需要的记录移到回收站。

分段运行的结果位于 Segments 下，不覆盖完整运行结果。分段设置涉及射频相位换算，请使用软件提供的分段功能。

## 实时包络与回放

运行页显示本次运行实时包络，结束后可回放；运行记录的回放按钮用于查看历史记录。新运行开始后切回本次运行。

结构页回放上次运行，曲线与正在编辑的结构对应；结构修改后应注意结果可能已过期。上次运行曲线默认隐藏，开始回放时自动打开。图例左侧的 × 可隐藏曲线。

束团和粒子云是按 rms 包络绘制的示意，不是真实粒子分布。与前一次运行对比默认关闭，可按需开启。动画受“视图 → 动效”控制。

## 参数扫描

研究页（原扫描页）分四个标签，全部在输入副本上计算，不改动项目输入和完整运行结果。

参数扫描：选择一个或两个扫描轴（lattice 元件参数，或 beam.txt、input.txt 关键字）和取值，选用线性模型（几秒得到全局图）或内核（每个点一次多粒子模拟，逐个运行，可在运行页暂停、停止）。一维结果画曲线，二维画热图；点击某个点查看它沿线的包络，内核运行还可在结果页打开。内核运行以固定随机种子保存在 `Research/gui/`，输入相同的点直接取缓存，脚本中的 `avas.research` 也能读取；扫描描述在 `Research/gui/scans/`。旧版 `Scans/` 中的扫描仍可在列表中查看。研究运行固定使用随机种子 12345，使用原内核或兼容模式（复现 AVAS.dll）时，扫描和响应标签会提示这样生成的初始分布中 x 与相位完全相关（见“模拟设置”）。

稳定区图谱：选一个周期和两个轴（元件参数或束流流强），逐点计算带空间电荷的匹配束、相移和包络稳定性，画成热图；空白格表示没有匹配束。

响应与可控性：监测器（位置或 rms 尺寸、分辨率）和旋钮（校正铁、元件参数或错位）默认取自 lattice 的 `diag_position`／`diag_size` 和校正铁，可编辑并保存到 `Research/diagnostics.json`。可计算线性模型或内核（每个旋钮运行一次）的响应矩阵、奇异值、秩、无法校正的读数模式和噪声对旋钮的影响，并给出单个周期内各模态是否稳定、可控、可观。

反馈：按脉冲仿真轨道反馈，可设置增益、延迟、漂移元件与幅度和监测器噪声，对比有无反馈的读数，并给出理论稳定判据。

## 结果分析

结果页选择最近输出、已保留运行、分段结果、研究页的内核运行或其他输出目录作为数据源，再选择所需曲线或相空间视图。支持交互缩放及图像导出。包络、质心、能量和发射度曲线可勾选“线性模型”，以虚线叠加按这次运行自己的输入计算的线性模型，用于判断多粒子效应的影响。

运行对比可叠加不同运行的同一物理量。比较前确认单位、输入和坐标范围一致；多线程模拟可能存在小幅随机差异，不应要求输出逐字节相同。两次运行的内核或兼容模式不同时，对比标签会注明差别可能来自内核。

回放入口在运行页，结果页用于数据分析。单粒子计算中 rms 列为 NaN 可能是内核的正常输出，需结合存活粒子数和日志判断。二次粒子运行没有包络（DataSet.txt 为空），结果页会注明没有包络曲线，数据在 `outData_*.txt` 和 `SeSynParticle.txt` 中。

## AI 助手

使用 Ctrl+Shift+A 打开助手，在设置中配置 OpenAI 兼容接口或本地模型。密钥存储在 Windows 凭据管理器。需要数据留在本机时使用本地模型服务。

助手可以读取项目、解释结果并在副本中试算。项目修改以提案卡片显示，批准后应用；若在当前对话开启自动应用，则按该设置处理。写入前备份，可撤销。

助手的试算输出位于 .avas_ai/runs，不改写 InputFile 和 OutputFile。项目运行锁定期间，修改提案会被拒绝，待运行结束后再提出。

## 常见问题

### 场图缺失或结构检查失败

检查引用文件是否存在、文件名和路径是否正确，并按结构页的问题提示修正。不要仅通过隐藏提示继续运行。

### 起点全部粒子丢失

先检查是否误写 multithreading 0，再结合束流参数、孔径、场图和日志检查。关闭多线程应删除关键字行。

### 修改代码后桌面程序没有变化

打包的可执行文件不会随源码自动更新，需要重新打包。普通用户使用发布包即可，无需安装 Node.js 或 Word。
