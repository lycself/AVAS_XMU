# 纵向动力学

前面几章讲的都是**横向**：怎样让束流不变粗。这一章转到**纵向**，也就是粒子前进的方向，回答两个问题：怎样让粒子越跑越快？一个束团里的粒子有先有后，怎样让它们在加速的同时不散开？

加速粒子要靠电场。可是加速器里的电场并不是稳定不变的，而是每秒来回振荡 1.625 亿次（162.5 MHz）：一会儿向前，一会儿向后。这样一个电场，怎么能一直把粒子往前推？束团里的粒子到达的时刻有早有晚，看到的电场各不相同，按理说能量会越来越分散，束团会越拉越长，可是真实的直线加速器里，束团能稳稳地走过几十上百个腔。是什么把早到和晚到的粒子拉回到一起？为什么 AVAS 示例把"同步相位"设为 −33°，而不是推得最狠的波峰？这一章就来回答。

先在心里放两个生活中的画面：

- **荡秋千**。推的时机对了，秋千越荡越高；推的时机错了，反而把它推慢。射频加速就是"看准时机推一把"。
- **冲浪**。冲浪的人不站在浪尖上，而是待在浪的前坡。稍微落后一点，坡更陡，被推得更猛，又追了上来；稍微超前一点，推力变弱，又退了回去。束团里的粒子正是靠同样的道理待在一起的。

先看一看。下面的实验让示例束流的质子（动能 1.527 MeV，速度约为光速的 5.7 %）飞过示例项目的一个射频腔（半波长谐振腔 HWR，长 0.21 m）：

```avas-lab
rf-cavity phase=-33 Ke=1.36 W=1.527
```

看"动能沿 z 的变化"一图：质子穿过腔，能量从 1.527 MeV 升到约 1.867 MeV，增加了 0.340 MeV。再看"能量增益随入口射频相位的变化"一图：它像一条波浪。质子在不同的时刻进入腔，得到的能量完全不同，最多约 0.48 MeV，有些时刻还会被**减速**（增益为负）。图上标出的点是"当前设置"；拖动"同步相位"滑块，看这个点怎样在波浪上移动。这条波浪，就是这一章的主角。

## 射频加速：看准时机推一把 {#longitudinal-rf}

### 为什么不用一个稳定的高电压

中学物理说：电荷 $q$ 穿过电压 $U$，电场对它做功 $qU$，动能就增加 $qU$。所以最直接的办法是造一个很高的电压。可是这条路走不远：几百万伏的直流高压很难做（空气和绝缘材料都会被击穿放电），而且不能把很多级"串"起来——静电场做的功只取决于起点和终点的电势，粒子要进入下一级，就得先回到"地"的电势，前面得到的能量又还回去了。

### 交变的电场 + 躲起来

解决办法是让电场**来回振荡**。在加速器里，粒子沿着一串金属腔飞行。每个腔中间有一道窄缝，叫**间隙**，电场只在间隙里作用于粒子。电场向前时，让粒子正好穿过间隙，被推一把；电场转向后方时，粒子正躲在金属管子里，管子屏蔽了电场，粒子不受影响。下一次电场向前时，粒子又到了下一个间隙。

这种振荡的频率在几十兆赫到几吉赫之间，和无线电波相同，所以叫**射频**（radio frequency，RF）。让射频电场"住"在里面的金属腔叫**射频腔**：它像一个瓶子，往瓶口吹气时瓶里的空气会以固定的音调振动，射频腔里的电磁场也以固定的频率振荡。

这和荡秋千一模一样：推的节奏必须和秋千摆动的节奏对上。

### 相位：用一个角度说"什么时候"

振荡是周而复始的，描述"在振荡的哪一刻"最方便的办法是用一个角度：一个完整的周期算 360°，这个角度叫**相位** $\varphi$。本章和 AVAS 都约定：

- $\varphi = 0$ 是向前的电场最强的时刻，叫**波峰**；
- **相位越大，表示粒子越晚到达**。

示例频率 $f = 162.5$ MHz，一个周期是 $1/f = 6.15$ ns（纳秒，十亿分之一秒），所以晚到 1 ns 相当于相位大 58.5°。

在一个射频周期里，光走过 $\lambda = c/f = 1.845$ m，叫**射频波长**；示例质子的速度只有光速的 $\beta = 0.05698$ 倍，一个周期里只走 $\beta\lambda = 0.1051$ m，也就是 105 mm。这个长度决定了低能段的腔有多大、腔与腔隔多远：粒子越慢，$\beta\lambda$ 越短，一切都得做得越紧凑。（$\beta$、$\gamma$ 这些量的来历见[相对论运动学](#kinematics)。）

## 一个间隙给多少能量 {#longitudinal-gap}

### 短间隙：能量增益按余弦变化

腔里间隙上的电场随时间按余弦振荡。如果间隙很短，粒子一眨眼就穿过去了，它看到的就是到达那一刻的电压。设电压的最大值是 $V_0$，粒子到达时的相位是 $\varphi$，那一刻的电压就是 $V_0\cos\varphi$，粒子得到的能量是

$$
\Delta W = q\,V_0\cos\varphi .
$$

$\varphi = 0$（波峰）时增益最大；$\varphi = \pm 90°$ 时电场正好为零，不加速也不减速；$\lvert\varphi\rvert > 90°$ 时电场向后，粒子被减速。开头实验里那条波浪，就是这个余弦。

### 渡越时间因子：间隙有长度

真实的间隙有一定长度，粒子穿过它要花时间，这段时间里电场还在变。粒子在间隙的前一段、中间、后一段看到的相位各不相同，得到的能量就是各段的 $\cos$ 的平均，总比"一直待在波峰"少。把这个折扣记作 $T$（$T \le 1$），叫**渡越时间因子**：

$$
\Delta W = q\,V_0\,T\cos\varphi .
$$

这叫 **Panofsky 公式**。这时的 $\varphi$ 是粒子到达间隙"电中心"时的相位（对称的间隙就是几何中心）。

$T$ 有多大，取决于穿过间隙花的时间占一个周期的多少。粒子走一个 $\beta\lambda$ 正好是一个周期，所以关键是间隙长度 $g$ 和 $\beta\lambda$ 之比。对一个电场均匀的间隙，

$$
T = \frac{\sin x}{x}, \qquad x = \frac{\pi g}{\beta\lambda}\ (\text{弧度}).
$$

用示例束流验算（$\beta\lambda = 105$ mm）：

- 间隙长 $\beta\lambda/4 = 26$ mm：$x = \pi/4$，$T = 0.707/0.785 = 0.90$。
- 间隙长 $\beta\lambda/2 = 53$ mm：粒子穿过间隙用了半个周期，若中心对准波峰，它看到的相位从 −90° 变到 +90°，$\cos$ 的平均值只有 $2/\pi = 0.64$。

间隙越短于 $\beta\lambda$，$T$ 越接近 1。实际腔的电场在间隙外还有延伸，$T$ 要按场的分布计算；公式的来历见[深入：一个间隙的能量增益](#longitudinal-deep-gap)。

## 两个间隙的腔：节奏要对上 {#longitudinal-multigap}

### 两个间隙，电场方向相反

示例里的半波长谐振腔（HWR）和常见的四分之一波长腔（QWR）都有**两个间隙**，而且两个间隙里的电场方向总是相反：第一个向前时，第二个向后。要两个间隙都加速，粒子从第一个间隙飞到第二个间隙必须恰好用**半个周期**，到达时电场正好反了过来。

像两个人站在一条路上相隔一段距离推小车，两人的节奏正好相反：后面那人向前推时，前面那人正往回拉。只有小车从后面那人跑到前面那人手边正好用半个节拍，前面那人才刚好转为向前推。

两间隙中心相距 $d$，粒子走 $d$ 用半个周期，意味着 $d = \beta\lambda/2$。所以每个腔有一个"设计速度" $\beta_g = 2d/\lambda$：速度等于它时两个间隙同步加速，速度偏离越多，第二个间隙越"不合拍"。间隙更多的腔对速度更挑剔；低速超导直线加速器因此用间隙少的腔，并分成几种不同的设计速度（见[超导加速段](#journey-sc)）。

### 示例腔 hwr010

对 `hwr010` 场图（乘以 `Ke = 1.36`）的轴上电场 $E_z$ 积分得到：

| 量 | 数值 |
|---|---|
| 轴上场峰值 | $+13.03\ \mathrm{MV/m}$ 与 $-12.74\ \mathrm{MV/m}$ |
| 场反号位置 | $z \approx 0.104\ \mathrm{m}$（两个间隙） |
| 两间隙场的重心 | $0.064\ \mathrm{m}$、$0.145\ \mathrm{m}$，间距 $d = 0.081\ \mathrm{m}$ |
| 由间距得到的 $\beta_g = 2d/\lambda$ | 0.088 |
| $V_0 = \int\lvert E_z\rvert\,\dd z$（两个间隙电压之和） | 0.978 MV |
| $T(\beta)$ 的最大值 | 0.82，在 $\beta \approx 0.104$ |
| 入口 $\beta = 0.0570$ 处的 $T$ | 0.40，$V_0 T = 0.39\ \mathrm{MV}$ |

$T$ 最大处的 $\beta \approx 0.10$ 与名字中的"010"（通常表示设计 $\beta = 0.10$）相符；它比由间距估计的 0.088 稍大，因为单个间隙的渡越时间因子也随 $\beta$ 增大。示例质子太慢了：从一个间隙中心飞到另一个要用约 0.77 个周期，而不是理想的半个周期，所以 $T$ 只有 0.40。质子在腔里被加速后 $T$ 逐渐增大。下图是这张场图的切片，可以看到两个间隙的场方向相反：

### 太慢时：两个间隙会互相抵消

如果粒子更慢，从一个间隙飞到另一个正好用**一整个周期**，会怎样？它到第二个间隙时电场又回到了和第一个间隙相同的状态，可是第二个间隙的电场方向本来就相反——第一个间隙推多少，第二个间隙就拉回多少，腔几乎不加速。示例腔按匀速粗算，这发生在约 0.9 MeV（两倍周期约在 0.23 MeV）。在这些能量附近，不论射频相位怎么设，腔都给不出想要的同步相位，AVAS 的内核会拒绝运行，见[深入：低能腔里的两个怪现象](#longitudinal-deep-lowbeta)和[在 AVAS 中](#longitudinal-in-avas)。

## 同步粒子与同步相位 {#longitudinal-synchronous}

束团里有成千上万个粒子，要说清"束团在哪里、处在什么相位"，需要一个参照。**同步粒子**（也叫参考粒子）就是设计上沿中心轴飞行、在每个腔里都处在设计相位的那个假想粒子；其他粒子的纵向位置和能量，都相对它来说。

同步粒子在某个腔里"有效地"看到的相位，叫这个腔的**同步相位** $\varphi_s$。对很短的间隙，它就是穿过间隙中心时的相位；对真实的腔，AVAS 用沿粒子实际路径、按电场强弱加权的平均来定义它（准确的式子见[深入](#longitudinal-deep-gap)）。

同步粒子到达下一个腔时的相位，由腔的射频相位和它在路上飞行的时间共同决定。腔与腔之间的漂移段会让相位前进 $360°\times L/(\beta\lambda)$：示例质子飞过 0.1 m，相位就前进 342.4°。低能时 $\beta\lambda$ 只有十几厘米，几毫米的长度误差或一点能量偏差都会明显改变下游腔的相位，这是低能段相位设置很敏感的根本原因。

用 AVAS 的线性预览算示例腔（lattice 为 `field 0.21 0.02 0 1 162.5e6 φs 1.36 -1.36 hwr010`）：

| $\varphi_s$（V3 = 0） | 入口相位 | 出口能量 / MeV | $\Delta W$ / MeV |
|---|---|---|---|
| −90° | −14.0° | 1.5270 | 0.000 |
| −60° | 18.6° | 1.6943 | 0.167 |
| −33° | 52.7° | 1.8665 | 0.340 |
| −20° | 69.7° | 1.9374 | 0.410 |
| 0° | 95.4° | 2.0023 | 0.475 |
| +20° | 119.7° | 1.9954 | 0.468 |

$\varphi_s = -90°$ 时增益为零，和余弦规律一致。注意"同步相位"和"入口相位"（粒子到达腔入口时的射频相位）是两回事，示例中相差约 86°。还有两个细节和简单的余弦不符：扫描入口相位得到的最大增益（0.482 MeV，出口 2.0087 MeV）出现在 $\varphi_s \approx +8°$ 而不是 0°；$\pm 33°$ 的增益也不对称。原因是质子在这个腔里加速得太多（能量增加约 30 %），见[深入：低能腔里的两个怪现象](#longitudinal-deep-lowbeta)。

AVAS 中 `field` 的参数 V3 决定写进 lattice 的相位是"同步相位""入口相位"还是"绝对相位"，三种写法和例子见[在 AVAS 中](#longitudinal-in-avas)。

## 相稳定：冲浪者待在浪的前坡 {#longitudinal-stability}

### 思想实验：三个粒子

设想三个粒子前后跟着飞进一串腔：同步粒子在相位 $\varphi_s$，一个早到一点（相位小一点），一个晚到一点（相位大一点）。能量增益按 $\cos\varphi$ 变化，波峰在 $\varphi = 0$。

- 若 $\varphi_s$ 在**波峰之前**（$-90° < \varphi_s < 0$，电场正在增强）：晚到的粒子更靠近波峰，得到**更多**能量；早到的离波峰更远，得到更少。低速粒子能量高就跑得快，于是在接下来的路上，晚到的追上来，早到的落回去。偏差被纠正了——这是一种**恢复力**。
- 若 $\varphi_s$ 在**波峰之后**（$0 < \varphi_s < 90°$）：晚到的得到更少能量，更慢，越落越后；早到的越跑越前。偏差被放大——**不稳定**。
- 若 $\varphi_s$ 正好在**波峰**：早到和晚到的都比同步粒子少得一点点能量，差别小到可以忽略（余弦在波峰处是平的），没有恢复力，束团只会越拉越长。

这就是冲浪：待在浪的前坡（波峰之前），落后了被推得更猛，超前了被推得更弱，人总被留在原地。这个原理叫**相稳定**（phase stability），是 1944–1945 年由 Veksler 和 McMillan 各自提出的，没有它就没有今天的直线加速器和同步加速器。

### 把恢复力算出来

恢复力由一条四个环节的链组成。用示例腔（$V_0 T = 0.39$ MV，$\varphi_s = -33°$）一环一环地算一个晚到 1° 的粒子：

1. **晚到 → 多得能量**。余弦曲线在 $\varphi_s$ 附近可以看成一段直线，斜率是 $-\sin\varphi_s$（每弧度）。晚到 $\Delta\varphi$，多得能量 $\Delta W - \Delta W_s \approx -q V_0 T\sin\varphi_s\cdot\Delta\varphi$。1° 是 0.01745 弧度，$\sin(-33°) = -0.545$，于是多得 $0.39\ \mathrm{MeV}\times 0.545\times 0.01745 = 3.7\ \mathrm{keV}$。
2. **多得能量 → 跑得更快**。低速时动能 $W = \tfrac12 m v^2$，能量的相对变化是速度相对变化的两倍：$\Delta v/v = \tfrac12\,\Delta W/W = \tfrac12\times 3.7/1527 = 0.12\ \%$。
3. **跑得快 → 早到**。参考粒子飞过 $L$ 用时 $L/v$；快 0.12 % 的粒子提前 $0.12\ \% \times L/v$ 到达。示例质子飞 1 m 用 58.5 ns，所以每米提前 0.071 ns。
4. **早到 → 相位变小**。1 ns 对应 58.5°，0.071 ns 对应 4.1°。

所以晚到 1° 的粒子，每飞 1 m 会相对追回约 4.1°：飞到约 0.24 m 时就追平了那 1°。这个"追平距离"正是一个腔的**纵向焦距**，下文还会用到。

把第 2、3、4 步合在一起写成一般的式子（对接近光速的粒子也成立）：能量偏差 $w = (W - W_s)/(mc^2)$ 的粒子，每走一米相位改变

$$
\frac{\Delta(\Delta\varphi)}{\Delta s} = -A\,w,\qquad A = \frac{2\pi}{\beta^3\gamma^3\lambda} .
$$

$mc^2$ 是静止能量（质子 938.27 MeV），$\gamma$ 是相对论因子。示例能量下 $A = 1.83\times 10^4\ \mathrm{m^{-1}}$：能量多 1 keV，每米相位提前约 1.1°。分母里的 $\beta^3\gamma^3$ 说明：粒子越快，能量差越难变成相位差。推导见[深入：相振荡的方程](#longitudinal-deep-oscillation)。

### 稳定条件

第 1 步给出：只有 $\sin\varphi_s < 0$ 时，晚到的粒子才多得能量，链条才是恢复力；要加速又需要 $\cos\varphi_s > 0$。两者合起来，稳定加速的区间是

$$
-90° < \varphi_s < 0° .
$$

这正是思想实验的结论：同步相位为负，表示同步粒子在波峰之前到达。整条链里有两个环节：腔让能量随相位变化，像一块"透镜"；漂移让速度差变成位置差（[漂移段](#drift-longitudinal)中的 $R_{56} = L/\gamma^2$）。这和横向"透镜 + 漂移"的结构完全相同。直线段里 $R_{56}$ 总是正的，所以稳定相位总在电场增强的一侧。

> 注意：相位的符号约定因文献而异。AVAS 和 Wangler《RF Linear Accelerators》用余弦约定、相位越大越晚，稳定同步相位为负，示例用 $-33°$。若采用正弦约定或把相位定义为 $-\omega t$，稳定区会变成正相位。从其他程序或文献移植相位时务必核对约定。

示例束流（初始 rms $z$ = 1.316 mm，rms $x$ = 0.954 mm）穿过一个 hwr010 腔，出口的 rms 尺寸（线性预览，不计空间电荷）：

| 情况 | rms $z$ / mm | rms $x$ / mm |
|---|---|---|
| 0.21 m 漂移（无腔） | 1.482 | 1.407 |
| $\varphi_s = -33°$ | 0.702 | 1.811 |
| $\varphi_s = +33°$ | 1.738 | 1.196 |

负同步相位把束团纵向压短（**聚束**），正同步相位把它拉长（**散束**），与稳定条件一致；横向却正好相反，这就是后面要讲的[射频散焦](#longitudinal-rf-defocusing)。顺便注意：$+33°$ 时能量增益 0.424 MeV，反而比 $-33°$ 的 0.340 MeV 多，原因见[深入](#longitudinal-deep-lowbeta)。

## 同步振荡：粒子在束团里来回摆 {#longitudinal-synchrotron}

### 一根看不见的弹簧

相稳定给出的恢复力和偏差成正比：晚到得越多，被推回得越多。中学物理里，"恢复力与偏离成正比"的运动是**简谐振动**，像弹簧振子和小角度的单摆。所以在一串腔里，每个粒子都绕着同步粒子前后来回摆动：一会儿在前、能量偏低，一会儿在后、能量偏高。这叫**同步振荡**。

把每个腔的推力平均到单位长度上（平均加速梯度 $E_0 T$，单位 MV/m），这根"弹簧"的强弱用**纵向波数** $k_{l0}$ 描述（每米转过的振荡角度，弧度），振荡一次走过的距离是 $\lambda_l = 2\pi/k_{l0}$：

$$
k_{l0}^2 = A\cdot\frac{qE_0T}{mc^2}\cdot\sin(-\varphi_s) = \frac{2\pi\,qE_0T\sin(-\varphi_s)}{mc^2\,\beta^3\gamma^3\lambda} .
$$

它就是上一节那条链的三个因素相乘：$A$（能量差变相位差有多快）、$qE_0T/mc^2$（腔推得多猛）、$\sin(-\varphi_s)$（余弦曲线在 $\varphi_s$ 处有多陡）。

数值例：若一串腔的平均梯度等于示例腔在入口处的 $V_0T/L = 0.39\ \mathrm{MV}/0.21\ \mathrm{m} = 1.86\ \mathrm{MV/m}$，取 $\varphi_s = -33°$，则 $k_{l0} = 4.44\ \mathrm{m^{-1}}$，$\lambda_l = 1.41$ m：粒子每走 1.41 m 前后摆动一次。实际结构中腔之间还有螺线管和漂移段，平均梯度更低，$k_{l0}$ 相应减小（正比于 $\sqrt{E_0T}$）。$\beta^3\gamma^3$ 在分母上：低能段的同步振荡最快，能量越高越慢。

### 一个腔就是一块纵向透镜

也可以把一个腔看成纵向的薄透镜。上一节算出，晚到 1° 的粒子约 0.24 m 后被追平，这就是纵向焦距：

$$
\frac{1}{f_z} = \frac{2\pi\,qV_0T\sin(-\varphi_s)}{mc^2\,\beta^3\gamma^3\lambda} \approx 4.1\ \mathrm{m^{-1}},\qquad f_z \approx 0.24\ \mathrm{m}.
$$

比[线性光学](#linear-optics)一章 FODO 实验里的四极铁（$f = 0.45$ m）还强。这是按平均公式的粗估（腔内 $\beta$ 变化约 14 %），但它解释了上表里 rms $z$ 为什么一个腔就从 1.48 mm 压到 0.70 mm。

### 用 AVAS 的纵向坐标来说

AVAS 描述纵向时不用相位和能量，而用粒子在参考粒子前方的距离 $z$（mm）和动量的相对偏差 $\delta = \Delta p/p$：

$$
z = -\frac{\beta\lambda}{2\pi}\,\Delta\varphi,\qquad
\delta = \frac{\Delta W}{\beta^2\gamma\,mc^2} .
$$

$z > 0$ 的粒子在前面、相位较小。示例束流的 `twissz 0.04275 0.37292 0.26506` 对应初始 rms $z = 1.316$ mm（rms 相位宽度 4.5°）、rms $\delta = 3.53$ mrad（rms 能散 10.8 keV）。Twiss 参数的含义见[相空间与发射度](#phase-space)，`twissz` 的写法见[在 AVAS 中](#longitudinal-in-avas)。

### 绝热阻尼：束团越加速越短

粒子被加速后越来越"重"、越来越快，同样的能量差能造成的速度差越来越小，这根纵向弹簧也慢慢变化。像一个摆绳被慢慢收短的单摆：摆动的幅度会变，但"幅度 × 速度幅度"所围的面积保持不变。对同步振荡，相位宽度与能散的乘积不变，而梯度、相位、频率不变时

$$
\Delta\varphi \propto (\beta\gamma)^{-3/4},\qquad \Delta W \propto (\beta\gamma)^{3/4}.
$$

例如从 1.527 MeV 加速到 10 MeV，相位宽度缩小到 0.49 倍，绝对能散增大到 2.0 倍，而相对能散 $\Delta W/W$ 下降到约 0.31 倍。束团在相位上越来越短，这也是下游可以把射频频率加倍的原因（见[从离子源到靶](#journey-overview)）。换成 $(z, \delta)$ 来说，这就是**归一化纵向发射度守恒**，和横向的情况一样（几何发射度 $\propto 1/\beta\gamma$），见[相空间与发射度](#phase-space)。推导见[深入：相振荡的方程](#longitudinal-deep-oscillation)。

> 注意：上面的守恒只对线性、无耦合、无空间电荷的运动成立。低能腔中的纵向非线性（相位宽度达到几十度时 $\cos\varphi$ 不再像直线）会使纵向 rms 发射度增长，线性预览不包含这一效应，要用多粒子内核计算。

## 纵向接受度：坑有多深 {#longitudinal-separatrix}

### 倾斜搓衣板上的小球

小振幅时纵向运动像弹簧，大振幅时呢？有一个准确的画面：把粒子想成一块**倾斜的搓衣板**上的小球。

- 板上一个个起伏来自射频场的余弦：每个坑底就是同步相位 $\varphi_s$，粒子在坑里来回滚，就是同步振荡；
- 整块板是倾斜的，因为同步粒子每过一个腔都必须得到一份固定的加速，这份"必须付出的代价"让板子朝一边歪；
- 每个坑的下坡一侧有一道"坎"，顶点在相位 $-\varphi_s$ 处。能量偏差太大的小球会越过坎，沿着倾斜的板一路滚下去——它的相位不断滑走，再也回不来，这就是**纵向损失**。

把"刚好越不过坎"的那些运动连起来，在相位–能量图上围出一条封闭的边界，叫**分界线**（separatrix）。边界以内的粒子做有界的同步振荡，这块形状像鱼、又像高尔夫球杆头的区域叫纵向**接受度**，也常叫"桶"（bucket）。边界以外的粒子成为纵向损失。

### 稳定区有多宽、多高

- 相位宽度：从左端 $\varphi_1$ 到坎顶 $-\varphi_s$。$\lvert\varphi_s\rvert$ 不太大时，总宽度约 $3\lvert\varphi_s\rvert$。
- 能量高度：在 $\varphi_s$ 处最高。坑的深度正比于 $\varphi_s\cos\varphi_s - \sin\varphi_s$：$\varphi_s = 0$ 时为零（根本没有坑），$\lvert\varphi_s\rvert$ 越大坑越深。

用上一节的平均梯度 1.86 MV/m、示例束流能量计算（公式见[深入：分界线的方程](#longitudinal-deep-separatrix)）：

| $\varphi_s$ | $\varphi_1$ | 相位宽度 | $\Delta W_{\max}$ / MeV | $\cos\varphi_s$ |
|---|---|---|---|---|
| −20° | −40.3° | 60° | ±0.073 | 0.940 |
| −30° | −60.9° | 91° | ±0.133 | 0.866 |
| −33° | −67.2° | 100° | ±0.153 | 0.839 |

这就是开头问题的答案：$\lvert\varphi_s\rvert$ 越大，接受度越大，但每个腔的加速正比于 $\cos\varphi_s$，越来越小。示例的 $-33°$ 付出了约 16 % 的能量增益，换来 100° 宽、±0.15 MeV 高的稳定区，而束团本身的 rms 相位宽度只有 4.5°、rms 能散 10.8 keV，余量很充足。低能段通常取较大的 $\lvert\varphi_s\rvert$（−30° 到 −40° 左右）保证接受度；到了高能段，束团在相位上变短了（绝热阻尼），再逐渐减小 $\lvert\varphi_s\rvert$ 多得一些能量。束流的纵向尺寸应只占分界线面积的一部分，以免边缘的非线性引起发射度增长和损失。

> **想一想**：为什么不能把同步相位放在波峰 $\varphi_s = 0$，再靠别的办法聚束？
>
> 答：$\varphi_s = 0$ 时搓衣板上没有坑，分界线面积为零：任何相位偏差都没有恢复力。低能质子的 $A$ 很大，一点能量差很快就变成大的相位差，束团几个腔就散开了。要么在腔之间另加聚束腔，要么让加速腔本身离开波峰——后者就是选择 $\varphi_s < 0$。

> 注意：分界线是对"把一串腔平均成连续推力"的周期结构推出的。在只有一两个腔的束线、或每个腔能量增益很大的低能段，它只能作定性估计，真实的纵向接受度要用多粒子模拟（扫描入口相位和能量）确定。

## 射频散焦：纵向聚焦的代价 {#longitudinal-rf-defocusing}

上面的表格里有个怪现象：让束团纵向变短的 $-33°$，同时让它横向变粗了。为什么让束团纵向聚集的腔，会让它横向散开？有两种互相印证的看法。

**跟着束团走的看法**。在跟着束团一起飞的参考系里，粒子之间的相对运动很慢，腔的场近似是静电场。静电场有一条铁律（**恩肖定理**）：在没有电荷的空间里，不可能有一个处处把粒子往中心推的"静电碗"。纵向要稳定，电势在前进方向上必须是个坑，那么横向至少有一个方向是坡，对轴对称的腔，两个横向方向都是坡。纵向聚焦和横向散焦来自同一个电势，不可能只要一个。这和[四极铁](#quadrupole)"不能两个方向同时聚焦"是同一类道理。

**看一个间隙的看法**。间隙入口处电场线向轴心收拢，把粒子往里推（聚焦）；出口处电场线向外张开，往外推（散焦）。如果电场不随时间变，两半大致抵消。但在稳定相位 $\varphi_s < 0$ 下，粒子穿过间隙的过程中电场正在**增强**（还没到波峰），出口那半的散焦比入口那半的聚焦更强，净效果就是散焦。

一个腔的横向散焦焦距（推导见[深入：射频散焦从哪里来](#longitudinal-deep-defocusing)）

$$
\frac{1}{f} = \frac{\pi\,qV_0T\sin(-\varphi_s)}{mc^2\,\beta^3\gamma^3\lambda} .
$$

和纵向焦距比较，正好是它的一半。示例腔、$\varphi_s = -33°$ 时 $1/f \approx 2.07\ \mathrm{m^{-1}}$，$f \approx 0.48$ m：一个腔的横向散焦和 FODO 实验里一块四极铁的聚焦（$f = 0.45$ m）差不多强。上表中 $-33°$ 时出口 rms $x$ 从漂移的 1.41 mm 增大到 1.81 mm，就是这个效应。线性预览沿实际轨迹积分场图的梯度，由它的传输矩阵得到 $x$ 方向 $-1/M_{21} \approx 0.37$ m、$y$ 方向 0.45 m，纵向 0.24 m：平均化的公式给对了量级和两者之间的 2 倍关系，但细节不准。HWR 并非轴对称，$x$ 与 $y$ 不必相同（内核是否给出同样的 $x$/$y$ 差别尚未核对）。

把一串腔平均起来，横向的"弹簧"变成负的：$k_r^2 = -k_{l0}^2/2$。上一节的数值例中 $k_r^2 = -9.9\ \mathrm{m^{-2}}$，必须由螺线管或四极铁提供更强的横向聚焦（见[螺线管](#solenoid)、[四极铁](#quadrupole)），这是低能超导段让螺线管与腔交替排列的重要原因之一。

腔里的磁场也会推粒子，但低能时它的作用比电场小得多（两者之比约为 $\beta^2$）：在示例中把 `Kb` 从 −1.36 改为 0，线性预览的出口 rms $x$ 只改变约 0.01 %，rms $y$ 约 0.2 %。场图的 $B$ 分量仍应与 $E$ 按同一个模式一致地给出。

## 想一想 {#longitudinal-think}

> **想一想 1**：10 MeV 的电子 $\gamma \approx 20.6$。电子直线加速器里还需要相稳定吗？
>
> 答：几乎不需要。$A \propto 1/(\beta^3\gamma^3)$，10 MeV 电子的 $A$ 只有示例质子的 $2\times 10^{-8}$ 倍：能量差几乎不改变速度，粒子的相位被"冻结"了。电子直线加速器因此可以把束团放在波峰附近（$\varphi_s \approx 0$）获得最大能量增益，纵向不会因为能量差而散开。低能质子则相反，必须靠相稳定把束团拉住。

> **想一想 2**：一个腔设成 $\varphi_s = -90°$，同步粒子一点能量也得不到。这样的腔有什么用？
>
> 答：它正好在电场为零、增强最快的时刻经过：同步粒子不加速，早到的粒子被减速，晚到的被加速，"头慢尾快"，再经过一段漂移，束团就变短了。这就是**聚束腔**，中能传输段用它把束团送进下游的加速段（见[中能传输段](#journey-mebt)和[漂移段](#drift-deep-longitudinal)）。

> **想一想 3**：示例腔用 V3 = 2（绝对相位）写在一段漂移之后。把这段漂移加长 5 mm，腔的入口相位变多少？
>
> 答：质子多飞 5 mm 要晚到 $360°\times 5/105.1 = 17.1°$，入口相位跟着变 17.1°，同步相位也随之改变。用 V3 = 0 写时，内核会重新求解入口相位，同步相位保持不变。

> **想一想 4**：为什么示例腔在约 0.9 MeV 附近完全给不出加速的同步相位？
>
> 答：这时质子从一个间隙飞到另一个约用一整个周期，两个方向相反的间隙互相抵消。详见[深入：低能腔里的两个怪现象](#longitudinal-deep-lowbeta)。

## 容易误解的地方 {#longitudinal-misconceptions}

- **同步相位的符号**：AVAS 用余弦约定、相位越大越晚，稳定区是 $-90° < \varphi_s < 0$。正弦约定或 $-\omega t$ 约定下稳定区是正相位。移植相位时符号错了，束团会纵向散开、横向反而聚焦。
- **同步相位不是入口相位**：示例腔 $\varphi_s = -33°$ 对应的入口相位是 52.7°，两者相差约 86°，取决于场图的零点和场分布，没有通用换算。
- **$\varphi_s = 0$ 能量增益最大？** 只在粒子速度几乎不变时成立。示例的低速腔最大增益在 $\varphi_s \approx +8°$，而且 $\pm 33°$ 的增益不对称。这不是数值误差：把速度冻结后不对称就消失了，它来自腔内的加速。
- **Panofsky 公式是精确的？** 它假设腔内速度不变；$\Delta W/W$ 达到百分之几十时，只能作估算。
- **V3 = 0 总能找到同步相位？** 不是。在两个间隙几乎抵消的能量附近，可能只有减速的解，甚至一个解也没有，见[在 AVAS 中](#longitudinal-in-avas)。
- **能散越来越大说明束流变差？** 不是。绝热阻尼使绝对能散 $\propto(\beta\gamma)^{3/4}$ 增大，但相位宽度同时缩小，归一化纵向发射度不变，相对能散还在减小。
- **束团可以占满分界线？** 分界线边缘附近运动高度非线性，粒子在那里转得慢、容易丝化，发射度增长和损失都从那里开始。束团应只占分界线的一小部分。
- **射频散焦是腔设计的缺陷？** 不是。它是静电场规律（拉普拉斯方程）的结果，任何纵向稳定的加速相位都伴随横向散焦，只能用外部聚焦补偿。
- **腔的频率就是束流频率？** 不一定。`field` 的 `f` 是腔的频率，`beam.txt` 的 `frequency` 是束团重复频率，倍频段两者不同。
- **电子和质子一样？** 高能电子的相位几乎冻结（$A \propto 1/\beta^3\gamma^3$），相稳定的需求和低能质子完全不同。

## 深入：一个间隙的能量增益 {#longitudinal-deep-gap}

正文直接给出了 Panofsky 公式 $\Delta W = qV_0T\cos\varphi$ 和均匀间隙的 $T = \sin x/x$。这一节一步步推出它们，只用中学的"功 = 力 × 距离"和三角公式，最后一段给学过微积分的读者。

### 第一步：粒子沿途看到的相位

腔里轴上的电场写成

$$
E_z(z, t) = E(z)\cos\left(\omega t + \varphi_0\right),
$$

$E(z)$ 是电场沿轴的分布（场图给出），$\omega = 2\pi f$ 是每秒转过的角度（弧度），$\varphi_0$ 是腔的射频相位。粒子在时刻 $t(z)$ 到达位置 $z$，它在那里看到的相位是 $\varphi(z) = \omega t(z) + \varphi_0$。

假设粒子在间隙里速度几乎不变（能量增益远小于原有能量），它每走 $\beta\lambda$ 相位就转 360°。选间隙里一个参考点 $z_c$，粒子到达那里时的相位记作 $\varphi$，则

$$
\varphi(z) = \varphi + k\,(z - z_c),\qquad k = \frac{2\pi}{\beta\lambda}.
$$

示例质子 $k = 2\pi/0.1051 = 59.8$ 弧度每米，即每毫米 3.42°。

### 第二步：把间隙切成小段，把功加起来

把间隙切成很多长 $\Delta z$ 的小段。第 $i$ 段的电场是 $E_i\cos\varphi_i$，电场力对粒子做的功是 $qE_i\cos\varphi_i\,\Delta z$。总能量增益是各段之和：

$$
\Delta W = q\sum_i E_i\cos\varphi_i\,\Delta z .
$$

### 第三步：用两角和公式拆开

记 $\theta_i = k(z_i - z_c)$，则 $\varphi_i = \varphi + \theta_i$。用中学的两角和公式 $\cos(\varphi + \theta) = \cos\varphi\cos\theta - \sin\varphi\sin\theta$：

$$
\Delta W = q\cos\varphi\sum_i E_i\cos\theta_i\,\Delta z \;-\; q\sin\varphi\sum_i E_i\sin\theta_i\,\Delta z .
$$

两个求和只取决于电场分布和粒子速度，与 $\varphi$ 无关。

### 第四步：选好参考点，第二项消失

总可以把 $z_c$ 选在一个位置，使第二个求和为零，这个位置叫间隙的**电中心**。对左右对称的间隙，它就是几何中心：$\sin\theta$ 左右正负相反，正好抵消。于是

$$
\Delta W = qV_0T\cos\varphi,\qquad
V_0 = \sum_i E_i\,\Delta z,\qquad
T = \frac{\sum_i E_i\cos\theta_i\,\Delta z}{\sum_i E_i\,\Delta z}.
$$

$V_0$ 是间隙的"电压"（电场沿轴加起来），$T$ 是 $\cos\theta$ 按电场强弱加权的平均，所以 $T \le 1$。这就是 Panofsky 公式，$E_0 = V_0/L$ 叫间隙长度 $L$ 上的平均轴上场，$V_0T = E_0TL$。

### 第五步：均匀间隙

若电场在长 $g$ 的间隙里处处相同，$T$ 就是 $\cos\theta$ 的普通平均，$\theta$ 从 $-x$ 均匀变到 $+x$，$x = kg/2 = \pi g/(\beta\lambda)$。$\cos\theta$ 在 $-x$ 到 $x$ 之间的平均值是 $\sin x/x$（下一段用微积分证明；也可以拿计算器把 $\cos$ 在这段区间里均匀取许多点求平均来验证）。$g = \beta\lambda/2$ 时 $x = \pi/2$：$\cos$ 的一个完整的"拱"，平均高度 $2/\pi = 0.64$，正是正文的结果。

### 第六步：两个方向相反的间隙

两个相同的间隙，中心相距 $d$，电场方向相反。把第一个间隙放在 $z_c - d/2$、第二个在 $z_c + d/2$，每个间隙各自的电压 $V_g$、渡越时间因子 $T_g$。按第四步，两个间隙各给

$$
\Delta W_1 = qV_gT_g\cos\!\left(\varphi - \tfrac{kd}{2}\right),\qquad
\Delta W_2 = -qV_gT_g\cos\!\left(\varphi + \tfrac{kd}{2}\right)
$$

（第二个带负号，因为电场方向相反）。用和差化积公式 $\cos(a - b) - \cos(a + b) = 2\sin a\sin b$：

$$
\Delta W = 2qV_gT_g\,\sin\frac{kd}{2}\,\sin\varphi .
$$

参考点取在两个间隙中间时，增益最大的相位在 $\varphi = 90°$；把相位零点平移 90°，就回到 $\cos$ 的形式。把 $V_0 = 2V_g$（两个间隙电压的绝对值之和，正负交替的场 $\sum E\,\Delta z \approx 0$，所以改用 $\int\lvert E\rvert\,\dd z$，正文的表格就是这样算的），得到

$$
T(\beta) = T_g(\beta)\left\lvert\sin\frac{kd}{2}\right\rvert = T_g(\beta)\left\lvert\sin\frac{\pi\beta_g}{2\beta}\right\rvert,\qquad d = \frac{\beta_g\lambda}{2}.
$$

三个结论：$\beta = \beta_g$ 时 $\sin(\pi/2) = 1$，两个间隙完全合拍；$\beta$ 偏离时 $T$ 下降；$kd/2 = \pi$、$2\pi$……时 $\sin = 0$，两个间隙完全抵消，这时 $d = \beta\lambda$、$2\beta\lambda$……，即粒子在两个间隙之间飞了整数个周期。示例腔 $d = 0.081$ m，$d = \beta\lambda$ 对应 $\beta = 0.0439$（约 0.90 MeV），$d = 2\beta\lambda$ 对应约 0.23 MeV。$N$ 个间隙的腔，$T(\beta)$ 更尖锐。

### 第七步：速度明显变化时的准确定义

当能量增益与原有能量可比时（低能质子、重离子），速度不变的假设不成立，第一步的 $\varphi(z)$ 不再是直线。但第三步的拆法仍然可以用，只是要沿参考粒子的**实际**到达时刻 $t(z)$ 求和：

$$
C = \sum_i E_i\cos\varphi_i\,\Delta z,\qquad S = \sum_i E_i\sin\varphi_i\,\Delta z,\qquad
\Delta W = q\sqrt{C^2 + S^2}\,\cos\varphi_s,\qquad \varphi_s = \operatorname{atan2}(S, C).
$$

把 $(C, S)$ 看成平面上的一个箭头：$\sqrt{C^2 + S^2}$ 是箭头的长度（"有效电压"），$\operatorname{atan2}(S, C)$ 是箭头与横轴的夹角（考虑了象限的反正切）。第一式本身就是能量增益 $\Delta W = qC$，第二式是同样的事换个写法，所以它是精确的。这个 $\varphi_s$ 就是 AVAS 所说的同步相位。代价是：有效电压本身取决于轨迹，因而取决于 $\varphi_s$，能量增益不再严格按 $\cos\varphi_s$ 变化。

### 给学过微积分的读者

求和换成积分：$\Delta W = q\int E(z)\cos\varphi(z)\,\dd z$，$T = \int E(z)\cos k(z - z_c)\,\dd z\big/\int E\,\dd z$，即电场分布在空间频率 $k = 2\pi/(\beta\lambda)$ 处的傅里叶变换（对电中心取实部）。均匀间隙 $\frac{1}{2x}\int_{-x}^{x}\cos\theta\,\dd\theta = \sin x/x$。两间隙场 $E(z) = e(z - d/2) - e(z + d/2)$ 的傅里叶变换由平移定理给出 $\tilde E(k) = -2i\sin(kd/2)\,\tilde e(k)$，即上面的 $\lvert\sin(kd/2)\rvert$ 因子。准确定义中的 $C + iS = \int E(z)\,\ee^{i\varphi(z)}\,\dd z$。

## 深入：低能腔里的两个怪现象 {#longitudinal-deep-lowbeta}

示例腔对示例质子来说太"短"了：质子在腔里能量增加约 30 %，$\beta$ 从 0.057 增大到约 0.063 至 0.065。这带来两个和简单余弦不符的现象。这一节把它们拆开看。

### 第一步：最大增益不在 0°，正负相位不对称

正文的表格里，$\Delta W/\cos\varphi_s$ 在 −33° 时为 0.405 MeV，在 0° 时为 0.475 MeV，相差约 15 %；扫描入口相位得到的最大增益（出口 2.0087 MeV）在 $\varphi_s \approx +8°$；$+33°$ 的增益 0.424 MeV 比 $-33°$ 的 0.340 MeV 多。

### 第二步：把速度冻结，怪现象消失

把同一张场图按"速度一直等于入口值"再积分一次：所有相位上 $\Delta W = qV_0T\cos\varphi_s$ 都在 1 % 以内成立，$V_0T = 0.389$ MV，$-33°$ 时 0.325 MeV，$+33°$ 时 0.328 MeV，最大值就在 $\varphi_s \approx 0$。可见不对称完全来自粒子在腔内的明显加速。

### 第三步：两个间隙分开看

示例质子从一个间隙中心飞到另一个约用 0.77 个周期，不是理想的半个周期，两个间隙不可能同时靠近波峰。

- $\varphi_s = -33°$：第一个间隙处在约 −81°，只给 0.043 MeV；第二个间隙接近波峰，给 0.297 MeV。$\varphi_s$ 是两者的加权平均。
- $\varphi_s = +33°$：正好反过来，第一个间隙接近波峰，先给了 0.292 MeV。粒子随后明显变快，更早到达第二个间隙，那里的相位从波峰后约 79° 提前到约 66°，增益从 0.054 MeV 增加到 0.132 MeV。

能量在腔里的哪个位置获得，决定了腔后半部分的时间关系移动多少——这就是"有效电压随相位变化"的物理含义。对这种低能、大增益的腔，速度不变的 Panofsky 公式只能作估算，设计要以沿真实轨迹积分的结果为准。

### 第四步：同步相位可能无解

把上一节第七步的 $(C, S)$ 想成两个箭头之和：第一个间隙一个，第二个间隙一个（方向相反）。速度不变时，改变入口相位 $\varphi_0$，两个箭头一起转动，合箭头也跟着转一整圈，任何同步相位都能取到。

速度变化时就不同了：第一个间隙给多少能量取决于 $\varphi_0$，这又决定粒子什么时候到第二个间隙，于是第二个箭头不再和第一个同步转动。在两个间隙几乎抵消的速度附近（上一节第六步：在间隙之间飞约整数个周期），合箭头是两个大箭头之差，很短，第二个箭头的一点点摆动就能让它左右来回晃，而转不了一整圈。这时扫遍 $\varphi_0$，$\varphi_s = \operatorname{atan2}(S, C)$ 只覆盖一段角度。按线性预览（示例腔，$K_e = 1.36$）：

| 入口能量 | $\varphi_s$ 能达到的范围 |
|---|---|
| 0.3 MeV | 约 65°～107° |
| 0.8 MeV | 约 58°～136° |
| 1.0 MeV | 约 14°～144° |

想要 $\varphi_s = -30°$ 时，按线性预览：

- 0.4–0.65 MeV 与 1.1 MeV 以上：存在加速的解；
- 0.7–0.75 MeV 与 1.05 MeV：没有加速的解，但有相差 180° 的解（$\varphi_s = 150°$，腔使束流**减速**），内核接受它；
- 0.15–0.35 MeV 与 0.8–1.0 MeV：两种解都没有，内核拒绝运行。

和第六步的粗算对照：两个间隙完全抵消的约 0.23 MeV 和 0.90 MeV，正好落在两个"无解"区间里。

下面的实验把入口能量设为 0.7 MeV、同步相位 −30°：看警告，以及能量增益为负（约 −0.113 MeV）、同步相位显示为 150°、入口相位约 −107.8°。把能量拖到 0.5 MeV，加速解又出现了（增益约 +0.072 MeV）；拖到 0.8 MeV，两种解都没有，预览取最接近的可达值并提示内核会报错。

```avas-lab
rf-cavity phase=-30 Ke=1.36 W=0.7
```

AVAS 内核遇到这些情形时的具体行为见[在 AVAS 中](#longitudinal-in-avas)。

### 给学过微积分的读者

$C + iS = \int E(z)\,\ee^{i\varphi(z;\varphi_0)}\,\dd z$，其中 $\varphi(z;\varphi_0) = \varphi_0 + \omega t(z;\varphi_0)$。速度不变时 $t$ 与 $\varphi_0$ 无关，$C + iS = \ee^{i\varphi_0}\times$ 常数，映射 $\varphi_0 \mapsto \varphi_s$ 是平移，环绕数为 1。$t$ 依赖 $\varphi_0$ 时，曲线 $\varphi_0 \mapsto C + iS$ 不必绕原点一周；当它不包围原点时，$\varphi_s(\varphi_0)$ 的值域是一段弧，某些 $\varphi_s$ 无解；有多个根时，内核取 $\varphi_s(\varphi_0)$ 上升分支上的那个。

## 深入：相振荡的方程 {#longitudinal-deep-oscillation}

正文用一个晚到 1° 的粒子算了恢复力。这一节把它写成方程，推出同步振荡和绝热阻尼。用到的工具：速度与能量的关系、简谐振动、椭圆面积。

### 第一步：两个记号

$$
\Delta\varphi = \varphi - \varphi_s,\qquad w = \frac{W - W_s}{mc^2}.
$$

$\Delta\varphi$ 是粒子比同步粒子晚到多少相位，$w$ 是它多出的能量（以静止能量 $mc^2$ 为单位，无量纲）。

### 第二步：能量差变成相位差

粒子走过 $\Delta s$ 用时 $\Delta s/v$，比同步粒子少用 $\Delta s/v_s - \Delta s/v \approx \Delta s\cdot\Delta v/v^2$。相位少走 $\omega$ 乘以这段时间。速度差与能量差的关系是（推导见[漂移段](#drift-deep-longitudinal)和[相对论运动学](#kinematics)）

$$
\frac{\Delta v}{v} = \frac{1}{\gamma^2}\frac{\Delta p}{p} = \frac{w}{\beta^2\gamma^3},
$$

低速时就是 $\tfrac12\Delta W/W$。合起来，每走一米相位的变化

$$
\frac{\Delta(\Delta\varphi)}{\Delta s} = -\frac{\omega}{\beta c}\cdot\frac{w}{\beta^2\gamma^3} = -\frac{2\pi}{\beta^3\gamma^3\lambda}\,w \equiv -A\,w .
$$

（用了 $\omega/c = 2\pi/\lambda$。）示例：$\beta^3\gamma^3 = 1.860\times 10^{-4}$，$A = 2\pi/(1.860\times 10^{-4}\times 1.8449) = 1.83\times 10^4\ \mathrm{m^{-1}}$。

### 第三步：相位差变成能量差

把一串腔的作用平均到单位长度，平均加速梯度 $E_0T$。同步粒子每米得到 $qE_0T\cos\varphi_s$，晚到 $\Delta\varphi$ 的粒子得到 $qE_0T\cos\varphi$，差是

$$
\frac{\Delta w}{\Delta s} = \frac{qE_0T}{mc^2}\left(\cos\varphi - \cos\varphi_s\right) \equiv B\left(\cos\varphi - \cos\varphi_s\right).
$$

### 第四步：小偏差时是简谐振动

偏差小时，$\cos\varphi - \cos\varphi_s \approx -\sin\varphi_s\,\Delta\varphi$（余弦曲线在 $\varphi_s$ 处的切线；用导数说，$(\cos\varphi)' = -\sin\varphi$）。第二步说相位变化的快慢正比于 $-w$，第三步说 $w$ 变化的快慢正比于 $-\sin\varphi_s\,\Delta\varphi$。把"变化的快慢再变化的快慢"记作 $\Delta\varphi''$（对 $s$ 的二阶导数，像加速度之于位置）：

$$
\Delta\varphi'' = -A\,w' = AB\sin\varphi_s\,\Delta\varphi .
$$

和弹簧振子 $x'' = -(k/m)\,x$ 比较：$\sin\varphi_s < 0$ 时右边是恢复力，运动是简谐振动，

$$
\Delta\varphi = a\cos(k_{l0}s),\qquad k_{l0}^2 = -AB\sin\varphi_s = \frac{2\pi\,qE_0T\sin(-\varphi_s)}{mc^2\,\beta^3\gamma^3\lambda}.
$$

示例数值：$B = 1.86/938.27 = 1.98\times 10^{-3}\ \mathrm{m^{-1}}$，$k_{l0}^2 = 1.83\times 10^4\times 1.98\times 10^{-3}\times 0.545 = 19.8\ \mathrm{m^{-2}}$，$k_{l0} = 4.44\ \mathrm{m^{-1}}$，与正文一致。$\sin\varphi_s > 0$ 时右边把偏差放大，粒子指数式地跑开。每个聚焦周期 $L_p$ 的纵向相移是 $\sigma_{0l} = k_{l0}L_p$。

### 第五步：相位振幅与能量振幅

由第二步 $w = -\Delta\varphi'/A$。$\Delta\varphi = a\cos(k_{l0}s)$ 时 $\Delta\varphi' = -ak_{l0}\sin(k_{l0}s)$，所以 $w$ 的振幅是 $ak_{l0}/A$：

$$
\frac{w_{\max}}{\Delta\varphi_{\max}} = \frac{k_{l0}}{A}.
$$

把一个腔集中成一块薄透镜：穿过腔后晚到 $\Delta\varphi$ 的粒子多得 $w = (qV_0T/mc^2)\sin(-\varphi_s)\Delta\varphi$，再走 $s$ 后相位改变 $-Aws$；改变量等于 $-\Delta\varphi$ 时的 $s$ 就是焦距：$1/f_z = A\,qV_0T\sin(-\varphi_s)/(mc^2)$，示例 $1.83\times 10^4\times(0.39/938.27)\times 0.545 = 4.1\ \mathrm{m^{-1}}$。

### 第六步：换成 AVAS 的 (z, δ)

一个周期里粒子飞过 $\beta\lambda$，所以相位差 360° 对应距离 $\beta\lambda$，且晚到（相位大）的粒子在后面（$z$ 小）：$z = -\beta\lambda\,\Delta\varphi/(2\pi)$。动量与能量的关系 $\Delta p/p = \Delta W/(\beta^2\gamma\,mc^2)$ 给出 $\delta = w/(\beta^2\gamma)$。$z$ 与 $\Delta\varphi$ 只差一个常数倍，满足同样的振荡方程。示例 rms $z = 1.316$ mm 对应 $360°\times 1.316/105.1 = 4.5°$；rms $\delta = 3.53$ mrad 对应 $3.53\times 10^{-3}\times\beta^2\gamma\,mc^2 = 3.53\times 10^{-3}\times 3.05\ \mathrm{MeV} = 10.8$ keV。

### 第七步：绝热阻尼

一个简谐振动在"相位–能量"图上画出一个椭圆，半轴是 $\Delta\varphi_{\max}$ 和 $w_{\max}$，面积 $\pi\,\Delta\varphi_{\max}w_{\max}$。当 $\beta\gamma$、$E_0T$ 在一次振荡的时间里只变化一点点时（"绝热"），这个面积保持不变——就像摆绳被慢慢收短的单摆。两条关系联立：

$$
\Delta\varphi_{\max}\,w_{\max} = \text{常数},\qquad \frac{w_{\max}}{\Delta\varphi_{\max}} = \frac{k_{l0}}{A} = \sqrt{\frac{qE_0T\sin(-\varphi_s)\,\lambda\,\beta^3\gamma^3}{2\pi\,mc^2}} .
$$

（第二式把第四步的 $k_{l0}$ 和第二步的 $A$ 代入即得。）记 $X = E_0T\sin(-\varphi_s)\,\lambda\,\beta^3\gamma^3$：两式相乘得 $w_{\max}^2 \propto X^{1/2}$，相除得 $\Delta\varphi_{\max}^2 \propto X^{-1/2}$，再开平方：

$$
\Delta\varphi_{\max} \propto \left[E_0T\sin(-\varphi_s)\,\lambda\,\beta^3\gamma^3\right]^{-1/4},\qquad
\Delta W_{\max} \propto \left[E_0T\sin(-\varphi_s)\,\lambda\,\beta^3\gamma^3\right]^{1/4}.
$$

梯度、相位和频率不变时 $\Delta\varphi \propto (\beta\gamma)^{-3/4}$，$\Delta W \propto (\beta\gamma)^{3/4}$。验算正文的例子：10 MeV 质子 $\beta\gamma = 0.1464$，与 0.05708 之比 2.565，$2.565^{-3/4} = 0.49$，$2.565^{3/4} = 2.03$，相对能散 $2.03\times 1.527/10 = 0.31$。在 $(z, \delta)$ 中，$\beta\gamma\cdot z\,\delta \propto \lambda\,\Delta\varphi\,\Delta W$ 不变，即归一化纵向发射度守恒。

### 给学过微积分的读者

第二、三步就是 $\dd\Delta\varphi/\dd s = \omega(1/\beta c - 1/\beta_s c) \approx -Aw$ 与 $\dd w/\dd s = B(\cos\varphi - \cos\varphi_s)$，用了 $\Delta\beta = \Delta\gamma/(\beta\gamma^3)$。$(\Delta\varphi, w)$ 是一对正则变量，作用量 $J = \oint w\,\dd\Delta\varphi$ 在参数缓慢变化时是绝热不变量（下一节给出哈密顿量）。线性化后的二阶方程 $\Delta\varphi'' + (A'/A)\Delta\varphi' + k_{l0}^2\Delta\varphi = 0$ 中阻尼项来自 $A$ 随 $s$ 变化，WKB 解给出同样的 $-1/4$ 幂律。

## 深入：分界线的方程 {#longitudinal-deep-separatrix}

正文用"倾斜的搓衣板"描述了大振幅的纵向运动。这一节说明这个画面在数学上是严格的，并推出分界线和稳定区的大小。需要的工具：机械能守恒，和中学学过的导数。

### 第一步：一个守恒量

小球在坡上滚动时，动能 + 势能守恒：$\tfrac12 m v^2 + U(x) = $ 常数。纵向运动也有这样一个守恒量：

$$
\frac{A}{2}w^2 + U(\varphi) = \text{常数},\qquad U(\varphi) = B\left(\sin\varphi - \varphi\cos\varphi_s\right).
$$

$\tfrac{A}{2}w^2$ 扮演"动能"，$U$ 扮演"势能"。验证：对 $s$ 求导，用 $(\sin\varphi)' = \cos\varphi$ 和上一节的两个方程 $\varphi' = -Aw$、$w' = B(\cos\varphi - \cos\varphi_s)$：

$$
A\,w\,w' + B(\cos\varphi - \cos\varphi_s)\,\varphi' = A w B(\cos\varphi - \cos\varphi_s) - B(\cos\varphi - \cos\varphi_s)Aw = 0 .
$$

$U$ 由两部分组成：$B\sin\varphi$ 是正弦形的起伏（射频场），$-B\varphi\cos\varphi_s$ 是线性的倾斜（同步粒子必须得到的那份加速）。这就是倾斜的搓衣板。

### 第二步：坑底和坎顶

小球静止（$w = 0$）且不受力的地方，"势能"的斜率为零：$U'(\varphi) = B(\cos\varphi - \cos\varphi_s) = 0$，即 $\cos\varphi = \cos\varphi_s$。在一个周期内有两个解：

- $\varphi = \varphi_s$：坑底，稳定（小球停在那里，推一下就在附近来回滚）；
- $\varphi_2 = -\varphi_s$：坎顶，不稳定（像立在山顶的球，一碰就滚走）。

### 第三步：分界线

经过坎顶的那条运动轨迹，就是分界线：它的"总能量"等于小球静止在坎顶时的能量 $U(-\varphi_s)$，

$$
\frac{A}{2}w^2 + B\left(\sin\varphi - \varphi\cos\varphi_s\right) = -B\left(\sin\varphi_s - \varphi_s\cos\varphi_s\right).
$$

总能量比它小的粒子被困在坑里，做有界的同步振荡；比它大的越过坎顶，相位一去不回。

### 第四步：稳定区的高度

能量偏差最大的地方在坑底 $\varphi = \varphi_s$（势能最低，"动能"最大）。分界线在那里的 $w$ 满足

$$
\frac{A}{2}w_{\max}^2 = U(-\varphi_s) - U(\varphi_s) = 2B\left(\varphi_s\cos\varphi_s - \sin\varphi_s\right).
$$

换回能量 $\Delta W = mc^2 w$，代入 $A = 2\pi/(\beta^3\gamma^3\lambda)$、$B = qE_0T/(mc^2)$：

$$
\Delta W_{\max} = 2\left[\frac{qE_0T\,\beta^3\gamma^3\,\lambda\, mc^2\left(\varphi_s\cos\varphi_s - \sin\varphi_s\right)}{2\pi}\right]^{1/2}.
$$

验算 $\varphi_s = -33°$（$-0.576$ 弧度）：$\varphi_s\cos\varphi_s - \sin\varphi_s = -0.483 + 0.545 = 0.0615$；$qE_0T\beta^3\gamma^3\lambda\,mc^2 = 1.86\times 1.860\times 10^{-4}\times 1.8449\times 938.27 = 0.599\ \mathrm{MeV^2}$；$\Delta W_{\max} = 2\sqrt{0.599\times 0.0615/(2\pi)} = 0.153$ MeV，与正文表格一致。

### 第五步：稳定区的宽度

分界线的左端 $\varphi_1$ 也在 $w = 0$ 上，所以 $U(\varphi_1) = U(-\varphi_s)$：

$$
\sin\varphi_1 - \varphi_1\cos\varphi_s = -\sin\varphi_s + \varphi_s\cos\varphi_s .
$$

这个方程没有简单的解，用计算器试几个值或二分法就能解出：$\varphi_s = -33°$ 时 $\varphi_1 = -67.2°$，总宽度 $33° + 67.2° = 100°$。表中三行的宽度与 $\lvert\varphi_s\rvert$ 之比都约为 3，这就是"小 $\lvert\varphi_s\rvert$ 时宽度约 $3\lvert\varphi_s\rvert$"。

### 第六步：这个画面的边界

这个类比在数学上是严格的，边界在于两点：$A$、$B$ 随能量缓慢变化（坑在慢慢变形，加速时坑变深、粒子相对坑底的振幅缩小，即绝热阻尼）；真实的腔是一个个离散的，"平均成连续推力"只在每个周期的纵向相移不大时成立。

### 给学过分析力学的读者

以 $s$ 为自变量、$\varphi$ 与 $w$ 共轭，哈密顿量

$$
H(\varphi, w) = -\frac{A w^2}{2} - B\left(\sin\varphi - \varphi\cos\varphi_s\right),
$$

$\varphi' = \partial H/\partial w = -Aw$，$w' = -\partial H/\partial\varphi = B(\cos\varphi - \cos\varphi_s)$。分界线是过双曲不动点 $(-\varphi_s, 0)$ 的等值线，它所围的面积是纵向接受度；$\varphi_s \to 0$ 时面积趋于零，$\varphi_s \to -90°$ 时变成静止桶（不加速）。

## 深入：射频散焦从哪里来 {#longitudinal-deep-defocusing}

正文用"恩肖定理"和"入口聚焦、出口散焦"两种看法解释了射频散焦。这一节推出焦距公式。需要的工具：电场线"进出相等"、变化的电场产生磁场、洛伦兹力。

### 第一步：纵向电场在变，就必然有横向电场

在轴附近取一个半径 $r$、长 $\Delta z$ 的小圆柱（间隙里没有电荷）。穿进去的电场线一定和穿出来的一样多（和[四极铁](#quadrupole-deep-field)深入一节的"规矩 1"相同，只是换成电场）。两个底面的差是 $\pi r^2\left[E_z(z + \Delta z) - E_z(z)\right]$，侧面是 $2\pi r\,\Delta z\,E_r$。两者之和为零：

$$
E_r = -\frac{r}{2}\,\frac{E_z(z + \Delta z) - E_z(z)}{\Delta z} = -\frac{r}{2}\frac{\partial E_z}{\partial z}.
$$

$\partial E_z/\partial z$ 表示 $E_z$ 沿轴的变化率（时间固定）。入口处 $E_z$ 沿轴增大，$E_r < 0$，指向轴心（聚焦）；出口处 $E_z$ 减小，$E_r > 0$（散焦）。横向场与离轴距离 $r$ 成正比，所以它是一块线性透镜。

### 第二步：变化的电场产生磁场

麦克斯韦发现，变化的电场也会产生磁场，就像电流一样（中学讲电磁波时提到过）。在半径 $r$ 的圆周上，磁场绕着轴：

$$
B_\theta = \frac{r}{2c^2}\frac{\partial E_z}{\partial t}.
$$

### 第三步：径向力

粒子受的径向力 $F_r = q(E_r - vB_\theta)$。沿粒子路径看，它在 $z$ 处、时刻 $t$，$E_z$ 的变化既因为位置在变，也因为时间在变。把两者合起来记作 $\dd E_z/\dd z = \partial E_z/\partial z + \partial E_z/\partial t\cdot\frac{1}{\beta c}$，整理得

$$
F_r = -\frac{qr}{2}\left[\frac{\dd E_z}{\dd z} - \frac{1}{\beta c\,\gamma^2}\frac{\partial E_z}{\partial t}\right].
$$

对整个间隙加起来时，第一项是"粒子看到的 $E_z$ 的总变化"，从零（间隙前）变回零（间隙后），合计为零（假设 $r$ 和 $\beta$ 在间隙里近似不变）。只剩第二项：电场随时间的变化。它在粒子到达时正比于 $-\omega\sin\varphi$，$\varphi < 0$ 时电场正在增强。

### 第四步：焦距

把第二项沿间隙加起来（加权平均同样给出渡越时间因子 $T$），得到横向动量的变化和角度的变化：

$$
\Delta p_r = -\frac{\pi qE_0TL\,r\sin\varphi}{c\,\beta^2\gamma^2\lambda},\qquad
\Delta r' = \frac{\Delta p_r}{p} = -\frac{\pi qE_0TL\sin\varphi}{mc^2\,\beta^3\gamma^3\lambda}\,r .
$$

$\sin\varphi < 0$（纵向稳定）时 $\Delta r'$ 与 $r$ 同号，间隙是散焦透镜，$1/f = \pi qE_0TL\sin(-\varphi)/(mc^2\beta^3\gamma^3\lambda)$。示例 $V_0T = E_0TL = 0.39$ MV、$\varphi_s = -33°$：$1/f = \tfrac12\times 4.1 = 2.07\ \mathrm{m^{-1}}$。纵向聚焦和横向散焦来自同一个 $\sin\varphi$，二者不能在同一相位同时得到。

### 第五步：三个方向加起来是零

把每米的散焦与上一节的纵向 $k_{l0}^2$ 比较：

$$
k_r^2 = -\frac{\pi qE_0T\sin(-\varphi_s)}{mc^2\,\beta^3\gamma^3\lambda} = -\frac{k_{l0}^2}{2}.
$$

$k_x^2 + k_y^2 + k_z^2 = 0$：纵向聚焦多少，两个横向方向就各散焦一半。这就是恩肖定理的定量形式。磁场项 $vB_\theta$ 与电场项之比约为 $\beta^2$，低能时很小，第三步的 $1/\gamma^2$ 正是电场与磁场两部分相减的结果。

### 给学过矢量分析的读者

第一步是 $\nabla\cdot\boldsymbol E = 0$ 在轴附近的展开，第二步是 $\nabla\times\boldsymbol B = c^{-2}\partial_t\boldsymbol E$。在束流静止系中场近似静电，$\nabla^2\Phi = 0$ 给出三个方向的聚焦常数之和为零。更一般的 Panofsky–Wenzel 定理 $\Delta\boldsymbol p_\perp \propto \nabla_\perp\Delta p_z$（沿直线轨迹积分）把横向冲量与纵向冲量的横向梯度联系起来，同样说明纵向能量增益随横向位置的变化必然伴随横向偏转。

## 在 AVAS 中 {#longitudinal-in-avas}

### 关键字

射频腔是 `field` 元件，`type = 1`：

```avas-params
field input:scanphase input:longlimits beam:twissz beam:frequency
```

```text
start
! L     R     V3 type f        phase Ke   Kb    file
field 0.21  0.02  0  1    162.5e6  -33   1.36 -1.36 hwr010
end
```

- `f` 是腔的频率；`beam.txt` 的 `frequency` 是束流频率（束团重复频率，决定每个束团的电荷 $Q = I/f$），二者可以不同（例如倍频段）。
- `Ke` 缩放电场（场图单位 MV/m），`Kb` 缩放磁场；改变腔的加速梯度时两者按比例一起改。示例 HWR 取 $K_b = -K_e$（入门里的射频腔实验也如此）。
- 腔的相位只由 field 行的 `phase` 与 V3 决定。`input.txt` 的 `scanphase` 和 `scanData.txt` 没有任何内核读取（原手册称它们控制相位扫描），模拟设置页保存时会删除残留的 `scanphase` 行。
- `longlimits` 设置纵向损失判定的相位和能量边界，对应上文分界线的概念：越过边界的粒子记为纵向损失。
- 输出文件 `Phase.txt` 每两行给出一个射频腔入口和出口的时间、位置和同步粒子能量，可用来核对每个腔的能量增益。
- `beam.txt` 的 `twissz` 是纵向 Twiss 参数：$\alpha_z$、$\beta_z$（mm/mrad，$z$ 单位 mm、$\delta = \Delta p/p$ 单位 mrad）、归一化 rms 纵向发射度（π·mm·mrad），与上文的 $(z, \delta)$ 换算一致。

### 射频场与相位的约定

> **AVAS 约定**：射频电场按 $K_e\,E(\boldsymbol r)\cos(\omega t + \varphi_0)$ 作用，射频磁场按 $K_b\,B(\boldsymbol r)\sin(\omega t + \varphi_0)$ 作用（场图中 $E$ 单位 MV/m，$B$ 单位 T）。这与 Wangler《RF Linear Accelerators》的余弦约定一致。纵向坐标 $z$ 与相位的关系为 $\Delta\varphi = -2\pi z/(\beta\lambda)$，即 $z > 0$ 的粒子在参考粒子前方、相位较小。

### 相位的三种含义（V3）

`field L R V3 type f phase Ke Kb file` 的第 3 个参数 V3 决定第 6 个参数 `phase` 的含义：

| V3 | `phase` 的含义 | 内核如何确定腔的入口相位 $\varphi_0$ |
|---|---|---|
| 0 | 同步相位 $\varphi_s$ | 求解 $\varphi_0$，使沿参考粒子轨迹的 $\operatorname{atan2}(S, C) = \varphi_s$，见[深入](#longitudinal-deep-gap)第七步 |
| 1 | 参考粒子到达元件入口时的射频相位 | $\varphi_0$ = `phase` |
| 2 | $t = 0$ 时刻的射频相位（绝对相位） | $\varphi_0 = $ `phase` $+ 360°\cdot f\cdot t_{\mathrm{in}}$，$t_{\mathrm{in}}$ 是参考粒子到达入口的时刻 |

V3 = 0 最方便设计：物理上有意义的是同步相位，入口相位由程序反求。V3 = 1 适合做相位扫描（入口相位与腔的几何直接对应）。V3 = 2 对应真实机器上"每个腔的射频相对公共参考时钟的相位"，上游元件改变时同步相位会跟着变。内核输出的 `synData.txt` 中，$\varphi_{\mathrm{RF}}$ = `phase_t0` $+ 360°\cdot f\cdot t_{\mathrm{in}}$。

例：示例腔前加一段 0.1 m 漂移，参考粒子到达腔入口的时刻 $t_{\mathrm{in}} = 0.1/(\beta c) = 5.854\ \mathrm{ns}$，$360°\,f\,t_{\mathrm{in}} = 342.45°$。V3 = 2、`phase = 0` 时入口相位为 $342.45° \equiv -17.55°$，对应同步相位约 −93.7°——这个腔几乎不加速。而 V3 = 0、`phase = -33` 时，无论前面漂移多长，入口相位都是 52.7°，同步相位保持 −33°。

> **AVAS 约定**：示例中同步相位 $-33°$ 对应的入口相位是 $52.7°$，两者之差（约 86°）取决于场图的零点位置和场分布，没有通用换算；对 V3 = 0 的腔，线性预览会给出求得的入口相位与同步相位。分段运行把一段 lattice 单独拿出来时，AVAS 从参考运行的同步粒子数据取每个腔的射频相位 $\varphi_{\mathrm{RF}}$，按 $\varphi_{\mathrm{RF}} - 360°\cdot f\cdot(t_{\mathrm{in}} - T_{\mathrm{entry}})$ 换算成以分段入口时刻为零点的 V3 = 2 相位，而不是沿用原来的相位或改成 V3 = 0。

### V3 = 0 的同步相位可能无解

V3 = 0 时同步相位按 $\varphi_s = \operatorname{atan2}(\int E\sin\varphi, \int E\cos\varphi)$ 定义。示例 hwr010（$K_e = 1.36$）在两个间隙几乎抵消的速度下，扫遍入口相位得到的 $\varphi_s$ 只覆盖一段角度（0.3 MeV 约 65°～107°，0.8 MeV 约 58°～136°，1.0 MeV 约 14°～144°）。以 $\varphi_s = -30°$ 为例（2026-11-02 用 Windows 内核核实）：

- 按线性预览，加速的 −30° 解在 0.4–0.65 MeV 与 1.1 MeV 以上存在。
- **没有加速解时，内核接受相差 180° 的解**：0.7 MeV 时入口相位 −107.7°，同步粒子减速 0.1129 MeV，`synData.txt` 仍记 $\varphi_s = -29.92°$（atan2 实为 150°）；线性预览给出 −107.79°、−0.11286 MeV。按线性预览这发生在 0.7–0.75 MeV 与 1.05 MeV（1.05 MeV 也已核实：入口相位 −165.8°，同步粒子减速 0.095 MeV，预览相差 0.02°、0.005 %）。有多个根时，内核取 $\varphi_s(\varphi_0)$ 上升分支上的那个。
- **两种解都没有时（0.15–0.35、0.8–1.0 MeV），内核拒绝运行**，报 “Initialisation stage error: … the scan phase to fail to find the corresponding RF phase”（已核实 0.3、0.8、1.0 MeV）。

线性预览先做不动点迭代（有解时都收敛），不收敛时扫描 $\varphi_0$ 并二分求根，依次找加速解、相差 180° 的解（给出"减速"警告），都没有时给出警告和可达范围，并取最接近的 $\varphi_s$。遇到这类警告时，可以改变入口能量、`Ke`，或改用 V3 = 1 直接指定入口相位。

### 能量：同步粒子与全部粒子的平均

线性预览的参考粒子与内核的同步粒子（`synData.txt`）能量相差约 0.01 %。但 **DataSet.txt 第 0 列是全部宏粒子的平均能量**：粒子离轴时在三维场图里感受到不同的 $E_z$，示例 hwr010 离轴 2 mm 处的增益比轴上高 4–6 %，内核的平均增益因此比预览高约 4.5 %（1.527 MeV 入口：0.3556 对 0.3395 MeV）；0.5 MeV 时两个间隙几乎抵消，内核平均增益反而低约 20 %。比较能量时要分清同步粒子与平均值。

### 线性预览中的纵向模型

线性预览按 1 mm 步长沿轴积分参考粒子的能量和时间，对 V3 = 0 的腔按上一小节的方法求入口相位，再以 $(z, \delta)$ 的线性聚束项和动量增加带来的阻尼推进二阶矩。它不包含纵向非线性，因而不能给出低能腔中纵向发射度的增长；rms 尺寸通常差 1–2 %。见[多粒子模拟要点](#simulation)。

### 常见问题

- **相位符号**：从其他程序移植时同步相位符号相反，束团会散开、横向反而聚焦；对照上面 ±33° 的表格判断。
- **腔的 $\beta$ 与束流不匹配**：$T(\beta)$ 很小时腔几乎不加速，且相位对能量非常敏感；先看能量增益是否合理。
- **V3 = 2 的腔在上游改动后失相**：漂移长度或上游能量改变会改变 $t_{\mathrm{in}}$，同步相位随之改变；设计阶段宜用 V3 = 0。
- **内核报 “scan phase” 错误**：V3 = 0 的同步相位在该入口能量下无解，见[上文](#longitudinal-in-avas)。
- **大相位宽度**：束团相位宽度接近分界线宽度时会出现纵向尾巴和损失，需要缩短入口束团或加大 $\lvert\varphi_s\rvert$。
