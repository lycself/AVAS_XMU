# 动手：搭一台小型超导直线加速器

只用一个螺线管和一个加速腔的场图，能不能搭出一段真正的直线加速器：既能给质子加速，又能让束流一直保持细细的一束？这一章就来动手试。

材料是示例项目 `examples/hwr010` 里的两张场图："场图"就是用计算机算好、存在文件里的元件电磁场。一张是 162.5 MHz 的半波长谐振腔 `hwr010`（长 0.21 m，负责加速），一张是螺线管 `sol`（长 0.35 m，负责聚焦）。我们分五步搭出一段质子超导加速段，每一步只加一样东西，也只讲一个道理：

1. 束流为什么会自己变粗；
2. 聚焦怎样把它收回来；
3. 加速为什么同时会让束流在横向散开；
4. 把同一个周期重复很多次，为什么能长期稳定；
5. 束流里的电荷多了（流强大了），为什么一切都会改变。

每一步都可以拖动参数，立即看到线性包络预览（一种很快的近似计算）；也可以点「用内核运行」，让 AVAS 的多粒子内核真正跑一遍，再把两种结果叠在一起比较。建议每次拖动参数之前，**先猜一猜曲线会怎样变，再看结果**。猜错的地方，正是值得回到前面章节去弄明白的地方。内核运行在沙盒里进行，不需要打开项目，也不会修改任何项目文件（详见 [在 AVAS 中](#tutorial-in-avas)）。

本章串起 [漂移段](#drift)、[螺线管](#solenoid)、[射频腔](#rf-cavity)、[纵向动力学](#longitudinal)、[lattice 设计](#lattice-design)、[匹配](#matching) 与 [空间电荷](#space-charge) 各章；整台加速器中这一段的位置见 [超导段](#journey-sc)。没读过这些章节也可以先动手，正文会用最直观的说法解释看到的现象，公式都放在后面的"深入"部分。

## 教程工具 {#tutorial-workbench}

下面的工具包含全部五个步骤。切换步骤时，你在前一步**亲手改过**的参数（比如螺线管系数、相位）会带到下一步，没改过的参数则用新步骤自己的默认值。

```avas-tutorial
build-linac
```

所有步骤的初始束流都来自示例项目的 `beam.txt`：质子，动能 $W_0 = 1.527\ \mathrm{MeV}$，速度约为光速的 5.7 %（$\beta \approx 0.057$），射频频率 162.5 MHz。入口处束流的 rms 尺寸（粒子离中心的典型距离）是 0.95 mm。束流在入口处正在发散，就像刚离开手电筒的光（用 Twiss 参数表示：$\alpha_x = -0.658$、$\beta_x = 0.377\ \mathrm{mm/mrad}$、归一化 rms 发射度 $\varepsilon_{n,x} = 0.138\ \pi\,\mathrm{mm\,mrad}$，$y$ 方向相近；$\alpha_x < 0$ 就表示正在发散，见 [漂移段](#drift-deep-matrix)）。第 1–4 步的流强是 `beam.txt` 中的 0.184 mA，第 5 步可以调节（默认 5 mA）。

> **AVAS 约定**：曲线中虚线（或只有一条曲线时）是线性包络预览，只是快速近似（rms 通常差 1–2 %，多粒子效应强时可到十几个百分点）；内核运行后出现的实线才是多粒子内核的结果，以它为准。见 [线性预览与内核](#simulation-preview)。

## 第 1 步：漂移段中的束流 {#tutorial-step1}

**这一步学什么**：没有任何力作用时，束流为什么还会变粗。

**搭什么**：只有一段漂移段 `drift L 0.02 0`，也就是一根长 $L$、半径 2 cm 的空管子。

**为什么会变粗**：每个粒子都沿直线飞，但它们的方向各不相同，就像手电筒射出的光线，走得越远分得越开。束流入口处本来就在发散（离中心越远的粒子越往外飞），所以从一开始就在变粗。

**看什么**：默认 $L = 0.8\ \mathrm{m}$，预览给出 rms $x$ 从 0.95 mm 增大到约 3.1 mm。走得远了，粗细几乎随距离直线增长（角度不变，偏离就和距离成正比）。

前进方向上也一样：漂移段里没有任何力把束团"捏"在一起，能量稍高的粒子跑得稍快，跑到前面去；能量稍低的落到后面，束团越拉越长。示例束流的 rms 动量分散约 0.35 %，rms $z$（束团长度的典型值）从约 1.3 mm 增大到约 3.1 mm。

**试一试**：先猜一猜，管子长 2 m 时束流有多粗？把 $L$ 拉到 2 m：预览中 rms $x$ 约 6.8 mm，并在 1.97 m 附近提示"3 倍 rms 超过孔径"。管子半径 20 mm，束流的 3 倍 rms 一旦碰到管壁，边缘的粒子就会丢失（经验上 rms 超过孔径的 1/3 左右就要警惕）。再用「用内核运行」比较：单纯漂移段里线性预览和内核应当很接近。

## 第 2 步：用螺线管聚焦 {#tutorial-step2}

**这一步学什么**：聚焦怎样把束流收回来，以及螺线管的聚焦为什么对磁场强弱如此敏感。

**搭什么**：在入口后放一个螺线管场图：

```text
field 0.35 0.02 0 3 0 0 0 Kb sol
```

这一行的意思是：长 0.35 m、孔径半径 2 cm 的场图元件；`3` 表示静磁场，频率与相位写 0，电场系数 `Ke` 写 0；`Kb` 是磁场系数，场图里的磁场乘以它才是实际磁场；最后的 `sol` 是场图文件名。场图 `sol` 轴上的峰值平滑后约 8.3 T（场图有噪声，个别点达 10 T），所以实际峰值磁场约为 $8.3\,K_b\ \mathrm{T}$。

**为什么能聚焦**：螺线管里的磁场主要沿着前进方向。粒子进入螺线管的入口时，那里的磁场有一点向外张开的分量，它让粒子开始绕着中心轴打转；打转的粒子在沿轴的磁场里又受到指向中心的力。两步各要用到一次磁场，所以聚焦的强弱正比于**磁场的平方**。

**看什么**：默认 $K_b = 0.35$（峰值约 2.9 T）时，束流在 $z \approx 0.6\ \mathrm{m}$（螺线管出口后约 0.2 m）处收到最细，这个最细处叫"束腰"，rms $x$ 约 0.81 mm。$K_b = 0.25$ 太弱：束流在螺线管出口附近只是停止变粗（约 1.5 mm），随后又继续变粗。$K_b = 0.45$ 太强：束腰更早、更细（约 0.42 mm），之后散开得更快，到出口反而有 3.2 mm。

**试一试**：先猜一猜，$K_b$ 从 0.25 加到 0.35，只多了 40 %，聚焦会强多少？答案是几乎翻倍：聚焦正比于磁场的平方，$1.4^2 = 1.96$，焦距从 0.51 m 缩短到 0.26 m。这种平方关系让螺线管在低能时很有效，也让它对设定误差很敏感。计算见"深入：用公式核对每一步"。

**注意**：螺线管还会让粒子绕轴转一个角度，把 $x$ 与 $y$ 两个方向搅在一起（耦合）；但对圆形的束流来说，rms $x$ 与 rms $y$ 仍然一样。螺线管同时聚焦两个方向，这也是低能段常用它的原因之一。

## 第 3 步：在腔中加速 {#tutorial-step3}

**这一步学什么**：同步相位怎样决定"加速多少"与"束团捏得多紧"之间的取舍，以及为什么前进方向上捏紧，横向上就会散开。

**搭什么**：加入一个 HWR 加速腔：

```text
field 0.21 0.02 0 1 162.5e6 phis Ke -Ke hwr010
```

`1` 表示射频场，`162.5e6` 是频率（Hz），`phis` 是同步相位 $\varphi_s$，`Ke` 与 `-Ke` 分别是电场和磁场系数（与示例一样取 $K_b = -K_e$），这一行第三个参数写 0（V3 = 0）表示第六个参数是同步相位，入口相位由内核自己求。这一步的默认值是 $K_b = 0.35$、$K_e = 1.36$。

**相位是什么**：腔里的电场以每秒 1.625 亿次的频率来回振荡，粒子什么时候穿过腔，决定了它赶上的电场有多强、指向前还是后。**同步相位**就是参考粒子（束团中心那个理想粒子）赶上的时机：$0^\circ$ 是电场最强的波峰，负值是波峰之前。在 AVAS 的约定里，电场按 $K_e E(\boldsymbol r)\cos(\omega t + \varphi_0)$、磁场按 $K_b B(\boldsymbol r)\sin(\omega t + \varphi_0)$ 变化。

**看什么**：预览中 $K_e = 1.36$ 的腔：

| $\varphi_s$ | 出口能量 (MeV) | 出口 rms $z$ (mm) |
|---|---|---|
| −60° | 1.694 | 2.15 |
| −30° | 1.884 | 1.12 |
| 0° | 2.002 | 2.43 |
| +20° | 1.995 | 5.05 |

$\varphi_s = 0$ 附近加速最多（赶上波峰），但束团被拉长了；$\varphi_s < 0$ 时加速稍少，束团却被捏紧了。这叫**相稳定性**：负的同步相位下，晚到的粒子赶上更强的电场，多得到一些能量，跑得快一些，追上参考粒子；早到的粒子得到的少，慢下来等它。正相位（$+20^\circ$）一侧正好相反，没有这种自动纠正，束团迅速变长。

代价是 [射频散焦](#longitudinal)：电场的规律决定了，前进方向上把束团捏得越紧，横向上就推得越散。预览中横向最大 rms $x$ 在 $\varphi_s = 0^\circ$ 时约 1.40 mm，$-30^\circ$ 时 1.94 mm，$-60^\circ$ 时 2.41 mm。

**试一试**：在 $-30^\circ$ 附近微调相位，观察出口能量和 rms $z$ 怎样此消彼长；然后用内核运行，比较能量（预览算的是轴上参考粒子，内核给的是全部宏粒子的平均；示例腔的平均增益比参考粒子高约 5 %，见下文「用内核运行」）和 rms $z$（差别更大，因为低能腔中纵向运动的非线性明显，线性预览不考虑纵向发射度增长）。

## 第 4 步：周期性加速段 {#tutorial-step4}

**这一步学什么**：为什么把同一个周期重复下去就能长期约束束流，以及为什么真实设计不能每个周期都用同一组参数。

**搭什么**：把「螺线管 + 漂移 + 腔 + 漂移」重复 $N$ 次，就是超导直线加速器最常见的结构：每个周期一个聚焦元件和一个加速腔。

```text
! period k
field 0.35 0.02 0 3 0 0 0 Kb sol
drift 0.1 0.02 0
field 0.21 0.02 0 1 162.5e6 phis Ke -Ke hwr010
drift 0.1 0.02 0
```

周期长度约 0.76 m。这一步的默认值比第 3 步温和：$K_b = 0.30$、$K_e = 0.8$（第 3 步是 $K_b = 0.35$、$K_e = 1.36$）。为什么要换？用第 3 步的参数重复周期，每个周期里束团在前进方向上"摆"得太快（第一个周期的纵向相移约 $128^\circ$，超过了下面说的 90° 规则），内核在 8 个周期的长束线上会有粒子跑出稳定区，rms $z$ 涨到十几毫米。

**看什么**（预览，$K_b = 0.30$、$\varphi_s = -30^\circ$、$K_e = 0.8$）：1 个周期出口约 1.73 MeV，3 个周期约 2.28 MeV，6 个周期约 3.35 MeV，8 个周期约 4.14 MeV。各周期的增益依次约为 0.21、0.25、0.30、0.33、0.36、0.38、0.39、0.40 MeV，越来越多：粒子速度升高后，越来越接近这个腔最适合的速度（$\beta \approx 0.10$），腔的渡越时间因子（衡量粒子穿过腔时能利用多少电场的系数）随之增大；第 8 个周期出口 $\beta \approx 0.094$，增益仍在缓慢增加。横向最大 rms 约 1.95 mm，第一个周期之后 rms $z$ 在约 1.1～2.1 mm 之间起伏，不再无限增长：横向和纵向都被周期性地约束住了。

**为什么能约束**：每个周期里，束流先被螺线管收拢，再在漂移段和腔里散开，下一个周期又被收拢。粒子就这样绕着中心来回摆动，而不是一去不回。每个周期粒子摆过的"角度"叫**相移**（摆一整个来回是 $360^\circ$）。设计上有几条经验（详见 [lattice 设计](#lattice-design)）：

- 每个周期的横向相移与纵向相移都应小于 90°，并避开横向和纵向运动之间的"共振"（例如二者接近相等或成简单整数比，见 Hofmann 稳定性图）。默认参数下第 1 个周期横向约 $74^\circ$～$77^\circ$、纵向约 $86^\circ$，满足这条规则。
- 随着能量升高，粒子越来越"硬"（$B\rho$ 变大，同样的螺线管弯不动它了），束团也越来越难被捏动，于是同样的 $K_b$ 聚焦变弱、腔的作用也在变化，相移逐周期下降。真实设计会逐段调整 $K_b$、$\varphi_s$ 甚至腔型；本教程为简单起见各周期用同一组参数。
- 入口束流并不匹配这个周期结构（束流的形状和通道不配套），前一两个周期的包络起伏就是失配的表现，见 [匹配](#matching)。

**试一试**：把周期数加到 8，看能量是否随周期数直线增长（不是：增益逐周期增大）；把 $K_b$ 调到 0.2 或 0.45，看包络怎样失控。两者失控的原因不同：$K_b = 0.2$ 时螺线管太弱，抵不过腔的射频散焦，几乎没有净聚焦，rms $x$ 增大到约 8.4 mm，预览提示 3 倍 rms 超过孔径；$K_b = 0.45$ 时螺线管太强，聚焦"过头"，单独就超过了周期稳定的极限，rms $x$ 增大到约 5.3 mm，$K_b = 0.5$ 时超过 20 mm。具体的相移数值见"深入：每个周期的相移与 90° 规则"。

## 第 5 步：加入束流流强 {#tutorial-step5}

**这一步学什么**：束流里的电荷怎样削弱聚焦，以及为什么低能时几个毫安就很明显。

**搭什么**：结构同第 4 步（默认 3 个周期，$K_b = 0.30$、$K_e = 0.8$），现在可以调节 `beam.txt` 中的流强 `current`。

**为什么**：质子都带正电，同种电荷互相排斥。束流越密，向外的推力越大，相当于抵消了一部分聚焦。这种效应叫**空间电荷**。粒子越慢，它越强：慢的束流在同一段管子里挤得更密，而且慢的粒子更容易被推偏。示例入口能量下，5 mA 就已经很明显。

**看什么**：预览中 3 个周期的最大 rms $x$：0.18 mA 时约 1.9 mm，5 mA 时约 3.1 mm，15 mA 时约 5.0 mm，30 mA 时约 7.1 mm。纵向最大 rms $z$ 依次约为 2.3、2.8、3.7、4.7 mm：空间电荷同样削弱纵向的"捏紧"，束团被拉长。

这一步最适合用内核验证：内核用宏粒子和网格求解束流自己的电场，能看到线性模型看不到的东西：发射度增长、束晕和束流损失（「传输效率（内核）」小于 100 % 即有粒子打到管壁）。可以把「宏粒子数」加到 5000 以上减小统计噪声，代价是运行更慢，见 [多粒子模拟要点](#simulation)。空间电荷强弱的公式见"深入：用公式核对每一步"第四步。

## 用内核运行与另存为项目 {#tutorial-engine}

「用内核运行」把当前这一步的 lattice（工具里「本步骤的 AVAS lattice」显示的文字）和修改过的 `beam.txt` 写进沙盒，用示例项目的 `input.txt`（空间电荷开启，FFT 求解）运行内核，读取 `DataSet.txt` 中的 rms 尺寸、能量和存活宏粒子数，与预览画在同一张图上。运行时间随周期数和宏粒子数增加；作为参考，示例项目（5260 个宏粒子、一个腔）在一般电脑上约需 10–30 秒。

比较时请注意：

- 预览的能量是轴上参考粒子的能量，内核曲线是全部宏粒子的平均能量。粒子离轴时感受到的加速电场与轴上不同，示例 HWR 场图在离轴 1～2 mm 处的增益比轴上高几个百分点，所以内核平均能量的增益通常比预览高约 5 %（示例的一个腔，1.5 MeV 附近），低能时差别可以更大，方向也可能相反。两者相差几十个百分点，多半是相位或场系数设置有误。
- rms 尺寸在低流强时，一个腔应相差 1 % 以内；周期多了差别会累积：内核里的粒子在非线性场中运动，横向发射度会增长（第 4 步默认的 8 个周期约 16 %），束流质心也会偏离轴线零点几毫米，线性预览都算不出来，所以 8 个周期后 rms 可差到约 10 %。流强大时差别更大，以内核为准。宏粒子少时内核结果本身也有几个百分点的统计起伏。
- 如果参数改过而没有重新运行，工具会提示内核结果属于之前的参数。

「另存为新项目」把当前这一步保存成普通 AVAS 项目并直接打开它。之后就可以在结构页里继续编辑（加输出平面、误差、诊断……），用运行页运行、结果页分析。

## 想一想 {#tutorial-think}

> **想一想 1**：第 1 步的漂移段里，发射度变了吗？
>
> 答：没有。相空间中的椭圆被"推斜"（位置随角度移动），面积不变，只是形状变了。束流变粗不是发射度增长，而是同样的相空间面积在 $x$ 方向投影得更宽。

> **想一想 2**：第 3 步中 $\varphi_s = -60^\circ$ 时纵向聚焦最强，为什么出口 rms $z$（2.15 mm）反而比 $-30^\circ$ 时（1.12 mm）大？
>
> 答：一个腔只是一次"纵向透镜"。$-60^\circ$ 时这个透镜太强，束团在腔内被压过头，到出口已经重新拉长，和第 2 步中 $K_b$ 太大时束腰提前、出口反而更粗是同一回事。

> **想一想 3**：第 4 步默认参数下，每个周期的相移满足"小于 90°"吗？
>
> 答：满足。第 1 个周期横向约 $74^\circ$～$77^\circ$、纵向约 $86^\circ$，之后逐周期下降。若沿用第 3 步的 $K_b = 0.35$、$K_e = 1.36$，第 1 个周期就是约 $90^\circ$～$94^\circ$ 和 $128^\circ$。详见"深入：每个周期的相移与 90° 规则"。

> **想一想 4**：同样 10 mA 的束流，到 100 MeV 时空间电荷会弱多少？
>
> 答：空间电荷的强度正比于 $1/(\beta\gamma)^3$（见"深入"第四步）。100 MeV 质子 $\beta\gamma \approx 0.47$，比 1.527 MeV 时大约 8.3 倍，空间电荷弱约 570 倍。这就是空间电荷主要是低能段问题的原因。

## 容易误解的地方 {#tutorial-misconceptions}

- **虚线不是结果**：虚线是线性预览，实线才是内核结果；两者在低流强时接近，流强大或纵向非线性强时可能差得多。
- **$K_b$ 不是磁场**：它是场图的系数，`sol` 场图的轴上峰值约为 $8.3\,K_b\ \mathrm{T}$。
- **各周期同一组参数不是设计**：教程为简单起见固定参数，真实的超导段会让聚焦和腔压随能量变化。
- **包络起伏不一定是问题**：前一两个周期的起伏来自入口失配，加上匹配段即可消除；越来越大的起伏才说明不稳定。

## 深入：用公式核对每一步 {#tutorial-deep-formulas}

正文只描述了现象。这一节把每一步背后的公式写出来，代入示例束流验算预览给出的数。所用的工具依次是中学的完全平方公式、洛伦兹力、能量 = 电荷 × 电压和库仑定律；每个公式的完整推导在对应的元件章节。

### 第一步：漂移段里的束流尺寸

《[漂移段](#drift-deep-matrix)》一章推出：设入口处位置平方的平均为 $\sigma_{x,0}^2$、位置与角度乘积的平均为 $\sigma_{xx',0}$、角度平方的平均为 $\sigma_{x'x',0}$，走过 $s$ 后

$$
\sigma_x^2(s) = \sigma_{x,0}^2 + 2\sigma_{xx',0}\, s + \sigma_{x'x',0}\, s^2 ,
$$

它就是 $x = x_0 + x's$ 平方后取平均（完全平方公式）。用 Twiss 参数写成 $\sigma_x(s) = \sqrt{\varepsilon\,(\beta_0 - 2\alpha_0 s + \gamma_0 s^2)}$：$\alpha_0 < 0$（正在发散）时中间一项为正，束流从一开始就变粗；$s$ 大时 $\gamma_0 s^2$ 项占主导，$\sigma_x$ 几乎正比于 $s$。代入示例（$\varepsilon = 2.41\ \mathrm{mm\,mrad}$，$\beta_0 = 0.377$，$\alpha_0 = -0.658$，$\gamma_0 = 3.80$）：$s = 0.8\ \mathrm{m}$ 时 $\sigma_x = \sqrt{2.41 \times (0.377 + 1.053 + 2.432)} = 3.05\ \mathrm{mm}$，预览给出约 3.1 mm（预览还包含 0.184 mA 的空间电荷）。

纵向：动量偏差为 $\delta = \Delta p/p$ 的粒子，每走一米与同步粒子拉开 $\delta/\gamma^2$，即 $R_{56} = L/\gamma^2$（《漂移段》的"深入：束团为什么变长"）。示例 $\gamma \approx 1.0016$，几乎就是"动量多 1 %，速度多 1 %"。

### 第二步：螺线管的焦距

《[螺线管](#solenoid)》一章给出聚焦强度 $k = B/(2B\rho)$，$B\rho$ 是磁刚度（动量 ÷ 电荷，示例质子 $B\rho \approx 0.179\ \mathrm{T\,m}$）。分母里的 2 和"两步各用一次磁场"相对应。薄透镜焦距约

$$
\frac{1}{f} \approx \int k^2\, \dd z = \int \left(\frac{B_z}{2B\rho}\right)^2 \dd z ,
$$

"$\int \dots \dd z$"的意思是沿轴把每一小段的贡献加起来。对 `sol` 场图（$K_b = 1$），沿轴求和得 $\int B_z\,\dd z = 0.729\ \mathrm{T\,m}$、$\int B_z^2\,\dd z \approx 4.04\ \mathrm{T^2\,m}$（场图噪声使后者略偏大）。乘上 $K_b^2$：

$$
\frac1f = K_b^2 \times \frac{4.04}{4 \times 0.179^2} = 31.7\,K_b^2\ \mathrm{m^{-1}} .
$$

$K_b = 0.25$、0.35、0.45 时焦距约为 0.51、0.26、0.16 m。束流绕轴旋转的角度（拉莫尔角）$\theta = \int k\,\dd z = K_b \times 0.729/(2 \times 0.179) = 2.04\,K_b$ 弧度，即约 $29^\circ$、$41^\circ$、$53^\circ$。

### 第三步：腔的能量增益与相稳定性

参考粒子的能量增益近似为（能量 = 电荷 × 电压，再乘上"赶上的时机"）

$$
\Delta W = q V_0 T \cos\varphi_s ,
$$

$V_0T$ 是腔的有效电压（见 [纵向动力学](#longitudinal)）。$\cos\varphi_s$ 在 $\varphi_s = 0$ 处最大，所以波峰加速最多；在 $\varphi_s < 0$ 一侧，$\cos$ 随相位增大而增大，晚到（相位更大）的粒子多得能量，这就是相稳定性。表中 $-30^\circ$ 的增益 0.357 MeV 与 $0^\circ$ 的 0.475 MeV 之比是 0.75，比 $\cos 30^\circ = 0.87$ 小：低能腔里粒子在腔内显著加速，有效电压本身随相位变化（见《[误差与校正](#errors-deep-rf)》）。

射频散焦来自电场的 Laplace 方程：真空里电场的"发散"和为零，前进方向上把粒子往中间推的电场分量，必然伴随横向往外推的分量。所以纵向聚焦越强，横向散焦也越强。

### 第四步：空间电荷的强度

空间电荷的强弱用**广义导流系数**衡量：

$$
K = \frac{q I}{2\pi \varepsilon_0 m c^3 (\beta\gamma)^3}
$$

（这是连续束的广义导流系数；束团束用平均电荷近似。）分子里的流强 $I$ 越大，推力越大；分母中的 $(\beta\gamma)^3$ 是三项的乘积：粒子越慢，同样的流强意味着管子里每米的电荷越多（$1/\beta$）；运动电荷还产生磁场，它的吸引抵消一部分电排斥，抵消后剩下 $1/\gamma^2$；动量越小的粒子越容易被横向推偏（$1/\beta^2\gamma$）。完整推导见 [空间电荷](#space-charge-perveance)。

代入示例入口：$\beta\gamma = 0.05708$，$(\beta\gamma)^3 = 1.86\times 10^{-4}$，5 mA 时 $K \approx 1.7\times 10^{-6}$。100 MeV 质子 $\beta\gamma \approx 0.47$，$(\beta\gamma)^3$ 大约 570 倍，同样流强的 $K$ 小约 570 倍。

### 给学过微积分和电动力学的读者

第一步是 $\Sigma_1 = M\Sigma_0M\tp$ 在漂移矩阵上的特例。螺线管的 $1/f = \int k^2\,\dd z$ 是在拉莫尔旋转坐标中、薄透镜极限下的结果，旋转坐标中 $x$、$y$ 解耦。腔的增益严格写作 $\Delta W = q\int E_z(z)\cos(\omega t(z) + \varphi_0)\,\dd z$，$T$ 是渡越时间因子；Laplace 方程 $\nabla\cdot\boldsymbol E = 0$ 给出近轴 $E_r = -\tfrac r2\,\partial E_z/\partial z$，这就是射频散焦。$K$ 出现在 KV 包络方程 $\sigma'' + k_0^2\sigma - K/(4\sigma) - \varepsilon^2/\sigma^3 = 0$ 中（这里 $\sigma$ 为 rms 尺寸），见空间电荷一章。

## 深入：每个周期的相移与 90° 规则 {#tutorial-deep-periods}

### 第一步：相移怎样算

把一个周期看成一个整体，它把入口的 $(x, x')$ 变成出口的 $(x, x')$，可以写成一张 2×2 的"换算表"（传输矩阵，见《[漂移段](#drift-deep-matrix)》）$M = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$。《[四极铁](#quadrupole-deep-fodo)》一章说明：重复同一个周期时，粒子稳定地来回摆动的条件是 $|\tfrac12(a + d)| < 1$，而每个周期的相移 $\sigma$ 满足

$$
\cos\sigma = \tfrac12\,(a + d).
$$

螺线管把 $x$、$y$ 搅在一起，所以横向要在"跟着粒子一起旋转的坐标"（拉莫尔旋转坐标）里算，那里 $x$、$y$ 又各自独立。纵向同样有一张 2×2 表，算出纵向相移。

### 第二步：默认参数的数值

按线性预览的周期传输矩阵估计（$K_b = 0.30$、$K_e = 0.8$、$\varphi_s = -30^\circ$）：第 1 个周期横向相移（拉莫尔旋转坐标中 $x$、$y$ 两个平面）约 $74^\circ$～$77^\circ$、纵向约 $86^\circ$；到第 3 个周期分别降到约 $58^\circ$～$62^\circ$ 和 $78^\circ$，第 5 个周期约 $48^\circ$～$51^\circ$ 和 $67^\circ$，横向与纵向也没有靠得太近。

若沿用第 3 步的 $K_b = 0.35$、$K_e = 1.36$，第 1 个周期是约 $90^\circ$～$94^\circ$ 和 $128^\circ$，第 3 个周期还有 $95^\circ$ 的纵向相移。对 0.18 mA 的弱流束，线性预览看不出问题（单个粒子只要求相移小于 $180^\circ$），但非线性的纵向运动已经让内核在长束线上丢失粒子。

### 第三步：为什么相移逐周期下降

$B\rho$ 随能量增大，同样的螺线管弯得动的角度变小；纵向上，束团被"捏动"的难易程度按 $\beta^3\gamma^3$ 增大。于是同样的螺线管和腔逐周期变"弱"。这正说明真实设计为什么要让 $K_b$、$K_e$ 随能量变化（[超导段](#journey-sc) 一章的束线就是逐周期加大）。

### 第四步：Kb 太弱和太强

- **$K_b = 0.2$**：螺线管单独给出的横向相移约 $57^\circ$。按"平滑近似"，射频散焦从横向相移的平方中减去纵向相移平方的一半：$\sigma_t^2 \approx \sigma_{0t}^2 - \sigma_{0l}^2/2$。纵向 $86^\circ$ 时要减去的相当于 $86^\circ/\sqrt2 \approx 61^\circ$，比螺线管能给的还多。完整的周期矩阵给出的横向相移只剩约 $11^\circ$～$25^\circ$，几乎没有净聚焦，所以 rms $x$ 增大到约 8.4 mm。
- **$K_b = 0.45$**：螺线管太强，第一个周期 $|\cos\sigma| > 1$，超过了周期稳定的极限（相当于第一步中的条件不满足），rms $x$ 增大到约 5.3 mm；$K_b = 0.5$ 时超过 20 mm。

### 给学过线性代数的读者

周期矩阵的本征值为 $e^{\pm i\sigma}$，$\operatorname{tr}M = 2\cos\sigma$；$|\operatorname{tr}M| > 2$ 时本征值为实数，其中一个模大于 1，振幅逐周期按几何级数增长。加速周期不严格辛，要先乘 $\sqrt{\beta\gamma_{\text{出}}/\beta\gamma_{\text{入}}}$ 归一化（见 [在 AVAS 中](#tutorial-in-avas) 关于辛条件的说明）。平滑近似 $\sigma_t^2 = \sigma_{0t}^2 - \sigma_{0l}^2/2$ 来自把射频散焦按周期平均成均匀的负聚焦。

## 在 AVAS 中 {#tutorial-in-avas}

### 沙盒与运行

内核运行发生在 AVAS 数据目录（`%LOCALAPPDATA%\AVAS\learn\runs\`）中的沙盒副本里，只保留最近 3 次运行，不会修改任何项目文件，也不需要先打开项目。运行期间运行页、工具栏和状态栏会显示这次运行，可以暂停或停止；此时不能开始其他模拟。

### 各步骤的 lattice

教程只用示例项目的 `hwr010`、`sol` 场图和漂移段，首尾不放矩阵元件，lattice 文字全部是 ASCII：

- 第 1 步：一段 `drift L 0.02 0`（$L$ 0.1–2 m，默认 0.8 m）。
- 第 2 步：`drift 0.05`、螺线管、螺线管后漂移段（0.05–1.5 m，默认 0.6 m）。
- 第 3–5 步：`drift 0.05`，然后 $N$ 个周期（螺线管、`drift 0.1`、HWR、`drift 0.1`；第 3 步 $N = 1$，第 4、5 步 1–8 个，默认 3 个），最后 `drift 0.2`。

参数范围：$K_b$ 0–0.8（默认 0.35，第 4、5 步 0.30），$\varphi_s$ −90° 到 +30°（默认 −30°），$K_e$ 0–2.5（默认 1.36，第 4、5 步 0.8），流强 0–30 mA（默认 5 mA），内核运行的宏粒子数 200–20000（默认 2000）。

### 束流与输入文件

束流取自示例项目的 `beam.txt`，只改两项：第 5 步的 `current`，以及内核运行使用的 `particlenumber`。`input.txt` 与 `ini.ini` 用示例项目的文件。

### 另存为新项目

「另存为新项目」只写入新的或空的文件夹，在其中创建 `InputFile/`（`beam.txt`、`input.txt`、`ini.ini`、`lattice_mulp.txt` 以及用到的场图）和 `OutputFile/`，并直接打开它。

### 周期传输矩阵的辛条件与线性预览模型

第 4 步中周期首尾都在无场漂移段中，除去腔的加速阻尼后，周期传输矩阵应当是辛矩阵，本征值的模都是 1。线性预览给出的模在 0.9996～1.0004 之间（$K_e = 0$ 时严格为 1），剩下的一点偏差来自腔：有加速时 $(x, x')$ 本来就不是正则坐标。若直接取 `sol` 场图自己的 $B_x$、$B_y$ 计算螺线管边缘的径向场，由于这两个分量与 $-\tfrac12\,\partial B_z/\partial z$ 逐点并不一致（场图的横向场比轴上场斜率所暗示的更低、更宽，见 [螺线管](#solenoid-in-avas)），本征值的模会变成 0.95 和 1.05，长束线上一个模式每周期增长约 4 %。线性预览的径向边缘场由轴上 $B_z$ 按 Maxwell 方程求出，满足辛条件。
