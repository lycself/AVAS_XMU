# 加速：从低 β 到高 β 的超导段

从 MEBT 出来，我们的质子还只有 1.527 MeV，速度是光速的 5.7 %；到终点要变成 1 GeV、光速的 87.5 %，能量涨六百多倍。这一路几乎全靠超导段。奇怪的是，它不是一根长长的加速管，而是几百只各自独立的小腔，分成形状完全不同的几族，低能处几乎每只腔后面都跟着一个螺线管。为什么用超导？为什么一族腔只能用一段？为什么腔和聚焦元件要交替排列，同步相位又为什么偏偏取在 $-30^\circ$ 到 $-20^\circ$ 附近？本章逐一回答，并且用 AVAS 示例项目的两张场图搭出这一段的开头。本章用到 [射频腔](#rf-cavity)、[纵向运动](#longitudinal) 和 [结构设计](#lattice-design) 的内容，[引导教程](#tutorial) 是本章的动手版本。

## 为什么用超导腔 {#journey-sc-why-sc}

射频腔里的电磁场在腔壁上感应出电流，电流在有电阻的壁上发热。设腔的加速电压为 $V$，壁损耗功率是

$$
P_c = \frac{V^2}{(R/Q)\,Q_0}
$$

$R/Q$（这里按直线加速器的约定 $R = V^2/P_c$；电路约定的值是它的一半）只由腔的形状决定，$Q_0$ 是固有品质因数（定义见 [射频腔](#rf-cavity)）。同一个形状，常温铜腔 $Q_0$ 约 $10^4$，超导铌腔是 $10^9$ 到 $10^{10}$，相差五六个量级。

算一个数。示例 HWR 场图在 $K_e = 1.36$ 时的电压约 1 MV，取 $R/Q = 150\ \Omega$（低 β 腔的典型量级是几十到几百欧姆，这里只作示意），连续波（CW）运行：铜腔 $Q_0 = 10^4$ 时壁损耗约 670 kW，超导腔 $Q_0 = 5\times10^9$ 时只有 1.3 W。而这只腔交给束流的功率，示例 0.18 mA 时约 65 W，10 mA 时也不过几千瓦。用 670 kW 去加速一个几十瓦到几千瓦的束流，显然不可行。超导腔的 1.3 W 是在 2–4 K 的低温下释放的，要靠制冷机搬到室温：理想卡诺机在 4.5 K 每带走 1 W 要 66 W 电功率，实际制冷机通常要几百瓦。即使这样，每只腔也只是千瓦量级以下。

所以对 CW 或高占空比的机器，超导几乎是唯一选择。它还带来两个好处：

- **孔径可以更大**。常温腔为了提高分路阻抗、减少壁损耗，要把束流孔做小；超导腔的壁损耗本来就很小，可以把孔径做大，束损风险随之下降。
- **每只腔独立供电、独立调相**。一只腔失效时，可以重新调整其余腔的相位和场幅来补偿（典型做法）。这在下一节的常温漂移管结构里做不到。

> **想一想**：既然超导这么好，为什么很多脉冲质子直线加速器仍然用常温加速结构？
> 答：壁损耗按平均功率计。脉冲机器的占空比如果只有百分之几，铜腔的平均壁损耗也降到同样比例，而峰值功率可以由脉冲射频源提供；同时超导要配低温系统，对低占空比的机器未必划算。超导的优势在 CW 和高占空比时最明显。

## 另一条路：常温漂移管直线加速器 {#journey-sc-dtl}

> **AVAS 不模拟这一段**：常温漂移管直线加速器（DTL）没有专门的模型。若有它的三维场图，原则上可以作为 `field` 元件读入，本入门不讨论。它的出口束流同样以粒子文件或 Twiss 参数交给 AVAS（见 [在 AVAS 中](#journey-sc-in-avas)）。

在超导段之外，另一种常见的低、中能加速结构是 Alvarez 型 DTL：一个很长的圆柱腔，以 TM010 模（"0 模"）工作，腔内沿轴挂着一串漂移管。0 模下所有间隙在同一时刻电场方向相同，所以质子必须在每个射频周期正好走过一个单元，单元长度等于 $\beta\lambda$。电场反向的那半个周期，质子正躲在漂移管里，感受不到减速的场。在 162.5 MHz 下这个长度在 1.527 MeV 是 105 mm，10 MeV 时 267 mm；DTL 通常工作在几百 MHz，单元更短。

漂移管里面装着四极铁，组成 FODO 一类的横向聚焦周期；低能时射频散焦和空间电荷都很强，必须每一两个单元就聚焦一次，这正是漂移管内能放四极铁的好处。DTL 的单元长度按设计的速度变化规律逐个加工，一旦造好，整个腔就只适合一种 $\beta(z)$ 曲线：腔内哪一部分场不对，都没法像独立的超导腔那样单独调相位。

## 为什么一族腔只管一段 β {#journey-sc-ttf}

[全貌](#journey-overview-velocity) 一章用渡越时间因子 $T(\beta)$ 说明了一族腔只适合一段速度：示例 HWR 场图的 $T$ 在 $\beta \approx 0.104$ 处最大，约 0.82；不低于最大值 70 % 的范围是 $\beta = 0.066$–$0.21$（约 2–22 MeV）；示例束流的 $\beta = 0.057$ 处只有 0.40。这里再追问两件事：窗口的宽度由什么决定，以及为什么低能处用两间隙的小腔、高能处用多单元的椭球腔。

先看场图本身。下面是 hwr010 的场分布，轴上 $E_z$ 有两个反号的峰，位于 $z \approx 0.074\ \mathrm{m}$ 和 $0.140\ \mathrm{m}$，相距 $d = 0.066\ \mathrm{m}$。两个间隙的场方向相反，质子要在半个射频周期里从一个间隙走到另一个，才能两次都被加速：$d = \beta\lambda/2$，即 $\beta = 2d/\lambda \approx 0.072$。$T$ 的最大值却在 0.104，原因是每个间隙自身有一定长度，单个间隙的渡越时间因子随 $\beta$ 增大而增大，乘在一起后最大值往高 β 一侧移。

```avas-field
map hwr010
```

把单个间隙的因子先放在一边，只看 $N$ 个相同间隙排成一列、相邻间隙场反向、间距 $\beta_g\lambda/2$ 的情形（$\beta_g$ 是几何 β）。速度为 $\beta$ 的质子相邻两个间隙之间的相位差是 $\pi\beta_g/\beta$，再加上场反向的 $\pi$，$N$ 个间隙的贡献相加：

$$
\frac{T(\beta)}{T_g} = \frac{1}{N}\left|\sum_{n=0}^{N-1} (-1)^n\,\ee^{\,\mathrm{i}\,n\pi\beta_g/\beta}\right|
$$

$\beta = \beta_g$ 时每一项都等于 1，和为 $N$；$\beta$ 偏离 $\beta_g$ 时各项的相位逐渐错开、互相抵消。$N$ 越大，抵消得越快：这个因子不低于 0.8 的范围，两间隙是 $\beta/\beta_g = 0.71$–$1.69$，五间隙 $0.87$–$1.17$，九间隙 $0.93$–$1.09$。这和光栅的道理完全一样：缝越多，衍射峰越窄。

再看质子每过一只腔速度变多少。在 1.527 MeV，一只腔加 0.36 MeV，$\beta$ 就从 0.0570 变到 0.0633，涨 11 %；而在 500 MeV，即使一只腔加 10 MeV，$\beta$ 也只变 0.5 %（$\dd\beta/\beta = \dd W/(mc^2\beta^2\gamma^3)$）。低能时速度变得飞快，腔必须间隙少、窗口宽，于是用两间隙的 HWR、QWR 或少间隙的轮辐腔；高能时速度几乎不变，可以用五到九个单元的椭球腔，每只腔给出大得多的电压。

常见的划分（典型值，不同装置不同）：HWR 的几何 β 在 0.1 附近；轮辐腔（spoke）在 0.2–0.5，对应约 19–145 MeV；椭球腔在 0.5 以上。我们的质子依次经过这几族腔。在 [全貌](#journey-overview-frequency) 一章里还讲了为什么换腔族时频率可以从 162.5 MHz 跳到 325 MHz、650 MHz。

## 周期：螺线管 + 腔 {#journey-sc-period}

为什么不把十几只腔连在一起，最后再聚焦一次？因为每只腔都在横向散焦束流。纵向聚焦（同步相位取负值）必然伴随横向散焦，强度 $\propto \sin(-\varphi_s)/(\beta\gamma)^3$（见 [射频腔](#rf-cavity)）。$1/(\beta\gamma)^3$ 在 1.527 MeV 是 5378，10 MeV 时 319：低能处散焦极强。按薄间隙公式粗估，下面第一个周期的腔（$K_e = 0.8$、$\varphi_s = -30^\circ$）每只的散焦强度约 $1.2\ \mathrm{m^{-1}}$，焦距不到 1 m。空间电荷又在同一处最强。所以低能段每只腔后面都要有聚焦元件。

聚焦用螺线管，有三个理由。它同时聚焦 $x$ 和 $y$，不像四极铁那样一个平面聚焦、另一个散焦，一个元件就够；它短而紧凑，可以和腔一起放在低温模块里（超导螺线管）；而且在低能处它很强。螺线管的薄透镜聚焦强度是

$$
\frac{1}{f} = \int\left(\frac{B_z}{2B\rho}\right)^2\dd z
$$

用示例场图 `sol`（$K_b = 0.30$，轴上峰值约 2.5 T）在 1.527 MeV 算出 $1/f = 2.85\ \mathrm{m^{-1}}$，焦距 0.35 m，同时束流绕轴转过 35°（拉莫尔角）。对比上面腔的散焦强度 $1.2\ \mathrm{m^{-1}}$，螺线管的聚焦有四成要用来抵消射频散焦。

但螺线管的强度按 $1/(B\rho)^2$ 下降，四极铁只按 $1/B\rho$ 下降（$k = G/B\rho$）。从 1.527 MeV 到 10 MeV，$B\rho$ 从 0.179 增到 0.458 T·m，同一螺线管的聚焦变成原来的 1/6.6，同一四极铁只变成 1/2.6；到 150 MeV 分别是 1/106 和 1/10。所以到了较高能量，聚焦改用四极铁双合透镜或 FODO，射频散焦这时也已弱得多，腔与腔之间可以隔得更远。

周期设计的核心规则是：每个周期的零流相移，横向和纵向都要小于 90°（来自包络的参数共振，推导见 [结构设计](#lattice-design)）。下面的束线是用示例场图排出的六个"螺线管 + 腔"周期，周期长 0.76 m。前两只腔 $K_e = 0.8$，中间两只 1.0，后两只 1.2；螺线管 $K_b$ 从 0.30 逐个增加到 0.40。按线性预览的周期矩阵，六个周期的纵向相移依次约为 86°、83°、89°、80°、80°、70°，横向（拉莫尔坐标中）约为 76°、77°、74°、72°、69°、67°，全都在 90° 以下（精度约 1°；有噪声的螺线管场图使预览的周期矩阵略微不辛，见 [引导教程](#tutorial-step4) 中的说明）。

> **想一想**：如果六个周期都用[引导教程](#tutorial)第 3 步单腔的 $K_e = 1.36$、$K_b = 0.35$，出口能到 4.99 MeV，比这里的 3.94 MeV 高得多。为什么这里要把前几只腔调弱？

## 同步相位：加速与稳定的折中 {#journey-sc-phase}

同步相位 $\varphi_s$ 是一根杠杆，一头是能量，一头是稳定。能量增益 $\propto\cos\varphi_s$，越靠近 0 越多；纵向稳定区的相位宽度约为 $3|\varphi_s|$，越负越宽；纵向聚焦（以及伴随的横向射频散焦）$\propto\sin(-\varphi_s)$。精确的稳定区宽度和这根杠杆的另外两头，用示例场图在头两个周期（全部 $K_e = 1.36$、$K_b = 0.35$）算出：

| $\varphi_s$ | $\cos\varphi_s$ | 稳定区相位宽度 | 两周期后能量 | 第一周期纵向相移 |
|---|---|---|---|---|
| $-20^\circ$ | 0.940 | 60° | 2.497 MeV | 107° |
| $-30^\circ$ | 0.866 | 91° | 2.374 MeV | 128° |
| $-40^\circ$ | 0.766 | 122° | 2.226 MeV | 149° |

（稳定区宽度用的是恒定参数下的分界线，见 [纵向运动](#longitudinal)；相移来自线性预览。）

$-20^\circ$ 能量多，但稳定区只有 60° 宽，而进入超导段的束团（经过 [中能传输段](#journey-mebt) 一章那段示意 MEBT 后 rms 约 5°）加上它的尾部和各种误差，需要留出足够的余量；$-40^\circ$ 稳定区宽，但 $\cos\varphi_s$ 小了 18 %（线性预览中头两个周期的能量增益实际少了 28 %，因为低能时 $V_0T$ 也随相位变化），纵向和横向射频散焦都更强。这就是为什么低能端常取 $-30^\circ$ 左右。随着加速，束团的相位宽度按绝热阻尼变窄（见 [全貌](#journey-overview-frequency)：10 MeV 时 rms 约 2.4°），可以逐渐把 $|\varphi_s|$ 减小到 $-20^\circ$ 左右，多拿能量。

下面的实验是单只 HWR 腔。把相位从 $-30^\circ$ 拖到 $-60^\circ$ 和 $0^\circ$，看能量增益、rms $z$ 和 rms $x$ 怎样此消彼长：越接近 0，能量越多，束团在纵向却越不受约束。

```avas-lab
rf-cavity phase=-30 Ke=0.8
```

> **想一想**：为什么同步相位必须是负的？取 $+30^\circ$ 能量增益不是一样吗？
> 答：$\cos$ 是偶函数，$\pm 30^\circ$ 的同步粒子增益相同；但对束团中其他粒子，结果相反。在 AVAS 的余弦约定下，$\varphi_s < 0$ 时晚到的质子相位更大、更靠近波峰，得到更多能量，追上来；早到的得到更少，慢下来：束团被纵向聚焦。$\varphi_s > 0$ 时正好反过来，束团散开。代价是纵向聚焦必然伴随横向散焦；反过来 $\varphi_s > 0$ 时横向聚焦而纵向不稳。没有一个相位能让两个方向同时聚焦，这正是要另加螺线管的原因。

## 每个周期增益多少，这一段要多长 {#journey-sc-energy-gain}

把上面的六个周期继续排下去，后面的腔用 $K_e = 1.36$，螺线管 $K_b$ 继续逐个加大，线性预览给出：约 16 个周期、12 m 后到达 10 MeV，也就是 HWR 段的典型出口能量（见 [全貌](#journey-overview-thread)）。到那里每只腔加约 0.6 MeV，纵向相移已降到约 30°，横向保持在 60°–70°。纵向相移降得这么低，说明高能端可以给一个螺线管配两只或更多腔，让每米加速更多：这是低 β 超导段常见的布局（如"螺线管–腔–腔"），见 [结构设计](#lattice-design)。

这一段的平均加速梯度（腔、螺线管和漂移一起平均）约 0.5–0.8 MeV/m，比单只腔的场强低得多：腔只占周期的不到三分之一，而且低能端的腔被调弱、$T(\beta)$ 也不在最佳处。按 [全貌](#journey-overview-thread) 中的假设（轮辐腔段平均 $E_0T = 1\ \mathrm{MV/m}$、$\varphi_s = -25^\circ$，椭球腔段 3 MV/m、$-20^\circ$）估算，从 10 MeV 到 150 MeV 约需 155 m，从 150 MeV 到 1 GeV 约需 300 m。超导段是整台加速器最长的部分。

在这一路上，我们的质子速度从 0.057 涨到 0.875，$B\rho$ 从 0.18 T·m 涨到 5.66 T·m，归一化发射度理想情况下不变，而几何发射度按 $1/(\beta\gamma)$ 缩小了 32 倍；束团以毫米计的长度变化不大，以射频相位计却从几度降到不到 1°（见 [全貌](#journey-overview-thread)）。

## 容易误解的地方 {#journey-sc-misconceptions}

**"腔的几何 β 就是质子在腔里的速度。"** 几何 β 由间隙间距决定，$T(\beta)$ 的最大值还受单个间隙长度影响，示例 hwr010 的两者分别约为 0.072 和 0.104；而一族腔实际要在两侧很宽的范围内工作。

**"同步相位越接近 0 越好，因为能量最多。"** $\varphi_s = 0$ 时纵向稳定区宽度为零，束团无法被约束。

**"一只腔的能量增益就是 $qV_0T\cos\varphi_s$，$V_0T$ 是常数。"** 在低能、单腔增益占入口能量 20 % 以上时，质子在腔里明显加速，$V_0T$ 随相位和场幅变化（见 [射频腔](#rf-cavity)）。AVAS 沿场图积分，不用这个近似。

**"螺线管只聚焦，不影响别的。"** 螺线管让横向相空间绕轴旋转（上面的例子每个周期约 35°），$x$ 与 $y$ 耦合。圆束看不出来，非圆束或有横向偏心时就会显现。横向相移要在拉莫尔坐标中计算。

**"相移小于 90° 只是横向的规则。"** 纵向同样适用；低 β 处恰恰是纵向先超标。

**"高能段聚焦变弱是坏事。"** 聚焦变弱的同时，射频散焦和空间电荷弱得更快（$\propto 1/(\beta\gamma)^3$），所以高能段可以用更长的周期、更少的聚焦元件。

## 在 AVAS 中 {#journey-sc-in-avas}

### 腔和螺线管

超导段是 AVAS 的主场，也就是示例项目 `examples/hwr010` 本身：它的 lattice 只有一只 HWR 腔（场图文件名 `efield`，与 `hwr010` 的文件内容完全相同，同步相位 $-33^\circ$），束流是 RFQ 出口的 1.527 MeV 质子。腔用射频场图（场类型 1），螺线管可以用静磁场图（场类型 3）或矩阵元件 `solenoid`，较高能量处的四极铁用 `quad` 或静磁场图。

```text
field  0.35  0.02  0  3  0        0    0     0.30   sol      ! solenoid map, Bz peak about 8.3*Kb T
field  0.21  0.02  0  1  162.5e6  -30  0.8   -0.8   hwr010   ! HWR, V3 = 0: phase is phi_s
```

```avas-params
field solenoid quad
```

> **AVAS 约定（已用内核核实）**：场图电场单位 MV/m，乘以 Ke；磁场单位 T，乘以 Kb。射频电场按 $\cos(\omega t + \varphi_0)$、射频磁场按 $\sin(\omega t + \varphi_0)$ 作用。`V3 = 0` 时 `phase` 是同步相位 $\varphi_s = \operatorname{atan2}(\int E\sin\varphi\,\dd z, \int E\cos\varphi\,\dd z)$；`V3 = 1` 是入口相位；`V3 = 2` 是 $t = 0$ 时刻的绝对相位（见 [射频腔](#rf-cavity)）。示例腔取 $K_b = -K_e$；示例螺线管场图 `sol` 轴上峰值平滑后约 $8.3\,K_b$ T。

> **AVAS 约定**：示例场图本身有噪声（沿 $z$ 的逐点起伏明显），切片图上的竖条纹是数据，不是读取错误（见 [场图](#field-maps)）。

### 周期标记与相移图

把周期结构放在 `lattice n1 n2` 与 `lattice_end` 之间（`n1` 是每个周期的元件数，`n2` 写 1），结果页的"相移"图就按周期给出每周期相移（用 DataSet 中实际束流的 Twiss β 计算，只有束流匹配时才等于结构本身的相移）。上面每个周期有 4 个元件（螺线管、漂移、腔、漂移）。详见 [结构设计](#lattice-design)。

```avas-params
lattice lattice_end
```

### 叠加场

螺线管和腔靠得很近、边缘场重叠时，用 `superpose` 让两个场在重叠区同时作用；一组叠加场中最多一个射频腔（见 [叠加场](#superpose)）。

### 束流从哪里来

超导段的入口束流来自 MEBT 的模拟结果，或者直接来自 RFQ 程序的粒子文件（`readparticledistribution`，示例为 `part_rfq.dst`），或 Twiss 参数。常温 DTL 的出口束流同样按这两种方式交给 AVAS。要把上游一段 AVAS 模拟的结果接下去，可以在上游末端用 `outputplane` 输出粒子分布。

```avas-params
beam:readparticledistribution outputplane
```

### 运行与检查

- 先用可视化编辑器的线性预览调 `Kb`、`Ke` 和相位：参考粒子能量误差约 0.01 %（内核的平均能量受离轴场影响，可差几个百分点的增益），rms 通常差 1–2 %；纵向非线性和发射度增长看不到，最终以多粒子内核为准。[引导教程](#tutorial) 可以在沙盒里直接运行内核比较。
- `input.txt` 的 `steppercycle` 是每个射频周期的积分步数，示例 50；腔相位只由 field 行的 `phase` 与 V3 决定，`scanphase` 和 `scanData.txt` 没有任何内核读取。
- `multithreading` 只能写 1 或不写：写 0 会让内核在起点丢失全部粒子（已用示例核实）。
- 分段运行时 V3 = 2 的相位要按 $\varphi_{RF} - 360^\circ\cdot f\cdot(t_{in} - T_{entry})$ 重新换算，AVAS 的分段运行会自动处理。

```avas-params
input:steppercycle input:scanphase input:multithreading
```
