# 二极铁

到目前为止，束流一直沿直线飞。可是束流总要被送到某个地方：送到不同的实验终端，送进束流收集器，或者在有限的厅里拐个弯。要让一束飞得飞快的质子转弯，用的是**二极铁**：两块磁极上下相对，中间夹着真空管，管里是一片均匀的磁场。

二极铁的任务听起来最简单，只是把束流的方向掰过一个角度。可是束流穿过二极铁以后，会出现两件意想不到的事：

1. 磁场处处一样强，没有任何"离中心越远、推得越狠"的梯度，可束流在弯转方向上却被**聚焦**了。
2. 束流变粗了多少，竟然取决于粒子的**能量**有多分散。

这两件事都来自同一个简单的事实：**每个粒子在磁场里走的都是一段圆弧**。这一章就从圆弧讲起。

先看一块二极铁做了什么。动画里束流先过 0.15 m 漂移段，再穿过一块偏转 30°、弯转半径 0.5 m 的二极铁（弧长 0.26 m），最后进入 0.5 m 的漂移段。


先点"3D"：磁铁和真空管都顺着圆弧弯过去，束流跟着转了 30°。磁铁是一块"H 形"磁铁（铁轭的截面像字母 H，上下两个磁极夹着真空管），上面是 S 极、下面是 N 极，磁场从下往上；粉色的 F 箭头是粒子受的力，指向弯转的圆心。

再看 2D 图。这里的 $x$ 不是从一条直线量起，而是从**弯曲的参考轨道**（理想粒子走的那条圆弧）量起，正方向指向弯转的外侧。所以整束粒子转了弯，图上却仍然在中间。注意三件事：

- **两条虚线**：它们是"动量比标准高 1 %"和"低 1 %"的两束粒子的中心。在二极铁里它们就从中间分开，到末端各偏了 3.2 mm。动量大的走在外侧（$+x$），动量小的走在内侧。这叫**色散**。
- **水平方向比竖直方向细**：末端 rms $x$ 是 2.7 mm，rms $y$ 是 3.4 mm。可是进二极铁时两个方向几乎一样（约 1.3 mm）。均匀磁场在弯转方向上帮了忙，这就是本章要解释的"弱聚焦"。
- **横截面里的红色箭头**：两个蓝色粒子一个偏在 $x$ 方向、一个偏在 $y$ 方向，可它们受的力方向相同，都指向 $-x$（弯转的圆心）。均匀磁场里力处处一样。聚焦到底从哪里来？后面会看到，答案在几何里。

可以拖动的参数：偏转角 α、弯转半径 ρ、场梯度指数 N、极面旋转角 β 和动能 W。每一个都对应正文里的一条结论，到那里再试。

## 二极铁用来做什么 {#dipole-role}

在直线加速器里二极铁不是主角，但在束流输运线、能量分析、束流收集器支线和注入 / 引出线中必不可少：

- **改变束流方向**：把束流引到不同的终端、靶站或束流收集器（见[高能传输段](#journey-hebt)）。
- **动量（能量）分析**：利用色散，把动量不同的粒子在空间上分开，配合一条窄缝（狭缝）就能挑出某个能量的粒子，或者测量能量分散有多大。
- **几何布局**：在有限的场地里折转束线。
- **纵向操作**：弯转段里，外侧粒子走的路长、内侧走的路短，可以用来调整束团的长短（压缩或拉伸束团）。不过对低能质子，速度差带来的拉长通常更大，详见[深入](#dipole-deep-matrix)。

## 磁场让粒子走圆弧 {#dipole-field}

### 洛伦兹力当向心力

中学物理里学过：带电粒子在磁场中运动，受到**洛伦兹力** $F = qvB$（速度和磁场垂直时），方向既垂直于速度、又垂直于磁场。力总是垂直于速度，所以它只改变方向、不改变快慢。一个大小不变、总是垂直于速度的力，正好就是匀速圆周运动的**向心力**：

$$
q\,v\,B = \frac{m\,v^2}{\rho}
\quad\Longrightarrow\quad
\rho = \frac{m v}{q B} = \frac{p}{q B}.
$$

$\rho$ 是圆的半径（**弯转半径**），$p = mv$ 是动量。把 $p/q$ 单独记作 $B\rho$，叫**磁刚度**：

$$
B\rho = \frac{p}{q}.
$$

它的意思是"这个粒子有多难被磁场掰弯"：要把它弯成半径 1 m 的圆，需要多少特斯拉。给定磁铁的场 $B$，弯转半径就是 $\rho = B\rho / B$。

代入示例质子：$m = 1.673\times 10^{-27}$ kg，$v = 1.708\times 10^{7}$ m/s（约光速的 5.7 %），$q = 1.602\times 10^{-19}$ C，得 $B\rho = 0.178$ T·m。（更准确的值是 0.1786 T·m：粒子越快，动量比 $mv$ 略大一点，这里只差 0.16 %，见[深入](#dipole-deep-geometry)。）

动画的默认设置要求 $\rho = 0.5$ m，所以磁场 $B = 0.1786/0.5 = 0.357$ T。在动画里把 ρ 拖到 1 m，磁场就只要一半（0.179 T）；把动能拖到 10 MeV，同样弯成 0.5 m 的半径要 0.916 T：越"硬"的粒子越难弯。

偏转角 $\alpha$ 和粒子在磁场里走过的弧长 $L$ 满足 $L = \rho\,\alpha$（$\alpha$ 用弧度）。动画里 $0.5\ \mathrm{m} \times 30^\circ \times \pi/180^\circ = 0.26$ m。

几个数：

| 束流 | $B\rho$ | $\rho = 1$ m 所需的 $B$ |
|---|---|---|
| 质子 35 keV（LEBT） | 0.0270 T·m | 0.027 T |
| 质子 1.527 MeV（示例） | 0.1786 T·m | 0.179 T |
| 质子 100 MeV | 1.483 T·m | 1.48 T |
| 质子 1 GeV | 5.66 T·m | 5.66 T |

铁芯常温二极铁的场一般在 1.5–2 T 以下（再强铁就饱和了），所以 1 GeV 质子要么用几米的弯转半径，要么用超导磁铁；对示例束流，0.18 T 就能做出 1 m 的弯转半径。

### 往哪边弯

用左手定则：让磁感线垂直穿入手心，四指指向正电荷运动的方向，大拇指所指就是受力方向。按 AVAS 的横截面约定（**从下游往上游看**，束流从屏幕里朝你飞出来，$x$ 向右、$y$ 向上），磁场向上（$B_y > 0$）时，正电荷受力向左（$-x$），所以向 $-x$ 偏转，圆心在左侧。下面是二极铁横截面的场（按参数算出的**示意图**，不是测量数据）：孔径里的场处处一样。这里的 `B` 只用来定符号，实际大小由 $B\rho/\rho$ 决定，图中画的是相对于轴上值的大小。

```avas-field
dipole B=0.18 N=0 rho=1 L=0.785 R=0.03
```

在动画里把 α 改成 −30°：束流转向另一边，两条色散虚线也换了边。

## 均匀场也会聚焦：两个一样大的圆 {#dipole-focusing}

### 两个半径相同的圆

现在回答开头的第一个谜题。设两个动量相同的粒子平行地射入均匀磁场，一个在参考轨道上，另一个偏向外侧一点点，距离 $x_0$。

它们动量相同、磁场相同，所以弯转半径也相同：两个圆一样大，只是第二个圆的圆心也向外挪了 $x_0$。两个一样大、圆心错开一点的圆，彼此之间的距离不是处处相等的：

- 在入口处，两条轨道相距 $x_0$；
- 转过 $90^\circ$ 时，两个圆**相交**，距离为零；
- 转过 $180^\circ$ 时，距离变成 $-x_0$，外侧的粒子跑到了内侧。

一般地，转过角度 $\theta$ 后距离是 $x_0\cos\theta$（推导见[深入](#dipole-deep-geometry)，只用到余弦定理）。距离一直在缩小，说明外侧的粒子在往参考轨道靠拢：**均匀场本身就是弯转方向上的一块透镜**。物理上的理解是：外侧的粒子绕的是一个往外挪了的圆，它在离开磁铁前转向参考轨道，好像被一股看不见的力拉了回来。其实没有这股力，每个粒子都只是老老实实地走自己的圆。这也是动画横截面里红色箭头方向相同、长度相同的原因：力确实处处一样，"聚焦"完全来自几何。

### 这块透镜有多强

按光学的定义，透镜的焦距 $f$ 是"偏转角 = 离轴距离 ÷ 焦距"中的那个 $f$。对一段转过 $\theta$ 的均匀场，得到

$$
f = \frac{\rho}{\sin\theta}.
$$

代入动画：$\rho = 0.5$ m，$\theta = 30^\circ$，$f = 1.0$ m。而[四极铁](#quadrupole)一章里 0.1 m 长、10 T/m 的四极铁焦距只有 0.18 m。二极铁的聚焦很弱，所以叫**弱聚焦**。

竖直方向呢？磁场是竖直的，粒子在竖直方向的速度分量与磁场平行，不受任何力（洛伦兹力只来自与磁场垂直的速度）。所以**竖直方向什么也没发生**，和同样长的漂移段一样。

这正是动画里看到的：进二极铁时两个方向的 rms 尺寸几乎一样（1.26 mm），出二极铁时（$z \approx 0.41$ m）rms $x$ 是 1.76 mm、rms $y$ 是 1.94 mm，到末端分别是 2.7 mm 和 3.4 mm。把 α 加大到 60°，末端 rms $y$ 变成 4.2 mm，rms $x$ 只有 3.0 mm：转得越多，弯转方向上的聚焦越多。

### 让场稍微不均匀：场梯度指数

能不能让竖直方向也得到聚焦？办法是让两块磁极不再严格平行，而是稍微张开一点，使磁场在外侧略弱、内侧略强。描述这件事的数叫**场梯度指数** $n$（AVAS 中写作 `N`）：$n = 0$ 是均匀场，$n > 0$ 表示越往外场越弱。

场变得不均匀以后，磁感线就不再是笔直的竖线，而是向外鼓出来一点。离开中间平面的粒子碰到这些斜着的磁感线，会受到一个指回中间平面的力：**竖直方向有了聚焦**。代价是水平方向的聚焦变弱了：外侧粒子走的场弱一些，转得少一些。$0 < n < 1$ 时两个方向都聚焦，$n = 0.5$ 时两个方向一样强。

下面是 $n = 0.5$ 时的场（**示意**）。在 3 cm 的孔径边缘，场只比轴上弱或强 1.5 %，场梯度指数是一个很温和的梯度。示意图同时画出了 $B_y$ 随 $x$ 的变化和那个随 $y$ 增大的水平分量 $B_x$（让磁感线向外鼓的那部分）；梯度的方向只取决于 $n$，与弯转方向无关（反向弯转时 $B_0$ 和"外侧"一起反号）。

```avas-field
dipole B=0.18 N=0.5 rho=1 L=0.785 R=0.03
```

在动画里把 N 拖到 0.5：末端 rms $x$ 变成 3.1 mm、rms $y$ 变成 2.9 mm，竖直方向比原来细了，水平方向粗了。（扣掉下一节的色散，两个方向都是 2.9 mm，正是"两个方向一样强"。）定量的推导见[深入](#dipole-deep-geometry)。

## 色散：动量不同，轨道不同 {#dipole-dispersion}

### 两个相切的圆

现在回答第二个谜题。让两个粒子从同一点、沿同一方向射入，一个是标准动量 $p$，另一个动量大一点，$p(1+\delta)$。$\delta$ 是动量的相对偏差，$\delta = 0.01$ 就是"多 1 %"。

动量大的粒子更难弯，圆的半径大了 $\rho\delta$。两个圆在入口处相切（同一点、同一方向），往后就越分越开。转过角度 $\theta$ 后，两条轨道之间的距离和夹角是

$$
\Delta x = \rho\,(1-\cos\theta)\,\delta,\qquad \Delta x' = \sin\theta\,\delta .
$$

（推导同样在[深入](#dipole-deep-geometry)。）$\Delta x'$ 是两条轨道的夹角，用弧度。系数 $D = \rho(1-\cos\theta)$ 和 $D' = \sin\theta$ 就是二极铁出口的**色散**：每 1（也就是每 100 %）的动量偏差带来的位置和角度偏移。

代入动画：$\rho = 0.5$ m，$\theta = 30^\circ$，$D = 0.5\times(1 - 0.866) = 0.067$ m，$D' = 0.5$。动量多 1 % 的粒子在二极铁出口向外偏 0.67 mm，而且带着 5 mrad 的角度继续往外走。走过 0.5 m 漂移段，又多偏 $0.5\ \mathrm{m}\times 5\ \mathrm{mrad} = 2.5$ mm，到末端一共 3.2 mm，正是动画里虚线末端的偏移。把 α 拖到 60°，末端偏移变成 6.8 mm；拖到 90°，变成 10.0 mm。

这说明了一件重要的事：**色散在二极铁里产生，却在下游的漂移段里继续长大**，直到被专门的结构消掉。

### 色散让束流变粗

束流里的粒子动量并不完全相同。示例束流的动量相对偏差的 rms 值（**动量分散**）是 $\sigma_\delta = 3.5\times 10^{-3}$，也就是 0.35 %。于是每个粒子除了自己原来的偏移，还要按自己的 $\delta$ 再挪动 $D\,\delta$。两种偏移彼此无关，按统计学，rms 值按平方相加：

$$
\sigma_x^2 = \sigma_{x,\beta}^2 + D^2\,\sigma_\delta^2 .
$$

$\sigma_{x,\beta}$ 是没有色散时的尺寸（加速器里叫 **betatron 部分**，即粒子围绕参考轨道的横向振荡）。动画末端 $D = 0.317$ m，$D\sigma_\delta = 1.1$ mm；betatron 部分是 2.44 mm；合起来 $\sqrt{2.44^2 + 1.1^2} = 2.7$ mm，正是动画给出的末端 rms $x$。

下面这条束线换成偏转 45°、$\rho = 1$ m 的扇形二极铁（前后各一个极面旋转角为 0 的 edge，见[下一节](#dipole-edge)），后接 0.5 m 漂移段；3D 视图中可以看到束线转弯。这里的线性预览包含示例束流 0.184 mA 的空间电荷。在二极铁出口（$z \approx 0.99$ m），弯转平面的 rms $x$ 是 3.2 mm，比 rms $y$ 的 3.7 mm 小，这是弱聚焦；到漂移段末端，rms $x$ 为 4.4 mm，其中按平方相减约 2.2 mm 来自色散：如果束流没有动量分散，这里的 rms $x$ 是 3.8 mm。

```avas-beamline
drift 0.2 0.03 0
edge 0 0.03 0 0 1 0 0 0 0
bend 0 0.03 0 45 1 0 0
edge 0 0.03 0 0 1 0 0 0 0
drift 0.5 0.03 0
```

45°、$\rho = 1$ m 时出口 $D = 0.293$ m：动量高 1 % 的粒子向外偏 2.9 mm，是示例束流起始 rms 尺寸（约 1 mm）的三倍。到漂移段末端 $D = 0.293 + 0.5\times 0.707 = 0.646$ m，$D\sigma_\delta = 2.3$ mm（预览中平方相减得到约 2.2 mm，差别来自空间电荷的耦合）。$90^\circ$ 时 $D = \rho = 1$ m；$180^\circ$ 时 $D = 2\rho = 2$ m 且 $D' = 0$：磁谱仪在 $180^\circ$ 处既成像又有最大的色散。

### 消色散

色散不消掉，下游所有元件看到的束流都会多出这一截。让 $D$ 和 $D'$ 在弯转段出口同时为零的布局叫**消色散**（achromat）。一个例子：两块相同的二极铁中间放一块四极铁，让中点处 $D' = 0$（两条色散轨道在中点平行于参考轨道）；由左右对称，出口的色散就和入口一样为零。

## 极面转一个角度：把聚焦挪到另一个平面 {#dipole-edge}

### 改变粒子在场里走的路

上面的二极铁叫**扇形磁铁**：磁场区像一块楔子（扇形），入口和出口的磁极端面（**极面**）都垂直于参考轨道。外侧的粒子在场里走的路更长、转得更多，所以向中心回归，这就是弱聚焦的另一种说法。

如果把极面转过一个角度 $\beta$（**极面旋转角**），外侧粒子在场里走的路就会变短或变长，偏转也随之变少或变多。离轴越远，变化越大，而且正好和离轴距离成正比：这就相当于在磁铁的入口和出口各加了一块薄透镜。按通行的约定，$\beta > 0$ 时外侧粒子在场里的路变短、偏转变少，弯转方向**散焦**，抵消一部分弱聚焦。

另一个方向也受影响。在磁铁边缘，磁场从满值逐渐减弱到零（这段叫**边缘场**），磁感线在这里向外弯；离开中间平面的粒子会碰到这些弯曲的磁感线。极面倾斜时，这股弯曲磁场有一部分与粒子速度垂直，产生竖直方向的力：$\beta > 0$ 时把粒子推回中间平面，竖直方向**聚焦**。

两个方向的作用一样大、符号相反：边缘就像一块薄的四极铁。这又是四极铁一章里"一个方向聚焦多少，另一个方向就散焦多少"的规律。

### 矩形磁铁

一个重要的特例：两端极面互相平行，都与入射轨道成 $\theta/2$ 的角，叫**矩形磁铁**（磁场区是一个长方形）。它相当于扇形磁铁两端各加 $\beta = \theta/2$。各处的粒子在场里走的路差不多一样长，水平方向的弱聚焦被完全抵消，而竖直方向得到了聚焦。

在动画里把极面旋转角拖到 15°（30° 磁铁的一半）：末端 rms $x$ 从 2.7 mm 变成 3.5 mm，rms $y$ 从 3.4 mm 变成 2.5 mm，聚焦从水平挪到了竖直。

把开头那条 45° 束线的两个 edge 改成 22.5°，也能看到同样的事：漂移段末端 rms $y$ 从扇形磁铁的 5.2 mm 降为 3.9 mm，rms $x$ 从 4.4 mm 增大到 5.5 mm。

```avas-beamline
drift 0.2 0.03 0
edge 0 0.03 0 22.5 1 0 0 0 0
bend 0 0.03 0 45 1 0 0
edge 0 0.03 0 22.5 1 0 0 0 0
drift 0.5 0.03 0
```

极面角不改变色散的大小（45° 矩形磁铁出口仍是 $D = 0.293$ m），但会改变它的角度 $D'$。具体的矩阵、边缘场宽度的修正和数值见[深入](#dipole-deep-edge)。

## 想一想 {#dipole-think}

> **想一想 1**：同一块二极铁，原来把 1.527 MeV 的质子弯成半径 0.5 m 的圆。如果飞来的是 H⁻ 离子（带一个负电荷，质量几乎相同），会怎样？
>
> 答：$B\rho$ 大小几乎不变，弯转半径仍是约 0.5 m，但力的方向反过来，它会弯向另一边。所以同一块磁铁可以按电荷、动量把不同的粒子分开。

> **想一想 2**：动画里两个蓝色粒子受的力完全一样，为什么束流在 $x$ 方向还是被聚焦了？
>
> 答：因为每个粒子走的是自己的圆，而圆心错开的两个一样大的圆会彼此靠近。聚焦来自圆弧的几何，不来自力的差别。

> **想一想 3**：螺线管和均匀二极铁都只有均匀场，却都能聚焦，强度都正比于 $B^2$。这是巧合吗？
>
> 答：不是。均匀场对平行于中心轨道的粒子只给出一个与位置无关的力，一阶聚焦为零；聚焦来自粒子的轨迹在场中被改变之后（二极铁里是路径长度不同，螺线管里是先产生绕轴的速度），场再作用一次，所以是二阶的。同样的场下，二极铁水平方向的 $h^2 = (B/B\rho)^2$ 正好是螺线管 $k^2 = (B/2B\rho)^2$ 的 4 倍（见[螺线管](#solenoid)）。

## 容易误解的地方 {#dipole-misconceptions}

- **"均匀场没有梯度，所以不聚焦"**：弯转平面有几何聚焦 $h^2 = 1/\rho^2$，只是比四极铁弱得多；垂直平面才真的不聚焦。
- **"色散是二极铁里的事"**：色散在二极铁里产生，但在下游的漂移段和四极铁里继续传播、增长，直到被消色散结构消掉。
- **"束流变粗是发射度增长"**：色散带来的 $D\sigma_\delta$ 是动量与位置的关联，消色散后可以恢复；它不是发射度本身，但不消掉时会表现为有效发射度增大。
- **"极面角只影响弯转平面"**：边缘同时作用于两个平面，符号相反。
- **"弯转半径只由磁铁决定"**：$\rho = B\rho/B$ 取决于束流的动量；同一块磁铁对不同能量、不同荷质比的粒子弯得不同，也正因此能做动量分析。
- **"界面上的 $z$ 是直线距离"**：经过二极铁之后，界面中的 $z$ 是沿中心轨道的路程长度。

## 深入：用圆的几何推出弱聚焦和色散 {#dipole-deep-geometry}

正文给出了三个结果：弯转平面的距离按 $x_0\cos\theta$ 变化、焦距 $f = \rho/\sin\theta$、色散 $D = \rho(1-\cos\theta)$。这一节只用中学的圆和余弦定理把它们推出来，最后一段给学过微积分的读者。

### 第一步：动量与磁刚度的准确值

正文用 $p = mv$ 算出 $B\rho = 0.178$ T·m。粒子很快时，动量要写成 $p = \gamma m v$，$\gamma = 1/\sqrt{1 - v^2/c^2}$ 是相对论因子（见[运动学](#kinematics)）。示例质子 $\gamma = 1.00163$，于是 $p$ 比 $mv$ 大 0.16 %。加速器里常用的公式是

$$
B\rho\,[\mathrm{T\,m}] = \frac{p\,[\mathrm{MeV}/c]}{299.792458\,Z},
$$

$Z$ 是电荷数。示例束流 $p = 53.55$ MeV/$c$，$B\rho = 53.55/299.79 = 0.1786$ T·m。推导 $\rho = p/(qB)$ 时只用到"力垂直于速度、大小不变"，相对论下同样成立。

### 第二步：一个有用的近似

设参考粒子绕圆心 $O$ 走半径为 $\rho$ 的圆。另一个粒子走半径为 $R$ 的圆，圆心 $C$ 离 $O$ 很近，$OC = c$。从 $O$ 出发，沿与 $OC$ 夹角为 $\phi$ 的方向画一条射线，它与第二个圆交于离 $O$ 距离 $r$ 的地方。在三角形 $O$、$C$、交点中用余弦定理：

$$
R^2 = r^2 + c^2 - 2\,r\,c\cos\phi .
$$

$c$ 很小时，$c^2$ 小得可以忽略，$r$ 又和 $R$ 差不多，于是 $r^2 - R^2 = (r - R)(r + R) \approx 2R\,(r - R)$，得到

$$
r \approx R + c\cos\phi .
$$

用一句话说：**圆心挪动一小段，圆在某个方向上就向外鼓出"挪动量在这个方向上的投影"**。下面三个结果都是这句话。

### 第三步：平行偏移的粒子

参考粒子在入口位于 $P$，离 $O$ 为 $\rho$。第二个粒子在 $P$ 外侧 $x_0$ 处平行射入，动量相同，所以 $R = \rho$，它的圆心也向外挪了 $x_0$，挪动方向就是入口处的"外侧"。参考粒子转过角度 $\theta$ 时，从 $O$ 看过去的方向与挪动方向的夹角正是 $\theta$。由第二步，两条轨道的径向距离

$$
x = x_0\cos\theta .
$$

验证：$\theta = 90^\circ$ 时为零（两圆相交），$\theta = 180^\circ$ 时为 $-x_0$。

### 第四步：带一个小角度的粒子

第二个粒子从 $P$ 出发，但向外偏了一个小角度 $x_0'$（弧度）。它的圆和参考圆一样大，只是绕 $P$ 转过了 $x_0'$，圆心因此沿参考轨道的前进方向挪了 $\rho\,x_0'$（半径乘角度就是弧长）。这个挪动方向与入口的"外侧"垂直，所以转过 $\theta$ 后它的投影是 $\rho\,x_0'\sin\theta$：

$$
x = \rho\sin\theta\;x_0' .
$$

$\theta = 180^\circ$ 时为零：从一点以各种小角度出发的粒子，转过半圈后又会聚到一点。这就是 $180^\circ$ 均匀场二极铁能"成像"的原因，早期磁谱仪就用这个原理。

### 第五步：动量偏大的粒子

第二个粒子从 $P$ 沿参考方向射入，动量是 $p(1+\delta)$，半径 $R = \rho(1+\delta)$。两个圆在 $P$ 相切，所以它的圆心在 $O$ 的另一侧（向内），离 $O$ 为 $\rho\delta$。用第二步（挪动方向与入口"外侧"相反，投影要带负号）：

$$
r \approx \rho(1+\delta) - \rho\,\delta\cos\theta ,\qquad
x = r - \rho = \rho\,(1-\cos\theta)\,\delta .
$$

这就是正文的色散 $D = \rho(1-\cos\theta)$。数值：$\rho = 0.5$ m、$\theta = 30^\circ$ 时 $D = 0.067$ m；$\rho = 1$ m、$\theta = 45^\circ$ 时 $D = 0.293$ m；$\theta = 90^\circ$ 时 $D = \rho$，$180^\circ$ 时 $D = 2\rho$。

### 第六步：从位置到角度，得到焦距

粒子的角度 $x'$ 是位置 $x$ 随路程 $s$ 的变化率。参考粒子走过的路程 $s = \rho\theta$。用中学导数（$\cos\theta$ 的导数是 $-\sin\theta$，$\sin\theta$ 的导数是 $\cos\theta$），每一项对 $s$ 求变化率就是对 $\theta$ 求导再除以 $\rho$：

- 第三步：$x' = -\dfrac{\sin\theta}{\rho}\,x_0$；
- 第四步：$x' = \cos\theta\;x_0'$；
- 第五步：$x' = \sin\theta\;\delta$，即正文的 $D' = \sin\theta$。

第一行说：平行进来、偏了 $x_0$ 的粒子出来时向轴偏转 $x_0\sin\theta/\rho$。按光学"偏转角 = 离轴距离 ÷ 焦距"，焦距 $f = \rho/\sin\theta$。动画（$\rho = 0.5$ m、$30^\circ$）是 1.0 m；45°、$\rho = 1$ m 是 1.41 m。

和四极铁比一比：四极铁的聚焦强度是 $k = G/B\rho$（单位 m⁻²），弯转平面的"弯曲强度"写成同样的形式是 $h^2 = 1/\rho^2 = (B/B\rho)^2$，$h = 1/\rho$ 叫**曲率**。示例束流在 0.18 T 中只有 1 m$^{-2}$，在动画的 0.357 T 中是 4 m$^{-2}$，而 6 T/m 的四极铁 $k = 33.6$ m$^{-2}$。$h^2$ 是场的平方，这就是"二阶"的意思。

### 第七步：竖直方向和场梯度指数

磁场竖直时，竖直方向的速度与场平行，不产生力，竖直方向是长度为 $L$ 的漂移。

场不均匀时，把轴附近的场写成

$$
B_y(x) = B_0\left(1 - n\,\frac{x}{\rho}\right),\qquad
n = -\frac{\rho}{B_0}\,\frac{\Delta B_y}{\Delta x},
$$

$x$ 从中心轨道指向曲率中心的外侧，$n$ 就是正文的场梯度指数。$n > 0$ 时外侧场弱，粒子转得少：在第六步的"弹簧"$h^2$ 上要减去 $n h^2$。另一方面，[四极铁](#quadrupole-deep-field)一章证明过，没有电流的地方磁场"不打旋"，水平方向的梯度 $\Delta B_y/\Delta x$ 必然伴随一个同样大小的竖直梯度 $\Delta B_x/\Delta y$，也就是 $B_x = -n B_0\,y/\rho$：$n > 0$ 时磁感线向外鼓，离开中间平面的粒子被推回去，竖直方向得到强度 $n h^2$ 的聚焦。

两个方向都像弹簧振子（[四极铁](#quadrupole-deep-matrix)一章的简谐振动，时间换成路程），"弹簧系数"分别是 $(1-n)h^2$ 和 $n h^2$：

- $0 < n < 1$ 时两个都为正，两个方向都聚焦（**弱聚焦**，早期回旋加速器和同步加速器都靠它）；
- $n = 1/2$ 时两个方向一样强；
- 转一整圈（$2\pi$）对应的振荡次数是 $\nu_x = \sqrt{1-n}$、$\nu_y = \sqrt{n}$，都小于 1，所以叫"弱"。

$n = 0$ 时 $\nu_x = 1$：转一整圈正好振荡一次，与第三步的 $\cos\theta$ 一致。

### 给学过微积分的读者

在随中心轨道弯曲的 Frenet–Serret 坐标系中（$x$ 指向曲率中心外侧，$h = 1/\rho$），线性运动方程为

$$
x'' + (1-n)\,h^2\,x = h\,\delta,\qquad
y'' + n\,h^2\,y = 0 .
$$

- $(1-n)h^2$ 中的 $h^2$ 是几何（弱）聚焦。
- $-n h^2$ 与 $+n h^2$ 来自四极分量，在两个平面符号相反（又是 $k_x + k_y = 0$，只是几何项另外加在了水平方向）。
- 右边的 $h\,\delta$ 是色散源项：动量较高的粒子半径较大，偏向外侧。它的特解就是色散函数 $D(s)$，满足 $D'' + (1-n)h^2 D = h$。

由 Maxwell 方程 $\partial B_x/\partial y = \partial B_y/\partial x$，水平梯度必然伴随 $B_x = -n B_0\,y/\rho$。第三至第五步的几何结果正是这个方程在 $n = 0$ 时的齐次解与特解。

## 深入：扇形磁铁的传输矩阵与路程长度 {#dipole-deep-matrix}

上一节得到了一个粒子穿过二极铁后的位置和角度。这一节把它们整理成[漂移段](#drift-deep-matrix)那样的"换算表"（传输矩阵），并说明色散怎样在下游传播、外侧粒子为什么会落后。

### 第一步：把三种情况合成一张表

一般的粒子同时有偏移 $x_0$、角度 $x_0'$ 和动量偏差 $\delta$。运动是线性的（偏移小时各部分互不干扰），把上一节第三到第六步加起来：

$$
\begin{pmatrix} x \\ x' \\ \delta \end{pmatrix} =
\begin{pmatrix}
\cos\theta & \rho\sin\theta & \rho(1-\cos\theta)\\
-\sin\theta/\rho & \cos\theta & \sin\theta\\
0 & 0 & 1
\end{pmatrix}
\begin{pmatrix} x_0 \\ x_0' \\ \delta \end{pmatrix}.
$$

最后一行说 $\delta$ 不变（磁场不做功，动量大小不变）。表里的元素按行列编号：$R_{11} = \cos\theta$，$R_{12} = \rho\sin\theta$，$R_{21} = -\sin\theta/\rho$，第三列在完整的 6 × 6 表中叫 $R_{16}$、$R_{26}$（第 6 个坐标是 $\delta$）。动画的 30°、0.5 m 磁铁：$R_{11} = 0.866$，$R_{12} = 0.25$ m，$R_{21} = -1.0$ m⁻¹，$R_{16} = 0.067$ m，$R_{26} = 0.5$。

### 第二步：色散像一条轨道一样被传下去

**色散函数** $D(s)$ 就是"$\delta = 1$ 的粒子相对参考轨道的偏移"。它和普通粒子一样被下游元件换算：

$$
\begin{pmatrix} D \\ D' \\ 1 \end{pmatrix}_1 =
\begin{pmatrix} R_{11} & R_{12} & R_{16} \\ R_{21} & R_{22} & R_{26} \\ 0 & 0 & 1 \end{pmatrix}
\begin{pmatrix} D \\ D' \\ 1 \end{pmatrix}_0 .
$$

从无色散的直线段进入（$D_0 = D'_0 = 0$）时，出口 $D = R_{16}$、$D' = R_{26}$。接一段长度为 $\ell$ 的漂移段，表是 $\begin{pmatrix} 1 & \ell & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1\end{pmatrix}$，做一次矩阵乘法得 $D_1 = D + \ell D'$。动画：$0.067 + 0.5\times 0.5 = 0.317$ m，每 1 % 动量偏 3.17 mm；正文的 45° 束线：$0.293 + 0.5\times 0.707 = 0.646$ m。

### 第三步：为什么尺寸按平方相加

每个粒子的偏移是 $x = x_\beta + D\delta$，$x_\beta$ 是不含色散的部分。取平方再对全体粒子求平均：

$$
\langle x^2\rangle = \langle x_\beta^2\rangle + 2D\,\langle x_\beta\,\delta\rangle + D^2\langle\delta^2\rangle .
$$

束流进入弯转段时横向位置与动量无关，中间那项平均为零，于是 $\sigma_x^2 = \sigma_{x,\beta}^2 + D^2\sigma_\delta^2$。写成 Twiss 参数（见[漂移段](#drift-deep-matrix)），$\sigma_{x,\beta}^2 = \beta_x\varepsilon_x$：

$$
\sigma_x^2 = \beta_x\,\varepsilon_x + D^2\,\sigma_\delta^2 .
$$

### 第四步：路程长度——外侧粒子落在后面

色散还有纵向的一面。用 $z$ 表示粒子相对参考粒子的纵向位置（$z > 0$ 在前方）。偏在外侧 $x$ 处的粒子绕的圆半径大了 $x$，走过同样角度时路程多 $x\,\Delta\theta = x\,\Delta s/\rho$，于是它每走 $\Delta s$ 就落后 $h\,x\,\Delta s$。另一方面，动量高的粒子跑得快，每走 $\Delta s$ 向前多 $\delta\,\Delta s/\gamma^2$（这一项漂移段里也有，见[漂移段](#drift-deep-longitudinal)）。合起来，纵向位置的变化率是

$$
z' = -h\,x + \frac{\delta}{\gamma^2}.
$$

对 $\delta$ 的粒子，$x = D\delta$。沿二极铁把 $-hD$ 加起来（$D = \rho(1-\cos\theta)$ 从 0 涨到出口值），得到 45° 扇形磁铁的

$$
R_{56} = \frac{L}{\gamma^2} - \rho\,(\theta - \sin\theta) = 0.783 - 0.078 = 0.705\ \mathrm{m}.
$$

第一项（速度差）远大于第二项（路程差）：对低能质子，弯转段的纵向行为主要还是漂移段式的去聚束（见[纵向运动](#longitudinal)）。$R_{51}$、$R_{52}$ 描述入口的横向坐标对路程的影响：入口处向外偏的粒子（$x > 0$）走更长的路，$z$ 变小。

### 第五步：带场梯度指数的一般形式

令 $K_x = (1-n)h^2$、$K_y = n h^2$，$C_x, S_x$ 为 $u'' + K_x u = 0$ 的余弦、正弦解（$C_x = \cos\sqrt{K_x}L$，$S_x = \sin(\sqrt{K_x}L)/\sqrt{K_x}$，$K < 0$ 时换成双曲函数）。$n = 0$ 时 $\sqrt{K_x}L = hL = \theta$，就回到第一步。弯转平面为 $x$ 时，扇形磁铁的 $6\times 6$ 矩阵为

$$
M_{\text{bend}} =
\begin{pmatrix}
C_x & S_x & 0 & 0 & 0 & R_{16}\\
-K_x S_x & C_x & 0 & 0 & 0 & R_{26}\\
0 & 0 & C_y & S_y & 0 & 0\\
0 & 0 & -K_y S_y & C_y & 0 & 0\\
R_{51} & R_{52} & 0 & 0 & 1 & R_{56}\\
0 & 0 & 0 & 0 & 0 & 1
\end{pmatrix},
$$

其中

$$
\begin{aligned}
R_{16} &= \frac{h\,(1-C_x)}{K_x}, &
R_{26} &= h\,S_x,\\
R_{51} &= -h\,S_x, &
R_{52} &= -\frac{h\,(1-C_x)}{K_x},\\
R_{56} &= \frac{L}{\gamma^2} - \frac{h^2\,(L - S_x)}{K_x}.
\end{aligned}
$$

这与 AVAS 线性包络预览使用的扇形磁铁矩阵一致。对 $n = 0$ 的均匀场扇形磁铁，$\theta = L/\rho$：

$$
R_{16} = \rho\,(1-\cos\theta),\quad
R_{26} = \sin\theta,\quad
R_{56} = \frac{L}{\gamma^2} - \rho\,(\theta - \sin\theta),
$$

垂直方向是长度为 $L$ 的漂移，正是上一节用圆得到的结果。数值见[在 AVAS 中](#dipole-in-avas)的表。

### 给学过线性代数的读者

$R_{51}$、$R_{52}$ 由辛条件 $M\tp J M = J$ 与 $R_{16}$、$R_{26}$ 联系在一起，不是独立的：$R_{51} = R_{21}R_{16} - R_{11}R_{26}$，$R_{52} = R_{22}R_{16} - R_{12}R_{26}$。横向 2 × 2 块的行列式为 1，二极铁保持发射度；色散只是把 $\delta$ 与 $x$ 关联起来，这种关联可以被消色散结构解除。

## 深入：极面旋转的薄透镜 {#dipole-deep-edge}

正文说极面转过 $\beta$ 相当于两端各加一块薄的四极透镜。这一节把它写成数，再算矩形磁铁。

### 第一步：水平方向

极面转过 $\beta$ 以后，离参考轨道 $x$ 处的粒子遇到的极面沿前进方向挪了 $x\tan\beta$（直角三角形：对边 = 邻边 × 正切）。$\beta > 0$ 时外侧粒子在场里少走 $x\tan\beta$，少转 $x\tan\beta/\rho = h\,x\tan\beta$。少向圆心转，就是向外多偏这么多：

$$
\Delta x' = +h\tan\beta\;x .
$$

偏转与 $x$ 成正比，是一块焦距 $-1/(h\tan\beta)$ 的薄透镜（负号表示散焦），即 $R_{21} = h\tan\beta$。

### 第二步：竖直方向

在倾斜的边缘处，边缘场沿极面法线方向衰减。由"没有电流就不打旋"（$\nabla\times\boldsymbol{B} = 0$），离开中平面 $y$ 处有一个沿极面法线的水平分量，正比于 $y$。极面倾斜时，这个水平分量有一部分垂直于粒子速度，产生竖直方向的力：$\beta > 0$ 时它把粒子推回中平面。硬边（边缘场宽度为零）时它的大小与水平方向相同、符号相反，$R_{43} = -h\tan\beta$：又一次 $k_x + k_y = 0$。

### 第三步：边缘场有宽度时的修正

采用 TRANSPORT / TraceWin 的形式：

$$
M_{\text{edge}}:\qquad
R_{21} = h\tan\beta,\qquad
R_{43} = -h\tan(\beta - \psi),
$$

其他元素与单位矩阵相同。边缘场有限宽度带来的修正角为

$$
\psi = K_1\,G\,h\,\frac{1 + \sin^2\beta}{\cos\beta}\,\left(1 - K_1 K_2\,G\,h\tan\beta\right),
$$

其中 $G$ 是磁体总间隙（全间隙），$K_1$、$K_2$ 是描述边缘场形状的积分因子。$K_1 = 0$ 时 $\psi = 0$，即硬边模型。这与 AVAS 线性包络预览使用的极面边缘矩阵一致。有限宽度的边缘场削弱竖直聚焦：$\beta = 22.5^\circ$、$\rho = 1$ m、$G = 0.05$ m、$K_1 = 0.45$、$K_2 = 2.8$ 时 $\psi = 1.56^\circ$，单个边缘的竖直聚焦从 $\tan 22.5^\circ = 0.414$ m⁻¹ 降为 0.383 m⁻¹，约弱 8 %。

### 第四步：矩形磁铁

45°、$\rho = 1$ m 的扇形磁铁两端各加 $\beta = 22.5^\circ$ 的硬边：

- 水平：两块散焦薄透镜 $h\tan 22.5^\circ = 0.414$ m⁻¹ 加上扇形磁铁本身的 $R_{21} = -0.707$ m⁻¹，三张表相乘得到 $R_{11} = 1$、$R_{21} = 0$：弱聚焦被完全抵消。
- 竖直：两块聚焦薄透镜中间夹一段 0.785 m 的漂移，$R_{43} = -0.414 - 0.414 + 0.414\times 0.785\times 0.414 = -0.694$ m⁻¹（[四极铁](#quadrupole-deep-fodo)一章两块透镜的光线追迹）。
- 出口色散不变（$D = 0.293$ m），$D' = 0.828$。

带上面的边缘场修正时，垂直 $R_{43} = -0.650$ m⁻¹。

### 给学过矢量分析的读者

按 TRANSPORT 约定，$\beta > 0$ 对应极面使外侧粒子在场中路程变短。在边缘区，$\nabla\times\boldsymbol{B} = 0$ 要求离开中平面处出现沿极面法线的分量 $B_n \approx y\,\partial B_y/\partial n$；它在与速度垂直的水平方向上的投影比例为 $\sin\beta$，跨过边缘积分后给出 $\Delta y' = -h\tan\beta\;y$。修正角 $\psi$ 来自对有限宽度边缘场形状的积分展开（$K_1$、$K_2$ 即其中的两个积分，见 Brown, SLAC-75）。

## 深入：色散、空间电荷与非线性 {#dipole-deep-dynamics}

### 色散与能散耦合

二极铁把纵向的动量偏差转换为横向位置。下游所有元件"看到"的束流尺寸都包含 $D\sigma_\delta$；如果色散不在弯转段出口消掉，它会沿输运线传播，并在有加速或空间电荷的地方造成横向–纵向耦合和有效发射度增长。

### 空间电荷

在色散区，空间电荷力依赖于包含色散的总束流尺寸，还会改变色散本身（色散函数也受空间电荷散焦），强流时消色散条件需要在有流强的条件下重新调。AVAS 内核的多粒子跟踪包含这些效应，线性预览只给出零流强或线性空间电荷下的估计。本章动画不含空间电荷。

### 非线性

大动量偏差下，色散和路程长度都有二阶项（$T_{166}$、$T_{566}$ 等），磁铁的边缘场和饱和还会带来六极分量；矩阵模型只有一阶。用场图描述二极铁时，线性预览会给出警告（不模拟场图的偶极分量），以内核结果为准。

## 在 AVAS 中 {#dipole-in-avas}

### 关键字

AVAS 中二极铁由两个关键字组成：扇形磁铁本体 `bend` 和极面边缘 `edge`。

```text
edge 0 R 0 beta rho G K1 K2 HV
bend arc R 0 alpha rho N HV
edge 0 R 0 beta rho G K1 K2 HV
```

```avas-params
bend edge
```

`bend`：

- `arc`：弧长 $\lvert\alpha\rho\rvert$（m），写 0 即可，程序按 $\alpha$、$\rho$ 自动计算。
- `R`：孔径半径（m）；第三个参数保留，写 0。
- `alpha`：偏转角（°），在 HV 所选平面内。
- `rho`：中心轨道曲率半径（m）。
- `N`：场梯度指数 $n$。
- `HV`：弯转平面，0 = 水平（$x$），1 = 垂直（$y$）。HV = 1 时[传输矩阵](#dipole-deep-matrix)中 $x$ 与 $y$ 的角色互换：色散出现在 $y$ 平面，$K_y = (1-n)h^2$，$K_x = nh^2$。

`edge`：

- 第一和第三个参数保留，写 0；`R` 为孔径。
- `beta`：极面旋转角 $\beta$（°）。
- `rho`：曲率半径（m），应与相邻 `bend` 的 $\rho$ 相同。
- `G`：磁体总间隙（m）。
- `K1`、`K2`：边缘场因子；`K1 = 0` 为硬边。
- `HV`：与相邻 `bend` 相同。

> **AVAS 约定**：线性预览把 `bend` 当作不含极面角的扇形磁铁本体，极面旋转由前后各一条 `edge` 给出（与 TraceWin 的 BEND/EDGE 习惯相同）。内核中 `bend` 本身是否带有边缘作用、是否必须配 `edge`，手册没有说明，以内核为准。`bend` 与 `edge` 都是 z-code 矩阵模型元件；`edge` 长度为 0。

> **弯转方向**：线性预览（以及本章的动画和场示意图）中，$\alpha > 0$ 让正电荷粒子向 $-x$ 偏转，$x$ 指向弯转外侧，$R_{16} > 0$；$\alpha$ 取负值时 $h$ 变号，$R_{16}$ 等随之变号，即向另一侧偏转。内核与此相同（手册没有说明，2026-11-15 用内核核实，新内核的默认模式与兼容模式结果一致）：正的 $\alpha$ 使动量较高的粒子在出口处 $x > 0$，即 $+x$ 是弯转外侧、束流向 $-x$ 偏转（竖直弯转向 $-y$），3D 视图按这个方向画。

### 示例

45° 矩形二极铁，$\rho = 1$ m，水平偏转，间隙 5 cm：

```text
drift 0.000001 0.03 0
edge 0 0.03 0 22.5 1.0 0.05 0.45 2.8 0
bend 0 0.03 0 45 1.0 0 0
edge 0 0.03 0 22.5 1.0 0.05 0.45 2.8 0
drift 0.3 0.03 0
```

$K_1 = 0.45$、$K_2 = 2.8$ 是 TraceWin 文档中常见的典型值；准确值取决于磁极形状，应由实测或三维场计算拟合得到。

### 弯转段中的 z 坐标

DataSet.txt 在没有二极铁时 $z$ = 第 5 列 + 第 33 列。有二极铁时，AVAS 界面在弯转步中按步长累加路程（第 35 列标出弯转步），之后继续累加；界面上的 $z$ 因此是沿中心轨道的**路程长度** $s$，不是实验室坐标系中的直线距离。

### 典型取值

| 量 | 典型范围（低能输运线） | 说明 |
|---|---|---|
| 场强 $B$ | 0.1–1.5 T | 铁芯常温磁铁；由 $B\rho$ 和 $\rho$ 决定 |
| 曲率半径 $\rho$ | 0.3–2 m | |
| 偏转角 $\alpha$ | 10°–90° | 大角度常分成几块 |

### 数值例子：45° 扇形磁铁

示例束流（$\gamma = 1.00163$），$\rho = 1$ m，$\alpha = 45^\circ$，$L = 0.7854$ m，$B = 0.1786$ T：

| | $n = 0$ | $n = 0.5$ |
|---|---|---|
| $R_{11}$，$R_{21}$ | 0.7071，−0.7071 m⁻¹ | 0.8497，−0.3728 m⁻¹ |
| $R_{33}$，$R_{43}$ | 1，0 | 0.8497，−0.3728 m⁻¹ |
| $R_{16}$（出口 $D$） | 0.2929 m | 0.3006 m |
| $R_{26}$（出口 $D'$） | 0.7071 | 0.7456 |
| $R_{56}$ | 0.7046 m | 0.7033 m |

几点观察：

- 1 % 的动量偏差在出口产生 2.9 mm 的位置偏移，与示例束流起始的 rms 尺寸（约 1 mm）相比很大。示例束流的 rms 动量散度 $\sigma_\delta = 3.5\times 10^{-3}$，出口处色散的贡献 $D\sigma_\delta \approx 1.0$ mm；开头那条束线在出口处的 betatron 部分约 3.0 mm，按平方和相加，色散在出口只让 rms 尺寸增加约 0.15 mm：它的分量随 $D + D's$ 向下游增长（漂移段末端为 2.3 mm）。
- $R_{56}$ 中漂移项 $L/\gamma^2 = 0.783$ m 远大于弯转项 $\rho(\theta - \sin\theta) = 0.078$ m：对低能质子，弯转段的纵向行为主要还是去聚束。
- 加上 $\beta = 22.5^\circ$ 的两个硬边边缘（矩形磁铁）后，水平 $R_{21} = 0$、$R_{11} = 1$，垂直 $R_{43} = -0.694$ m⁻¹；出口色散不变（$D = 0.293$ m），$D' = 0.828$。
- 带边缘场修正（$G = 0.05$ m，$K_1 = 0.45$，$K_2 = 2.8$）时 $\psi = 1.56^\circ$，单个边缘的垂直聚焦从 $\tan 22.5^\circ = 0.414$ m⁻¹ 降为 0.383 m⁻¹，约弱 8 %。
- $n = 0.5$ 时两个平面的矩阵相同，正是"两个平面聚焦强度相同"。

本章动画（30°、$\rho = 0.5$ m，前接 0.15 m、后接 0.5 m 漂移段，无空间电荷）的默认值：$B = 0.357$ T，弧长 0.262 m，末端每 1 % 动量偏移 3.17 mm，末端 rms $x$ 2.69 mm（其中 betatron 部分 2.44 mm）、rms $y$ 3.39 mm。

### 常见问题

- 设计中有极面角却没写 `edge`：线性预览得到的是纯扇形磁铁，垂直方向没有聚焦，束流在垂直面上可能比预期大很多（内核对 `bend` 边缘的处理以内核为准，见上文约定）。
- `edge` 的 `rho` 或 `HV` 与 `bend` 不一致。
- `bend` 的 `arc` 写成角度或写错单位；写 0 最省事。
- 用实验室坐标比较弯转段的位置：界面中的 $z$ 是路程长度。
