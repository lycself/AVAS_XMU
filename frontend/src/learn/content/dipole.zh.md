# 二极铁

二极铁的任务看上去最简单：用均匀的磁场把束流的方向掰转一个角度。可是束流经过一块二极铁以后，在弯转平面里变得和另一个平面不一样了：均匀场里没有任何梯度，它却在弯转平面里聚焦；而且束流变粗了多少，还取决于粒子的能量分散。这两件事都来自同一个简单的事实——每个粒子在磁场里走的都是一段圆弧。

本章从圆弧出发，说明多强的场能把束流掰弯（磁刚度 $B\rho$）、为什么均匀场有"弱聚焦"、动量不同的粒子为什么走不同的轨道（色散），以及极面倾斜怎样在两端加上额外的聚焦。用到[线性光学](#linear-optics)和[四极铁](#quadrupole)一章的矩阵方法，以及[纵向运动](#longitudinal)中的 $\delta = \Delta p/p$；磁刚度的计算见[运动学](#kinematics)。

一个 45°、$\rho = 1$ m 的扇形二极铁（前后各一个极面旋转角为 0 的 edge），后接 0.5 m 漂移段；3D 视图中可以看到束线转弯。在二极铁出口（$z \approx 0.99$ m），弯转平面的 rms $x$ 是 3.2 mm，比 rms $y$ 的 3.7 mm 小，这是弯转平面的弱聚焦；到漂移段末端，rms $x$ 为 4.4 mm，其中按平方相减约 2.2 mm 来自色散——如果束流没有动量分散，这里的 rms $x$ 是 3.8 mm。

```avas-beamline
drift 0.2 0.03 0
edge 0 0.03 0 0 1 0 0 0 0
bend 0 0.03 0 45 1 0 0
edge 0 0.03 0 0 1 0 0 0 0
drift 0.5 0.03 0
```

## 作用与位置 {#dipole-role}

在直线加速器里二极铁不是主角，但在束流输运线、能量分析、束流收集器支线和注入 / 引出线中必不可少：

- **改变束流方向**：把束流引到不同的终端、靶站或束流收集器（见[高能传输段](#journey-hebt)）。
- **动量（能量）分析**：利用色散，把不同动量的粒子在空间上分开，配合狭缝做能量选择或测量能散。
- **几何布局**：在有限的场地中折转束线。
- **纵向操作**：弯转段的 $R_{56}$ 可以与漂移段的 $L/\gamma^2$ 相抵或相加，用于束团压缩或拉伸（低能质子束中 $L/\gamma^2$ 通常占主导）。

## 磁刚度：多强的场才能把束流掰弯 {#dipole-field}

### 圆周运动

在垂直于速度的均匀磁场 $B$ 中，洛伦兹力 $q v B$ 大小不变、方向始终垂直于速度，粒子做匀速圆周运动。向心力 $\gamma m v^2/\rho$ 由它提供：$q v B = \gamma m v^2/\rho$，即

$$
\rho = \frac{p}{qB} = \frac{B\rho}{B},\qquad
B\rho\,[\mathrm{T\,m}] = \frac{p\,[\mathrm{MeV}/c]}{299.792458\,Z}.
$$

$B\rho = p/q$ 叫**磁刚度**：它衡量束流有多"硬"，是把粒子掰成半径 1 m 的圆所需的场。偏转角 $\alpha$ 与弧长 $L$ 的关系为 $L = \rho\,\alpha$（$\alpha$ 用弧度）。几个数：

| 束流 | $B\rho$ | $\rho = 1$ m 所需的 $B$ |
|---|---|---|
| 质子 35 keV（LEBT） | 0.0270 T·m | 0.027 T |
| 质子 1.527 MeV（示例） | 0.1786 T·m | 0.179 T |
| 质子 100 MeV | 1.483 T·m | 1.48 T |
| 质子 1 GeV | 5.66 T·m | 5.66 T |

铁芯常温二极铁的场一般在 1.5–2 T 以下，所以 1 GeV 质子要么用几米的弯转半径，要么用超导磁铁；对示例束流，0.18 T 就能做出 1 m 的弯转半径。

### 往哪边弯

按 AVAS 的横截面约定（从下游往上游看，束流垂直屏幕向外，$x$ 向右、$y$ 向上），$B_y > 0$（向上）时正电荷受力 $-q v B_y\,\hat{x}$，向左（$-x$）偏转，曲率中心在左侧。下面是二极铁横截面的场（**示意**）：$n = 0$ 时孔径内场均匀。这里的 `B` 只用来定符号，实际场由 $B\rho/\rho$ 决定，图中是相对于轴上值的大小。

```avas-field
dipole B=0.18 N=0 rho=1 L=0.785 R=0.03
```

### 场梯度指数

一般的二极铁场可以在中心轨道附近展开为

$$
B_y(x) = B_0\left(1 - n\,\frac{x}{\rho} + \cdots\right),\qquad
n = -\frac{\rho}{B_0}\,\frac{\partial B_y}{\partial x}\bigg\rvert_{x=0},
$$

$x$ 从中心轨道指向曲率中心的外侧。$n$ 称为**场梯度指数**（field index），AVAS 中记为 `N`。$n = 0$ 是均匀场（极面平行）；$n \ne 0$ 的二极铁同时带有四极分量（组合作用磁铁）。由 Maxwell 方程 $\partial B_x/\partial y = \partial B_y/\partial x$，水平方向的梯度必然伴随 $B_x = -n B_0\,y/\rho$：$n > 0$ 时场线向外鼓出，离开中平面的粒子被推回中平面。

$n = 0.5$ 时场沿弯转平面线性变化（**示意**）。在 3 cm 的孔径边缘，场只比轴上弱或强 1.5 %——场梯度指数是一个很温和的梯度。注意示意图只画了 $B_y$ 随 $x$ 的变化，没有画上面那个与 $y$ 成正比的 $B_x$。

```avas-field
dipole B=0.18 N=0.5 rho=1 L=0.785 R=0.03
```

## 均匀场里的弱聚焦 {#dipole-focusing}

### 两个半径相同的圆

在均匀场里，所有动量相同的粒子都走半径相同的圆。设一个粒子与参考粒子平行射入，只是向外偏了 $x_0$：它的圆和参考粒子的圆一样大，只是圆心也偏了 $x_0$。转过角度 $\theta$ 后，两个圆在径向上的距离是 $x_0\cos\theta$：在 $90^\circ$ 处两条轨道相交，在 $180^\circ$ 处偏移变成 $-x_0$。也就是说，均匀场本身就是弯转平面里的一块透镜，传输矩阵的 $R_{11} = \cos\theta$，焦距 $f = \rho/\sin\theta$。物理上：外侧的粒子在场中走的圆弧更长，转得更多，于是向中心轨道回归。

同样，一个从参考轨道上以小角度射出的粒子，它的圆绕入射点转了一个小角度，转过 $180^\circ$ 后回到参考轨道上（$R_{12} = \rho\sin\theta = 0$）：$180^\circ$ 均匀场二极铁能把一个点成像到另一个点，这是早期磁谱仪的原理。

这种聚焦很弱：45°、$\rho = 1$ m 的扇形二极铁焦距 $\rho/\sin 45^\circ = 1.41$ m，而[四极铁](#quadrupole)一章里 0.1 m、6 T/m 的四极铁焦距只有 0.3 m。聚焦强度 $h^2 = 1/\rho^2 = (B/B\rho)^2$ 是场的二阶量，示例束流在 0.18 T 中只有 1 m$^{-2}$，而那块四极铁的 $k = 33.6$ m$^{-2}$。在垂直方向，均匀场没有任何作用，与漂移段相同。

### 运动方程

在随中心轨道弯曲的 Frenet–Serret 坐标系中（$x$ 指向曲率中心外侧，$h = 1/\rho$），线性运动方程为

$$
x'' + (1-n)\,h^2\,x = h\,\delta,\qquad
y'' + n\,h^2\,y = 0 .
$$

- $(1-n)h^2$ 中的 $h^2$ 是上面说的**几何（弱）聚焦**。
- $-n h^2$ 与 $+n h^2$ 来自四极分量，在两个平面符号相反（又是 $k_x + k_y = 0$，只是几何项另外加在了水平方向）。
- $0 < n < 1$ 时两个平面都聚焦（**弱聚焦**），$n = 1/2$ 时两个平面聚焦强度相同；一个完整回转（$2\pi$）对应的振荡数为 $\nu_x = \sqrt{1-n}$、$\nu_y = \sqrt{n}$。
- 右边的 $h\,\delta$ 是色散源项：动量较高的粒子半径较大，偏向外侧（下一节）。

> **想一想**：螺线管和均匀二极铁都只有均匀场，却都能聚焦，强度都正比于 $B^2$。这是巧合吗？
> 答：不是。均匀场对平行于中心轨道的粒子只给出一个与位置无关的力，一阶聚焦为零；聚焦来自粒子的轨迹在场中被改变之后（二极铁里是路径长度不同，螺线管里是先产生方位速度），场再作用一次，所以是二阶的。同样的场下，二极铁水平方向的 $h^2 = (B/B\rho)^2$ 正好是螺线管 $k^2 = (B/2B\rho)^2$ 的 4 倍。

## 色散：动量不同，轨道不同 {#dipole-dispersion}

### 两个相切的圆

现在让两个粒子从同一点、沿同一方向射入，一个是参考动量 $p$，另一个是 $p(1+\delta)$。后者的圆半径大了 $\rho\delta$，两个圆在入口处相切。转过角度 $\theta$ 后，两条轨道的径向距离和夹角是

$$
\Delta x = \rho\,(1-\cos\theta)\,\delta,\qquad \Delta x' = \sin\theta\,\delta .
$$

系数 $D = \rho(1-\cos\theta)$ 和 $D' = \sin\theta$ 就是二极铁出口的**色散**：每 1 的动量偏差带来的位置和角度偏移。45°、$\rho = 1$ m 时 $D = 0.293$ m：动量高 1 % 的粒子在出口向外偏 2.9 mm，是示例束流起始 rms 尺寸（约 1 mm）的三倍，与开头那张图里束流在二极铁出口已经长到的 3.2 mm 相近。$90^\circ$ 时 $D = 1$ m，$180^\circ$ 时 $D = 2\rho = 2$ m 且 $D' = 0$——磁谱仪在 $180^\circ$ 处既成像又有最大的色散。

### 色散函数

一般地，**色散函数** $D(s)$ 是动量偏差 $\delta = 1$ 的粒子的特解轨道，满足 $D'' + (1-n)h^2 D = h$。它像一条轨道一样被下游元件传输：

$$
\begin{pmatrix} D \\ D' \\ 1 \end{pmatrix}_1 =
\begin{pmatrix} R_{11} & R_{12} & R_{16} \\ R_{21} & R_{22} & R_{26} \\ 0 & 0 & 1 \end{pmatrix}
\begin{pmatrix} D \\ D' \\ 1 \end{pmatrix}_0 .
$$

从无色散的直线段进入时，出口处 $D = R_{16}$、$D' = R_{26}$。之后即使没有二极铁，色散也会在漂移段里按 $D + D' s$ 继续增长：开头那条束线末端（出口后 0.5 m）$D = 0.293 + 0.5\times 0.707 = 0.646$ m。有色散处的 rms 束流尺寸为

$$
\sigma_x^2 = \beta_x\,\varepsilon_x + D^2\,\sigma_\delta^2 .
$$

示例束流的 rms 动量散度 $\sigma_\delta = 3.5\times 10^{-3}$，所以开头那条束线末端色散的贡献 $D\sigma_\delta = 2.3$ mm（预览中平方相减得到约 2.2 mm，差别来自空间电荷的耦合）。

让 $D$ 和 $D'$ 在弯转段出口同时为零的布局称为**消色散**（achromat），例如两块相同的二极铁之间放一个四极铁，使中点处 $D' = 0$：由对称性，出口的色散和入口一样为零。

### 路程长度

色散还有纵向的一面。纵向坐标（$z > 0$ 在参考粒子前方）沿弯转段的变化率为

$$
z' = -h\,x + \frac{\delta}{\gamma^2}.
$$

第一项是路程差：外侧的粒子走更长的路，落在后面；第二项是速度差：动量高的粒子跑得快，在漂移段里也有。对 45° 扇形二极铁，$R_{56} = L/\gamma^2 - \rho(\theta - \sin\theta) = 0.783 - 0.078 = 0.705$ m：对低能质子，弯转段的纵向行为主要还是漂移段式的去聚束（见[纵向运动](#longitudinal)）。

### 动手试试

二极铁实验给出扇形磁铁矩阵、出口处的 $D$、$D'$、偏离动量粒子的轨道和 $x$、$y$ 包络（包络中不含动量分散）：

1. 用 `N=0`、`edge=0` 复现 $R_{16} = 0.293$ m；把 `angle` 改为 90 和 180，验证 $D = \rho(1-\cos\theta)$，并看 $180^\circ$ 时 $R_{21} = 0$、$D' = 0$。
2. 把 `edge` 改为 22.5（矩形磁铁，见下文），观察水平聚焦被抵消、垂直包络被约束。
3. 把 `N` 改为 0.5，比较两个平面的包络。轨道图总是同时画出 $+\delta$ 和 $-\delta$ 两个粒子（`delta` 是幅值，0–10 %）：它们从参考轨道的两侧离开；把 `delta` 加倍，两边的偏移都加倍——色散对 $\delta$ 是线性的。

```avas-lab

```

## 扇形磁铁的传输矩阵 {#dipole-matrix}

把上面的运动方程在长度 $L$ 上解出来。令 $K_x = (1-n)h^2$、$K_y = n h^2$，$C_x, S_x$ 为 $u'' + K_x u = 0$ 的余弦、正弦解（$C_x = \cos\sqrt{K_x}L$，$S_x = \sin(\sqrt{K_x}L)/\sqrt{K_x}$，$K < 0$ 时换成双曲函数）。弯转平面为 $x$ 时，扇形磁铁的 $6\times 6$ 矩阵为

$$
M_{\text{bend}} =
\begin{pmatrix}
C_x & S_x & 0 & 0 & 0 & R_{16}\\
-K_x S_x & C_x & 0 & 0 & 0 & R_{26}\\
0 & 0 & C_y & S_y & 0 & 0\\
0 & 0 & -K_y S_y & C_y & 0 & 0\\
R_{51} & R_{52} & 0 & 0 & 1 & R_{56}\\
0 & 0 & 0 & 0 & 0 & 1
\end{pmatrix},
$$

其中

$$
\begin{aligned}
R_{16} &= \frac{h\,(1-C_x)}{K_x}, &
R_{26} &= h\,S_x,\\
R_{51} &= -h\,S_x, &
R_{52} &= -\frac{h\,(1-C_x)}{K_x},\\
R_{56} &= \frac{L}{\gamma^2} - \frac{h^2\,(L - S_x)}{K_x}.
\end{aligned}
$$

这与 AVAS 线性预览的 `bend_matrix(L, angle, n_index, plane, gamma)` 一致。$R_{51}$、$R_{52}$ 由辛条件与 $R_{16}$、$R_{26}$ 联系在一起，它们描述横向坐标对路程长度的影响：入口处向外偏的粒子（$x > 0$）走更长的路，$z$ 变小。

对 $n = 0$ 的均匀场扇形磁铁，$\theta = L/\rho$：

$$
R_{16} = \rho\,(1-\cos\theta),\quad
R_{26} = \sin\theta,\quad
R_{56} = \frac{L}{\gamma^2} - \rho\,(\theta - \sin\theta),
$$

垂直方向是长度为 $L$ 的漂移——正是上两节用两个圆得到的结果。

## 极面旋转与边缘聚焦 {#dipole-edge}

### 极面转过一个角度会怎样

扇形磁铁的场区像一块楔子：入口和出口的极面都垂直于中心轨道，外侧的轨道在场里走得更长，这就是上面的几何聚焦。如果把极面转过角度 $\beta$，在 $x$ 处的粒子在场中走过的长度就多出或少掉 $x\tan\beta$，偏转角也随之改变 $h\,x\tan\beta$：这相当于在边缘处加了一块与 $x$ 成正比的薄透镜。按 TRANSPORT 的约定，$\beta > 0$ 时外侧粒子在场中的路程变短、偏转变少，弯转平面**散焦**。

另一个平面也受影响。在倾斜的边缘处，边缘场沿极面法线方向衰减，由 $\nabla\times\boldsymbol{B} = 0$，离开中平面 $y$ 处有一个沿法线的水平分量，正比于 $y$。极面倾斜时，这个水平分量有一部分垂直于粒子速度，于是产生竖直方向的力：$\beta > 0$ 时它把粒子推回中平面，另一平面**聚焦**。硬边时两个平面的作用大小相等、符号相反：边缘就是一块薄的四极透镜，又一次 $k_x + k_y = 0$。

### 边缘矩阵

采用 TRANSPORT / TraceWin 的形式：

$$
M_{\text{edge}}:\qquad
R_{21} = h\tan\beta,\qquad
R_{43} = -h\tan(\beta - \psi),
$$

其他元素与单位矩阵相同。边缘场有限宽度带来的修正角为

$$
\psi = K_1\,G\,h\,\frac{1 + \sin^2\beta}{\cos\beta}\,\left(1 - K_1 K_2\,G\,h\tan\beta\right),
$$

其中 $G$ 是磁体总间隙（全间隙），$K_1$、$K_2$ 是描述边缘场形状的积分因子。$K_1 = 0$ 时 $\psi = 0$，即硬边模型。这与线性预览的 `edge_matrix(beta, rho, gap, k1, k2, plane)` 一致。有限宽度的边缘场削弱竖直聚焦：$\beta = 22.5^\circ$、$\rho = 1$ m、$G = 0.05$ m、$K_1 = 0.45$、$K_2 = 2.8$ 时 $\psi = 1.56^\circ$，单个边缘的竖直聚焦从 $\tan 22.5^\circ = 0.414$ m⁻¹ 降为 0.383 m⁻¹，约弱 8 %。

### 矩形磁铁

**矩形磁铁**是一个重要的特例：两端极面互相平行，都与入射轨道成 $\theta/2$ 的角，相当于扇形磁铁两端各加 $\beta = \theta/2$ 的边缘。各处粒子在场里走的长度近似相同，水平方向的弱聚焦被边缘完全抵消（$R_{21} = 0$），而垂直方向获得了聚焦。45°、$\rho = 1$ m 的矩形磁铁（硬边）：水平 $R_{11} = 1$、$R_{21} = 0$，垂直 $R_{43} = -0.694$ m⁻¹；出口色散不变（$D = 0.293$ m），$D' = 0.828$。带上面的边缘场修正时，垂直 $R_{43} = -0.650$ m⁻¹。

把开头那条束线的两个 edge 改成 22.5°，比较一下：漂移段末端 rms $y$ 从扇形磁铁的 5.2 mm 降为 3.9 mm，rms $x$ 从 4.4 mm 增大到 5.5 mm——边缘把聚焦从弯转平面挪到了另一个平面。

```avas-beamline
drift 0.2 0.03 0
edge 0 0.03 0 22.5 1 0 0 0 0
bend 0 0.03 0 45 1 0 0
edge 0 0.03 0 22.5 1 0 0 0 0
drift 0.5 0.03 0
```

## 动力学效应 {#dipole-dynamics}

### 色散与能散耦合

二极铁把纵向的动量偏差转换为横向位置。下游所有元件"看到"的束流尺寸都包含 $D\sigma_\delta$；如果色散不在弯转段出口消掉，它会沿输运线传播，并在有加速或空间电荷的地方造成横向–纵向耦合和有效发射度增长。

### 空间电荷

在色散区，空间电荷力依赖于包含色散的总束流尺寸，还会改变色散本身（色散函数也受空间电荷散焦），强流时消色散条件需要在有流强的条件下重新调。AVAS 内核的多粒子跟踪包含这些效应，线性预览只给出零流强或线性空间电荷下的估计。

### 非线性

大动量偏差下，色散和路程长度都有二阶项（$T_{166}$、$T_{566}$ 等），磁铁的边缘场和饱和还会带来六极分量；矩阵模型只有一阶。用场图描述二极铁时，线性预览会给出警告（不模拟场图的偶极分量），以内核结果为准。

## 容易误解的地方 {#dipole-misconceptions}

- **"均匀场没有梯度，所以不聚焦"**：弯转平面有几何聚焦 $h^2$，只是比四极铁弱得多；垂直平面才真的不聚焦。
- **"色散是二极铁里的事"**：色散在二极铁里产生，但在下游的漂移段和四极铁里继续传播、增长，直到被消色散结构消掉。
- **"束流变粗是发射度增长"**：色散带来的 $D\sigma_\delta$ 是动量与位置的关联，消色散后可以恢复；它不是发射度本身，但不消掉时会表现为有效发射度增大。
- **"极面角只影响弯转平面"**：边缘同时作用于两个平面，符号相反。
- **"弯转半径只由磁铁决定"**：$\rho = B\rho/B$ 取决于束流的动量；同一块磁铁对不同能量、不同荷质比的粒子弯得不同，也正因此能做动量分析。
- **"界面上的 $z$ 是直线距离"**：经过二极铁之后，界面中的 $z$ 是沿中心轨道的路程长度。

## 在 AVAS 中 {#dipole-in-avas}

### 关键字

AVAS 中二极铁由两个关键字组成：扇形磁铁本体 `bend` 和极面边缘 `edge`。

```text
edge 0 R 0 beta rho G K1 K2 HV
bend arc R 0 alpha rho N HV
edge 0 R 0 beta rho G K1 K2 HV
```

```avas-params
bend edge
```

`bend`：

- `arc`：弧长 $\lvert\alpha\rho\rvert$（m），写 0 即可，程序按 $\alpha$、$\rho$ 自动计算。
- `R`：孔径半径（m）；第三个参数保留，写 0。
- `alpha`：偏转角（°），在 HV 所选平面内。
- `rho`：中心轨道曲率半径（m）。
- `N`：场梯度指数 $n$。
- `HV`：弯转平面，0 = 水平（$x$），1 = 垂直（$y$）。HV = 1 时上述矩阵中 $x$ 与 $y$ 的角色互换：色散出现在 $y$ 平面，$K_y = (1-n)h^2$，$K_x = nh^2$。

`edge`：

- 第一和第三个参数保留，写 0；`R` 为孔径。
- `beta`：极面旋转角 $\beta$（°）。
- `rho`：曲率半径（m），应与相邻 `bend` 的 $\rho$ 相同。
- `G`：磁体总间隙（m）。
- `K1`、`K2`：边缘场因子；`K1 = 0` 为硬边。
- `HV`：与相邻 `bend` 相同。

> **AVAS 约定**：线性预览把 `bend` 当作不含极面角的扇形磁铁本体，极面旋转由前后各一条 `edge` 给出（与 TraceWin 的 BEND/EDGE 习惯相同）。内核中 `bend` 本身是否带有边缘作用、是否必须配 `edge`，手册没有说明，以内核为准。`bend` 与 `edge` 都是 z-code 矩阵模型元件；`edge` 长度为 0。

> 注意：线性预览中 $\alpha$ 取负值时 $h$ 变号，$R_{16}$ 等随之变号，即向另一侧偏转。内核中正的 $\alpha$ 究竟朝 $+x$ 还是 $-x$ 偏转，手册没有说明；需要时用单粒子内核运行确认。

### 示例

45° 矩形二极铁，$\rho = 1$ m，水平偏转，间隙 5 cm：

```text
drift 0.000001 0.03 0
edge 0 0.03 0 22.5 1.0 0.05 0.45 2.8 0
bend 0 0.03 0 45 1.0 0 0
edge 0 0.03 0 22.5 1.0 0.05 0.45 2.8 0
drift 0.3 0.03 0
```

$K_1 = 0.45$、$K_2 = 2.8$ 是 TraceWin 文档中常见的典型值；准确值取决于磁极形状，应由实测或三维场计算拟合得到。

### 弯转段中的 z 坐标

DataSet.txt 在没有二极铁时 $z$ = 第 5 列 + 第 33 列。有二极铁时，AVAS 界面在弯转步中按步长累加路程（第 35 列标出弯转步），之后继续累加；界面上的 $z$ 因此是沿中心轨道的**路程长度** $s$，不是实验室坐标系中的直线距离（见 AGENTS.md §6 与 `dataset_stream.PathLength`）。

### 典型取值

| 量 | 典型范围（低能输运线） | 说明 |
|---|---|---|
| 场强 $B$ | 0.1–1.5 T | 铁芯常温磁铁；由 $B\rho$ 和 $\rho$ 决定 |
| 曲率半径 $\rho$ | 0.3–2 m | |
| 偏转角 $\alpha$ | 10°–90° | 大角度常分成几块 |
| 场梯度指数 $n$ | 0；分析磁铁常用 0.5 | 0 < n < 1 两平面弱聚焦 |
| 极面角 $\beta$ | 0 至 $\alpha/2$ 量级 | 用于平衡两个平面的聚焦 |
| 间隙 $G$ | 0.03–0.1 m | |

### 数值例子：45° 扇形磁铁

示例束流（$\gamma = 1.00163$），$\rho = 1$ m，$\alpha = 45^\circ$，$L = 0.7854$ m，$B = 0.1786$ T：

| | $n = 0$ | $n = 0.5$ |
|---|---|---|
| $R_{11}$，$R_{21}$ | 0.7071，−0.7071 m⁻¹ | 0.8497，−0.3728 m⁻¹ |
| $R_{33}$，$R_{43}$ | 1，0 | 0.8497，−0.3728 m⁻¹ |
| $R_{16}$（出口 $D$） | 0.2929 m | 0.3006 m |
| $R_{26}$（出口 $D'$） | 0.7071 | 0.7456 |
| $R_{56}$ | 0.7046 m | 0.7033 m |

几点观察：

- 1 % 的动量偏差在出口产生 2.9 mm 的位置偏移，与示例束流起始的 rms 尺寸（约 1 mm）相比很大。示例束流的 rms 动量散度 $\sigma_\delta = 3.5\times 10^{-3}$，出口处色散的贡献 $D\sigma_\delta \approx 1.0$ mm；开头那条束线在出口处的 betatron 部分约 3.0 mm，按平方和相加，色散在出口只让 rms 尺寸增加约 0.15 mm——它的分量随 $D + D's$ 向下游增长（漂移段末端为 2.3 mm）。
- $R_{56}$ 中漂移项 $L/\gamma^2 = 0.783$ m 远大于弯转项 $\rho(\theta - \sin\theta) = 0.078$ m：对低能质子，弯转段的纵向行为主要还是去聚束。
- 加上 $\beta = 22.5^\circ$ 的两个硬边边缘（矩形磁铁）后，水平 $R_{21} = 0$、$R_{11} = 1$，垂直 $R_{43} = -0.694$ m⁻¹；出口色散不变（$D = 0.293$ m），$D' = 0.828$。
- 带边缘场修正（$G = 0.05$ m，$K_1 = 0.45$，$K_2 = 2.8$）时 $\psi = 1.56^\circ$，单个边缘的垂直聚焦从 $\tan 22.5^\circ = 0.414$ m⁻¹ 降为 0.383 m⁻¹，约弱 8 %。
- $n = 0.5$ 时两个平面的矩阵相同，正是"两个平面聚焦强度相同"。

### 常见问题

- 设计中有极面角却没写 `edge`：线性预览得到的是纯扇形磁铁，垂直方向没有聚焦，束流在垂直面上可能比预期大很多（内核对 `bend` 边缘的处理以内核为准，见上文约定）。
- `edge` 的 `rho` 或 `HV` 与 `bend` 不一致。
- `bend` 的 `arc` 写成角度或写错单位；写 0 最省事。
- 用实验室坐标比较弯转段的位置：界面中的 $z$ 是路程长度。
