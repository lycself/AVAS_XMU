# 校正铁

实际加速器里的每一块四极铁、每一个螺线管和腔体都有零点几毫米的安装误差，束流中心因此一点点偏离设计轴线。校正铁（steerer，又称偶极校正器、导向磁铁）只是一个弱的二极场，给束流中心一个零点几毫弧度的小偏转。它不改变束流的大小，却决定了束流会不会擦到管壁上。那么：多大的场能把偏了 1 mm 的束流拉回来？同样的偏转放在哪里最有效？为什么校正铁总是成对使用？

本章先算出一个偏转有多大，再看它在下游怎样随 betatron 振荡传播，最后说明沿线的校正铁和束流位置探测器（BPM）怎样配合，把束流"拉回"轴线附近。用到[四极铁](#quadrupole)和[二极铁](#dipole)中的偏转与传输矩阵，以及[线性光学](#linear-optics)的 beta 函数和相移；误差的来源和 AVAS 的误差、校正命令在[误差与校正](#errors)一章中系统介绍。

校正铁长度为 0，作用于其后的元件（这里是 0.2 m 漂移段）：$B_y = 1$ mT 在 0.2 m 上的积分场是 $2\times 10^{-4}$ T·m，使示例束流偏转 1.12 mrad，到束线末端（偏转中心之后 0.5 m）束流中心偏移约 0.56 mm，约为该处 rms 尺寸（2.8 mm）的五分之一。包络图只画 rms 尺寸，与去掉校正铁时完全相同，看不出这个偏移。

```avas-beamline
drift 0.1 0.02 0
steerer 0 0.02 0 0 0.001 0 0.002
drift 0.2 0.02 0
drift 0.4 0.02 0
```

## 作用与位置 {#steerer-role}

- **轨道校正**：抵消元件错位、磁场误差和初始束流偏移造成的轨道畸变，降低因中心偏离而带来的束损和有效发射度增长。
- **束流对中**：让束流穿过四极铁、螺线管和腔体的电中心，避免偏心通过带来的额外偏转（四极铁）、耦合（螺线管）或横向 RF 踢（腔体）。
- **局部凸轨（bump）**：用 3–4 个校正铁在局部制造一段受控的轨道偏移，例如绕开障碍或扫描孔径。
- **位置**：通常紧邻四极铁或嵌入四极铁 / 螺线管线圈内（超导螺线管内常附带偶极校正线圈），与 BPM 交错分布，每个平面每个聚焦周期至少一个。

## 一个小角度的偏转 {#steerer-field}

### 磁场校正铁

校正铁内的场近似均匀，横向分量为 $B_x$、$B_y$。对沿 $+z$ 运动的粒子，$\boldsymbol{F} = q\boldsymbol{v}\times\boldsymbol{B}$ 给出

$$
F_x = -q v B_y,\qquad F_y = q v B_x .
$$

$B_y$ 使粒子在 $x$ 方向偏转，$B_x$ 使粒子在 $y$ 方向偏转：场和偏转方向互相垂直。在 AVAS 的横截面图中（从下游往上游看，束流垂直屏幕向外，$x$ 向右、$y$ 向上），$B_y > 0$ 使正电荷粒子向左（$-x$）偏转。下面两张是按参数算出的横截面**示意图**：孔径内是均匀的横向场。先看 $B_y > 0$：场竖直向上，用右手定则读出正电荷受力向左。

```avas-field
steerer Bx=0 By=0.01 R=0.02
```

换成 $B_x > 0$：场水平向右，受力向上（$+y$）。

```avas-field
steerer Bx=0.01 By=0 R=0.02
```

### 偏转角

它和[二极铁](#dipole)是同一种场，只是弱得多：粒子在场中走过的弧长远小于弯转半径，轨迹只转过一个小角度。设场作用的有效长度为 $L$，粒子在校正铁里位置几乎不变，校正铁相当于一个只改变角度、不改变位置的薄"踢"：

$$
\Delta x' = -\frac{q B_y L}{p} = -\frac{B_y L}{B\rho},\qquad
\Delta y' = \frac{q B_x L}{p} = \frac{B_x L}{B\rho}.
$$

偏转角就是积分场 $BL$ 除以磁刚度——等价于把二极铁的 $L/\rho$ 用在一个很大的 $\rho = B\rho/B$ 上。示例束流（$B\rho = 0.17863$ T·m）在 $B_y = 1$ mT、$L = 0.1$ m 的校正铁中偏转 0.56 mrad；产生 1 mrad 偏转需要 $BL = 1.79\times 10^{-4}$ T·m。偏转与 $1/B\rho$ 成正比：同样的 $10^{-4}$ T·m，对 35 keV 质子偏转 3.7 mrad，对 100 MeV 质子只有 0.067 mrad。

### 电场校正铁

一对平行极板产生横向电场 $E_x$（或 $E_y$），力 $F_x = q E_x$ 与速度无关，方向与电场相同。粒子在场中停留的时间是 $L/v$，横向动量的变化为 $qE_x L/v$，所以

$$
\Delta x' = \frac{q E_x L}{p v} = \frac{E_x L}{E\rho},\qquad
\Delta y' = \frac{E_y L}{E\rho},\qquad
E\rho = \frac{p v}{q} = B\rho \cdot v .
$$

电刚度 $E\rho$ 的单位是 V；以 MeV 计时 $pv = \beta^2\gamma\,mc^2$，非相对论下约为 $2W$。示例束流 $pv = 3.05$ MeV，$E\rho = 3.05$ MV：$E_x = 10^5$ V/m 在 0.1 m 上偏转 3.28 mrad，产生 1 mrad 偏转需要 $EL = 3.05\times 10^3$ V。

电场偏转 $\propto 1/(pv)$，磁场偏转 $\propto 1/p$：两者之比正是速度 $v$。对示例束流（$\beta = 0.057$，$v = 1.71\times 10^7$ m/s），$10^5$ V/m 的电场与 5.9 mT 的磁场等效（$E = vB$）；同样的 $10^4$ V 积分电压，对 35 keV 质子偏转 143 mrad，对 100 MeV 质子只有 0.053 mrad。速度越低，电场校正铁越有效，这是低能束流传输线常用静电偏转板的原因。

## 偏转只移动质心 {#steerer-matrix}

### 一个平移

均匀场给束流中所有粒子相同的角度变化，与粒子的位置无关。所以校正铁的作用不是线性映射，而是平移：

$$
\begin{pmatrix} x \\ x' \\ y \\ y' \end{pmatrix}_1 =
\begin{pmatrix} x \\ x' \\ y \\ y' \end{pmatrix}_0 +
\begin{pmatrix} 0 \\ \Delta x' \\ 0 \\ \Delta y' \end{pmatrix}.
$$

它移动束流中心，不改变束流的二阶中心矩（rms 尺寸、发射度、Twiss 参数）——相空间里的椭圆整体沿 $x'$ 方向挪了一段，形状不变。在 $6\times 6$ 线性矩阵中校正铁等于单位矩阵，偏转需要用 $7\times 7$ 的增广矩阵或单独跟踪中心轨道来表示。

既然不改变 rms 尺寸，校正铁为什么重要？因为损失看的是束流边缘离管壁多远：中心偏 1 mm、rms 尺寸 1.5 mm 的束流，3 倍 rms 的边缘在 5.5 mm 处，而不是 4.5 mm。偏心通过四极铁还会额外偏转，通过腔体会受到横向 RF 踢，这些都会进一步放大轨道偏离。

> **AVAS 约定**：线性包络预览把校正铁当作单位矩阵，只计算 rms 包络，不计算中心轨道。校正铁对轨道的效果要用内核运行查看：DataSet.txt 中 $x$ 中心 = 第 29 列（同步粒子 $x$）+ 第 1 列（质心相对偏移），$y$ 中心 = 第 31 列 + 第 3 列，单位 m。

## 偏转在下游怎样传播 {#steerer-orbit}

### 在漂移段里

漂移段中，偏转后的中心沿直线离开轴线：$\Delta x = \theta\,s$。开头那条束线就是这样：1.12 mrad 乘 0.5 m 得到 0.56 mm。

### 在聚焦通道里

有聚焦时，偏转后的中心不再沿直线跑，而是像一个粒子一样绕轴作 betatron 振荡。在第 $j$ 个位置施加角度 $\theta_j$，下游第 $i$ 个位置（无加速）的位置偏移为

$$
\Delta x_i = \sqrt{\beta_i\,\beta_j}\,\sin(\psi_i - \psi_j)\,\theta_j ,
$$

其中 $\beta$、$\psi$ 是该平面的 beta 函数与相位（见[线性光学](#linear-optics)）。它就是传输矩阵元 $R_{12}$ 用 Twiss 参数写出来的样子。有加速时还要乘以绝热阻尼因子 $\sqrt{(\beta\gamma)_j/(\beta\gamma)_i}$。这个公式说明：

- 校正铁在 $\beta$ 大的地方更"有力"：$\sqrt{\beta_j}$ 越大，同样的角度在下游产生越大的偏移。在 FODO 里，校正铁通常放在本平面 $\beta$ 最大的聚焦四极铁旁。
- 偏移随相位正弦变化：相位差 $90^\circ$ 处最大，$180^\circ$ 处为零。一个校正铁只能在相位差 $90^\circ$ 的地方修正位置、在 $0^\circ$ 或 $180^\circ$ 的地方修正角度；要同时修正位置和角度，需要两个相隔约 $90^\circ$ 相移的校正铁。

举个数：[四极铁](#quadrupole)一章那个 $G = 6$ T/m 的 FODO 周期（$L_q = 0.1$ m、$L_d = 0.2$ m，每周期相移 52.7°，$\beta_x$ 在 QF 处 1.06 m、QD 处 0.43 m）中，在 QF 处施加 0.56 mrad，下游轨道振荡的幅度在各 QF 处为 $\sqrt{1.06 \times 1.06}\times 0.56 = 0.59$ mm，在各 QD 处为 $\sqrt{0.43\times 1.06}\times 0.56 = 0.38$ mm；到下一个 QF（相位差 52.7°）实际偏移 0.47 mm。

### 轨道误差从哪里来

反过来看，四极铁的错位就是一个不想要的校正铁：横向偏移 $d$ 的四极铁给束流中心一个 $\Delta x' = kL\,d$ 的踢。$G = 6$ T/m、$L = 0.1$ m 的四极铁偏 0.1 mm，对示例束流的踢是 0.34 mrad，相当于积分场 $6\times 10^{-5}$ T·m 的校正铁。沿线许多这样的随机踢叠加起来，就是需要校正的轨道畸变（见[误差与校正](#errors)）。

### 局部凸轨

用三个校正铁可以只在局部改变轨道：第一个把束流踢出去，第二个把它折回，第三个把剩余的角度消掉，使凸轨之外的轨道不受影响。三个踢角按上面的传播公式解出，使第三个校正铁之后的位置和角度都回到零；无加速时结果为

$$
\theta_2 = -\theta_1\sqrt{\frac{\beta_1}{\beta_2}}\,\frac{\sin\psi_{13}}{\sin\psi_{23}},\qquad
\theta_3 = \theta_1\sqrt{\frac{\beta_1}{\beta_3}}\,\frac{\sin\psi_{12}}{\sin\psi_{23}},
$$

$\psi_{ij}$ 是第 $i$ 个到第 $j$ 个校正铁的相移。只有 $\sin\psi_{23} = 0$ 时无解，$\psi_{23}$ 接近 $180^\circ$ 的整数倍时所需踢角趋于无穷；实际中让整个凸轨的相移小于约 $180^\circ$，踢角不至于过大，凸轨也比较短。用四个校正铁，还可以分别设定凸轨中间的位置和角度。

> **想一想**：沿线放满 BPM 和校正铁，把每个 BPM 处的读数都调成零，束流就一定在每个四极铁的磁中心通过吗？
> 答：不一定。BPM 读的是束流相对 BPM 电中心的位置，BPM 本身相对四极铁磁中心也有偏差（BPM 偏置）；而且两个 BPM 之间的轨道还可以是一个在 BPM 处恰好为零的振荡。所以校正后中心在 BPM 处为零，不代表在四极铁或腔中心为零。

## 轨道校正与副作用 {#steerer-dynamics}

### 响应矩阵

把所有校正铁到所有 BPM 的响应写成响应矩阵 $\mathsf{R}$，$R_{ij} = \partial x_i/\partial\theta_j$（直线加速器中只有 $j$ 在 $i$ 上游时非零，数值由上节公式或逐个改动校正铁的模拟得到）。测得轨道 $\boldsymbol{x}$ 后，求校正量

$$
\boldsymbol{\theta} = -\,\mathsf{R}^{+}\,\boldsymbol{x},
$$

$\mathsf{R}^{+}$ 是伪逆（最小二乘解，常用奇异值分解，必要时截断小奇异值以避免校正量过大）。常见的简化做法有"一对一"校正（每个校正铁对准下游最近的 BPM）和局部凸轨。AVAS 的 `adjust` 以梯度下降迭代调节参数，使束诊目标满足（见[误差与校正](#errors)）。

### 校正铁也有副作用

- **色散**：校正铁本质上是弱二极铁，偏转后会产生小量色散 $D \sim \theta\cdot(\text{距离})$；对能散大的束流，大偏转的校正会使有效尺寸变大。
- **偏心通过元件**：校正后中心在 BPM 处为零，不代表在四极铁或腔中心为零；BPM 与元件磁中心的偏差（BPM 偏置）同样需要考虑。
- **场质量**：小型校正铁的场在孔径边缘不均匀，大振幅粒子受到的偏转不同，矩阵模型不包含这一效应。
- **饱和与上限**：如果 `max` 是校正量的上限（见下文关键字说明），校正量用到 `max` 附近说明误差超出了校正能力，应检查误差设置或增加校正铁。

## 容易误解的地方 {#steerer-misconceptions}

- **"校正铁会改变束流尺寸"**：理想的均匀场只移动质心，rms 尺寸和发射度不变；线性预览中看不到它的效果正是因为这个。
- **"偏转越大越好，校正铁放在哪里都一样"**：同样的角度在 $\beta$ 大的地方效果大；而偏移随相位正弦变化，放在离目标相位差 $180^\circ$ 的地方几乎不起作用。
- **"BPM 读数为零就对中了"**：见上面的"想一想"。
- **"电场和磁场校正铁对所有能量一样有效"**：两者之比是速度，低能时电场校正铁效率高得多。
- **"校正铁的长度就是它的作用长度"**：在 AVAS 中校正铁长度写 0，作用长度取下一个元件的长度（见下文）。

## 在 AVAS 中 {#steerer-in-avas}

### 关键字

```text
steerer 0 R 0 Bx By kind max
```

```avas-params
steerer
```

- 第一个参数（长度）**必须为 0**；第三个参数保留，写 0。
- `R`：孔径半径（m）。
- `Bx`、`By`：`kind = 0` 时为磁场（T），`kind = 1` 时为电场 `Ex`、`Ey`（V/m）。
- `kind`：0 = 磁场校正铁，1 = 电场校正铁。
- `max`：最大值。手册只写"最大值"，通常理解为校正时允许的上限；其含义和单位手册都没有进一步说明，以内核为准。

> **AVAS 约定**：校正铁长度写 0，但它**作用于下一个元件**：作用长度默认等于下一个元件的长度，并位于下一个元件的中间（手册原文）。因此积分场为 $B\,L_{\text{next}}$，偏转角按上面的公式用下一个元件的长度计算。lattice 检查会对长度不为 0 的 `steerer` 给出警告。

例：在四极铁上叠加一个垂直磁场 $B_y = 1$ mT 的校正铁：

```text
steerer 0 0.02 0 0 0.001 0 0.002
quad 0.1 0.02 0 6
```

对示例束流（$B\rho = 0.17863$ T·m），$B_y L = 1\times 10^{-4}$ T·m，偏转 $\lvert\Delta x'\rvert = 0.56$ mrad。偏转的正负方向按右手系由 $\boldsymbol{F} = q\boldsymbol{v}\times\boldsymbol{B}$ 推出；内核实际采用的符号约定手册没有写明，需要时用单粒子运行确认。

### 校正命令

AVAS 的静态误差校正由 `adjust` 指定要调的参数，由束诊命令给出目标：

```avas-params
adjust diag_position
```

`adjust 0 v n min max first_step` 写在要调的元件前，`v` 是该元件的第几个参数。手册唯一的例子是 `adjust 1 7 5 0 3 0` 写在 `field` 前、修改第 7 个参数 `Ke`，即从关键字后第一个数起计；按同样的数法类推，`steerer` 的第 4 个是 `Bx`，第 5 个是 `By`。手册没有给出校正铁的例子，这一对应以内核为准，使用前先用一次短的误差研究确认校正铁的场确实被修改。`diag_position 0 x y 0` 给出目标中心位置（mm）。一个示意片段：

```text
adjust 0 5 1 -0.002 0.002 0
steerer 0 0.02 0 0 0 0 0.002
quad 0.1 0.02 0 6
drift 0.3 0.02 0
diag_position 0 0 0 0
```

校正在误差研究中进行（需要 `err_step` 等命令），算法、参数含义与完整的案例见[误差与校正](#errors)。

### 在内核里看轨道

线性预览不跟踪中心轨道。要看校正铁的效果，可以在示例项目的副本中加入一个 `steerer`（后接一段 drift 或四极铁），以单粒子或少量粒子运行内核，观察 DataSet.txt 中束流中心（第 29 列 + 第 1 列）沿 $z$ 的变化，并用 $\Delta x' = B_y L/B\rho$ 核对下游的偏移量和方向。

### 典型取值

| 量 | 典型范围 | 说明 |
|---|---|---|
| 积分场 $BL$ | $10^{-5}$–$10^{-3}$ T·m | 常温小型校正线圈 |
| 电场 $E$ | $10^4$–$10^6$ V/m | 低能静电偏转板 |
| 偏转角 | 0.1–数 mrad | 由轨道误差预算决定 |
| 数量 | 每个平面每 1–2 个聚焦周期一个 | 与 BPM 配对 |

### 数值例子

示例束流：质子 1.527 MeV，$B\rho = 0.17863$ T·m，$E\rho = 3.05$ MV（$pv = 3.05$ MeV）。

| 校正铁 | 场 | 作用长度 | 偏转角 |
|---|---|---|---|
| 磁场 | $B_y = 1$ mT | 0.1 m | 0.56 mrad |
| 磁场 | $B_y = 10$ mT | 0.1 m | 5.6 mrad |
| 电场 | $E_x = 10^5$ V/m | 0.1 m | 3.28 mrad |

产生 1 mrad 偏转需要 $BL = 1.79\times 10^{-4}$ T·m 或 $EL = 3.05\times 10^{3}$ V。对这样低的速度（$\beta = 0.057$），$10^5$ V/m 的电场与 5.9 mT 的磁场等效（$E = vB$，$v = 1.71\times 10^7$ m/s）。

### 常见问题

- 给 `steerer` 写了非零长度：手册要求长度为 0，lattice 会给出警告。
- 把 `steerer` 放在 lattice 最后：它没有"下一个元件"可作用；而且它是矩阵模型元件，本来也不宜放在首尾。
- `kind` 与单位不符：`kind = 1` 时 `Bx`、`By` 位置写的是 V/m，数值通常比磁场（T）大好几个数量级。
- 在线性预览里看不到校正铁的效果：线性预览不跟踪中心轨道，要用内核运行。
