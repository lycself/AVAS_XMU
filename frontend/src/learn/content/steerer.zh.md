# 校正铁

加速器里的每一块四极铁、每一个螺线管和腔，安装时都会偏零点几毫米。束流中心经过这些装偏的元件，就被一点点推离设计好的中心线（这条束流中心走过的路线叫**轨道**）。偏得多了，束流就会擦到管壁上。

要把束流拉回来，需要一个能让**整束**粒子轻轻拐个小弯的元件，这就是**校正铁**（steerer，又称偶极校正器、导向磁铁）。它只是一个很弱的均匀磁场，给束流一个零点几到几毫弧度的偏转。打个比方：轻轻转一下水管的喷嘴，水柱整体换了方向，粗细一点不变。

这一章回答三个问题：多大的磁场能让束流拐多大的弯？它既然不改变束流的粗细，为什么又很重要？同样的偏转放在哪里最有效？

动画里束流先过一小段漂移，然后穿过一块校正铁：竖直磁场 $B_y = 3$ mT，作用在它后面 0.1 m 长的元件上（3D 里画成一个"窗框"形的磁铁），再进入 1 m 的漂移段。这个动画不含空间电荷。

```avas-motion

```

先看 2D 里从上方看的图（水平方向 $x$）：穿过磁铁以后，整束粒子一起向 $-x$ 方向偏过去。图里的实线是束流中心，到末端偏了 1.76 mm。束流本身的粗细和没有校正铁时完全一样（把 $B_y$ 调成 0 对比）。再看从侧面看的图（竖直方向 $y$）：什么都没变，因为 $B_x = 0$。拖动播放条，让粒子停在磁铁里面，看横截面（从下游往上游看，束流从屏幕里朝你飞出来）：两个蓝色粒子身上的红色受力箭头一样长、都指向 $-x$。受力和粒子在哪里无关，这一点和四极铁完全不同。切到 3D：$B_y > 0$ 时 N 极在下面，磁感线从下往上穿过束流，两个粒子身上标着 F 的粉色受力箭头都指向 $-x$。

## 为什么需要校正铁 {#steerer-role}

- **轨道校正**：抵消元件装偏、磁场误差和初始束流偏移造成的轨道偏离（叫"轨道畸变"），减少因中心偏离带来的束流损失和有效发射度增长。
- **束流对中**：让束流从四极铁、螺线管和腔的电磁中心穿过，避免偏心通过带来的额外偏转（四极铁）、两个方向的耦合（螺线管）或横向的射频"踢"（腔）。
- **局部凸轨（bump）**：用 3–4 个校正铁在一小段里制造一段受控的轨道偏移，例如绕开障碍物或扫描孔径。
- **放在哪里**：通常紧挨着四极铁，或者把校正线圈嵌在四极铁、螺线管的线圈里（超导螺线管里常附带偶极校正线圈），和测量束流位置的**束流位置探测器**（BPM）交错排列，每个方向、每个聚焦周期至少一个。

## 一个小角度的偏转 {#steerer-field}

### 力的方向

校正铁里的磁场近似均匀，并且是横向的（在 $x$、$y$ 方向）。中学讲过，带电粒子在磁场中受**洛伦兹力** $F = qvB$（速度和磁场垂直时），方向用左手定则判断：让磁感线垂直穿入手心，四指指向正电荷运动的方向，大拇指所指就是受力方向。粒子沿 $+z$ 飞时：

- 竖直的磁场 $B_y$ 让粒子在水平方向（$x$）偏转；
- 水平的磁场 $B_x$ 让粒子在竖直方向（$y$）偏转。

磁场和偏转方向互相垂直。在 AVAS 的横截面图里（从下游往上游看，束流垂直屏幕向外，$x$ 向右、$y$ 向上），$B_y > 0$ 使正电荷粒子向左（$-x$）偏转。下面两张是按参数算出的横截面**示意图**：孔径内是均匀的横向场。先看 $B_y > 0$：磁场竖直向上，用左手定则读出正电荷受力向左。

```avas-field
steerer Bx=0 By=0.01 R=0.02
```

换成 $B_x > 0$：磁场水平向右，受力向上（$+y$）。

```avas-field

```

### 偏转多大：用冲量算

设粒子穿过一段长 $L$、磁场为 $B$ 的校正铁：

- 它受的力是 $F = q\,v\,B$；
- 穿过磁铁用的时间是 $t = L/v$；
- 横向动量的变化（冲量）是 $F\,t = q\,B\,L$，速度消掉了；
- 横向动量除以前进方向的动量 $p$，就是轨迹偏转的角度。

所以

$$
\Delta x' = -\frac{q B_y L}{p} = -\frac{B_y L}{B\rho},\qquad
\Delta y' = \frac{q B_x L}{p} = \frac{B_x L}{B\rho}.
$$

$x'$、$y'$ 是粒子轨迹相对中心线的角度，$\Delta$ 表示变化量；负号表示 $B_y > 0$ 时向 $-x$ 偏。$B\rho = p/q$ 是[四极铁](#quadrupole-lorentz)一章讲过的**磁刚度**（粒子有多难被磁场偏转），示例质子 $B\rho = 0.179$ T·m。乘积 $BL$ 叫**积分场**：偏转角就是积分场除以磁刚度。

代入动画的默认值：$B_y L = 0.003\ \mathrm{T}\times 0.1\ \mathrm{m} = 3\times 10^{-4}$ T·m，偏转 $3\times 10^{-4}/0.179 = 1.68$ mrad。产生 1 mrad 偏转需要 $BL = 1.79\times 10^{-4}$ T·m。

这里有一个关键：力只取决于磁场，而磁场处处一样，所以**每个粒子都偏转同样的角度**，不管它离中心多远。这和四极铁正好相反：四极铁的力和离中心的距离成正比，离得越远推得越狠。

它和[二极铁](#dipole)是同一种场，只是弱得多：粒子在里面走的是半径 $\rho = B\rho/B$ 的圆弧，默认值下 $\rho = 60$ m，而磁铁只有 0.1 m 长，所以只转过一个很小的角度。

偏转角和 $1/B\rho$ 成正比，粒子越"硬"越难偏：同样的 $10^{-4}$ T·m，对 35 keV 质子偏转 3.7 mrad，对 100 MeV 质子只有 0.067 mrad。

### 下游偏多少

偏转后，束流中心在漂移段里沿直线离开中心线，偏移 = 偏转角 × 距离。动画里从磁铁中点到末端是 1.05 m，所以末端偏 $1.68\ \mathrm{mrad}\times 1.05\ \mathrm{m} = 1.76$ mm（为什么从磁铁中点量起，见[想一想](#steerer-think)）。

拖动参数验证：

- 把 $B_y$ 加倍到 6 mT：偏转角变成 3.36 mrad，末端偏 3.53 mm，正好加倍。
- 把 $B_y$ 调成 $-3$ mT：束流改向 $+x$ 偏，末端 $+1.76$ mm。
- 把 $B_y$ 调成 0、$B_x$ 调成 3 mT：上方看的图不再偏，侧面看的图里束流向 $+y$ 偏 1.76 mm。
- 把动能调到 10 MeV：磁刚度变成 0.458 T·m，偏转只剩 0.65 mrad，末端偏 0.69 mm。

## 电场校正铁 {#steerer-electric}

也可以用电场偏转：一对平行极板产生横向电场 $E_x$（或 $E_y$）。电场力 $F = qE_x$ 与速度无关，方向和电场相同（对正电荷）。用同样的冲量算法：粒子在场中停留的时间是 $L/v$，横向动量的变化为 $qE_x L/v$，所以

$$
\Delta x' = \frac{q E_x L}{p v} = \frac{E_x L}{E\rho},\qquad
\Delta y' = \frac{E_y L}{E\rho},\qquad
E\rho = \frac{p v}{q} = B\rho \cdot v .
$$

$E\rho$ 叫**电刚度**，单位是 V。速度不太快时 $pv = mv^2 = 2W$（$W$ 是动能），以 MeV 计严格的写法是 $pv = \beta^2\gamma\,mc^2$。示例束流 $pv = 3.05$ MeV，$E\rho = 3.05$ MV：$E_x = 10^5$ V/m 在 0.1 m 上偏转 3.28 mrad，产生 1 mrad 偏转需要 $EL = 3.05\times 10^3$ V。

电场偏转 $\propto 1/(pv)$，磁场偏转 $\propto 1/p$：两者之比正是速度 $v$。对示例束流（$\beta = 0.057$，$v = 1.71\times 10^7$ m/s），$10^5$ V/m 的电场与 5.9 mT 的磁场等效（$E = vB$）；同样的 $10^4$ V 积分电压，对 35 keV 质子偏转 143 mrad，对 100 MeV 质子只有 0.053 mrad。速度越低，电场校正铁越有效，这是低能束流传输线常用静电偏转板的原因。

## 只移动束流中心，不改变粗细 {#steerer-matrix}

每个粒子都偏转同样的角度，所以校正铁的作用是把整束粒子**平移**：在"位置–角度"图（相空间，见[漂移段](#drift-size)）里，代表束流的椭圆整体沿角度方向挪了一段，形状不变。束流的 rms 尺寸、发射度和 Twiss 参数都不变，变的只有束流中心。在动画里比较 $B_y = 3$ mT 和 $B_y = 0$：末端 rms 尺寸都是 4.23 mm。

既然不改变 rms 尺寸，校正铁为什么重要？因为会不会撞墙，看的是束流**边缘**离管壁多远。中心偏 1 mm、rms 尺寸 1.5 mm 的束流，3 倍 rms 的边缘在 5.5 mm 处，而不是 4.5 mm。在动画里把后面的漂移段 `Ld` 拉到 2 m，束流长粗到 rms 约 7.2 mm：$B_y = 0$ 时 60 个粒子里有 1 个撞上管壁（红叉），$B_y = 3$ mT 时有 3 个，rms 尺寸一点没变。偏心穿过四极铁还会被额外偏转，穿过腔会受到横向射频"踢"，这些都会进一步放大轨道偏离。

反过来看，四极铁装偏就是一个"不想要的校正铁"。束流相对四极铁的磁中心偏了，等于整束都在四极铁的一侧，四极铁对整束的平均推力不再是零，于是整束被踢一下。$G = 6$ T/m、$L = 0.1$ m 的四极铁偏 0.1 mm，对示例束流的踢是 0.34 mrad，相当于积分场 $6\times 10^{-5}$ T·m 的校正铁。沿线许多这样的随机踢叠加起来，就是需要校正的轨道畸变（见[误差与校正](#errors)、[轨道校正](#orbit-correction)）。

下面这条束线里，校正铁长度为 0，作用于它后面的元件（这里是 0.2 m 漂移段）：$B_y = 1$ mT 在 0.2 m 上的积分场是 $2\times 10^{-4}$ T·m，使示例束流偏转 1.12 mrad，到束线末端（偏转中心之后 0.5 m）束流中心偏移约 0.56 mm，约为该处 rms 尺寸（2.8 mm）的五分之一。编辑器里的包络图只画 rms 尺寸，与去掉校正铁时完全相同，看不出这个偏移。

## 偏转在下游怎样传播 {#steerer-orbit}

在漂移段里，偏转后的中心沿直线离开中心线，前面已经算过。

在有四极铁的聚焦通道里就不一样了。束流中心的运动和单个粒子一模一样：在[四极铁](#quadrupole-fodo)一章的 FODO 动画里，粒子绕着中心轴来回摆动，像小球在山谷里来回滚。被校正铁踢了一下的束流中心也这样：它不会一直跑远，而是绕着中心线来回摆。由此得到三条实用的结论（定量的公式在"深入"部分）：

- **在束流粗的地方，校正铁更"有力"**。粒子摆动得大的地方，束流也粗；在那里踢一下，下游的摆动幅度也大。所以在 FODO 里，水平校正铁通常放在水平方向最粗的那块聚焦四极铁旁边，竖直方向同理。
- **偏移随摆动的"相位"变化**。踢一下以后，中心在下游先偏出去、再回来、再偏到另一边，就像小球的摆动。摆过四分之一个周期（相位差 90°）的地方偏移最大，摆过半个周期（180°）的地方偏移为零。所以要在某一处同时修正位置和角度，需要两个相隔约 90° 的校正铁。
- **用三个校正铁可以只改变一小段轨道**：第一个把束流踢出去，第二个把它折回，第三个把剩下的角度消掉，这一段之外的轨道不受影响。这就是局部凸轨。

沿线放满 BPM 和校正铁，就能测出整条轨道并把它拉回来。怎样根据 BPM 读数算出每个校正铁该调多少，[轨道校正](#orbit-correction)一章有完整的讲解和动画。

## 想一想 {#steerer-think}

> **想一想 1**：同一块 $B_y > 0$ 的校正铁，飞过来的是带负电的 H⁻ 离子，往哪边偏？
>
> 答：力反过来，向 $+x$ 偏。偏转方向取决于磁场和电荷两者的符号。

> **想一想 2**：动画里偏转角 1.68 mrad，磁铁后面的漂移段长 1 m，可末端偏移是 1.76 mm，不是 1.68 mm。多出来的从哪里来？
>
> 答：粒子在 0.1 m 长的磁铁里已经开始偏转，出磁铁时已经偏了约 0.08 mm。效果相当于在磁铁**中点**一下子踢一个角度，所以要从中点量起：$1.68 \times (0.05 + 1) = 1.76$ mm（推导见"深入"）。

> **想一想 3**：沿线放满 BPM 和校正铁，把每个 BPM 处的读数都调成零，束流就一定在每个四极铁的磁中心通过吗？
>
> 答：不一定。BPM 读的是束流相对 BPM 电中心的位置，BPM 本身相对四极铁磁中心也有偏差（BPM 偏置）；而且两个 BPM 之间的轨道还可以是一个在 BPM 处恰好为零的振荡。所以校正后中心在 BPM 处为零，不代表在四极铁或腔中心为零。

## 容易误解的地方 {#steerer-misconceptions}

- **"校正铁会改变束流尺寸"**：理想的均匀场只移动质心（束流中心），rms 尺寸和发射度不变；编辑器的包络图里看不到它的效果，一是因为 rms 尺寸本来就不变，二是因为包络预览不画中心轨道。
- **"偏转越大越好，校正铁放在哪里都一样"**：同样的角度在束流粗（$\beta$ 大）的地方效果大；而偏移随相位正弦变化，放在离目标相位差 $180^\circ$ 的地方几乎不起作用。
- **"BPM 读数为零就对中了"**：见上面的"想一想 3"。
- **"电场和磁场校正铁对所有能量一样有效"**：两者之比是速度，低能时电场校正铁效率高得多。
- **"校正铁的长度就是它的作用长度"**：在 AVAS 中校正铁长度写 0，作用长度取下一个元件的长度（见下文）。

## 深入：从冲量到"踢"的矩阵 {#steerer-deep-kick}

正文用冲量算出了偏转角。这一节把数一个一个算出来，说明为什么能把校正铁看成磁铁中点的一下"踢"，再把它写进[漂移段](#drift-deep-matrix)一章的换算表（矩阵）。最后一段给学过线性代数的读者。

### 第一步：数一数力和冲量

示例质子的速度 $v = 1.71\times 10^7$ m/s，在 $B_y = 3$ mT 中受力

$$
F = q v B = 1.60\times 10^{-19}\ \mathrm{C} \times 1.71\times 10^{7}\ \mathrm{m/s}\times 0.003\ \mathrm{T} = 8.2\times 10^{-15}\ \mathrm{N}.
$$

穿过 0.1 m 用时 $t = 0.1/(1.71\times 10^7) = 5.85$ ns，冲量 $F t = 4.8\times 10^{-23}$ kg·m/s。质子的动量 $p = \gamma m v = 2.86\times 10^{-20}$ kg·m/s（$\gamma = 1.0016$，几乎就是 $mv$），两者之比 $1.68\times 10^{-3}$，就是正文的 1.68 mrad。

### 第二步：磁铁里面走的是一段圆弧

在均匀磁场里，粒子走半径 $\rho = p/(qB) = B\rho/B$ 的圆弧（中学的 $R = mv/(qB)$）。默认值下 $\rho = 0.179/0.003 = 59.5$ m。走过弧长 $L$ 后，速度方向转过的角度是 $L/\rho = 0.1/59.5 = 1.68$ mrad，和冲量算出的一样。

出磁铁时粒子横向偏了多少？设粒子沿原方向走了 $s$，离开原方向的距离是 $d$。从粒子当前位置向入口处的半径作垂线，得到一个直角三角形：斜边是半径 $\rho$，两条直角边是 $s$ 和 $\rho - d$。由勾股定理 $(\rho - d)^2 + s^2 = \rho^2$，展开得 $2\rho d = s^2 + d^2$。$d$ 比 $s$ 小得多，略去 $d^2$，得 $d \approx s^2/(2\rho)$。代入 $s = L = 0.1$ m：

$$
\frac{L^2}{2\rho} = \frac{0.01}{119} = 8.4\times 10^{-5}\ \mathrm{m} = 0.084\ \mathrm{mm}.
$$

而 $\theta\cdot L/2 = 1.68\ \mathrm{mrad}\times 0.05\ \mathrm{m} = 0.084$ mm，正好相等。也就是说，出口处的位置和角度，与"在磁铁中点一下子转过 $\theta$、前后都走直线"完全一样（到 $\theta$ 的一次方为止）。所以可以把校正铁换成中点处一个只改变角度、不改变位置的薄"踢"。

### 第三步：一下"踢"不是乘法，而是加法

漂移段的换算表是乘法：$(x, x')$ 乘一个矩阵得到新的 $(x, x')$。校正铁却是给角度**加**一个常数：

$$
\begin{pmatrix} x \\ x' \end{pmatrix}_1 =
\begin{pmatrix} x \\ x' \end{pmatrix}_0 +
\begin{pmatrix} 0 \\ \theta \end{pmatrix}.
$$

加上的数和粒子原来的 $x$、$x'$ 无关，所以它不能写成一张 2 × 2 的换算表。有一个小技巧：在状态后面补一个永远等于 1 的数，写成 $(x, x', 1)$，"加 $\theta$"就变成了乘法：

$$
\begin{pmatrix} x \\ x' \\ 1 \end{pmatrix}_1 =
\begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & \theta \\ 0 & 0 & 1 \end{pmatrix}
\begin{pmatrix} x \\ x' \\ 1 \end{pmatrix}_0 .
$$

漂移段也补上一行一列：$\begin{pmatrix} 1 & L & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix}$。验算：轴上的粒子 $(0, 0, 1)$ 先被踢 $\theta = -1.68$ mrad，再走 1.05 m，按矩阵乘法得 $x = 1.05\times(-1.68) = -1.76$ mm，正是动画的结果。

### 第四步：几个踢可以分别算、再相加

上面的式子说明，每个粒子的状态都等于"没有校正铁时的状态"加上"校正铁单独造成的偏移"。几个校正铁一起作用时，下游的偏移就是每个校正铁单独造成的偏移之和；把某个校正铁的场加倍，它造成的偏移也加倍。这种"可以叠加、成比例"的性质叫**线性**，是[轨道校正](#orbit-correction)里响应矩阵的基础。

### 给学过线性代数的读者

校正铁是一个仿射映射 $\boldsymbol{x} \to \boldsymbol{x} + \boldsymbol{d}$，$\boldsymbol{d} = (0, \Delta x', 0, \Delta y', 0, 0)\tp$：它移动束流中心，不改变二阶中心矩（rms 尺寸、发射度、Twiss 参数）。在 $6\times 6$ 线性矩阵中校正铁等于单位矩阵，偏转需要用 $7\times 7$ 的增广矩阵 $\begin{pmatrix} M & \boldsymbol{d} \\ 0 & 1 \end{pmatrix}$ 或单独跟踪中心轨道来表示。整条束线是这些仿射映射的复合，中心轨道 $\bar{\boldsymbol{x}}$ 按 $\bar{\boldsymbol{x}} \to M\bar{\boldsymbol{x}} + \boldsymbol{d}$ 传播，而关于中心的二阶矩 $\Sigma \to M\Sigma M\tp$ 与 $\boldsymbol{d}$ 无关。

## 深入：偏转在聚焦通道里的传播 {#steerer-deep-orbit}

正文说"被踢了一下的束流中心绕着中心线来回摆"。这一节把它算成数字：先用中学的简谐振动，再推广到真实的 FODO 通道，最后解出局部凸轨的三个踢角。

### 第一步：束流中心就是一个粒子

线性模型里，每个粒子都按同一张换算表传输，束流中心（所有粒子的平均）也按这张表传输。所以"被踢的中心怎样走"就是"一个从中心线出发、带着角度 $\theta$ 的粒子怎样走"。

### 第二步：均匀聚焦：简谐振动

先粗略地把 FODO 通道看成处处一样的"弹簧"（叫平滑近似）：粒子的运动是简谐振动

$$
x'' = -\frac{1}{\bar\beta^2}\,x ,
$$

和[四极铁](#quadrupole-deep-matrix)一章的 $x'' = -kx$ 一样，只是把弹簧系数写成 $1/\bar\beta^2$。$\bar\beta$ 有长度的单位，叫平均 **beta 函数**，它是粒子摆动"波长"除以 $2\pi$。从中心线 $x = 0$ 出发、初始角度 $\theta$ 的解是

$$
x(s) = \bar\beta\,\theta\,\sin\frac{s}{\bar\beta}
$$

（验算：$s = 0$ 时 $x = 0$，角度 $x' = \theta\cos 0 = \theta$）。摆动的幅度是 $\bar\beta\,\theta$：$\bar\beta$ 越大，同样的踢造成的偏移越大。$s/\bar\beta$ 是摆动走过的相位。

举个数：[四极铁](#quadrupole-deep-fodo)一章那个 $G = 6$ T/m 的 FODO 周期（$L_q = 0.1$ m、$L_d = 0.2$ m，周期长 0.6 m）每个周期相移 52.7° = 0.920 rad，平均 $\bar\beta \approx 0.6/0.920 = 0.65$ m。踢 0.56 mrad，摆动幅度约 $0.65\times 0.56 = 0.37$ mm。

### 第三步：beta 函数沿线变化时

真实 FODO 里 $\beta$ 不是常数：束流在聚焦四极铁里粗、在散焦四极铁里细，$\beta$ 跟着变。这时在第 $j$ 个位置施加角度 $\theta_j$，下游第 $i$ 个位置（无加速）的位置偏移为

$$
\Delta x_i = \sqrt{\beta_i\,\beta_j}\,\sin(\psi_i - \psi_j)\,\theta_j ,
$$

其中 $\beta$、$\psi$ 是该方向的 beta 函数与相位（见[线性光学](#linear-optics)）。$\beta$ 处处相同时它就退回第二步的 $\bar\beta\,\theta\sin(\Delta\psi)$。它就是传输矩阵元 $R_{12}$ 用 Twiss 参数写出来的样子。有加速时还要乘以绝热阻尼因子 $\sqrt{(\beta\gamma)_j/(\beta\gamma)_i}$（$\beta\gamma$ 是相对论速度因子，能量升高时摆动幅度变小）。

同一个 FODO 周期里，$\beta_x$ 在 QF 处 1.06 m、QD 处 0.43 m。在 QF 处施加 0.56 mrad，下游轨道振荡的幅度在各 QF 处为 $\sqrt{1.06 \times 1.06}\times 0.56 = 0.59$ mm，在各 QD 处为 $\sqrt{0.43\times 1.06}\times 0.56 = 0.38$ mm；到下一个 QF（相位差 52.7°）实际偏移 $0.59\times\sin 52.7^\circ = 0.47$ mm。平滑近似的 0.37 mm 介于两者之间。

这个公式说明：

- 校正铁在 $\beta$ 大的地方更"有力"：$\sqrt{\beta_j}$ 越大，同样的角度在下游产生越大的偏移。在 FODO 里，校正铁通常放在本方向 $\beta$ 最大的聚焦四极铁旁。
- 偏移随相位正弦变化：相位差 $90^\circ$ 处最大，$180^\circ$ 处为零。一个校正铁只能在相位差 $90^\circ$ 的地方修正位置、在 $0^\circ$ 或 $180^\circ$ 的地方修正角度；要同时修正位置和角度，需要两个相隔约 $90^\circ$ 相移的校正铁。

### 第四步：局部凸轨：解一个方程

三个校正铁，踢角 $\theta_1$、$\theta_2$、$\theta_3$，要求第三个校正铁之后位置和角度都回到零。

第三个校正铁只改变角度、不改变位置，所以在它那里，前两个踢造成的**位置**必须已经是零。用第三步的公式：

$$
\sqrt{\beta_3\beta_1}\,\sin\psi_{13}\,\theta_1 + \sqrt{\beta_3\beta_2}\,\sin\psi_{23}\,\theta_2 = 0 ,
$$

$\psi_{ij}$ 是第 $i$ 个到第 $j$ 个校正铁的相移。这是关于 $\theta_2$ 的一次方程，解出 $\theta_2$；再让第三个校正铁把剩下的角度消掉，求出 $\theta_3$。无加速时结果为

$$
\theta_2 = -\theta_1\sqrt{\frac{\beta_1}{\beta_2}}\,\frac{\sin\psi_{13}}{\sin\psi_{23}},\qquad
\theta_3 = \theta_1\sqrt{\frac{\beta_1}{\beta_3}}\,\frac{\sin\psi_{12}}{\sin\psi_{23}}.
$$

只有 $\sin\psi_{23} = 0$ 时无解，$\psi_{23}$ 接近 $180^\circ$ 的整数倍时所需踢角趋于无穷；实际中让整个凸轨的相移小于约 $180^\circ$，踢角不至于过大，凸轨也比较短。用四个校正铁，还可以分别设定凸轨中间的位置和角度。

### 给学过线性代数的读者

任意一段的 2 × 2 传输矩阵可用两端的 Twiss 参数写成（无加速）

$$
R_{12} = \sqrt{\beta_i\beta_j}\,\sin\Delta\psi ,\qquad
R_{22} = \sqrt{\beta_j/\beta_i}\,\left(\cos\Delta\psi - \alpha_i\sin\Delta\psi\right),
$$

薄踢只改变角度，所以下游位置偏移是 $R_{12}\theta_j$，角度偏移是 $R_{22}\theta_j$。局部凸轨就是要求 $\sum_j R^{(3j)}\theta_j = 0$（位置与角度两行）的线性方程组。

## 深入：轨道校正与副作用 {#steerer-deep-dynamics}

### 响应矩阵

把所有校正铁到所有 BPM 的响应写成响应矩阵 $\mathsf{R}$，$R_{ij} = \partial x_i/\partial\theta_j$（第 $j$ 个校正铁的踢角改变一点，第 $i$ 个 BPM 的读数改变多少；直线加速器中只有 $j$ 在 $i$ 上游时非零，数值由上节公式或逐个改动校正铁的模拟得到）。测得轨道 $\boldsymbol{x}$ 后，求校正量

$$
\boldsymbol{\theta} = -\,\mathsf{R}^{+}\,\boldsymbol{x},
$$

$\mathsf{R}^{+}$ 是伪逆（最小二乘解，常用奇异值分解，必要时截断小奇异值以避免校正量过大）。常见的简化做法有"一对一"校正（每个校正铁对准下游最近的 BPM）和局部凸轨。AVAS 的 `adjust` 以梯度下降迭代调节参数，使束诊目标满足（见[误差与校正](#errors)）。最小二乘、奇异值和截断从中学知识起步的逐步讲解见[轨道校正](#orbit-correction-deep-svd)。

### 校正铁也有副作用

- **色散**：校正铁本质上是弱二极铁，偏转后会产生小量色散（不同能量的粒子偏转角不同，下游位置也不同），$D \sim \theta\cdot(\text{距离})$；对能散大的束流，大偏转的校正会使有效尺寸变大。
- **偏心通过元件**：校正后中心在 BPM 处为零，不代表在四极铁或腔中心为零；BPM 与元件磁中心的偏差（BPM 偏置）同样需要考虑。
- **场质量**：小型校正铁的场在孔径边缘不均匀，大振幅粒子受到的偏转不同，矩阵模型不包含这一效应。
- **饱和与上限**：如果 `max` 是校正量的上限（见下文关键字说明），校正量用到 `max` 附近说明误差超出了校正能力，应检查误差设置或增加校正铁。

## 在 AVAS 中 {#steerer-in-avas}

### 关键字

```text
steerer 0 R 0 Bx By kind max
```

```avas-params
steerer
```

- 第一个参数（长度）**必须为 0**；第三个参数保留，写 0。
- `R`：孔径半径（m）。
- `Bx`、`By`：`kind = 0` 时为磁场（T），`kind = 1` 时为电场 `Ex`、`Ey`（V/m）。
- `kind`：0 = 磁场校正铁，1 = 电场校正铁。
- `max`：最大值。手册只写"最大值"，通常理解为校正时允许的上限；其含义和单位手册都没有进一步说明，以内核为准。

> **AVAS 约定**：校正铁长度写 0，但它**作用于下一个元件**：作用长度默认等于下一个元件的长度，并位于下一个元件的中间（手册原文）。因此积分场为 $B\,L_{\text{next}}$，偏转角按正文的公式用下一个元件的长度计算。lattice 检查会对长度不为 0 的 `steerer` 给出警告。

例：在四极铁上叠加一个垂直磁场 $B_y = 1$ mT 的校正铁：

```text
steerer 0 0.02 0 0 0.001 0 0.002
quad 0.1 0.02 0 6
```

对示例束流（$B\rho = 0.17863$ T·m），$B_y L = 1\times 10^{-4}$ T·m，偏转 $\lvert\Delta x'\rvert = 0.56$ mrad。偏转的正负方向按右手系由 $\boldsymbol{F} = q\boldsymbol{v}\times\boldsymbol{B}$ 推出；手册没有写明内核的符号约定，2026-11-03 已用内核单粒子运行核实：磁场 $B_y > 0$ 使正粒子向 $-x$ 偏，$B_x > 0$ 向 $+y$，电场 $E_x > 0$（`kind = 1`，单位 V/m）向 $+x$，方向、单位和作用长度（整个下一个元件上的均匀场）都与 AVAS 线性模型一致（三个算例的末端偏移内核为 −1.2312／+1.2312／+7.2069 mm，线性模型为 −1.2316／+1.2316／+7.2094 mm）。

### 线性预览、线性模型与内核

- **包络预览**（结构编辑器的包络图和本章的束线图）只计算 rms 包络，不画中心轨道，所以那里看不出校正铁的效果。
- **线性模型**（`avas.model`）本身会推动束流中心：每一步都是"矩阵乘法加一个常数"，常数项来自校正铁、元件错位和场图轴上的横向场。本章的动画、[轨道校正](#orbit-correction)的动画和研究页的响应矩阵用的就是它；对校正铁，线性模型的响应矩阵是精确的。
- **内核**：DataSet.txt 中 $x$ 中心 = 第 29 列（同步粒子 $x$）+ 第 1 列（质心相对偏移），$y$ 中心 = 第 31 列 + 第 3 列，单位 m。

### 校正命令

AVAS 的静态误差校正由 `adjust` 指定要调的参数，由束诊命令给出目标：

```avas-params
adjust diag_position
```

`adjust 0 v n min max first_step` 写在要调的元件前，`v` 是该元件的第几个参数。手册唯一的例子是 `adjust 1 7 5 0 3 0` 写在 `field` 前、修改第 7 个参数 `Ke`，即从关键字后第一个数起计；按同样的数法类推，`steerer` 的第 4 个是 `Bx`，第 5 个是 `By`。手册没有给出校正铁的例子，这一对应以内核为准，使用前先用一次短的误差研究确认校正铁的场确实被修改。`diag_position 0 x y 0` 给出目标中心位置（mm）。一个示意片段：

```text
adjust 0 5 1 -0.002 0.002 0
steerer 0 0.02 0 0 0 0 0.002
quad 0.1 0.02 0 6
drift 0.3 0.02 0
diag_position 0 0 0 0
```

校正在误差研究中进行（需要 `err_step` 等命令），算法、参数含义与完整的案例见[误差与校正](#errors)。

### 在内核里看轨道

要用内核看校正铁的效果，可以在示例项目的副本中加入一个 `steerer`（后接一段 drift 或四极铁），以单粒子或少量粒子运行内核，观察 DataSet.txt 中束流中心（第 29 列 + 第 1 列）沿 $z$ 的变化，并用 $\Delta x' = -B_y L/B\rho$ 核对下游的偏移量和方向。

### 典型取值

| 量 | 典型范围 | 说明 |
|---|---|---|
| 积分场 $BL$ | $10^{-5}$–$10^{-3}$ T·m | 常温小型校正线圈 |
| 电场 $E$ | $10^4$–$10^6$ V/m | 低能静电偏转板 |
| 偏转角 | 0.1–数 mrad | 由轨道误差预算决定 |
| 数量 | 每个方向每 1–2 个聚焦周期一个 | 与 BPM 配对 |

### 数值例子

示例束流：质子 1.527 MeV，$B\rho = 0.17863$ T·m，$E\rho = 3.05$ MV（$pv = 3.05$ MeV）。

| 校正铁 | 场 | 作用长度 | 偏转角 |
|---|---|---|---|
| 磁场 | $B_y = 1$ mT | 0.1 m | 0.56 mrad |
| 磁场 | $B_y = 3$ mT | 0.1 m | 1.68 mrad |
| 磁场 | $B_y = 10$ mT | 0.1 m | 5.6 mrad |
| 电场 | $E_x = 10^5$ V/m | 0.1 m | 3.28 mrad |

产生 1 mrad 偏转需要 $BL = 1.79\times 10^{-4}$ T·m 或 $EL = 3.05\times 10^{3}$ V。对这样低的速度（$\beta = 0.057$），$10^5$ V/m 的电场与 5.9 mT 的磁场等效（$E = vB$，$v = 1.71\times 10^7$ m/s）。

### 常见问题

- 给 `steerer` 写了非零长度：手册要求长度为 0，lattice 会给出警告。
- 把 `steerer` 放在 lattice 最后：它没有"下一个元件"可作用；而且它是矩阵模型元件，本来也不宜放在首尾。
- `kind` 与单位不符：`kind = 1` 时 `Bx`、`By` 位置写的是 V/m，数值通常比磁场（T）大好几个数量级。
- 在包络预览里看不到校正铁的效果：包络预览不画中心轨道，要看动画、研究页或内核运行。
