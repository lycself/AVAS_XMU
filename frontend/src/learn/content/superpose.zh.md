# 叠加场

在 AVAS 的 lattice 里，元件一个接一个首尾相连，每个元件独占一段 $z$。可真实的加速器不是这样排的：超导螺线管的边缘场伸进相邻的腔里，螺线管里还绕着校正线圈，长边缘场的磁铁靠得很近。两个元件怎么能占据同一段空间？把两张场图的数值加起来就行吗？什么时候加起来是错的？

本章用一个事实回答这些问题：真空中的 Maxwell 方程是线性的，所以分别算出的场可以相加——前提是两个元件彼此不改变对方的场。在此基础上说明 AVAS 的 `superpose` 命令怎样确定每个元件的纵向位置，叠加在示例里实际改变了什么，以及 `superposeend` 与 `superposeout` 的区别。需要先读 [场图](#field-maps)；场图元件的物理见 [射频腔](#rf-cavity) 与 [静电与静磁场图](#static-fields)。

下面是手册示例的叠加组：螺线管 sol 与腔 hwr010 重叠 5 mm。2D 图把重叠的元件上下分层画出（分层只是示意，不表示横向偏移）。线性预览中，块从 $z = 0.085\ \mathrm{m}$ 开始、在 0.64 m 结束，束流在螺线管下游 $z \approx 0.42\ \mathrm{m}$ 处到达束腰（rms x 0.27 mm），腔把动能从 1.527 MeV 提到 1.866 MeV，末端（0.94 m）rms x 为 5.25 mm。

```avas-beamline
drift 0.085 0.02 0
superpose 0 0 0 0 0 0
field 0.35 0.02 0 3 0 0 1 0.531 sol
superpose 0.345 0 0 0 0 0
field 0.21 0.02 0 1 162.5e6 -33 1.36 -1.36 hwr010
superposeend
drift 0.3 0.02 0
```

## 为什么要让场重叠 {#superpose-role}

把一张场图放进 lattice，等于说"从这里到这里，粒子感受到的是这张图里的场"。如果两个元件的场在空间上重叠，而我们仍然把它们首尾相接，就只剩两种选择：要么把两张场图都在交界处截断，丢掉各自伸进对方的那部分边缘场（截断处若场还不小，粒子会受到虚假的边缘冲击，见 [场图两端](#field-maps-grid)）；要么承认它们重叠，让两张图在重叠区里同时起作用。`superpose` 就是第二种选择。

典型用途：

- **螺线管与射频腔**：低 β 超导段中螺线管紧挨着腔，螺线管场图的边缘部分与腔场图重叠。手册与案例教程的示例就是螺线管场图 `sol` 与腔场图 `hwr010` 的叠加。
- **带校正线圈的磁铁**：螺线管或四极中嵌有偶极校正线圈，可以把校正线圈的场图与主磁铁场图叠加。这是重叠最彻底的情形：两个场占据同一段空间。
- **边缘场很长的场图**：两个场图首尾相接时，必须把各自的边缘场截断在交界处；叠加允许两个场图都保留完整的边缘场，在重叠区内场相加。

不需要用叠加的情况：矩阵模型的四极里放一个校正铁，直接在 `quad` 前写 `steerer` 即可——校正铁长度为 0，默认作用于下一个元件的全长并位于其中间，见 [校正铁](#steerer)。

## 叠加的物理：Maxwell 方程是线性的 {#superpose-physics}

真空中的 Maxwell 方程是线性的：若 $(\boldsymbol{E}_1, \boldsymbol{B}_1)$ 和 $(\boldsymbol{E}_2, \boldsymbol{B}_2)$ 各自是解，它们的和也是解。几个源产生的总场等于各自场的矢量和，粒子受到的力为

$$
\boldsymbol{F} = q\Bigl[\sum_i \boldsymbol{E}_i(\boldsymbol{r}, t) + \boldsymbol{v}\times\sum_i \boldsymbol{B}_i(\boldsymbol{r}, t)\Bigr]
$$

其中每个场按其所在元件的坐标平移：第 $i$ 个元件的场图坐标 $z_i' = z - z_b - z_{0,i}$（$z_b$ 为块的起点，见 [下一节](#superpose-z)），并乘以各自的 Ke、Kb；射频场再乘以各自的时间因子（电场 cos、磁场 sin，见 [射频腔](#rf-cavity-in-avas)）。内核用 t-code 在总场中积分。

> **想一想**：两张各自满足 $\nabla\cdot\boldsymbol{B} = 0$ 的场图相加，和还满足 $\nabla\cdot\boldsymbol{B} = 0$ 吗？这里有没有隐含的条件？
>
> 答：散度是线性运算，所以和的散度为零。隐含的条件是：每张场图在重叠区里都是**同一个真空区域**中的解。若一个元件的导体、铁轭或线圈恰好处在另一个元件的场里，那里就不是真空，单独算出的场图在那里并不是正确的解。

这个隐含条件就是叠加的局限：

- **只有线性介质才能叠加**。分别计算的场图相加，默认各元件互不影响。含铁磁轭的磁铁靠得很近时，铁的饱和与相互磁化会改变各自的场；超导腔壁会屏蔽冷却之后才加上的静磁场（迈斯纳效应；冷却时已存在的磁通则可能被冻结在铌中），螺线管在腔内的真实杂散场与单独计算的螺线管场图并不相同。要求精确时应在同一个电磁场计算中求出组合场，再作为一张场图使用。
- **射频场的时间结构**。不同射频腔各自有频率与相位，AVAS 规定一组叠加场中最多一个射频腔；静态场的个数不受此限制。手册没有说明这条规则的原因；两个腔的场明显重叠的情形不能用 AVAS 的叠加描述。
- **静态场与射频场叠加时**，静磁场不做功，不直接改变能量增益；它改变的是腔内的横向运动。

## 纵向位置怎么算 {#superpose-z}

### 块的零点

叠加块从第一条 `superpose` 开始。设此时 lattice 已累计到 $z_b$（第一条 superpose 之前所有元件的总长），则块内第 $i$ 个元件占据

$$
z \in \bigl[\,z_b + z_{0,i},\ \ z_b + z_{0,i} + L_i\,\bigr]
$$

其中 $z_{0,i}$ 是该元件前面那条 `superpose` 的第一个参数，即"该元件入口相对于第一条 superpose 后元件入口的纵向位置"。第一条 superpose 的参数必须全为 0，它定义了零点。换句话说，块里的位置不再是"接着上一个元件往下排"，而是每个元件都相对同一个零点各自定位。

### 块之后的位置

AVAS 界面（结构页、二维布局、线性预览）把块的长度取为块内元件出口的最远位置：

$$
z_{after} = z_b + \max_i\bigl(z_{0,i} + L_i\bigr)
$$

`superposeend` 之后的元件从 $z_{after}$ 接着排。手册没有明确写出内核对块后位置的规则；正式计算前可以用运行结果 DataSet.txt 的位置（第 5 列加第 33 列）或束线图核对总长度。

### 示例

手册与案例教程中的 lattice：

```text
start
drift      0.085  0.02   0
superpose  0 0 0 0 0 0
field      0.35   0.02     0   3   0   0   1    0.531  sol
superpose  0.345 0 0 0 0 0
field      0.21   0.02     0   1   162.5e6   -33   1.36    -1.36   hwr010
superposeend
end
```

| 元件 | $z_0$ / m | 占据范围 / m |
|---|---|---|
| drift | — | 0 – 0.085 |
| sol（静磁） | 0 | 0.085 – 0.435 |
| hwr010（射频） | 0.345 | 0.430 – 0.640 |
| 块之后 | — | 从 0.640 开始 |

螺线管场图的最后 5 mm 与腔场图的最初 5 mm 重叠，两张场图的边缘都完整保留。若把 $z_0$ 写成 0.35（= 螺线管长度），两个元件恰好首尾相接，与不用叠加、依次写两个 `field` 等价；线性预览中两种写法的结果完全相同。

> **注意**：手册原文的这个例子中第二条 superpose 写了 7 个数（`superpose 0.345 0 0 0 0 0 0`），多了一个 0；superpose 只有 6 个参数，见 [在 AVAS 中](#superpose-in-avas)。

## 叠加改变了什么 {#superpose-effect}

先估计一下手册示例的 5 mm 重叠里有多少场。`sol` 场图最后 5 mm 的轴上 $B_z$ 只有峰值的约 0.25 %，这段只占整个 $\int B_z\,\dd z$ 的约 0.01 %、$\int B_z^2\,\dd z$ 的 $4\times 10^{-7}$；`hwr010` 最初 5 mm 的 $\int\lvert E_z\rvert\,\dd z$ 只占全腔的 0.04 %。两张图在重叠区里都几乎为零——这正是场图两端"应已衰减到可以忽略"的要求。那么在这个例子里，叠加改变的是什么？

做一个对照（线性预览，无空间电荷）：只改变腔前那条 superpose 的 $z_0$，并调整块后漂移段的长度，让束线总长都是 0.945 m，这样末端在同一个位置比较。再把每种情况的腔场关掉（Ke = Kb = 0）各算一次：

| $z_0$ / m | 与螺线管的重叠 | 腔占据 / m | 出口能量 / MeV | 末端 rms x / mm | 腔场关掉时 / mm |
|---|---|---|---|---|---|
| 0.35 | 无（等价于依次排列） | 0.435 – 0.645 | 1.8665 | 5.36 | 4.80 |
| 0.345 | 5 mm | 0.430 – 0.640 | 1.8665 | 5.32 | 4.80 |
| 0.30 | 50 mm | 0.385 – 0.595 | 1.8665 | 4.82 | 4.81 |
| 0.25 | 100 mm | 0.335 – 0.545 | 1.8665 | 4.13 | 4.79 |

三件事一目了然：

- **出口能量几乎不变**（差别小于 0.1 keV）：静磁场不做功，而腔用 V3 = 0 指定同步相位，内核（以及预览）会按新的位置重新反解入口相位（示例四种情况都是 $52.67^\circ$）。
- **螺线管尾部本身几乎没有作用**：最后一列（只有螺线管）在 4.79–4.81 mm 之间，即使重叠 100 mm，尾部也只含 $\int B_z^2$ 的 0.4 %。
- **变化来自腔相对束腰的位置**：螺线管把束流聚到 $z \approx 0.42\ \mathrm{m}$ 的束腰（rms x 0.27 mm）。$z_0$ 越小，腔越靠近束腰：$z_0 = 0.35$ 时腔中心处 rms x 约 1.2 mm，$z_0 = 0.25$ 时只有约 0.3 mm。腔的散焦大部分来自第一个间隙（在这么低的 β 下，第一个间隙远离自己的波峰，见 [射频腔](#rf-cavity-transverse)），它位于腔入口后约 6.5 cm。$z_0 = 0.35$ 时这个间隙在束腰下游约 8 cm，束流已经在发散，向外的冲量叠加到角度上，末端尺寸变大（5.36 mm，不开腔为 4.80 mm）；$z_0 = 0.25$ 时它在束腰**上游**约 2 cm，束流还在会聚，同样向外的冲量反而抵消了一部分会聚角，腔后的角度分散变小，再加上加速带来的绝热阻尼（角度缩小约 10 %），末端尺寸比不开腔时还小（4.13 mm 对 4.79 mm）。把腔近似成两个薄透镜的估算重现了这个趋势（四行依次为 5.14、5.10、4.65、4.07 mm）。

所以在手册示例里，`superpose` 的意义主要是**把腔放在它真实的位置上**、同时保留两张场图完整的边缘，而不是重叠区里的场本身。重叠区的场真正起作用的，是校正线圈嵌在主磁铁里、或边缘场很长的情形。

> **想一想**：为什么一个透镜放在束腰处几乎不改变下游的束流尺寸？
>
> 答：透镜给每个粒子的角度冲量正比于它离轴的距离 $x$。束腰处所有粒子的 $x$ 都很小，冲量也就很小；而下游的尺寸由束腰处的角度决定，透镜几乎碰不到它们。用传输矩阵说：$\Delta x' = x/f$ 的薄透镜（这里 $f > 0$ 表示散焦）使 $\sigma_{22}$ 改变 $2\sigma_{12}/f + \sigma_{11}/f^2$。束腰处 $\sigma_{12} = 0$、$\sigma_{11}$ 最小，只剩很小的第二项。离开束腰时第一项占主导，而且符号要紧：束腰之后（$\sigma_{12} > 0$）散焦透镜增大角度分散，束腰之前（$\sigma_{12} < 0$）反而减小它——上表 $z_0 = 0.25$ 的情形正是如此。

## 容易误解的地方 {#superpose-pitfalls}

- **"叠加就是把场图数值加起来，总是对的"**：只适用于线性介质中分别计算的场；铁磁饱和、相互磁化和超导壁的迈斯纳效应都不能用叠加近似，见 [叠加的物理](#superpose-physics)。
- **"重叠越多，叠加越重要"**：示例中 5 mm 的重叠里几乎没有场；叠加改变结果主要是因为元件的位置变了，见 [叠加改变了什么](#superpose-effect)。
- **第一条不为零**：第一条 superpose 写了非零 $z_0$，整个块会被错误地平移；它必须全为 0。
- **漏写 superpose**：块内每个元件前都要有一条，连续两条也不行。
- **忘记结束**：没有 superposeend / superposeout 时，后面的元件都会被当作块内元件。
- **两个射频腔**：两个腔的场重叠时不能放进同一块。若只是边缘场的尾部轻微重叠，可以在场已衰减到可忽略处截断场图、首尾相接（截断处的场要足够小，见 [场图两端](#field-maps-grid)）。
- **把块长度算错**：块后元件从块内最远的出口开始，而不是从最后一个元件的出口开始；块内元件建议按 $z$ 的顺序书写。
- **偏移参数被忽略**：以 superposeend 结束时，$x_0$、$y_0$ 和角度都不起作用；需要偏移时要用 superposeout。

## 在 AVAS 中 {#superpose-in-avas}

### 语法与规则

```text
superpose     z0  x0  y0  θz0  θx0  θy0
superposeend
superposeout  z0  x0  y0  θz0  θx0  θy0
```

```avas-params
superpose superposeend superposeout
```

规则（来自手册，结构页会检查）：

1. 第一条 `superpose` 的参数必须全为 0，作为其他 superpose 的零点。
2. `superpose`（以及 `superposeout`）的 6 个参数给出其后一个元件的入口平面（转换平面）相对于第一条 superpose 后元件入口平面的位置（$z_0$、$x_0$、$y_0$，m）和角度（$\theta_{z0}$、$\theta_{x0}$、$\theta_{y0}$，度）。
3. 叠加块必须以 `superposeend` 或 `superposeout` 结束；只有以 `superposeout` 结束时，$z_0$ 以外的参数才生效。以 `superposeend` 结束时元件只在纵向上叠加。
4. 一组叠加场中最多只能有一个射频腔。
5. 叠加块中每个元件前有且只有一条 `superpose`。

> **AVAS 约定**：手册只给出了场图元件的叠加示例。块内放矩阵模型元件（`quad`、`solenoid`、`bend` 等）的行为没有文档；线性预览会忽略块内除 `field`、`drift`、`steerer` 和束诊以外的元件并给出警告。请只在块内放场图元件。

### superposeend 与 superposeout

| 结束方式 | 生效的参数 | 用途 |
|---|---|---|
| `superposeend` | 只有各 superpose 的 $z_0$ | 同轴元件的纵向重叠（最常见） |
| `superposeout` | $z_0$ 以及 $x_0$、$y_0$、$\theta_{z0}$、$\theta_{x0}$、$\theta_{y0}$ | 块内元件相对于零点有横向偏移或转角，例如研究螺线管相对腔的错位、倾斜，或绕 $z$ 轴转动场图 |

手册的原文是 `superpose`（`superposeout`）后面的 6 个参数给出该命令之后一个元件的入口平面相对于块零点的位置和角度。按字面理解，`superposeout` 自身的参数对应块之后的元件；内核是否据此改变块后束线的位置和方向，手册没有进一步说明，以内核为准。

> **注意**：偏移和转角的具体约定（三个转角的作用顺序、坐标系的正方向）手册没有说明，以内核为准；使用前建议用单粒子运行（`particlenumber 1`）验证一个简单的偏移是否按预期出现在轨迹中。AVAS 界面的束线布局不读取这些参数，线性预览也忽略 superposeout 的偏移和转角（会给出警告）。对静态的安装误差，更常规的做法是使用误差命令，见 [误差与校正](#errors)。

### 界面中的叠加组

- **结构树**：一个叠加块显示为一个组 `superpose (n)`，$n$ 是块内元件数；块内的 superpose 行、元件和结束行都在组内。
- **检查提示**：第一条 superpose 不全为 0（警告）；块没有以 superposeend / superposeout 结束（错误）；元件前缺少 superpose（错误）；连续两条 superpose（错误）；块内多于一个射频腔（警告）。
- **二维布局与结构页小束线图**：按真实 $z$ 区间把重叠的元件上下分层显示，横向位置和长度不变；分层只是示意，不表示横向偏移。每一层可以单独点击选中，鼠标悬停时列出该位置的全部叠加元件，叠加组用括线标出；层数不限，层多时可以滚动。
- **可视化编辑器的拖放**：把元件拖到某个非漂移元件的图形上，会以该元件的入口为起点建立叠加，可以连续叠加多个同起点元件；拖到普通非漂移元件内部会自动创建叠加组，端点仍按顺序插入，漂移段照常拆分。组内位置相对首元件计算，首元件固定为 0；组长度变化会移动下游元件。作用于整组的按钮会明确写出"整组"。二维、三维视图中的右键菜单提供叠加元件、复制、删除等操作；浏览状态或运行锁下写操作不可用。
- **线性预览**：同一块内所有场图的场按位置相加后统一计算，参考粒子能量、横向梯度与螺线管场都一并叠加。

### 练习

1. 复制示例项目，在结构页新建一个 lattice，写入 [示例](#superpose-z)，确认二维布局中两个元件分两层显示，悬停在重叠处能看到两个元件。
2. 把 $z_0$ 改成 0.35，再改成依次写两个 `field` 的形式，比较两种写法的线性预览曲线是否重合。
3. 把块的结束改成 superposeout，并给腔的 superpose 一个 $x_0 = 0.001$，观察线性预览给出的警告；再用单粒子运行看内核中轨迹的变化。
4. 在场图查看器中看螺线管场图出口端的 $B_z$ 衰减，判断 5 mm 的重叠里还有多少场：

```avas-field
map sol
```
