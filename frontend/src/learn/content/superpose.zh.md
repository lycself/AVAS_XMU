# 叠加场

在 AVAS 的 lattice 里，元件像火车车厢一样一节接一节：每个元件从上一个元件的出口开始，独占自己那一段 $z$。可真实的加速器不是这样排的。磁铁的场并不在铁的端面处戛然而止，而是向外伸出一段、逐渐减弱，这段叫**边缘场**。超导螺线管的边缘场会伸进紧挨着的射频腔里；有的螺线管里面还绕着一组小的校正线圈，两个场干脆占据同一段空间。

于是有三个问题：

1. 两个元件怎么能占据同一段空间？
2. 把两张场图（记录空间各点场强的数据表，见[场图](#field-maps)）的数值直接加起来就行吗？
3. 什么时候这样加起来是错的？

这一章用一个中学就学过的事实回答它们：**几个场同时存在时，粒子受的力就是各个场单独施加的力之和**，前提是这几个元件彼此不改变对方的场。在此基础上，再说明 AVAS 的 `superpose` 命令怎样确定每个元件的位置、在示例里叠加实际改变了什么，以及 `superposeend` 与 `superposeout` 的区别。场图元件本身的物理见[射频腔](#rf-cavity)与[静电与静磁场图](#static-fields)。

下面是手册示例的叠加组：螺线管 sol（静磁场图，0.35 m）与射频腔 hwr010（0.21 m）重叠 5 mm。点开 2D 图，重叠的两个元件被上下分成两层画出来（分层只是示意，不表示横向偏移）。再看曲线：块从 $z = 0.085\ \mathrm{m}$ 开始、在 0.64 m 结束；螺线管把束流聚焦，束流在螺线管下游 $z \approx 0.42\ \mathrm{m}$ 处最细（这叫**束腰**，rms x 0.27 mm）；腔把动能从 1.527 MeV 提到 1.866 MeV；末端（0.94 m）rms x 为 5.35 mm。

```avas-beamline
drift 0.085 0.02 0
superpose 0 0 0 0 0 0
field 0.35 0.02 0 3 0 0 1 0.531 sol
superpose 0.345 0 0 0 0 0
field 0.21 0.02 0 1 162.5e6 -33 1.36 -1.36 hwr010
superposeend
drift 0.3 0.02 0
```

## 为什么要让场重叠 {#superpose-role}

把一张场图放进 lattice，等于说"从这里到这里，粒子感受到的是这张图里的场"。如果两个元件的场在空间上重叠，而我们仍然把它们首尾相接，就只剩两种选择：

- 把两张场图都在交界处截断，丢掉各自伸进对方的那部分边缘场。截断处如果场还不小，粒子会在那里突然从"有场"跳到"没场"，受到一个现实中并不存在的冲击（见[场图两端](#field-maps-grid)）。
- 承认它们重叠，让两张图在重叠区里同时起作用。

`superpose`（叠加）就是第二种选择。典型用途：

- **螺线管与射频腔**：低速段（粒子速度只有光速的百分之几到二十几，叫低 β 段）的超导加速段里，螺线管紧挨着腔，螺线管场图的边缘部分与腔场图重叠。手册与案例教程的示例就是螺线管场图 `sol` 与腔场图 `hwr010` 的叠加。
- **带校正线圈的磁铁**：螺线管或四极铁中嵌有偶极校正线圈（让束流整体偏一点角度的小线圈，见[校正铁](#steerer)），可以把校正线圈的场图与主磁铁场图叠加。这是重叠最彻底的情形：两个场占据同一段空间。
- **边缘场很长的场图**：两个场图首尾相接时，必须把各自的边缘场截断在交界处；叠加允许两个场图都保留完整的边缘场，在重叠区内场相加。

不需要用叠加的情况：矩阵模型的四极铁里放一个校正铁，直接在 `quad` 前写 `steerer` 即可。校正铁长度为 0，默认作用于下一个元件的全长并位于其中间，见[校正铁](#steerer)。

## 叠加的物理：力可以相加 {#superpose-physics}

### 中学里的叠加原理

中学物理有两条大家熟悉的规律：

- **力的合成**：几个力同时作用在一个物体上，效果等于它们的矢量和（平行四边形定则）。
- **场的叠加**：两个点电荷在某点产生的电场，等于各自单独产生的电场的矢量和；两根通电导线周围的磁场也一样。

把两条合起来：一个粒子同时处在螺线管的磁场和腔的电场里，它受的力就是"螺线管单独对它的力"加上"腔单独对它的力"。所以要算总的效果，只需要把两张场图在同一位置的数值加起来。

每张场图都要先放到自己的位置上（下一节讲怎么算位置），再乘以自己的缩放系数：电场乘 Ke，磁场乘 Kb；射频场还要乘以各自随时间振荡的因子（电场按 cos、磁场按 sin，见[射频腔](#rf-cavity-in-avas)）。AVAS 内核用 t-code（按场一步步积分粒子运动的跟踪方式）在总场中跟踪粒子。完整的公式见[深入](#superpose-deep-linearity)。

### 什么时候不能相加

叠加原理有一个容易忽略的前提：**各个场要能各自单独算出来，而且放在一起时互不影响**。两张场图是分别计算（或分别测量）的，计算螺线管的场时，旁边并没有腔；计算腔的场时，旁边也没有螺线管。只要真的放在一起后它们互相改变了对方，相加就不对了：

- **铁会被磁化**。很多磁铁靠铁轭引导磁感线，而铁被磁化的程度取决于它所处的总磁场。两块带铁的磁铁靠得很近时，一块磁铁的场会改变另一块的铁的磁化，铁还会饱和（场再强，铁也帮不上更多忙）。这时单独算出的两张场图相加，不等于真实的总场。
- **超导腔壁会挡住磁场**。超导体冷却以后会把新加上的磁场排斥在外（迈斯纳效应；冷却时已经存在的磁通则可能被"冻结"在铌壁里）。所以螺线管在超导腔里的真实杂散场，和单独计算的螺线管场图并不相同。

要求精确时，应在同一个电磁场计算中把几个元件一起算出组合场，再作为一张场图使用。

另外还有两条规则和一个事实：

- **一组叠加场中最多一个射频腔**。不同的射频腔各有自己的频率与相位，AVAS 规定一组叠加场里最多放一个射频腔，静态场的个数不受此限制。手册没有说明这条规则的原因；两个腔的场明显重叠的情形不能用 AVAS 的叠加描述。
- **静磁场不改变能量**。磁场力总是垂直于速度，不做功（中学的"洛伦兹力不做功"）。所以静磁场和射频场叠加时，静磁场不直接改变能量增益，它改变的是腔内的横向运动。

## 纵向位置怎么算 {#superpose-z}

### 块的零点

叠加块从第一条 `superpose` 开始。设此时 lattice 已累计到 $z_b$（第一条 superpose 之前所有元件的总长），则块内第 $i$ 个元件占据

$$
z \in \bigl[\,z_b + z_{0,i},\ \ z_b + z_{0,i} + L_i\,\bigr]
$$

其中 $L_i$ 是该元件的长度，$z_{0,i}$ 是该元件前面那条 `superpose` 的第一个参数，即"该元件入口相对于第一条 superpose 后元件入口的纵向位置"。第一条 superpose 的参数必须全为 0，它定义了零点。换句话说，块里的位置不再是"接着上一个元件往下排"，而是每个元件都相对同一个零点各自定位，就像在一把尺子上各自标出起点。

### 块之后的位置

AVAS 界面（结构页、二维布局、线性预览）把块的长度取为块内元件出口的最远位置：

$$
z_{\text{after}} = z_b + \max_i\bigl(z_{0,i} + L_i\bigr)
$$

`superposeend` 之后的元件从 $z_{\text{after}}$ 接着排。手册没有明确写出内核对块后位置的规则；正式计算前可以用运行结果 DataSet.txt 的位置（第 5 列加第 33 列）或束线图核对总长度。

### 示例

手册与案例教程中的 lattice：

```text
start
drift      0.085  0.02   0
superpose  0 0 0 0 0 0
field      0.35   0.02     0   3   0   0   1    0.531  sol
superpose  0.345 0 0 0 0 0
field      0.21   0.02     0   1   162.5e6   -33   1.36    -1.36   hwr010
superposeend
end
```

| 元件 | $z_0$ / m | 占据范围 / m |
|---|---|---|
| drift | — | 0 – 0.085 |
| sol（静磁） | 0 | 0.085 – 0.435 |
| hwr010（射频） | 0.345 | 0.430 – 0.640 |
| 块之后 | — | 从 0.640 开始 |

验算：腔从 $0.085 + 0.345 = 0.430$ m 开始，到 $0.430 + 0.21 = 0.640$ m 结束；螺线管到 $0.085 + 0.35 = 0.435$ m 结束。所以螺线管场图的最后 5 mm 与腔场图的最初 5 mm 重叠，两张场图的边缘都完整保留。若把 $z_0$ 写成 0.35（= 螺线管长度），两个元件恰好首尾相接，与不用叠加、依次写两个 `field` 等价；线性预览中两种写法的结果完全相同。

> **注意**：手册原文的这个例子中第二条 superpose 写了 7 个数（`superpose 0.345 0 0 0 0 0 0`），多了一个 0；superpose 只有 6 个参数，见[在 AVAS 中](#superpose-in-avas)。

## 叠加改变了什么 {#superpose-effect}

### 腔本身做了什么

要看懂叠加改变了什么，先得知道腔单独对束流做了什么。下面的动画就是示例里的那张腔场图 hwr010，单独放在一段 5 cm 的漂移段后面，后接 0.2 m 漂移段；束流是示例束流（同步相位 −30°，Ke = 1.36，0.184 mA）。

```avas-motion
cavity
```

点"3D"，跟着束团走一遍：腔里有两个加速间隙，中心分别在腔入口后约 7 cm 和约 14 cm 处（动画把场线画在这两处），两个间隙的场方向相反，带小圆锥的场线随射频相位翻转、变大变小。束流穿过腔后动能增加 0.357 MeV。

再看 2D 的上方图（水平方向 $x$）：束流在腔里和腔后越来越粗，末端 rms x 是 3.0 mm。把 Ke 拖到 0，腔就变成一段空管道，末端只有 2.1 mm。所以这个腔在加速的同时，还像一块**散焦透镜**把束流横向推开。注意示例束流进腔时本来就在变粗（发散），腔的推力加在本来就向外的角度上。下面会看到，这正是叠加示例里结果变化的关键。

这个动画能说明的是腔的两个作用：**加速**和**横向散焦**。它不能说明叠加本身：动画里只有腔一个元件，没有螺线管，也没有两张场图相加；束流进腔前没有被螺线管聚焦成束腰；同步相位是 −30°，不是示例的 −33°，所以能量增益（0.357 MeV）和示例的 0.339 MeV 不同。另外，动画只在两个间隙处画场线，并不显示场图两端的场有多弱，这要看下面的数。

### 重叠区里有多少场

数一数手册示例的 5 mm 重叠里有多少场：`sol` 场图最后 5 mm 的轴上 $B_z$ 只有峰值的约 0.25 %，这段只占整个 $\int B_z\,\dd z$（沿轴把 $B_z$ 加起来的总量）的约 0.01 %、$\int B_z^2\,\dd z$（决定螺线管聚焦强度的量）的 $4\times 10^{-7}$；`hwr010` 最初 5 mm 的 $\int\lvert E_z\rvert\,\dd z$ 只占全腔的 0.04 %。两张图在重叠区里都几乎为零，这正是场图两端"应已衰减到可以忽略"的要求。那么在这个例子里，叠加改变的是什么？

### 一个对照实验

做一个对照（线性预览，无空间电荷）：只改变腔前那条 superpose 的 $z_0$，并调整块后漂移段的长度，让束线总长都是 0.945 m，这样末端在同一个位置比较。再把每种情况的腔场关掉（Ke = Kb = 0）各算一次：

| $z_0$ / m | 与螺线管的重叠 | 腔占据 / m | 出口能量 / MeV | 末端 rms x / mm | 腔场关掉时 / mm |
|---|---|---|---|---|---|
| 0.35 | 无（等价于依次排列） | 0.435 – 0.645 | 1.8665 | 5.46 | 4.87 |
| 0.345 | 5 mm | 0.430 – 0.640 | 1.8665 | 5.42 | 4.88 |
| 0.30 | 50 mm | 0.385 – 0.595 | 1.8665 | 4.94 | 4.90 |
| 0.25 | 100 mm | 0.335 – 0.545 | 1.8665 | 4.22 | 4.86 |

三件事一目了然：

- **出口能量几乎不变**（差别小于 0.1 keV）：静磁场不做功；腔用 V3 = 0 指定同步相位，内核（以及预览）会按新的位置重新反解入口相位（示例四种情况都是 $52.67^\circ$），所以束团总是在同一个相位上被加速。
- **螺线管尾部本身几乎没有作用**：最后一列（只有螺线管）在 4.86–4.90 mm 之间，即使重叠 100 mm，尾部也只含 $\int B_z^2$ 的 0.4 %。
- **变化来自腔相对束腰的位置**：$z_0$ 越小，腔越靠近螺线管造成的束腰（$z \approx 0.42$ m）。

### 透镜放在哪里很要紧

上面的动画已经看到，射频腔除了加速，还会把束流横向推开，像一块散焦透镜（原因见[射频腔](#rf-cavity-transverse)）。在这么低的速度下，散焦大部分来自第一个间隙（腔入口后约 6.5–7 cm）。

一块透镜的作用和它所在处束流的粗细关系很大。透镜给每个粒子的偏转正比于粒子离轴的距离；在束腰处所有粒子都离轴很近，偏转也就很小。所以：

- $z_0 = 0.35$ 时，腔中心处 rms x 约 1.2 mm，第一个间隙在束腰**下游**约 8 cm。束流已经在变粗（发散），和动画里的情形一样，向外的推力加在本来就向外的角度上，末端更粗：5.46 mm，不开腔时是 4.87 mm。
- $z_0 = 0.25$ 时，腔中心处 rms x 只有约 0.3 mm，第一个间隙在束腰**上游**约 2 cm。束流还在变细（会聚），同样向外的推力反而抵消了一部分会聚的角度，腔后粒子的角度更整齐。再加上加速让角度缩小约 10 %（**绝热阻尼**：横向动量不变而纵向动量变大，角度就变小），末端比不开腔时还细：4.22 mm 对 4.86 mm。

把腔近似成两块薄透镜的估算重现了这个趋势（四行依次为 5.14、5.10、4.65、4.07 mm）。"为什么放在束腰处几乎没用、放在束腰前后符号相反"的一步步推导见[深入](#superpose-deep-waist)。

所以在手册示例里，`superpose` 的意义主要是**把腔放在它真实的位置上**、同时保留两张场图完整的边缘，而不是重叠区里的场本身。重叠区的场真正起作用的，是校正线圈嵌在主磁铁里、或边缘场很长的情形。

## 想一想 {#superpose-think}

> **想一想 1**：两张场图各自满足"磁感线不会凭空出现或消失"。把它们相加，和还满足吗？这里有没有隐含的条件？
>
> 答：满足。穿进一个小盒子的磁感线数等于穿出的，两张图各自成立，加起来也成立。隐含的条件是：每张场图在重叠区里都是**同一片真空**中的场。若一个元件的导体、铁轭或线圈恰好处在另一个元件的场里，那里就不是真空，单独算出的场图在那里并不是正确的场。

> **想一想 2**：为什么一个透镜放在束腰处几乎不改变下游的束流尺寸？
>
> 答：透镜给每个粒子的偏转正比于它离轴的距离。束腰处所有粒子都离轴很近，偏转也就很小；而下游的尺寸由束腰处粒子的角度决定，透镜几乎碰不到它们。

> **想一想 3**：把示例中腔的 $z_0$ 从 0.345 改成 0.35，结果几乎不变；改成 0.25，末端尺寸小了 1.2 mm。这两件事矛盾吗？
>
> 答：不矛盾。前者只改变了 5 mm 的重叠，重叠区里几乎没有场；后者把腔挪近了束腰 10 cm，改变的是腔所在处束流的粗细和会聚 / 发散状态。

## 容易误解的地方 {#superpose-pitfalls}

- **"叠加就是把场图数值加起来，总是对的"**：只适用于线性介质中分别计算的场；铁磁饱和、相互磁化和超导壁的迈斯纳效应都不能用叠加近似，见[叠加的物理](#superpose-physics)。
- **"重叠越多，叠加越重要"**：示例中 5 mm 的重叠里几乎没有场；叠加改变结果主要是因为元件的位置变了，见[叠加改变了什么](#superpose-effect)。
- **第一条不为零**：第一条 superpose 写了非零 $z_0$，整个块会被错误地平移；它必须全为 0。
- **漏写 superpose**：块内每个元件前都要有一条，连续两条也不行。
- **忘记结束**：没有 superposeend / superposeout 时，后面的元件都会被当作块内元件。
- **两个射频腔**：两个腔的场重叠时不能放进同一块。若只是边缘场的尾部轻微重叠，可以在场已衰减到可忽略处截断场图、首尾相接（截断处的场要足够小，见[场图两端](#field-maps-grid)）。
- **把块长度算错**：块后元件从块内最远的出口开始，而不是从最后一个元件的出口开始；块内元件建议按 $z$ 的顺序书写。
- **偏移参数被忽略**：以 superposeend 结束时，$x_0$、$y_0$ 和角度都不起作用；需要偏移时要用 superposeout。

## 深入：为什么场可以相加，什么时候不行 {#superpose-deep-linearity}

正文用"力的合成"和"场的叠加"说明了场图可以相加。这一节一步步说明这件事为什么成立、哪一步会在铁和超导体里失效，最后一段给学过电磁学的读者。

### 第一步：力相加

牛顿第二定律只关心物体受的合力。粒子同时受到电场力 $q\boldsymbol{E}$ 和磁场力（洛伦兹力），合力就是它们的矢量和。若有两个元件，各自单独给出的力是 $\boldsymbol{F}_1$ 和 $\boldsymbol{F}_2$，只要这两个力在放在一起时不变，合力就是 $\boldsymbol{F}_1 + \boldsymbol{F}_2$。问题于是变成：两个元件放在一起时，各自的场会不会变？

### 第二步：线圈的场正比于电流

中学学过长直螺线管内部的磁场 $B = \mu_0 n I$（$n$ 是单位长度的匝数，$I$ 是电流），通电直导线周围的磁场也正比于电流。电流加倍，磁场加倍；两组线圈同时通电，磁场就是各自磁场之和。这种"原因加倍、结果也加倍，原因相加、结果也相加"的关系叫**线性**。真空中的电场和磁场都是线性的，所以分别算出的场可以相加。

### 第三步：相加以后仍然是"合法"的场

磁场有一条铁律：磁感线不会凭空出现或消失，穿进任意小盒子的磁感线数等于穿出的（见[四极铁](#quadrupole-deep-field)）。两张场图各自满足这一条，把穿进、穿出的数目分别相加，等式仍然成立。所以相加后的场也满足这条铁律，不会出现物理上不可能的场。

### 第四步：铁为什么破坏线性

铁的作用是被磁化，自己也产生磁场，帮着线圈把磁感线引到需要的地方。可是铁的磁化程度并不和外加磁场成正比：外场不大时，铁的磁化随外场迅速增加；到 1–1.5 T 附近铁开始**饱和**，外场再加，铁也帮不上多少忙。所以铁轭磁铁的场并不严格正比于电流。两块铁轭磁铁靠得很近时，一块的场会改变另一块的铁的磁化程度，"分别算再相加"就不等于"一起算"了。

### 第五步：超导体为什么破坏叠加

超导腔用铌制成，冷却到超导状态后，它会把冷却之后才加上的磁场排斥在外（迈斯纳效应）；而冷却时已经存在的磁通可能被"冻结"在铌壁中。单独计算螺线管场图时，旁边并没有这样一个会排斥磁场的腔壁，所以螺线管在腔内的真实杂散场和单独算出的场图不同。

### 第六步：射频场与静磁场一起时

射频场随时间振荡，每张射频场图要乘以自己的时间因子（电场按 $\cos(\omega t + \varphi_0)$，磁场按 sin）。静磁场不随时间变。洛伦兹力总是垂直于速度，力在速度方向上的分量为零，所以它不做功：静磁场不直接改变能量，只改变横向运动。这就是正文对照实验里四种重叠下出口能量相同的原因之一（另一个原因是 V3 = 0 时腔的入口相位会重新反解）。

### 给学过电磁学的读者

真空中的 Maxwell 方程是线性的：若 $(\boldsymbol{E}_1, \boldsymbol{B}_1)$ 和 $(\boldsymbol{E}_2, \boldsymbol{B}_2)$ 各自是解，它们的和也是解。几个源产生的总场等于各自场的矢量和，粒子受到的力为

$$
\boldsymbol{F} = q\Bigl[\sum_i \boldsymbol{E}_i(\boldsymbol{r}, t) + \boldsymbol{v}\times\sum_i \boldsymbol{B}_i(\boldsymbol{r}, t)\Bigr]
$$

其中每个场按其所在元件的坐标平移：第 $i$ 个元件的场图坐标 $z_i' = z - z_b - z_{0,i}$（$z_b$ 为块的起点，见[纵向位置](#superpose-z)），并乘以各自的 Ke、Kb；射频场再乘以各自的时间因子（电场 cos、磁场 sin，见[射频腔](#rf-cavity-in-avas)）。内核用 t-code 在总场中积分。散度是线性运算，两张各自满足 $\nabla\cdot\boldsymbol{B} = 0$ 的场图之和仍满足 $\nabla\cdot\boldsymbol{B} = 0$；隐含的条件是两张图在重叠区里都是同一真空区域中的解。铁磁介质的 $\boldsymbol{B} = \mu(\boldsymbol{H})\,\boldsymbol{H}$ 是非线性的本构关系，超导体给出 $\boldsymbol{B} = 0$ 的边界条件，它们都使"分别求解再相加"失效，需要在同一个边值问题中求组合场。

## 深入：透镜放在束腰处为什么几乎没用 {#superpose-deep-waist}

正文的对照实验里，腔离束腰越近，末端束流越细，腔放在束腰上游时甚至比不开腔还细。这一节用中学的代数（展开平方、求平均）一步步说明为什么。

### 第一步：一块薄透镜做什么

把腔的横向作用近似成一块薄的散焦透镜：粒子位置 $x$ 不变，角度 $x'$ 增加 $x/f$（$f > 0$ 表示散焦，离轴越远被往外推得越多）：

$$
x'_{\text{新}} = x' + \frac{x}{f}.
$$

### 第二步：角度的分散怎么变

下游的束流尺寸主要由粒子角度的分散决定。把上式平方，对所有粒子求平均（尖括号 $\langle\ \rangle$ 表示平均）：

$$
\langle x'^2_{\text{新}}\rangle = \langle x'^2\rangle + \frac{2}{f}\,\langle x\,x'\rangle + \frac{1}{f^2}\,\langle x^2\rangle .
$$

这就是中学的完全平方展开 $(a + b)^2 = a^2 + 2ab + b^2$，再逐项求平均。

### 第三步：中间那一项的意思

$\langle x\,x'\rangle$ 描述位置和角度的关系：

- 束流在**变粗**（发散）时，偏在外侧的粒子往外飞（$x > 0$ 时 $x' > 0$，$x < 0$ 时 $x' < 0$），$\langle x\,x'\rangle > 0$；
- 束流在**变细**（会聚）时正好相反，$\langle x\,x'\rangle < 0$；
- 在**束腰**处，束流不粗不细，$\langle x\,x'\rangle = 0$。

### 第四步：三种位置

- **在束腰处**：中间项为零，只剩 $\langle x^2\rangle/f^2$。束腰处 $\langle x^2\rangle$ 最小，这一项很小，透镜几乎不改变角度分散。
- **在束腰下游**（发散）：中间项为正，散焦透镜让角度分散变大，下游更粗。$z_0 = 0.35$ 时腔的第一个间隙在束腰下游约 8 cm，末端 5.46 mm（不开腔 4.87 mm）。
- **在束腰上游**（会聚）：中间项为负，只要 $\langle x^2\rangle/f^2$ 不太大，散焦透镜反而让角度分散变小。$z_0 = 0.25$ 时第一个间隙在束腰上游约 2 cm，末端 4.22 mm（不开腔 4.86 mm）。

数一数大小：$\langle x^2\rangle$ 是 rms 尺寸的平方。$z_0 = 0.35$ 时腔中心处 rms x 约 1.2 mm，$z_0 = 0.25$ 时约 0.3 mm，平方相差十几倍；最后一项小了这么多，中间项的符号就决定了结果。

### 第五步：加速让角度变小

角度是横向动量与纵向动量之比 $x' = p_x/p$。腔加速时纵向动量 $p$ 变大，横向动量基本不变，角度就按 $p_{\text{入}}/p_{\text{出}}$ 缩小（绝热阻尼）。示例束流 $p$ 从 53.55 MeV/$c$（1.527 MeV）增加到 59.21 MeV/$c$（1.866 MeV），角度缩小到 0.904 倍，约 10 %。

### 给学过线性代数的读者

用束流的二阶矩矩阵 $\sigma$（$\sigma_{11} = \langle x^2\rangle$，$\sigma_{12} = \langle x x'\rangle$，$\sigma_{22} = \langle x'^2\rangle$），薄透镜 $M = \begin{pmatrix} 1 & 0 \\ 1/f & 1\end{pmatrix}$ 使 $\sigma \to M\sigma M\tp$，于是 $\sigma_{22}$ 改变 $2\sigma_{12}/f + \sigma_{11}/f^2$。束腰处 $\sigma_{12} = 0$、$\sigma_{11}$ 最小，只剩很小的第二项。离开束腰时第一项占主导，而且符号要紧：束腰之后（$\sigma_{12} > 0$）散焦透镜增大角度分散，束腰之前（$\sigma_{12} < 0$）反而减小它，正文表中 $z_0 = 0.25$ 的情形正是如此。

## 在 AVAS 中 {#superpose-in-avas}

### 语法与规则

```text
superpose     z0  x0  y0  θz0  θx0  θy0
superposeend
superposeout  z0  x0  y0  θz0  θx0  θy0
```

```avas-params
superpose superposeend superposeout
```

规则（来自手册，结构页会检查）：

1. 第一条 `superpose` 的参数必须全为 0，作为其他 superpose 的零点。
2. `superpose`（以及 `superposeout`）的 6 个参数给出其后一个元件的入口平面（转换平面）相对于第一条 superpose 后元件入口平面的位置（$z_0$、$x_0$、$y_0$，m）和角度（$\theta_{z0}$、$\theta_{x0}$、$\theta_{y0}$，度）。
3. 叠加块必须以 `superposeend` 或 `superposeout` 结束；只有以 `superposeout` 结束时，$z_0$ 以外的参数才生效。以 `superposeend` 结束时元件只在纵向上叠加。
4. 一组叠加场中最多只能有一个射频腔。
5. 叠加块中每个元件前有且只有一条 `superpose`。

> **AVAS 约定**：手册只给出了场图元件的叠加示例。块内放矩阵模型元件（`quad`、`solenoid`、`bend` 等）的行为没有文档；线性预览会忽略块内除 `field`、`drift`、`steerer` 和束诊以外的元件并给出警告。请只在块内放场图元件。

### superposeend 与 superposeout

| 结束方式 | 生效的参数 | 用途 |
|---|---|---|
| `superposeend` | 只有各 superpose 的 $z_0$ | 同轴元件的纵向重叠（最常见） |
| `superposeout` | $z_0$ 以及 $x_0$、$y_0$、$\theta_{z0}$、$\theta_{x0}$、$\theta_{y0}$ | 块内元件相对于零点有横向偏移或转角，例如研究螺线管相对腔的错位、倾斜，或绕 $z$ 轴转动场图 |

手册的原文是 `superpose`（`superposeout`）后面的 6 个参数给出该命令之后一个元件的入口平面相对于块零点的位置和角度。按字面理解，`superposeout` 自身的参数对应块之后的元件；内核是否据此改变块后束线的位置和方向，手册没有进一步说明，以内核为准。

> **注意**：偏移和转角的具体约定（三个转角的作用顺序、坐标系的正方向）手册没有说明，以内核为准；使用前建议用单粒子运行（`particlenumber 1`）验证一个简单的偏移是否按预期出现在轨迹中。AVAS 界面的束线布局不读取这些参数，线性预览也忽略 superposeout 的偏移和转角（会给出警告）。对静态的安装误差，更常规的做法是使用误差命令，见[误差与校正](#errors)。

### 界面中的叠加组

- **结构树**：一个叠加块显示为一个组 `superpose (n)`，$n$ 是块内元件数；块内的 superpose 行、元件和结束行都在组内。
- **检查提示**：第一条 superpose 不全为 0（警告）；块没有以 superposeend / superposeout 结束（错误）；元件前缺少 superpose（错误）；连续两条 superpose（错误）；块内多于一个射频腔（警告）。
- **二维布局与结构页小束线图**：按真实 $z$ 区间把重叠的元件上下分层显示，横向位置和长度不变；分层只是示意，不表示横向偏移。每一层可以单独点击选中，鼠标悬停时列出该位置的全部叠加元件，叠加组用括线标出；层数不限，层多时可以滚动。
- **可视化编辑器的拖放**：把元件拖到某个非漂移元件的图形上，会以该元件的入口为起点建立叠加，可以连续叠加多个同起点元件；拖到普通非漂移元件内部会自动创建叠加组，端点仍按顺序插入，漂移段照常拆分。组内位置相对首元件计算，首元件固定为 0；组长度变化会移动下游元件。作用于整组的按钮会明确写出"整组"。二维、三维视图中的右键菜单提供叠加元件、复制、删除等操作；浏览状态或运行锁下写操作不可用。
- **线性预览**：同一块内所有场图的场按位置相加后统一计算，参考粒子能量、横向梯度与螺线管场都一并叠加。

### 练习

1. 复制示例项目，在结构页新建一个 lattice，写入[示例](#superpose-z)，确认二维布局中两个元件分两层显示，悬停在重叠处能看到两个元件。
2. 把 $z_0$ 改成 0.35，再改成依次写两个 `field` 的形式，比较两种写法的线性预览曲线是否重合。
3. 把块的结束改成 superposeout，并给腔的 superpose 一个 $x_0 = 0.001$，观察线性预览给出的警告；再用单粒子运行看内核中轨迹的变化。
4. 在场图查看器中看螺线管场图出口端的 $B_z$ 衰减，判断 5 mm 的重叠里还有多少场：
