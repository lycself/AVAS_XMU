# 抵达：高能传输段与靶

我们的质子终于到了 1 GeV，速度是光速的 87.5 %。如果设计流强是 10 mA，这股直径只有几毫米的束流携带着 10 MW 的功率，相当于几千台电暖器加在一起，却集中在一根铅笔芯粗细的束流里。

加速已经结束，为什么不让直线加速器顺着直线一头扎进靶里？加速器末端到靶之间的这段束线叫**高能传输段**（HEBT，High Energy Beam Transport），本章回答关于它的三个问题：

1. 为什么要拐弯？
2. 为什么要把束流故意放大，而不是聚得越小越好？
3. 为什么要担心每米丢掉一千万分之一的粒子？

两个日常的画面可以先放在心里。一个是放大镜：把太阳光聚成一个小点，能把纸点着；同样的阳光铺开照在纸上，纸只是暖一点。高功率束流打靶也一样，必须把束斑铺开。另一个是三棱镜：白光穿过它会散成彩虹，因为不同颜色的光偏折得不一样多。磁铁让束流拐弯时，能量不同的质子偏转得不一样多，也会"散开"；要让它们重新会合，就要用两块方向相反的"棱镜"。

最后，本章用一页把整段旅程从头走一遍。本章用到 [二极铁](#dipole)、[四极铁](#quadrupole) 和 [误差与校正](#errors) 的内容，各段数据见 [全貌](#journey-overview-thread)。

## 到达时的质子 {#journey-hebt-arrival}

在 1 GeV：洛伦兹因子 $\gamma = 2.066$（质子的总能量是静止能量的 2.066 倍），$\beta = 0.8750$，$\beta\gamma = 1.808$，动量 1696 MeV/c，磁刚度 $B\rho = 5.657\ \mathrm{T\,m}$，是 RFQ 出口的 32 倍：同样的磁铁，对它的偏转能力只剩三十二分之一。

束流变细了。归一化 rms 发射度（不随加速改变的那个束流品质，见 [漂移段](#drift-size)）若一路保持 0.14 π·mm·mrad，实际的（几何）发射度就只剩 $0.14/1.808 = 0.077\ \pi\,\mathrm{mm\,mrad}$；在 β 函数为 10 m 的地方（β 函数描述这一处束流有多粗，这里只作示意），rms 束流尺寸约 0.9 mm。束团在 650 MHz 下 rms 长约 0.8 mm（3 ps），rms 能散约 0.26 MeV，即相对动量分散 $\sigma_\delta \approx 2\times10^{-4}$（由 [全貌](#journey-overview-frequency) 中纵向发射度守恒的估算推出）。

此刻困扰低能段的问题几乎都消失了。空间电荷的强弱（广义导流系数）$\propto 1/(\beta\gamma)^3$，同样 10 mA 在 1 GeV 只有 1.527 MeV 时的约三万分之一；射频散焦也一样弱。

取而代之的是一个新问题：**功率**。束流功率按中学的 $P = UI$ 算：质子带一个单位电荷，1 GeV 相当于被 $10^9$ V 的电压加速，所以示例的 0.18 mA 在 1 GeV 是 $10^9\ \mathrm{V} \times 0.184\ \mathrm{mA} = 184\ \mathrm{kW}$。高功率 CW 质子直线加速器的设计流强通常是几到十几毫安（典型值），10 mA 就是 10 MW。HEBT 的设计几乎都围绕这一点：把这份功率安全地送到该去的地方，并且一路上几乎不丢。

## 为什么要拐弯：色散与消色散 {#journey-hebt-bending}

**为什么不走直线。** 把靶放在直线加速器的轴线正前方有几个坏处（典型考虑，不同装置不同）：靶产生的中子和其他辐射会沿束流管道反向射回加速器；调试时往往需要一个正前方的束流收集器，与靶分开；用二极铁偏转还能顺便测量和限制束流能量。所以 HEBT 通常要用**二极铁**（产生均匀磁场、让束流拐弯的磁铁，见 [二极铁](#dipole)）拐弯。

**拐弯半径。** 质子在均匀磁场里做圆周运动，洛伦兹力提供向心力：$qvB = mv^2/\rho$，整理得 $B\rho = mv/q = p/q$，这就是磁刚度这个名字的来历。所以二极铁的场 $B = B\rho/\rho$。在 1 GeV 用 1.5 T 的常温铁芯二极铁（铁的饱和使这类磁铁一般不超过约 1.5～1.8 T），偏转半径就是 $\rho = 5.657/1.5 = 3.77\ \mathrm{m}$。比起 RFQ 出口时同样场强下 0.12 m 的半径，高能束流"硬"得多。

**色散：磁铁是束流的三棱镜。** 拐弯带来一个新现象。动量较高的质子更"硬"，在同样的磁场里圆弧半径较大，于是偏向弯道外侧。设相对动量偏差为 $\delta$，它偏离中心轨道的位移是

$$
x = D\,\delta ,
$$

$D$ 叫**色散函数**，单位是米：动量多 1 %，位置偏开 $0.01\,D$。一块偏转角 $\theta$、半径 $\rho$ 的扇形二极铁，出口处

$$
D = \rho\,(1 - \cos\theta),\qquad D' = \sin\theta
$$

（$D'$ 是色散随路程增长的斜率；用中学几何的推导见 [深入：二极铁、色散与消色散的几何](#journey-hebt-deep-dispersion)，也见 [二极铁](#dipole)）。$15^\circ$、$\rho = 3.77\ \mathrm{m}$ 时 $D = 0.128\ \mathrm{m}$、$D' = 0.259$。出口之后色散像一条斜线那样随漂移增长，5 m 后已达 $0.128 + 5 \times 0.259 = 1.42\ \mathrm{m}$。

这有什么后果？假如上游某只腔的相位稍有偏差，让束流能量低了 1 MeV，相对动量偏差 $\delta = \Delta W/(\beta^2\gamma\,mc^2) = 6.7\times10^{-4}$（换算公式见 [中能传输段](#journey-mebt-deep-bunching)），靶上的束流中心就移动 $1.42 \times 6.7\times10^{-4} \approx 0.95\ \mathrm{mm}$，与 rms 束流尺寸相当。靶上的束斑位置随着能量抖动而晃动，这是不能接受的。

在下面的实验里，把能量设为 1000 MeV、偏转角 $15^\circ$、半径 3.77 m，可以看到所需的场 1.50 T、出口色散 0.128 m 和 $D' = 0.259$。

```avas-lab
dipole angle=15 rho=3.77 W=1000 delta=0.1
```

**消色散：两块棱镜反着放。** 解决办法是**消色散**（achromat）：安排几块二极铁和四极铁，使弯转段出口处 $D$ 与 $D'$ 同时为零，这样出口之后束流位置与能量无关。最简单的一种利用镜像对称：两块相同的二极铁，正中放一块四极铁。

- 四极铁之前，色散以 $D' = \sin\theta$ 的斜率增长，像一条往外斜的光线；
- 四极铁像一块透镜，把这条"光线"折回来。如果它把斜率正好反过来变成 $-\sin\theta$，后半段就是前半段的镜像；
- 前半段色散从 0 涨到最大，后半段就从最大回到 0：第二块二极铁出口处 $D = D' = 0$。

薄透镜把斜率改变 $-D_q/f$（$D_q$ 是四极铁处的色散，$f$ 是焦距），要从 $+\sin\theta$ 变成 $-\sin\theta$，就要改变 $2\sin\theta$：

$$
\frac{D_q}{f} = 2\sin\theta \quad\Rightarrow\quad f = \frac{D_q}{2\sin\theta} .
$$

取二极铁出口到四极铁中心 2 m，$D_q = 0.128 + 2\times0.259 = 0.646\ \mathrm{m}$，$f = 1.25\ \mathrm{m}$；四极铁长 0.3 m 时梯度 $G = B\rho/(fL_q) \approx 15.1\ \mathrm{T/m}$（焦距公式见 [四极铁](#quadrupole-focal)）。按厚透镜矩阵（AVAS 线性预览）精确求得 15.7 T/m，此时出口 $D$ 和 $D'$ 都为零，段内色散最大约 0.63 m。

## 在靶上把束流铺开 {#journey-hebt-expansion}

**放大镜的反面。** 把 10 MW 的束流以 rms 1 mm 的高斯束斑打在靶上，中心的功率密度是 $P/(2\pi\sigma_x\sigma_y) \approx 1.6\ \mathrm{MW/mm^2}$：每平方毫米一百多万瓦。没有任何材料能承受。靶能承受多少取决于材料和冷却方式，不同装置差别很大；但无论哪种靶，都必须把束斑从毫米量级放大到厘米甚至十厘米量级，面积放大上千到上万倍。

**用线性光学放大。** rms 尺寸 $\sigma = \sqrt{\beta\varepsilon}$，要 $\sigma = 30\ \mathrm{mm}$，在几何发射度 0.077 π·mm·mrad 下需要 $\beta \approx 1.2\times10^4\ \mathrm{m}$。这并非做不到：就像手电筒的光束越照越宽（见 [漂移段](#drift-spread)），从一个很细的束腰出发漂移足够远，束流就会变得很粗。按 [深入：靶上的束斑与束损统计](#journey-hebt-deep-target) 的公式，从 β 函数为 $\beta^* = 1\ \mathrm{m}$ 的束腰出发，漂移约 108 m 就够了（仅作示意；实际靶前的发射度往往比理想值大，所需的 β 会小一些）。

**但形状没变。** 线性放大不改变分布的形状：高斯束斑放大以后仍然中间高、四周低，中心的功率密度是同样面积（按 $\pm 2\sigma$ 的方形计）均匀分布的约 2.5 倍，而靶的寿命由最热点决定。常见的两种改进（典型做法）：

- **非线性磁铁**：八极铁等多极铁对远离轴的粒子作用更强，把分布的尾部"折"回来，使靶上分布接近均匀。
- **束流扫描**：用快速变化的偏转磁铁让一个较小的束斑在靶面上来回扫，就像用手电筒快速来回晃动照亮一面墙；扫描速度比靶的热响应快得多，时间平均后靶面受热均匀。

> **AVAS 不能直接模拟这两种做法**：AVAS 的元件里没有八极铁等多极铁的矩阵模型，也没有随时间变化的偏转磁铁；靶本身更不在模拟范围之内。线性部分（四极铁、二极铁、漂移段）可以模拟，靶前的粒子分布可以输出给专门的靶程序（见 [在 AVAS 中](#journey-hebt-in-avas)）。

## 束损：为什么是每米 1 瓦 {#journey-hebt-losses}

**活化。** 高能质子打在管壁或磁铁上，会引起核反应，让设备带上放射性（**活化**）。停机以后人员要靠近设备维护，所以高功率质子直线加速器广泛使用一个经验指标：沿线的束流损失不超过约 **1 W/m**，这样设备的残余活化可以接受人员上手维护（这是一个通用的设计准则，不是物理极限；它适用于能量足够高、会引起明显活化的区段）。

**这个数有多严？** 每个 1 GeV 的质子带 $10^9\ \mathrm{eV} = 10^9 \times 1.602\times10^{-19}\ \mathrm{J}$ 的能量，所以 1 W 相当于每秒 $1/(10^9 \times 1.602\times10^{-19}) = 6.2\times10^{9}$ 个质子。10 mA 的束流每秒有 $0.01/(1.602\times10^{-19}) = 6.2\times10^{16}$ 个质子，所以每米允许丢失的份额是 $10^{-7}$，一千万个里只能丢一个；示例的 0.18 mA（184 kW）是 $5.4\times10^{-6}$。

**对模拟的要求。** 这一点很容易被忽略。示例项目用 5260 个宏粒子（每个"宏粒子"代表一大群真实质子），每个宏粒子代表束流的 $1/5260 = 1.9\times10^{-4}$，在 10 MW 下就是 1.9 kW。也就是说，即使模拟里一个粒子也没丢，也只能说明损失低于千瓦量级，远不能证明满足 1 W/m。研究束损要用多得多的粒子、关注晕的形成（失配和非线性是主要来源，见 [匹配](#matching)），并做误差研究，看最坏情况下包络离孔径有多远（见 [误差与校正](#errors)）。

**准直器。** HEBT 里通常还有专门的**准直器**挡掉晕粒子，让损失集中在设计好的、屏蔽良好的地方。一个常用的原则：两块准直器相隔约 90° 的横向相移，一块挡住位置大的粒子，另一块挡住角度大的粒子。道理和单摆一样：摆球在最远处速度为零、在中间速度最大，过了四分之一个周期，"位置大"就变成了"速度大"。在束流里，粒子的横向摆动每走过 90° 的相移，角度大的粒子就变成了位置大的粒子（见 [深入：靶上的束斑与束损统计](#journey-hebt-deep-target)）。低能端的刮束则在 MEBT，那里的质子几乎不引起活化（见 [中能传输段](#journey-mebt-chopper)）。

## 质子一共得到了什么 {#journey-hebt-total}

把起点和终点放在一起：

| 量 | 离子源出口 | RFQ 出口 | 终点 | 终点 / 起点 |
|---|---|---|---|---|
| 动能 $W$ | 35 keV | 1.527 MeV | 1 GeV | 约 28600 倍 |
| $\beta$ | 0.00864 | 0.05698 | 0.8750 | 101 倍 |
| 动量 $p$ | 8.10 MeV/c | 53.6 MeV/c | 1696 MeV/c | 209 倍 |
| $B\rho$ | 0.0270 T·m | 0.1786 T·m | 5.657 T·m | 209 倍 |
| 几何 rms 发射度（归一化 0.14 不变时） | 16.2 | 2.45 | 0.077 π·mm·mrad | 1/209 |
| rms 束团时间宽度 | 直流 | 73 ps | 约 3 ps | — |

几点值得体会：

- **速度只涨了 101 倍，能量却涨了两万多倍。** 后半程质子已接近光速，加给它的能量几乎全部变成了 $\gamma$ 的增长，而不是速度。
- **动量和 $B\rho$ 涨了 209 倍**，这决定了同样的磁铁在终点只有起点 1/209 的偏转能力。
- **几何发射度缩小同样的倍数**（绝热阻尼），束流越来越细，但这不是"冷却"：理想情况下归一化发射度不变，实际上它在每次失配、每处非线性场里都会长一点。
- **束团在时间上**从连续束变成几皮秒的短脉冲，正是这一点让频率可以从 162.5 MHz 翻倍到 650 MHz。

## 回头看一遍全程 {#journey-hebt-recap}

**离子源和 LEBT**（[出生](#journey-source)）：质子在等离子体里产生，被几十千伏引出，成为 35 keV 的直流束。Child–Langmuir 定律把流强和引出电压、间隙绑在一起；低能下空间电荷最强，LEBT 用螺线管同时聚焦两个平面，靠残余气体电离产生的电子部分中和空间电荷，把强会聚的束流送进 RFQ。AVAS 不模拟这一段。

**RFQ**（[成团](#journey-rfq)）：直流束不能直接进腔，只有四分之一能被稳定区接住。RFQ 用电四极场聚焦（电场力不随速度变弱），用电极调制产生纵向场，缓慢地把连续束切成束团再加速，到 1.527 MeV。AVAS 通常不模拟 RFQ，它的输出 `part_rfq.dst` 就是 AVAS 示例的起点。

**MEBT**（[整形](#journey-mebt)）：束团离开 RFQ 后会因动量分散自己变长（$R_{56} = L/\gamma^2$），横向在发散，形状也不合下游。四极铁和不增能的聚束腔在三个平面上把束流匹配到超导段，同时完成斩束、测量和低能刮束。AVAS 从这里开始模拟。

**超导段**（[加速](#journey-sc)）：CW 运行下只有超导腔的壁损耗可以承受。速度一路变化，一族腔只能管一段 β，于是有 HWR、轮辐腔、椭球腔几族，频率随束团变短而翻倍。低能段"螺线管 + 腔"交替排列，压住射频散焦；同步相位取 $-30^\circ$ 到 $-20^\circ$，在能量增益和纵向稳定之间折中；每周期相移在两个方向都小于 90°。

**HEBT**（本章）：功率成了主要问题。二极铁拐弯并用消色散让靶上的束斑位置不随能量晃动；放大束斑、使分布均匀以保护靶；把损失控制在每米 1 W 左右。

整条路线背后只有三件事实（见 [全貌](#journey-overview)）：质子的速度变了一百倍，空间电荷在低能处最强，射频只能加速成团的束流。每一段的结构，都是在当时的速度和流强下回答这三件事的最好办法；段与段之间的匹配，则保证上一段的答案能被下一段接住。

## 想一想 {#journey-hebt-think}

> **想一想 1**：消色散段内部色散不为零，束流在这里会变宽吗？
>
> 答：会，但很少。四极铁处 $D \approx 0.63\ \mathrm{m}$，乘上动量分散 $\sigma_\delta \approx 2\times10^{-4}$ 只有约 0.12 mm，与 0.9 mm 的束流尺寸按勾股定理相加只增加不到 1 %。高能束流能散小，这一点不难；难的是能量的整体偏移（腔的相位、幅度误差）和下游位置的耦合，这正是消色散要消掉的。反过来，在色散大的地方放一个狭缝，就能挡掉能量偏离太多的粒子，或测量能散。

> **想一想 2**：同样是偏转 $15^\circ$，在 RFQ 出口（1.527 MeV）用 1.5 T 的二极铁，色散 $D$ 是多少？为什么低能时色散"不那么可怕"？
>
> 答：$\rho = 0.1786/1.5 = 0.12\ \mathrm{m}$，$D = 0.12 \times (1 - \cos 15^\circ) = 4\ \mathrm{mm}$，比 1 GeV 时小三十多倍。色散正比于偏转半径，而半径正比于 $B\rho$。不过低能束流的能散在相对值上大得多（RFQ 出口的 rms 动量分散是 0.375 %），所以真正要比较的是 $D\,\sigma_\delta$ 与束流尺寸之比。

> **想一想 3**：如果把示例的模拟粒子数从 5260 提高到 10 万，"一个粒子也没丢"能说明什么？
>
> 答：每个宏粒子代表束流的 $10^{-5}$，在 10 MW 下是 100 W。没丢一个粒子，按统计（见 [深入：靶上的束斑与束损统计](#journey-hebt-deep-target)）只能说明损失份额大概低于 $3\times10^{-5}$，即几百瓦，仍远高于每米 1 W。直接用宏粒子数证明 $10^{-7}$ 量级的损失需要几千万个粒子，所以实际工作中要结合晕的分析和误差研究。

## 容易误解的地方 {#journey-hebt-misconceptions}

**"到了高能，束流动力学就简单了。"** 空间电荷和射频散焦确实变弱了，但束流功率让每一点损失都变得昂贵：$10^{-5}$ 的损失在 10 MW 下就是 100 W。

**"消色散就是处处没有色散。"** 消色散只保证弯转段出口 $D = D' = 0$；段内色散可以很大（上面的例子约 0.63 m），能散大的束流在这里会变宽。

**"把束流聚得越小，打靶越准越好。"** 对高功率靶恰恰相反，要把束斑放大并尽量均匀。

**"1 W/m 是物理极限。"** 它是保证可维护性的经验准则；能量较低时同样功率引起的活化少得多，要求可以放宽，具体以装置的辐射防护设计为准。

**"模拟里没丢粒子，就说明没有束损。"** 5260 个宏粒子中丢一个就是束流的 $1.9\times10^{-4}$；没丢只说明损失低于这个量级。

**"质子已经接近光速，再加速也没用了。"** 加速改变的是能量和动量，它们在终点附近仍然线性增长；只是速度几乎不再变化。

## 深入：二极铁、色散与消色散的几何 {#journey-hebt-deep-dispersion}

正文给出了 $D = \rho(1 - \cos\theta)$、$D' = \sin\theta$ 和消色散条件 $f = D_q/(2\sin\theta)$。这一节只用中学的圆周运动和三角形把它们推出来。

### 第一步：磁刚度从哪里来

带电粒子垂直于均匀磁场运动，洛伦兹力 $qvB$ 始终垂直于速度，提供向心力：

$$
qvB = \frac{mv^2}{\rho}\quad\Rightarrow\quad B\rho = \frac{mv}{q} = \frac{p}{q} .
$$

高速时 $p = \gamma mv$，结论不变（只要把 $m v$ 换成真正的动量）。常用的换算是 $B\rho\,[\mathrm{T\,m}] = p\,[\mathrm{MeV}/c]/299.79$：1 GeV 质子 $p = 1696\ \mathrm{MeV}/c$，$B\rho = 5.657\ \mathrm{T\,m}$。在 $B = 1.5\ \mathrm{T}$ 中半径 $\rho = 3.77\ \mathrm{m}$。

### 第二步：两个圆

把二极铁的磁场区画成从入口开始、绕圆心 $O$ 转过 $\theta$ 的扇形。参考质子沿半径为 $\rho$ 的圆弧走，从入口点 $P$ 出发，入口时速度沿切线。动量多 $\delta$ 的质子从同一点、同一方向出发，半径是 $\rho(1 + \delta)$。两个圆在 $P$ 点相切，所以它们的圆心都在过 $P$ 垂直于速度的那条直线上：高动量质子的圆心 $O'$ 比 $O$ 离 $P$ 远 $\rho\delta$，也就是在 $O$ 的另一侧、距 $O$ 为 $\rho\delta$。

### 第三步：在出口处量偏离

扇形磁铁的出口是从 $O$ 出发、与 $OP$ 成 $\theta$ 角的半径线。高动量质子与这条线相交于点 $X$，设 $OX = \rho + x$，$x$ 就是它偏离参考轨道的距离。在三角形 $OO'X$ 中，三边分别是 $OO' = \rho\delta$、$O'X = \rho(1 + \delta)$、$OX = \rho + x$，$\angle O'OX = 180^\circ - \theta$。用余弦定理：

$$
\rho^2(1 + \delta)^2 = (\rho + x)^2 + \rho^2\delta^2 + 2(\rho + x)\rho\delta\cos\theta .
$$

$\delta$ 和 $x$ 都很小，只保留一次项（$\delta^2$、$x^2$、$x\delta$ 都扔掉）：$\rho^2 + 2\rho^2\delta = \rho^2 + 2\rho x + 2\rho^2\delta\cos\theta$，于是

$$
x = \rho\,\delta\,(1 - \cos\theta),\qquad D = \frac{x}{\delta} = \rho\,(1 - \cos\theta) .
$$

代入 $\rho = 3.77\ \mathrm{m}$、$\theta = 15^\circ$：$D = 3.77 \times (1 - 0.9659) = 0.128\ \mathrm{m}$，与实验的 0.128 m 相同。

### 第四步：色散的斜率

色散沿路程的增长率 $D'$ 告诉我们出口之后色散怎样继续变化。把扇形多转一个很小的角度 $\Delta\theta$：$D$ 从 $\rho(1 - \cos\theta)$ 变成 $\rho(1 - \cos(\theta + \Delta\theta))$，增加约 $\rho\sin\theta\,\Delta\theta$（和角公式加小角度近似）；这段弧长 $\rho\,\Delta\theta$。两者相除：

$$
D' = \sin\theta .
$$

$15^\circ$ 时 $D' = 0.259$。出了磁铁，色散像一条光线那样直线增长：漂移 $L$ 后 $D = 0.128 + 0.259\,L$，$L = 2\ \mathrm{m}$ 时 0.646 m，$L = 5\ \mathrm{m}$ 时 1.42 m。

### 第五步：镜像对称的消色散

把消色散段想成一部"色散的录像"。前半段：从第一块二极铁入口（$D = 0$、$D' = 0$）到中间的四极铁，色散涨到 $D_q$，斜率 $+\sin\theta$。后半段和前半段是镜像。把后半段的录像倒着放，就是前半段的样子，只是斜率的符号反过来（倒放时往外斜变成往里斜）。所以只要在中点处斜率正好是 $-\sin\theta$，后半段就会把色散沿着前半段的路"原路退回"，在第二块二极铁出口处 $D = 0$、$D' = 0$。

薄透镜对色散的作用和对光线一样：位置不变，斜率改变 $-D_q/f$。要求 $\sin\theta - D_q/f = -\sin\theta$，即 $f = D_q/(2\sin\theta)$。代入 $D_q = 0.646\ \mathrm{m}$：$f = 0.646/(2 \times 0.2588) = 1.25\ \mathrm{m}$，梯度 $G = B\rho/(fL_q) = 5.657/(1.25 \times 0.3) = 15.1\ \mathrm{T/m}$。厚透镜的精确值 15.7 T/m 来自四极铁 0.3 m 的长度：色散在四极铁内部边走边被折回，等效位置和强度都和薄透镜略有不同。用 AVAS 线性预览检验：15.74 T/m 时出口 $D$、$D'$ 都小于 $10^{-3}$，段内色散最大 0.63 m（在四极铁附近）；用薄透镜的 15.1 T/m，出口还剩 $D = 0.066\ \mathrm{m}$。

### 给学过线性代数的读者

扇形二极铁（极面角为 0）在弯转平面内的 3 × 3 传输矩阵作用在 $(x, x', \delta)$ 上：

$$
\begin{pmatrix}
\cos\theta & \rho\sin\theta & \rho(1 - \cos\theta)\\
-\sin\theta/\rho & \cos\theta & \sin\theta\\
0 & 0 & 1
\end{pmatrix},
$$

第三列就是第三、四步的 $D$、$D'$；$-\sin\theta/\rho = -0.0687\ \mathrm{m^{-1}}$ 是二极铁自身的弱聚焦，与实验给出的 $R_{21}$ 一致。色散函数满足 $D'' + K(s)D = 1/\rho(s)$，消色散条件是整段矩阵的 $R_{16} = R_{26} = 0$；双弯消色散（DBA）、三弯消色散等更一般的设计在此基础上同时控制 β 函数。

## 深入：靶上的束斑与束损统计 {#journey-hebt-deep-target}

正文用了三个结论：从束腰漂移可以把 β 函数放到 $10^4$ m；两块相隔 90° 相移的准直器分别挡住位置大和角度大的粒子；模拟里没丢粒子不能证明损失很低。这一节逐个算清楚。

### 第一步：β 函数和束流尺寸

在一个方向上，rms 尺寸 $\sigma = \sqrt{\beta\varepsilon}$，$\varepsilon$ 是几何发射度（束流自带，不随漂移改变），$\beta$ 描述这一处束流的粗细（见 [漂移段](#drift-deep-matrix)）。1 GeV、$\varepsilon = 0.077\ \mathrm{mm\,mrad}$ 时，要 $\sigma = 30\ \mathrm{mm}$，需要 $\beta = \sigma^2/\varepsilon = 900/0.077 \approx 1.2\times10^4\ \mathrm{m}$（$\mathrm{mm^2}/(\mathrm{mm\,mrad})$ 的单位就是米）。

### 第二步：从束腰出发的漂移

在束腰处，束流最细，尺寸 $\sigma^*$，粒子角度和位置互不相关，rms 角度 $\sigma'^* = \varepsilon/\sigma^*$（发射度 ≈ 尺寸 × 角度）。漂移 $L$ 后，每个粒子的位置增加"角度 × $L$"。原有位置和新增的偏移互不相关，按勾股定理：

$$
\sigma^2 = \sigma^{*2} + (\sigma'^*L)^2 .
$$

两边除以 $\varepsilon$，并用 $\sigma^{*2} = \beta^*\varepsilon$、$\sigma'^{*2} = \varepsilon/\beta^*$：

$$
\beta = \beta^* + \frac{L^2}{\beta^*} .
$$

$\beta^* = 1\ \mathrm{m}$ 时，要 $\beta = 1.2\times10^4\ \mathrm{m}$，需要 $L = \sqrt{(\beta - \beta^*)\beta^*} \approx 108\ \mathrm{m}$。束腰越细（$\beta^*$ 越小），漂移同样的距离长得越快：这就是手电筒的原理。

### 第三步：高斯分布的最热点

二维高斯束斑中心的功率密度是 $P/(2\pi\sigma_x\sigma_y)$。$P = 10\ \mathrm{MW}$、$\sigma_x = \sigma_y = 1\ \mathrm{mm}$ 时为 $10^7/(2\pi) = 1.6\times10^6\ \mathrm{W/mm^2}$。如果同样的功率均匀分布在边长 $4\sigma$（$\pm 2\sigma$）的方形里，功率密度是 $P/(16\sigma^2)$。两者之比 $16/(2\pi) = 2.5$：同样大的束斑，高斯分布的中心比均匀分布热 2.5 倍。

### 第四步：为什么准直器要相隔 90°

周期性聚焦通道里，粒子的横向运动是简谐振动：$x = A\cos\phi$，角度 $x' \propto -A\sin\phi$，$\phi$ 是走过的相移。和单摆一样，位置最大时角度为零，位置为零时角度最大。第一块准直器挡掉此刻 $\lvert x\rvert$ 大的粒子；那些此刻正在中间、却带着很大角度的粒子，在相移再走 $90^\circ$ 以后，$\cos$ 和 $\sin$ 互换，变成位置大的粒子，被第二块准直器挡掉。两块合起来，相空间里振幅大的粒子不论此刻处在摆动的哪个阶段，都会被挡住。

### 第五步：没丢粒子能说明什么

假设真实的损失份额是 $p$，模拟用 $N$ 个宏粒子。每个宏粒子独立地以概率 $p$ 丢失，一个都不丢的概率是 $(1 - p)^N$。$p$ 很小时 $(1 - p)^N \approx \ee^{-pN}$（可用计算器验证：$p = 10^{-4}$、$N = 5260$ 时两者都约为 0.591）。若要"一个都不丢"的概率只剩 5 %，需要 $\ee^{-pN} = 0.05$，即 $pN \approx 3$。所以：

> 模拟中 $N$ 个粒子一个都没丢，只能说明损失份额大概（95 % 的把握）低于 $3/N$。

$N = 5260$ 时是 $5.7\times10^{-4}$；要证明 $10^{-7}$，需要约 $3\times10^7$ 个宏粒子。这就是正文说"研究束损要用多得多的粒子"的定量含义，也是实际工作中要结合晕的分析和误差研究的原因。

### 给学过概率统计和线性代数的读者

第二步是 σ 矩阵经漂移矩阵的变换 $\Sigma \to M\Sigma M\tp$ 的 (1,1) 元素；一般位置的 $\beta(s) = \beta^* + (s - s^*)^2/\beta^*$。第四步说的是相空间以 $(x, \alpha x + \beta x')$ 归一化后作刚性转动，两块准直器在归一化相空间里切出一个多边形孔径，相移越接近 90° 越接近方形。第五步是泊松分布的零计数置信上限（"三法则"）；真正的束损研究还要注意宏粒子的抽样只代表初始分布，晕粒子的产生来自非线性和失配，粒子数不够时连晕的形状都描述不出来。

## 在 AVAS 中 {#journey-hebt-in-avas}

### 可以模拟的部分

HEBT 的线性部分都可以在 AVAS 中模拟：漂移段 `drift`、四极铁 `quad`、二极铁 `bend` 加两侧的极面 `edge`、校正铁 `steerer`；有场图时也可以用静磁场图（场类型 3）。上面的消色散段写成 AVAS lattice（扇形二极铁，极面角为 0；孔径取 5 cm）：

```text
start
drift  0.5   0.05  0
edge   0  0.05  0  0  3.77  0  0  0  0
bend   0  0.05  0  15  3.77  0  0
edge   0  0.05  0  0  3.77  0  0  0  0
drift  1.85  0.05  0
quad   0.3   0.05  0  15.74
drift  1.85  0.05  0
edge   0  0.05  0  0  3.77  0  0  0  0
bend   0  0.05  0  15  3.77  0  0
edge   0  0.05  0  0  3.77  0  0  0  0
drift  0.5   0.05  0
end
```

```avas-params
bend edge quad steerer
```

> **AVAS 约定**：`bend 0 R 0 alpha rho N HV` 中第一个参数是弧长，写 0 即可（程序由 α 和 ρ 计算）；`alpha` 是偏转角（°），`rho` 是偏转半径（m），`N` 是场梯度指数，`HV` 选弯转平面（0 = 水平，1 = 垂直）；两侧的 `edge 0 R 0 beta rho G K1 K2 HV` 中 `beta` 是极面旋转角、`G` 是磁铁间隙、`K1`/`K2` 是边缘场因子，`rho`、`HV` 必须与 `bend` 一致（见 [二极铁](#dipole)）。`quad` 中 $G > 0$ 在 $x$ 平面聚焦。多粒子模拟时首末元件不要用矩阵元件，所以上面以漂移段开头和结尾。

> **注意**：二极铁用场图描述时，线性预览不模拟场图的偶极分量并给出警告，以内核结果为准（见 [二极铁](#dipole)）。本章的数值都来自矩阵模型。

### 不在 AVAS 元件之内的部分

靶、八极铁等非线性多极铁、扫描磁铁这类随时间变化的元件，以及斩束器，都不是 AVAS 的元件。准直器没有专门的元件，但内核按每个元件的孔径 `R` 判断粒子损失，可以用孔径较小的漂移段在模拟中代替；`input.txt` 中 `boundary 1` 时改用 `boundary.txt` 中的边界。

### 把束流交给靶程序

在靶前用 `outputplane` 输出粒子分布，交给专门的靶或屏蔽计算程序。输出平面不能超出 lattice 末端，离末端太近（5 mm）也会失败，留 2 cm 以上即可；内核结束时总会写出末端的 `outData_<末端>.dst`（见 [模拟设置与输出](#simulation)）。

```avas-params
outputplane beam:particlenumber
```

### 估计束损

- 结果页看存活宏粒子数（DataSet 第 28 列）和最大尺寸与 rms 尺寸之比（第 22/24 列对第 16/18 列）：后者持续增大说明在形成晕。
- 宏粒子数 `particlenumber` 决定能分辨的最小损失份额（约为其倒数）；研究低损失要增加粒子数，并用误差研究（`err_*` 命令）看最坏情况。
- 线性预览在 3 倍 rms 尺寸超过孔径时给出"可能有束损"的警告，它只基于 rms，不能代替多粒子模拟。
