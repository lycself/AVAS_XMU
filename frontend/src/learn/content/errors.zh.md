# 误差与校正

前面各章里，每块磁铁都放在设计图纸上的位置，每个腔的电压和相位都正好等于设定值。真实的加速器做不到这一点：一块四极铁装偏 0.1 mm（大约一根头发丝的粗细）是很平常的事，磁铁电源有微小的波动，射频腔的电压和相位也会轻轻抖动。这些偏离设计的小毛病统称为**误差**。

误差这么小，值得专门花一章吗？值得。一条十个周期的 FODO 通道有 20 块四极铁，如果每块都随机地装偏 0.1 mm，束流中心到出口会偏约 1 mm，超过那里束流本身 rms 尺寸的一半。小误差为什么会被放大？加速器能容忍多大的误差？怎样用模拟回答这些问题？这一章从零讲起。

先看动画。这是《轨道校正》一章用过的 6 周期 FODO 通道，12 块四极铁全都随机地装偏了一点（这里设成 rms 0.1 mm）。实线是束流中心，橙色的点是粒子，灰色菱形是测量束流位置的探测器（BPM）。

```avas-motion
orbit err=0.1
```

"参与校正的奇异值个数"保持 0，也就是不做任何校正，只看误差本身。请看三件事：

- **束流中心不再沿中心线走**，而是左右、上下摆动。默认误差样本下，BPM 处的束流中心 $x$ 的 rms 约 0.26 mm、$y$ 约 0.48 mm，沿线 $x$ 最远偏 0.48 mm。
- **偏差和误差成正比**：把"四极铁错位"从 0.1 改到 0.2 mm，所有偏差都正好加倍（BPM 处 $x$ 变成 0.52 mm）。
- **换一个误差样本，结果就不一样**：把"误差样本"从 1 改成 2，同样是 rms 0.1 mm 的错位，BPM 处 $x$ 的 rms 变成 0.48 mm，差不多翻了一倍。所以只算一次是不够的，要算很多次，再看统计结果，这就是后面要讲的**误差研究**。

怎样用 BPM 和校正铁把束流拉回来，《[轨道校正](#orbit-correction)》一章已经详细讲过（就是动画里的那个滑块）。这一章讲误差本身：它从哪里来、会造成什么后果、怎样估计、怎样用 AVAS 做统计。

本章会用到 [线性光学](#linear-optics) 里的 β 函数与相移、[匹配](#matching) 里的失配、[纵向动力学](#longitudinal) 里的同步相位。不熟悉也没关系，正文会先用最直观的说法讲清楚。估算的例子沿用 [lattice 设计](#lattice-design-periods) 中的 FODO（梯度 $G = 5\ \mathrm{T/m}$、四极铁长 $L_q = 0.1\ \mathrm{m}$、漂移段长 $L_d = 0.3\ \mathrm{m}$，示例质子束 1.527 MeV）。校正铁本身见 [校正磁铁](#steerer)。

## 误差的来源与分类 {#errors-types}

真实加速器里的误差大致有五类：

| 类别 | 通俗地说 | 例子 | AVAS 中的列 |
|---|---|---|---|
| 元件位置 | 装偏了 | 横向位移 $dx$、$dy$，纵向位移 $dz$ | `dx`、`dy`（mm），`dz`（mm） |
| 元件姿态 | 装歪了 | 绕 x、y、z 轴的转角 | `dφx`、`dφy`、`dφz`（°） |
| 静态场强 | 磁铁比设定的强一点或弱一点 | 四极铁梯度、螺线管场的标定误差 | `dG`（%） |
| 射频幅值与相位 | 腔的电压和"节拍"不准 | 腔压、腔相位的设定误差与抖动 | `ke/kb`（%）、`φs`（°） |
| 初始束流 | 进来的束流本身就偏了 | 入口位置、角度、能量、相位、发射度、流强偏差 | `dx dy dφ dx' dy' dE dεx dεy dεz … dIb` |

表里的"AVAS 中的列"是写误差命令时用的名字，到本章最后的"在 AVAS 中"再细说。

按误差**随时间怎样变化**，又可以分成两类。这个区分非常重要，因为它决定了误差能不能被补偿：

- **静态误差**：在一次运行（一段时间）里不变。比如墙上的画挂歪了，歪了就一直歪着。安装位置误差、磁铁标定误差都属于这一类。它们可以先用束流诊断设备测出来，再用校正铁、调整腔的相位等办法补偿，就像把画扶正一次就好。
- **动态误差**：随时间变化。比如端着一杯水的手在轻轻发抖。射频幅值和相位的抖动、机械振动、电源纹波属于这一类。它们变化得比校正回路快，或者根本测不到，通常没法补偿，只能靠把公差（允许的误差范围）定得足够严来控制。

一次**误差研究**，就是按误差的统计规律随机抽取很多组误差（每一组叫一个"种子"或一个样本），每组都跟踪一遍束流，再统计束流损失、发射度增长、中心偏移这些指标的分布。

## 一块错位的四极铁会做什么 {#errors-effects}

这一节用中学物理估算各种误差的后果，判断量级。这些估算基于线性光学，忽略空间电荷，可以用来检验模拟结果是否合理。

### 错位等于"踢"一下

回忆《[四极铁](#quadrupole)》一章：四极铁像一块透镜，中心没有磁场，粒子离中心越远，被推回中心的角度越大，角度 = 离中心的距离 ÷ 焦距 $f$。

现在四极铁整体向右装偏了 $d$。沿着管道中心线飞来的束流，相对磁铁中心是**向左**偏了 $d$，于是被往磁铁中心（右边）推了一个角度

$$
\Delta x' = \frac{d}{f}.
$$

所以**错位的四极铁 = 一块装正的四极铁 + 一个小小的"踢"**。例子中的四极铁焦距 $f = 0.357\ \mathrm{m}$，错位 0.1 mm 时踢的角度是 $0.1/0.357 \approx 0.28\ \mathrm{mrad}$（毫弧度，千分之一弧度）。

### 一次"踢"怎样传到下游

被踢了一下的束流中心，就像被推了一下的秋千：它不会一直往一边跑，因为下游的四极铁会把它往回推，于是束流中心开始绕着中心线来回摆动。这种摆动叫 **betatron 振荡**（横向振荡）。

摆动有多大？最简单的情形是踢完之后只有漂移段：偏移 = 角度 × 距离。0.28 mrad 的踢，走 1 m 后束流中心偏 0.28 mm（记住"1 mrad 走 1 m 偏 1 mm"）。有四极铁时，偏移还取决于两件事：踢的地方束流有多粗（束流粗的地方，同样的踢影响更大），以及踢完之后摆动到了哪个阶段（摆到最远处，还是刚好回到中心线）。准确的公式在下面的"深入：误差怎样传播和累积"里。

### 许多随机的"踢"：随机行走

20 块四极铁各踢一下，结果是一块的 20 倍吗？不是，大约只有 $\sqrt{20} \approx 4.5$ 倍。

原因可以用抛硬币来理解：每抛一次，正面向前走一步，反面向后退一步。抛 20 次，你一般不会走出 20 步那么远，因为前进和后退会部分抵消；平均来说，离起点的距离约为 $\sqrt{20}$ 步。各块四极铁的错位方向随机（有的向左，有的向右），摆动的阶段也随机，它们的踢同样会部分抵消。这叫**随机行走**。

用这个办法估算例子中的 FODO：20 块四极铁，每块错位是 rms 0.1 mm 的随机数，出口处束流中心偏移的 rms 约 $0.94\ \mathrm{mm}$；让计算机真的抽 20000 组误差逐一计算，得到 $0.96\ \mathrm{mm}$，估算很准。同一位置束流本身的 rms 尺寸约 $1.74\ \mathrm{mm}$：0.1 mm 的安装误差，让束流中心偏到了束流尺寸的一半以上。这就是长束线需要轨道校正的原因。中心偏移随四极铁数目的平方根 $\sqrt N$ 增长；束流加速时，偏移会慢慢缩小（按 $1/\sqrt{\beta\gamma}$ 缩小，$\beta\gamma$ 随能量增大）。

### 装歪了：两个方向搅在一起

四极铁绕前进方向（z 轴）转了一个小角度 $\varphi_z$，它就不再只在 $x$、$y$ 两个方向各管各的，而是把水平和竖直的运动搅在一起：水平方向的偏差会变成竖直方向的偏差，反过来也一样。这叫**耦合**。耦合会让单独看 $x$ 或 $y$ 时的发射度变大。绕 x、y 轴的转角，相当于磁铁一头高一头低，两端各偏一点，效果和位移误差类似但小一些。螺线管本身就耦合两个方向，它的位移和转角误差还会给束流一个偏转。

### 场强不准：聚焦变强或变弱

四极铁的梯度比设定大了 1 %，并不会把束流中心推偏（束流还在磁铁中心，那里没有场），但透镜变"凸"了一点，聚焦变强。结果有两个：

- **束流形状和通道不再配套**（失配）：束流的粗细会出现额外的起伏。一块 F 铁 1 % 的梯度误差，失配因子约 0.019（失配因子的意思见 [匹配](#matching-mismatch-factor)），很小；但许多块的误差会累积。
- **每个周期的振荡快一点**（相移变大）：全部四极铁都大 1 % 时，每个周期的相移增加约 0.7°。

在下面的 FODO 实验里验证：梯度 `G` 已经设成 5.05，比 5 大 1 %（相当于所有四极铁都有 1 % 的梯度误差）。实验给出的每周期相移是 $62.12^\circ$；把 `G` 改回 5，相移是 $61.44^\circ$，只差 $0.68^\circ$，与估算相符。周期入口的 β 从 $1.256$ 变为 $1.251\ \mathrm{m}$，变化也很小。

```avas-lab
fodo Lq=0.1 G=5.05 Ld=0.3 cells=10 W=1.527 mass=938.272 q=1 emit=0.1377 I=0 mismatch=1
```

### 射频腔不准：能量差一点

腔给粒子的能量，等于电荷乘以粒子"感受到的电压"。腔压大了 1 %，能量增益也大约多 1 %；腔的相位错了一点，粒子赶上的电场就强了或弱了一点。用《[纵向动力学](#longitudinal)》里的薄间隙公式估算示例 HWR 腔（同步相位 $-33^\circ$，能量增益 0.339 MeV）：1 % 的幅值误差让能量增益变化约 $3.4\ \mathrm{keV}$，$1^\circ$ 的相位误差约 $3.8\ \mathrm{keV}$。与纵向能接受的能量范围（约 $\pm 0.09\ \mathrm{MeV}$，见 [lattice 设计](#lattice-design-longitudinal)）相比都很小。

但低能腔有一个陷阱：用 AVAS 的线性预览直接算，相位误差的影响比这个估算大 1.2～1.6 倍，而且大多少还取决于"哪一个相位"有误差。原因和数值都放在下面的"深入：低能腔的相位误差"里。

有纵向聚焦时，能量和相位误差会让束团中心绕同步粒子前后摆动（纵向振荡）。误差太大时，粒子跑出纵向的稳定区，先在纵向丢失，随后因为能量不对又在横向撞墙。低能段粒子的速度对能量很敏感，能量差一点，到达下游腔的时刻就差一点，相当于相位偏了；每个腔各自控制相位的腔链对此尤其敏感。

在射频腔实验里试一试：同步相位已经设成 $-32^\circ$，把它改回 $-33^\circ$，或把 `Ke` 改变 1 %（1.36 → 1.3736），比较出口能量的变化。实验还显示求得的入口相位 $\varphi_0$：$\varphi_s$ 改变 $1^\circ$ 时它约变化 $1.3^\circ$。

```avas-lab
rf-cavity phase=-32 Ke=1.36 W=1.527
```

### 进来的束流就偏了

入口处位置和角度的偏差，和四极铁错位一样引起束流中心的横向摆动；能量和相位的偏差引起纵向摆动；发射度和流强的偏差则主要表现为失配（束流形状和通道不配套）。

## 静态与动态误差 {#errors-static-dynamic}

两类误差的处理方式不同，关键在于能不能被测到并补偿。

静态误差在一次运行中不变：先用 BPM 等束流诊断设备测出束流中心，再调校正铁和腔相位把它拉回来，剩下的是校正后的残余。动态误差变化太快，测到时它已经变了，只能直接叠加在校正后的束流上。

所以误差预算通常分两步：先只加静态误差并做校正，得到"校正后"的状态；再在这个状态上叠加动态误差，看总效果。

AVAS 的误差研究正是按这个思路组织的：可以只研究静态误差、只研究动态误差，或者两者一起，而校正只"看到"静态误差。具体怎样实现，见 [在 AVAS 中](#errors-in-avas)。

## 统计误差研究 {#errors-statistics}

### 为什么要很多个种子

误差是随机的，算一次只是抽了一个样本，就像只掷一次骰子。动画里已经看到，同样大小的错位，换一个样本，束流中心的偏差就差了一倍。束流损失、发射度增长这类指标的分布往往是偏的：大多数样本还好，少数样本特别糟（"长尾"）。只看平均值会低估风险。

一般的做法分三步：

1. **每类误差单独研究**：从小到大逐步加大误差，找出让指标（损失率、发射度增长、中心偏移）刚好达到允许值的误差大小，作为这一项的公差。
2. **综合研究**：把各项公差一起加上，确认总效果仍在预算内，必要时收紧个别公差。
3. **加上校正后重复**：得到"校正后的公差"。

### 要算多少次

- 平均值的统计误差约为 $\sigma/\sqrt N$（$\sigma$ 是单次结果的分散程度，$N$ 是样本数）：样本多 4 倍，误差减半。要估计"最坏的 1 %"这样的尾部，需要的样本远多于估计平均值。
- **零损失不等于不会损失**："三法则"说，$N$ 次运行都没有损失时，只能说单次运行有损失的概率大概不超过 $3/N$（95 % 的把握）。跑 100 次都没损失，只能说概率不超过约 3 %。来历见"深入：要算多少次"。
- **误差的"大小"有不同说法**：在 $[-A, A]$ 之间均匀分布的误差，rms 是 $A/\sqrt3 \approx 0.58A$，不是 $A$；高斯分布的 rms 就是它的标准差 σ。比较不同分布的结果时，要换算成 rms。

### 分组扫描误差大小

把误差大小从小到大分成若干组，每组抽若干个样本，一次研究就能画出"指标随误差大小变化"的曲线。AVAS 的 `err_step a b` 正是这样：a 组、每组 b 次，第 g 组的误差大小是给定值的 $g/a$ 倍（固定值类型除外，见 [在 AVAS 中](#errors-in-avas)），最后一组是给定的满幅度。

## 校正：把束流拉回中心 {#errors-correction}

既然错位的四极铁相当于"踢"了一下，就可以用另一个反方向的"踢"把它抵消。这就是轨道校正：在四极铁附近放校正铁（产生均匀磁场的小磁铁，见 [校正磁铁](#steerer)）和 BPM，调校正铁，把下游 BPM 处的束流中心拉回零。最经典的"一对一"校正，是每块四极铁旁边各放一个校正铁和一个 BPM。按上一节的估计，0.1 mm 量级的安装误差就需要校正。

校正铁要多强？用例子中的 FODO 估算：校正铁放在一块 F 铁处，BPM 放在下一块 F 铁处，校正铁每踢 1 mrad，BPM 处的束流中心移动约 $1.18\ \mathrm{mm}$。要把 1 mm 的偏移拉回，需要 $0.85\ \mathrm{mrad}$ 的踢，相当于一块 0.1 m 长、1.5 mT 的校正铁（磁场积分 $1.5\times 10^{-4}\ \mathrm{T\,m}$）。计算过程见"深入：误差怎样传播和累积"的第三步。

许多 BPM、许多校正铁时怎样一起算、为什么不能"精确求解"，见《[轨道校正](#orbit-correction)》一章（响应矩阵与奇异值分解）。

校正也有做不到的事：

- **BPM 本身的误差**：BPM 的零点不准或读数有噪声，会直接变成校正后的残余偏差。
- **BPM 之间的摆动**：校正只保证 BPM 处为零，两个 BPM 之间束流仍可能偏离。
- **动态误差**：变化太快，测不到或来不及补偿。
- **场强误差引起的失配**：轨道校正只管束流中心，不管束流的粗细；失配要靠匹配段或调整聚焦元件来处理。

在 AVAS 中做校正的命令和算法见 [在 AVAS 中](#errors-in-avas)。

## 想一想 {#errors-think}

> **想一想 1**：20 块四极铁、每块踢 0.28 mrad，为什么结果不是单块的 20 倍？
>
> 答：各块的踢方向随机、摆动的阶段也随机，会部分抵消，就像抛硬币走路。它们按"平方相加"：20 块只相当于 $\sqrt{20} \approx 4.5$ 倍。

> **想一想 2**：束流中心偏 0.94 mm，算大还是算小？
>
> 答：要和束流本身的尺寸比。同一位置束流 rms 尺寸约 1.74 mm，比值 0.54。有意思的是，沿着通道，中心偏移和束流尺寸在束流粗的地方一起变大、细的地方一起变小，这个比值处处相同（见"深入：误差怎样传播和累积"第五步）。

> **想一想 3**：为什么 BPM 离校正铁最好"隔四分之一个摆动"（相位差 $90^\circ$ 附近），而不是紧挨着放？
>
> 答：校正铁踢的是角度，角度要走一段才变成位置。紧挨着放时，校正铁在 BPM 处几乎移动不了束流，只改变了它的方向；摆动走过半圈（相位差 $180^\circ$）时束流中心又回到原处，同样看不出来。隔四分之一圈时位置变化最大，需要的踢最小。

> **想一想 4**：动画里换一个"误差样本"，结果差了一倍。那么算多少个样本才能可靠地说"平均偏 0.3 mm"？
>
> 答：平均值的误差按 $1/\sqrt N$ 减小。如果单个样本的结果分散 ±50 %，要把平均值的误差压到 5 %，需要约 $(50/5)^2 = 100$ 个样本。

## 容易误解的地方 {#errors-misconceptions}

- **误差大小与 rms**：均匀分布 $[-A, A]$ 的 rms 是 $A/\sqrt3$，不是 $A$。"0.1 mm 的均匀误差"与"rms 0.1 mm 的高斯误差"差了 $\sqrt3$ 倍。
- **高斯不截断**：AVAS 的高斯误差抽样不截断（见下文抽样规则），个别种子会有很大的误差，这是分布本身的尾部，不是程序错误。
- **只看平均值**：损失和发射度增长的分布有长尾，公差应按坏的那部分（例如最坏的 10 % 或 1 %）确定。
- **运行完成不等于校正成功**：校正可能没有收敛，务必检查校正后的束诊数据。
- **两个种子**：误差抽样的种子与初始粒子分布的种子是两个设置，比较两次研究时都要固定。
- **薄间隙公式低估低 β 腔的相位敏感度**：对示例 HWR（线性预览），射频相位平移约为估计的 1.2 倍，改变 V3 = 0 腔的同步相位设定值约为 1.6 倍。给相位公差时要说明指的是哪一个相位。

## 深入：误差怎样传播和累积 {#errors-deep-propagation}

正文用"踢一下""秋千""抛硬币"讲了误差的传播。这一节一步步把它们变成准确的公式：前五步只用中学物理和代数，最后一段给学过线性代数和概率论的读者。

### 第一步：错位为什么只是一个"踢"

四极铁里，粒子受到的推力正比于它离**磁铁中心**的距离。磁铁偏了 $d$，粒子离磁铁中心的距离就是 $x - d$。按薄透镜，穿过后角度改变

$$
\Delta x' = -\frac{x - d}{f} = -\frac{x}{f} + \frac{d}{f}.
$$

第一项 $-x/f$ 是正常的聚焦，每个粒子按自己的 $x$ 计算；第二项 $d/f$ 对所有粒子都一样，是一个常数的"踢"。所以错位只把整束粒子一起推偏，不改变束流的形状。

焦距和梯度的关系是 $1/f = kL_q$，其中 $k = G/(B\rho)$ 是聚焦强度，$B\rho$ 是磁刚度（示例质子 $B\rho = 0.179\ \mathrm{T\,m}$，见《[四极铁](#quadrupole)》）。例子：$k = 5/0.1786 = 28.0\ \mathrm{m^{-2}}$，$kL_q = 2.80\ \mathrm{m^{-1}}$，于是

$$
\Delta x' = kL_q\,d = 2.80\ \mathrm{m^{-1}} \times 0.1\ \mathrm{mm} = 0.28\ \mathrm{mrad}.
$$

### 第二步：两个描述摆动的量：β 函数和相移

为了说清"踢完之后束流中心怎样摆动"，需要两个量，它们在《[线性光学](#linear-optics)》里有详细介绍，这里只用它们的直观意思：

- **β 函数** $\beta(s)$：沿线每一点束流有多粗的量度。束流的 rms 尺寸 $\sigma = \sqrt{\beta\varepsilon}$，$\varepsilon$ 是几何发射度（相空间椭圆的面积，见《[漂移段](#drift)》）。例子中的 FODO，F 铁中心 $\beta = 1.35\ \mathrm{m}$（粗），D 铁中心 $\beta = 0.45\ \mathrm{m}$（细）。
- **相移** $\psi(s)$：从起点到 $s$，摆动走过了"多少圈"，用角度计，走完一整圈是 $360^\circ$。例子的 FODO 每个周期相移 $61.4^\circ$，约 5.9 个周期摆一整圈。

### 第三步：一个"踢"在下游产生多大偏移

在 $s_i$ 处踢一个角度 $\theta_i$，到下游 $s$ 处束流中心偏了多少？答案是

$$
x_c(s) = \sqrt{\beta(s)\,\beta_i}\;\sin\!\big(\psi(s) - \psi_i\big)\;\theta_i .
$$

三个因子各有意思：$\sqrt{\beta_i}$ 说明在束流粗的地方踢，影响更大；$\sqrt{\beta(s)}$ 说明在束流粗的地方看，偏移也显得更大；$\sin$ 因子是摆动的阶段：刚踢完（相位差 0）还没偏，摆了四分之一圈（$90^\circ$）偏得最远，半圈（$180^\circ$）又回到中心线。

检验一下：只有漂移段时，这个式子应该退回"角度 × 距离"。设束腰在 $s_i$ 处、那里 $\beta_i = \beta_0$，《[漂移段](#drift)》一章给出 $\beta(s) = \beta_0 + L^2/\beta_0$（$L$ 是离开束腰的距离），相移满足 $\tan\Delta\psi = L/\beta_0$。于是 $\sqrt{\beta\beta_i} = \sqrt{\beta_0^2 + L^2}$，$\sin\Delta\psi = L/\sqrt{\beta_0^2 + L^2}$，两者相乘正好是 $L$：确实退回 $x_c = \theta\times L$。

用例子算正文里的校正铁响应：校正铁在一块 F 铁处（$\beta_c = 1.35\ \mathrm{m}$），BPM 在下一块 F 铁处（$\beta_b = 1.35\ \mathrm{m}$，相位差 $61.4^\circ$）：

$$
\frac{\Delta x}{\theta_c} = \sqrt{1.35 \times 1.35}\ \mathrm{m} \times \sin 61.4^\circ = 1.35 \times 0.878 = 1.18\ \mathrm{mm/mrad}.
$$

拉回 1 mm 需要 $\theta = 1/1.18 = 0.85\ \mathrm{mrad}$。校正铁的偏转角是 $\theta = \int B\,\dd l\,/\,B\rho$（磁场积分除以磁刚度），所以 $\int B\,\dd l = 0.85\times 10^{-3} \times 0.179 = 1.5\times 10^{-4}\ \mathrm{T\,m}$，例如 0.1 m 长、1.5 mT。

### 第四步：许多随机的踢：方差相加

先看抛硬币。每步 $+1$ 或 $-1$，概率各一半。走两步，四种等可能的结果：$+2$、$0$、$0$、$-2$。离起点距离的平方的平均是 $(4 + 0 + 0 + 4)/4 = 2$，开方得 $\sqrt2$。走 $N$ 步，距离平方的平均是 $N$，rms 距离是 $\sqrt N$。

道理是：把 $N$ 个互相独立、平均为零的随机数加起来，展开平方时，交叉项（比如"第 1 步 × 第 2 步"）一半为正一半为负，平均起来是零，只剩下各项自己的平方。所以**独立随机量之和的"平方的平均"等于各自"平方的平均"之和**，这叫方差相加。

把它用到第三步的式子：每块四极铁贡献一项 $\sqrt{\beta(s)\beta_i}\sin(\Delta\psi_i)\,\theta_i$。错位 $\theta_i$ 随机且彼此独立，于是

$$
\langle x_c^2(s)\rangle = \beta(s)\sum_i \beta_i\,\langle\sin^2\Delta\psi_i\rangle\,\langle\theta_i^2\rangle .
$$

尖括号 $\langle\ \rangle$ 表示对许多组误差取平均。$\sin^2$ 在一圈里的平均是 $1/2$（$\sin^2 + \cos^2 = 1$，两者平均相同，各占一半），所以

$$
\langle x_c^2(s)\rangle^{1/2} = \sqrt{\frac{\beta(s)}{2}\sum_i \beta_i\,\langle\theta_i^2\rangle} .
$$

代入例子：10 个周期 20 块四极铁，每块 $x$ 错位 rms 0.1 mm，$\sigma_\theta = 0.28\ \mathrm{mrad}$；F 铁 $\beta = 1.35$、D 铁 $0.45\ \mathrm{m}$，所以 $\sum\beta_i = 10\times(1.35 + 0.45) = 18\ \mathrm{m}$；出口（F 铁入口）$\beta = 1.26\ \mathrm{m}$：

$$
\sqrt{\frac{1.26}{2} \times 18 \times (0.28\times 10^{-3})^2}\ \mathrm{m} = \sqrt{8.9\times 10^{-7}}\ \mathrm{m} \approx 0.94\ \mathrm{mm}.
$$

用厚透镜传输矩阵做 20000 次随机抽样得到 $0.96\ \mathrm{mm}$。四极铁数 $N$ 增大时，$\sum$ 里的项数正比于 $N$，所以偏移按 $\sqrt N$ 增长。

### 第五步：和束流尺寸比

同一位置束流的 rms 尺寸是 $\sigma = \sqrt{\beta(s)\,\varepsilon}$。例子中 $\varepsilon = 0.1377/0.05708 = 2.41\ \mathrm{mm\,mrad}$（归一化发射度除以 $\beta\gamma$），所以 $\sigma = \sqrt{1.256 \times 2.41} = 1.74\ \mathrm{mm}$。

注意中心偏移和 $\sigma$ 都正比于 $\sqrt{\beta(s)}$，它们的比值与位置无关：

$$
\frac{\langle x_c^2\rangle^{1/2}}{\sigma} = \sqrt{\frac{\sum_i\beta_i\,\theta_i^2}{2\varepsilon}} = \sqrt{\frac{18 \times 7.84\times 10^{-8}}{2 \times 2.41\times 10^{-6}}} = 0.54,
$$

正好是 $0.94/1.74$。换一种看法：每次踢的角度 $\theta_i$ 要和那里束流本身的 rms 角度 $\sqrt{\varepsilon/\beta_i}$ 比较。

加速时，几何发射度按 $1/(\beta\gamma)$ 缩小（归一化发射度不变），束流和它的中心偏移都按 $1/\sqrt{\beta\gamma}$ 缩小，这叫**绝热阻尼**。

### 给学过线性代数和概率论的读者

一次踢在下游的效果是传输矩阵元 $M_{12}(s_i \to s)\,\theta_i$，用 Twiss 参数写出 $M_{12} = \sqrt{\beta\beta_i}\sin\Delta\psi$，这就是第三步。线性模型里每一步是仿射映射 $\boldsymbol x \to M\boldsymbol x + \boldsymbol d$，常数项 $\boldsymbol d$ 来自校正铁和错位，所以质心对误差严格线性，σ 矩阵（关于质心的二阶矩）不受错位影响。第四步是独立随机变量的方差可加，系综平均 $\langle\sin^2\rangle = 1/2$ 假设各相位在 $[0, 2\pi)$ 上分布足够均匀；周期数少或相移接近 $180^\circ$ 的整数倍时要按实际相位求和。绝热阻尼来自 $\varepsilon_n = \beta\gamma\,\varepsilon$ 守恒。

## 深入：梯度误差、转角与失配 {#errors-deep-gradient}

### 第一步：梯度误差 = 一块额外的薄透镜

梯度相对误差 $\Delta G/G$ 让焦距的倒数（透镜的"强度"）改变

$$
\Delta\!\left(\frac1f\right) = kL_q\,\frac{\Delta G}{G}.
$$

1 % 的误差：$\Delta(1/f) = 2.80 \times 0.01 = 0.028\ \mathrm{m^{-1}}$，相当于在原来的四极铁上叠了一块焦距 36 m 的弱透镜。

### 第二步：失配有多大

匹配的束流穿过这块额外的弱透镜后，相空间椭圆的形状不再和通道配套。由 [失配因子](#matching-mismatch-factor) 一节，失配因子约为

$$
M \approx \frac{\beta\, kL_q}{2}\,\frac{\Delta G}{G}.
$$

$\beta$ 是透镜处的 β 函数：透镜所在处束流越粗，同样的透镜误差扰动越大。一块 F 铁 1 % 的误差：$M \approx 1.35 \times 2.80 \times 0.01/2 = 0.019$。许多独立的小误差引起的失配大致按平方和累积（和上一节的随机行走是同一个道理）。

### 第三步：相移变多少

透镜变强，摆动就变快。每周期相移的变化约为

$$
\Delta\sigma \approx \frac12\sum_i \beta_i\,\Delta\!\left(\frac1f\right)_i
$$

（弧度，聚焦为正，散焦为负）。全部四极铁都大 1 % 时，一个周期内 F 铁贡献 $+\tfrac12 \times 1.35 \times 0.028$，D 铁是散焦透镜，变强后散焦更多，贡献 $-\tfrac12 \times 0.45 \times 0.028$，合计约 $0.0125\ \mathrm{rad} \approx 0.71^\circ$。正文的 FODO 实验用厚透镜矩阵算出 $61.44^\circ \to 62.12^\circ$，增加 $0.68^\circ$，与估算相符。

### 第四步：转角误差

四极铁绕 z 轴转 $\varphi_z$ 后，可以拆成一块装正的四极铁加一块"斜四极铁"（磁极转了 45° 的四极铁），斜四极分量的强度约为正常分量的 $2\varphi_z$ 倍。斜四极铁让 $x$ 方向的偏差产生 $y$ 方向的力，把两个平面耦合起来，投影发射度增大。绕 x、y 轴的转角 $\varphi$ 使长 $L$ 的元件两端横向偏移约 $\pm L\varphi/2$，平均起来中心不偏，所以效果与位移误差类似但较小。

### 给学过矢量分析的读者

绕 z 轴转 $\varphi_z$ 的四极场，在原坐标中等于强度 $G\cos 2\varphi_z$ 的正常四极场加上强度 $G\sin 2\varphi_z$ 的斜四极场，小角度时斜四极分量约为 $2\varphi_z G$。失配因子公式的推导见匹配一章；相移变化 $\Delta\sigma = \tfrac12\oint\beta\,\Delta k\,\dd s$ 是一阶微扰论的结果，对应 $\cos\sigma = \tfrac12\operatorname{tr}M$ 的线性化。

## 深入：低能腔的相位误差 {#errors-deep-rf}

正文说低能腔的相位误差比薄间隙公式估计的大。这一节一步步看清楚原因。

### 第一步：薄间隙公式

把腔想成一个很薄的加速间隙，粒子穿过时电场来不及变化。能量增益是

$$
\Delta W = qV_0T\cos\varphi_s ,
$$

$V_0T$ 是有效电压，$\varphi_s$ 是同步相位。幅值变化 $\Delta V/V$ 和相位变化 $\Delta\varphi$ 引起的能量变化是（第二个式子用了中学的近似 $\cos(\varphi + \Delta\varphi) \approx \cos\varphi - \sin\varphi\,\Delta\varphi$，$\Delta\varphi$ 用弧度）：

$$
\Delta W = qV_0T\cos\varphi_s\,\frac{\Delta V}{V},\qquad
\Delta W \approx -qV_0T\sin\varphi_s\,\Delta\varphi .
$$

### 第二步：代入示例腔

示例 HWR 在 $\varphi_s = -33^\circ$ 时增益 0.339 MeV，取这个相位下的有效 $V_0T = \Delta W/\cos\varphi_s \approx 0.405\ \mathrm{MV}$。1 % 幅值误差：$\Delta W \approx 0.339\ \mathrm{MeV} \times 0.01 = 3.4\ \mathrm{keV}$。$1^\circ = 0.01745\ \mathrm{rad}$ 的相位误差：$\Delta W \approx 0.405 \times \sin 33^\circ \times 0.01745\ \mathrm{MeV} = 3.8\ \mathrm{keV}$。

### 第三步：线性预览给出的数

用线性预览直接改参数再算：`Ke` 增大 1 % 时增益增加 $3.5\ \mathrm{keV}$，与第二步一致。相位则要先说清楚是**哪一个**相位有误差：

- **射频相位平移**：真实的射频相位误差，是射频相对到达的束流移动了，也就是入口相位 $\varphi_0$ 变了。把 $\varphi_0$ 移动 $1^\circ$（V3 = 1），增益变化 $4.6\ \mathrm{keV}$，约为薄间隙估计的 1.2 倍。
- **同步相位设定值**：把 V3 = 0 腔的同步相位**设定值**从 $-33^\circ$ 改为 $-32^\circ$，增益增加 $6.0\ \mathrm{keV}$，约为 1.6 倍。这时程序重新求解入口相位。在 $-33^\circ$ 附近，入口相位每移动 1°，[纵向动力学](#longitudinal-deep-gap)里用 atan2 定义的 $\varphi_s$ 只变化约 $0.76^\circ$；反过来，$\varphi_s$ 改 1° 相当于入口相位（射频相位）改约 $1/0.76 \approx 1.3^\circ$（正文实验里入口相位从 $52.66^\circ$ 变到 $53.97^\circ$）。

### 第四步：为什么薄间隙公式不够

低 β 腔里粒子在腔内显著加速，速度一变，穿过各个间隙的时刻就变，有效电压本身随相位变化。$\Delta W/\cos\varphi_s$ 在 $-30^\circ$ 到 $-40^\circ$ 之间每度变化约 $2.6\ \mathrm{keV}$，乘以 $\cos\varphi_s$，在 $3.8\ \mathrm{keV/{}^\circ}$ 之外又贡献约 $2.2\ \mathrm{keV/{}^\circ}$，两者相加约 $6.0\ \mathrm{keV}$，正是第三步的数。

这是物理，不是数值误差：把同一场图按入口速度冻结不变来积分，得到 $\Delta W = qV_0T\cos\varphi_s$，其中 $V_0T = 0.389\ \mathrm{MV}$ 与相位无关，两种敏感度都回到约 $3.7\ \mathrm{keV/{}^\circ}$ 的薄间隙值。

### 第五步：对公差的意义

低能段的相位公差要按实际场图估计，并同时注明相位误差指的是什么（射频相位平移还是同步相位设定值）。内核如何把 `err_cav_*` 的 `φs` 列加到 V3 = 0 的腔上（作为同步相位设定值的改变，还是射频相位的平移），手册未说明，以内核为准。

### 给学过微积分的读者

记 $\Delta W(\varphi_s) = qV(\varphi_s)\cos\varphi_s$，其中 $V(\varphi_s) = \Delta W/\cos\varphi_s$ 是随相位变化的有效电压，则 $\dd\Delta W/\dd\varphi_s = -qV\sin\varphi_s + q\cos\varphi_s\,\dd V/\dd\varphi_s$。薄间隙公式只保留第一项；第二项在低 β 腔里与第一项同量级。入口相位与 $\varphi_s = \operatorname{atan2}(\int E\sin\varphi, \int E\cos\varphi)$ 之间的映射 $\dd\varphi_s/\dd\varphi_0 \approx 0.76$ 也不是 1，这是"设定值"与"平移"两种敏感度不同的原因。

## 深入：要算多少次 {#errors-deep-statistics}

### 第一步：平均值的误差

单次结果的分散程度（标准差）为 $\sigma$，$N$ 次结果的平均值，分散程度是 $\sigma/\sqrt N$。理由和抛硬币一样：$N$ 个独立结果之和的方差是 $N\sigma^2$，除以 $N$ 求平均，方差变成 $N\sigma^2/N^2 = \sigma^2/N$，开方得 $\sigma/\sqrt N$。

### 第二步：三法则

单次运行有损失的概率为 $p$，那么一次没损失的概率是 $1 - p$，$N$ 次都没损失的概率是 $(1 - p)^N$。

如果 $p$ 很大，"$N$ 次都没损失"就很难发生。我们问：$p$ 最大多少时，"$N$ 次都没损失"还有 5 % 的机会？令 $(1 - p)^N = 0.05$。$p$ 很小时 $(1 - p)^N \approx e^{-pN}$（例如 $0.99^{100} = 0.366$，$e^{-1} = 0.368$），于是 $e^{-pN} = 0.05$，

$$
p = \frac{-\ln 0.05}{N} = \frac{3.0}{N}.
$$

这就是"三法则"：$N$ 次都没损失时，有 95 % 的把握说 $p < 3/N$。

### 第三步：均匀分布的 rms

在 $[-A, A]$ 之间均匀分布的数，平方的平均是多少？把区间等分成很多小段，等于求 $x^2$ 的平均高度。用中学的求和公式 $1^2 + 2^2 + \dots + n^2 = n(n+1)(2n+1)/6 \approx n^3/3$：取 $x = A\cdot k/n$（$k = 1 \dots n$），平均值 $\approx A^2 \cdot (n^3/3)/n^3 = A^2/3$。所以 rms $= A/\sqrt3 \approx 0.577A$。

### 给学过概率论的读者

$\langle x^2\rangle = \frac{1}{2A}\int_{-A}^{A}x^2\,\dd x = A^2/3$。三法则是零事件时二项分布单侧 95 % 置信上限的近似（Hanley 与 Lippman-Hand，1983）。分位数的估计误差取决于分布在该分位处的密度，尾部密度小，误差大，所以估计"最坏的 1 %"需要的样本远多于估计均值。

## 在 AVAS 中 {#errors-in-avas}

### 静态与动态误差的实现

AVAS 的每一次误差运行（一个"组"中的一"次"）都由 Python 重新从输入快照读取 lattice，按本次的组号抽取所有误差，把抽到的数值写成内核命令后运行内核。

> **AVAS 约定**：内核只认识动态误差关键字（`err_*_ncpl_dyn`、`err_beam_dyn` 与 `*_dyn_on` 开关）。静态误差研究把抽到的静态误差改写成固定数值的动态误差命令交给内核。因此"静态"与"动态"在 AVAS 中的区别不在内核里，而在于流程：

- `error_type = stat`：只抽取静态误差（`*_stat` 命令），动态误差命令被忽略；可以执行 `adjust` 校正。
- `error_type = dyn`：只抽取动态误差，静态误差命令被忽略；不执行校正。
- `error_type = stat_dyn`：两者都抽取。校正（若有）只"看到"静态误差——优化时写给内核的 lattice 只含静态误差；校正结果确定后，同一元件的静态和动态误差逐列相加写成一条动态误差命令，开关取两者的并集，再运行内核。这正对应物理上"先根据静态误差调好校正元件，再叠加无法补偿的抖动"。

每次运行中误差数值在整条束流跟踪过程中是否保持不变由内核决定，手册未说明；按 Python 写给内核的命令，每次运行只有一组固定数值。

### 误差命令：分组与初始束流误差

误差命令写在 lattice 文件中（`start` 与 `end` 之间，通常放在开头），作用于命令**下面**的元件。

```avas-params
err_step err_beam_dyn err_beam_stat
```

- `err_step a b`：a 组，每组 b 次；误差研究必须有它。
- `err_beam_dyn r dx dy dφ dx' dy' dE dεx dεy dεz mx my mz dIb`：初始束流的动态误差，`r` 为分布类型；参数可以不写满，后面空着的列没有误差。
- `err_beam_stat 0 …`：静态版本，手册规定第一个参数写 0。

> **注意**：`mx`、`my`、`mz` 手册未说明含义。当前代码对 `err_beam_stat` 的第一个参数按与 `err_beam_dyn` 的 `r` 相同的方式解释，写 0 即为固定值误差，与手册一致。

### 误差命令：静磁元件与射频腔

```avas-params
err_quad_ncpl_stat err_quad_cpl_stat err_cav_ncpl_stat err_cav_cpl_stat
```

动态版本 `err_quad_ncpl_dyn`、`err_quad_cpl_dyn`、`err_cav_ncpl_dyn`、`err_cav_cpl_dyn` 的列相同：

```text
err_quad_ncpl_stat  N  r  dx  dy  dφx  dφy  dφz  dG  dz  Nb
err_cav_ncpl_stat   N  r  dx  dy  dφx  dφy  ke/kb  φs  dz  Nb
```

- `N`：作用于命令下面的 N 个**元件**。计数包括所有元件（漂移段、场图、矩阵元件、束诊），但误差只加到合适类型的元件上；想作用于全部元件可写一个很大的值。
- 静磁元件误差（`err_quad_*`）加到 `quad` 和静磁场图（`field` 类型 3，如螺线管场图）上；射频腔误差（`err_cav_*`）加到射频场图（`field` 类型 1）上。`solenoid` 矩阵元件和静电场图（类型 2）不接受这两类误差。
- `Nb` 手册未说明，抽样时不处理。

> **注意**：当前代码对元件误差命令的**最后一列**不做抽样、原样保留。写满到 `Nb` 时这一列就是 `Nb`；若写到 `dz` 为止而省略 `Nb`，`dz` 会成为最后一列，不随分布抽样、也不随组号缩放。需要 `dz` 误差时请把 `Nb` 也写上（例如 0）。

### 开关

```avas-params
err_quad_stat_on err_cav_stat_on err_beam_stat_on
```

`err_quad_dyn_on`、`err_cav_dyn_on`、`err_beam_dyn_on` 同理。每列只能写 0 或 1，顺序与对应误差命令的误差列一致；开关为 0 的列不加误差。误差研究要求该模式下至少有一个开关列为 1，否则报错（Missing … error on command）。

### 一个例子

```text
start
err_step 3 20
err_quad_stat_on 1 1 0 0 0 0 0
err_quad_ncpl_stat 1000 1 0.1 0.1
err_cav_dyn_on 0 0 0 0 1 1 0
err_cav_ncpl_dyn 1000 2 0 0 0 0 1.0 1.0
drift 0.05 0.02 0
...
end
```

含义：3 组、每组 20 次。所有四极铁 / 静磁场图在 x、y 有均匀分布位移，第 3 组为 $[-0.1, 0.1]\ \mathrm{mm}$，第 1 组为 $[-0.033, 0.033]\ \mathrm{mm}$；所有射频腔有高斯分布的幅值和相位动态误差，第 3 组标准差为 1 % 与 $1^\circ$。用 `stat_dyn` 模式运行时两者同时生效；用 `stat` 只有位移误差，用 `dyn` 只有射频误差。

### 抽样规则

分布类型 `r`：

| r | 含义 | 第 g 组（共 a 组）给定值 A 的列 |
|---|---|---|
| 0 | 固定值 | 每次都取 A，不随组号缩放 |
| 1 | 均匀分布 | 在 $[-A g/a,\ A g/a]$ 内均匀抽样 |
| 2 | 高斯分布 | 均值 0、标准差 $A g/a$（不截断） |
| -1 | 等步长 | 取 $A g/a$（等价于 TraceWin 的 0 类型） |

```avas-params
err_quad_ncpl_dyn
```

> **注意**：初始束流误差的等步长（r = −1）在当前代码中按 $A(g+1)/a$ 计算，与元件误差不同；使用前请核对生成的误差记录。抽到的数值保留 5 位小数。

耦合与非耦合：

- `ncpl`（非耦合）：每个受影响的元件**各自独立**抽样。
- `cpl`（耦合）：每条命令只抽一次，同样的数值加到它覆盖的全部元件上，用来模拟共同的支架、共同的电源等整体误差。
- 同一元件被多条同类（静态或动态）四极铁 / 腔误差命令覆盖时，当前代码只保留离元件最近（最靠下）的一条，不叠加。

随机种子：

- `ini.ini` 的 `[error] seed`（模拟设置页"误差分析"中的"随机种子"，命令行 `--seed`）决定误差抽样（以及校正的随机初值）。同一种子、同一 lattice 给出相同的误差序列。
- `randomseed`（手册列在 `beam.txt` 中，示例项目写在 `input.txt` 中）是生成初始粒子分布的随机数种子，与误差种子是两个独立的设置。比较两次误差研究时，两者都要固定。

### 静态误差校正：命令

```avas-params
adjust diag_energy diag_size diag_position
```

- `adjust 0 v n min max first_step`：紧放在要调的元件前，把该元件的第 v 个参数设为旋钮（从关键字后第 1 个参数数起：`field` 的相位为第 6 个、`Ke` 第 7 个、`Kb` 第 8 个；`quad` 的梯度第 4 个；`steerer` 的 `Bx`/`By` 第 4/5 个），取值限制在 `[min, max]`；`n` 相同（且非 0）的旋钮被约束为同一值；`first_step = 1` 从元件当前值开始，0 则在范围内随机取初值。
- `diag_position 0 x y 0`：该位置束流中心的目标（mm）。
- `diag_size 0 sx sy 0`：该位置 rms 尺寸的目标（mm）。
- `diag_energy 0 W 0`：该位置能量的目标（MeV）。
- `diag_*` 是长度为零的元件，标出目标所在位置；它们不传给内核，Python 从 DataSet 中读取该位置的束流参数。

### 静态误差校正：算法

以下是当前 AVAS 静态误差校正的做法，手册没有记载这些细节，以后可能变化：

1. 只有当某个 `adjust` 与某个 `diag_*` 的第一个参数相同时才执行校正（手册把它写作"无意义，写 0"；全部写 0 即为一组）。不同编号按从小到大依次校正，后一组从前一组校正后的 lattice 开始。
2. 每组用 SLSQP 优化：每次函数求值把旋钮写入 lattice，运行内核到最后一个束诊之后，计算目标函数——本组各束诊的平均平方偏差：位置 $(x_c - x)^2 + (y_c - y)^2$（mm²），尺寸 $(x_{\mathrm{rms}} - s_x)^2 + (y_{\mathrm{rms}} - s_y)^2$（mm²），能量 $(W - W_{\mathrm{target}})^2$（MeV²）。
3. 目标函数低于 0.05 即停止；最多 100 次迭代，数值差分步长 0.1（旋钮自身单位），收敛容差 $10^{-4}$。
4. 每次误差运行都重新校正，校正值写入 `Adjust_Datas_<组>_<次>.txt`，各束诊处的束流参数写入 `par_diag_datas_<组>_<次>.txt`。校正过程的内核运行放在 `error_adjust/` 下。校正值不会写回 lattice 文件。

> **注意**：差分步长固定为 0.1，旋钮的有效范围远小于 0.1 时（例如以 T 为单位的校正铁磁场 ±0.01 T）梯度估计不可靠；目标函数阈值 0.05 的量纲依目标类型而定（mm² 或 MeV²），对小束流尺寸可能过松：0.05 mm² 相当于中心偏差约 0.22 mm。案例教程中按手册写的能量校正例子（目标 5 MeV）并未达到目标（记录的末能量仍约 $2.3\ \mathrm{MeV}$）——运行完成不等于校正成功，务必检查校正后的束诊数据。

### 轨道校正的写法示意

下面的写法只说明命令怎样搭配，未经内核验证：

```text
adjust 0 4 0 -0.005 0.005 1
adjust 0 5 0 -0.005 0.005 1
steerer 0 0.02 0 0 0 0 0.005
field 0.35 0.02 0 3 0 0 1 0.38 sol
drift 0.05 0.02 0
diag_position 0 0 0 0
```

两条 `adjust` 分别把校正铁的 `Bx`、`By` 设为旋钮，校正铁作用于下一个元件（螺线管场图）；`diag_position` 要求下游中心回到 (0, 0)。注意磁场单位 T 与上面的差分步长问题；实际使用前应先用小规模研究检查收敛情况。

### 运行误差研究

`ini.ini` 的 `[error]` 段：

| 键 | 含义 |
|---|---|
| `error_type` | 空 = 普通运行；`stat`、`dyn`、`stat_dyn` = 相应误差研究 |
| `seed` | 误差抽样的随机种子 |
| `if_normal` | 1 = 先运行一次无误差的参考 |

在界面中：模拟设置页的"误差分析"选择 无 / 静态 / 动态 / 静态 + 动态，并填写"随机种子"（界面运行总会先跑无误差参考）；然后在结构中写好 `err_step`、误差命令与开关，保存并运行。命令行用 `avas run --input … --output … --mode stat|dyn|stat_dyn --seed 7`，`--no-normal` 跳过参考运行；`--mode auto`（默认）读取 `ini.ini`。AI 助手的 `set_error_study` 工具同样修改这两项（需用户批准）。

误差研究和完整运行一样在输出目录的 `inputs/` 快照上进行，不改写项目的 InputFile；运行期间（包括暂停）输入文件只读。

### 输出文件

| 路径（相对输出目录） | 内容 |
|---|---|
| `error_output/output_0_0/` | 无误差参考运行 |
| `error_output/output_<组>_<次>/` | 每次误差运行的完整输出（DataSet.txt 等，及所用 lattice.txt） |
| `error_middle/output_0/` | 正在进行的那一次运行，完成后移到 `error_output` |
| `errors_par_tot.txt` | 每次运行一行：损失率、三个平面的发射度增长 $\varepsilon_{\mathrm{out}}/\varepsilon_{\mathrm{in}} - 1$、末端中心与角度、rms 尺寸与角散、相对参考运行的能量差、末端 Twiss |
| `errors_par.txt` | 每组一行：从损失率到能量差（不含 Twiss）各量在本组各次运行上的平均值，以及中心、角度、尺寸、角散与能量差的均方根 |
| `Error_Datas_<组>_<次>.txt` | 本次加到每个腔 / 四极铁上的具体误差值 |
| `Adjust_Datas_<组>_<次>.txt`、`par_diag_datas_<组>_<次>.txt` | 校正值、各束诊处的束流参数 |
| `density_par_*.dat`、`density_tot_par*.dat` | 粒子密度统计（需要 `input.txt` 中 `pchistogram 1 …`） |

束流没有到达 lattice 末端（DataSet 的最后位置比总长短 5 cm 以上）的运行记为损失率 1，其余列为 0。

### 在界面中查看

- 运行页实时显示当前种子的包络，已完成的种子以包络带叠加（"已完成的误差种子"），可以直观看到误差引起的包络散布。
- 结果页"误差分析"组有"发射度增长与损失"（读 `errors_par*.txt`）和"输出参数"（可选平均值或均方根统计量）两类图。
- 单次运行的详细结果可以在结果页选择对应的 `error_output/output_<组>_<次>` 目录查看。

真正的统计研究要用内核：复制示例项目到练习目录，按上面的例子加入 `err_step` 与误差命令，在模拟设置页选择误差模式后运行。
