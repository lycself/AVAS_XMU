# 静电与静磁场图元件

离子源出口 30 keV 的质子穿过 1 T 的磁场，受到的力和 2.4 MV/m 的电场一样大；到了 1.527 MeV，同样 1 T 相当于 17 MV/m。为什么低能段的束线里常见静电透镜，而高能段只用磁铁？另一个问题：AVAS 已经有 `quad`、`solenoid` 这些矩阵元件，为什么还要用一张几十万个数的场图去描述一个不随时间变化的磁铁？

本章用两个想法回答这两个问题：一是电力与速度无关、磁力正比于速度；二是真空中的静态场由轴上分布完全决定，它的纵向形状（边缘场）会改变束流，而硬边模型把这部分丢掉了。`field` 元件的场类型 2 是**静电场**（单透镜、静电四极、静电偏转板等），类型 3 是**静磁场**（用场图描述的螺线管、四极铁、带偏转成分的磁铁等）。建议先读 [螺线管](#solenoid) 和 [四极铁](#quadrupole)；场图文件本身见 [场图](#field-maps)。

先看示例项目的静磁场图螺线管 sol（Kb = 0.35，平滑后的轴上峰值约 2.9 T）。点开元件可以看到场图的轴上分布。线性预览中，束流在螺线管中心附近 rms x 最大（约 1.40 mm），之后被聚到 $z \approx 0.62\ \mathrm{m}$ 处的束腰（0.81 mm），末端为 0.97 mm；把 Kb 改成 0，末端会是 3.09 mm。

```avas-beamline
drift 0.05 0.02 0
field 0.35 0.02 0 3 0 0 0 0.35 sol
drift 0.4 0.02 0
```

本章的数值例子使用示例项目的质子束：$W = 1.527\ \mathrm{MeV}$，$\beta = 0.0570$，$\beta\gamma = 0.0571$，$p = 53.55\ \mathrm{MeV}/c$，$B\rho = 0.1786\ \mathrm{T\,m}$。

## 电还是磁：速度说了算 {#static-fields-role}

Lorentz 力 $\boldsymbol{F} = q(\boldsymbol{E} + \boldsymbol{v}\times\boldsymbol{B})$ 已经给出了答案的一半：横向电场的力与速度无关，横向磁场的力正比于速度。两者等效的条件是 $E = vB = \beta cB$：

| 质子动能 | β | 1 T 相当于 |
|---|---|---|
| 30 keV（离子源出口的典型值） | 0.0080 | 2.4 MV/m |
| 1.527 MeV（示例） | 0.0570 | 17 MV/m |

另一半在工程上：直流电极之间的场强受击穿限制，实际一般只能做到每米几 MV 到十几 MV 的量级（典型值），而常温磁铁做到 1 T 并不难，超导螺线管可以到几 T。以 10 MV/m 对 1 T 为界，两者打平的速度是 $\beta = 10^7/(3\times 10^8) \approx 0.033$，即质子动能约 0.52 MeV。低于这个量级，同样技术难度的电场更"值钱"；高于它，磁场占优，而且越快优势越大。

这就是静电元件主要出现在低能段的原因。它们还有没有磁滞、电压可快速调节的优点；代价是电场会把用来补偿空间电荷的低能电子扫走，所以低能传输段在静电与磁聚焦之间要权衡，参见 [离子源与低能传输段](#journey-source)。

> **想一想**：RFQ 工作在几十 keV 到几 MeV，为什么它用电四极场而不是磁四极来聚焦？
>
> 答：同样的道理。电场力不随速度降低而减弱，在 $\beta \sim 0.01$ 时同样的力需要的磁场是电场的 $1/\beta \sim 100$ 倍（以 SI 单位比较 $E$ 与 $cB$）。见 [RFQ](#journey-rfq)。

元件在束线中的典型用途：

- **低能束流输运**：几十 keV 到几百 keV 的区段常用静电单透镜和静电四极。
- **超导直线加速器的横向聚焦**：低 β 段腔与腔之间的超导螺线管场强高、边缘场长，常和相邻腔的场重叠，用场图比硬边模型可靠，参见 [螺线管](#solenoid)、[叠加场](#superpose)。
- **组合功能元件**：同一个磁体中既有四极又有偏转或校正线圈，或磁铁有明显的高阶场，用场图可以一并描述。
- **核对矩阵模型**：用场图计算与硬边矩阵 [四极铁](#quadrupole)、[螺线管](#solenoid) 的结果对比，可以判断硬边近似的误差有多大。

## 静电场：能量会变的透镜 {#static-fields-electric}

### 能量随电势变化

静电场是保守场，$\boldsymbol{E} = -\nabla\Phi$，粒子在静电元件中的总能量守恒：

$$
W(\boldsymbol{r}) + q\,\Phi(\boldsymbol{r}) = \text{常数}
$$

所以粒子在电极之间会被加速或减速，离开元件回到原电势时动能恢复。这是静电元件与磁元件最根本的区别：磁场不做功，粒子在磁铁里速度大小不变；而在静电元件里，速度、动量和聚焦强度都随位置变化。这正是不能简单套用恒定能量矩阵、必须在场里积分的原因。AVAS 的线性预览也把类型 2 场图的轴上 $E_z$ 计入参考粒子的能量。

### 电刚度

磁场中的偏转能力用磁刚度 $B\rho = p/q$ 衡量。在静电场中做同样的推导：横向电场提供向心力 $qE = \gamma mv^2/\rho = pv/\rho$，于是**电刚度**

$$
E\rho = \frac{p\,v}{q} = \frac{\beta^2\gamma\,mc^2}{q}\ \xrightarrow{\ \beta\ll 1\ }\ \frac{2W}{q}
$$

对示例质子 $E\rho = 53.55\ \mathrm{MeV}/c\times 0.0570 \approx 3.05\ \mathrm{MV}$（非相对论近似 $2W/q = 3.054\ \mathrm{MV}$）。横向电场 $E$ 产生的曲率半径为 $\rho = E\rho/E$，例如 $E = 1\ \mathrm{MV/m}$ 时 $\rho \approx 3.05\ \mathrm{m}$。$E\rho$ 正比于动能，而 $B\rho$ 正比于动量（非相对论时 $\propto\sqrt{W}$），动能降低时电刚度降得更快——又一次说明低能时电场更有效。

### 静电四极

理想静电四极的四个双曲面电极分别加 $\pm V$，口径半径为 $a$，电势为

$$
\Phi = \frac{V}{a^2}\,(x^2 - y^2),\qquad E_x = -\frac{2V}{a^2}\,x,\qquad E_y = +\frac{2V}{a^2}\,y
$$

定义电场梯度 $G_E = 2V/a^2$（V/m²），线性运动方程为

$$
x'' + k\,x = 0,\quad y'' - k\,y = 0,\qquad k = \frac{G_E}{E\rho}
$$

$V > 0$ 时正粒子在 $x$ 方向聚焦、$y$ 方向散焦，传输矩阵与磁四极形式完全相同（见 [四极铁](#quadrupole)）。这里电极上的电势在 $x$ 轴上是 $+V$，近似的前提是粒子动能远大于 $qV$，否则粒子在四极里的能量变化不能忽略。

数一数：$V = \pm 10\ \mathrm{kV}$、$a = 15\ \mathrm{mm}$ 时 $G_E = 8.9\times 10^7\ \mathrm{V/m^2}$。对示例质子 $k \approx 29\ \mathrm{m^{-2}}$，相当于梯度 $kB\rho \approx 5.2\ \mathrm{T/m}$ 的磁四极；对 50 keV 质子，同一个静电四极给出 $k \approx 890\ \mathrm{m^{-2}}$，相当于 29 T/m 的磁四极——常温磁四极在这么小的口径里很难做到。

### 单透镜（Einzel lens）

单透镜由三个同轴圆筒电极组成，两端电极接地、中间电极加电压，入口与出口动能相同。在非相对论、轴对称、近轴条件下，令 $\hat\Phi(z)$ 为以"动能为零"为参考的轴上电势（$q\hat\Phi = W$），粒子轨迹满足近轴射线方程

$$
r'' + \frac{\hat\Phi'}{2\hat\Phi}\,r' + \frac{\hat\Phi''}{4\hat\Phi}\,r = 0
$$

第二项是动量变化引起的"阻尼"，第三项是径向电场的作用。作 Picht 变换 $R = r\,\hat\Phi^{1/4}$ 消去一阶导数项，得到

$$
R'' + \frac{3}{16}\left(\frac{\hat\Phi'}{\hat\Phi}\right)^{2}R = 0
$$

右边系数恒为正，所以**无论中间电极加正电压还是负电压，单透镜总是聚焦的**。弱透镜近似下焦距为

$$
\frac{1}{f} \approx \frac{3}{16}\int\left(\frac{\hat\Phi'}{\hat\Phi}\right)^{2}\dd z
$$

这个式子里只出现 $\hat\Phi'/\hat\Phi$，所以焦距只取决于电极几何和电压与动能之比 $qV/W$，与束流能量本身无关：能量加倍，电压也要加倍才能得到同样的焦距。举个典型例子：轴上电势取高斯形状，$1/\mathrm{e}$ 半宽 20 mm，中心处使粒子动能减为一半（减速模式）时 $f \approx 0.17\ \mathrm{m}$；同样大小的电压反号，中心处动能升到 1.5 倍（加速模式）时 $f \approx 0.54\ \mathrm{m}$。减速模式强约 3 倍，因为分母 $\hat\Phi$ 在场最强处更小；但若 $q\Phi$ 接近动能，粒子会在透镜中停下或被反射。焦距与透镜长度可比时弱透镜近似只是估计。相对论修正在本手册涉及的能量下很小，完整形式见 Reiser 第 3 章。

> **想一想**：单透镜里径向电场 $E_r = \tfrac{r}{2}\Phi''$ 在电势弯曲向上处散焦、弯曲向下处聚焦，两种区域都有，为什么净效果总是聚焦？
>
> 答：看粒子在哪里慢。减速模式下电势在中间隆起，中间是聚焦区，粒子恰好在那里最慢、受力时间最长；加速模式下中间是散焦区，粒子却在那里最快、受力时间最短，聚焦区在两端。无论哪种，聚焦区总是"占便宜"的一方。这是二阶效应，所以焦距正比于 $(\hat\Phi'/\hat\Phi)^2$，符号与电压方向无关。

### 静电偏转

圆柱或球面电极之间的径向电场可以让束流转弯，半径 $\rho = E\rho/E$。静电偏转在偏转平面内的聚焦性质与磁偏转不同（与电极形状有关），而且偏转中粒子动能会随电势变化。AVAS 的二极铁 `bend` 只描述磁偏转；静电偏转只能用场图描述，见 [在 AVAS 中](#static-fields-in-avas)。

## 静磁场：轴上的场决定一切 {#static-fields-magnetic}

### 为什么只需要知道轴上的场

在没有电流和磁性材料的真空区域，静磁场满足 $\nabla\cdot\boldsymbol{B} = 0$ 和 $\nabla\times\boldsymbol{B} = 0$，可以写成标量势的梯度，而标量势满足 Laplace 方程。Laplace 方程的解由边界值决定，对轴对称场，它在轴附近的展开只由轴上 $B_z(z)$ 及其导数给出：

$$
B_r(r,z) = -\frac{r}{2}\,B_z'(z) + \frac{r^3}{16}\,B_z'''(z) - \cdots,\qquad
B_z(r,z) = B_z(z) - \frac{r^2}{4}\,B_z''(z) + \cdots
$$

第一项最容易理解：取一个半径 $r$、长 $\dd z$ 的小圆柱面，$\nabla\cdot\boldsymbol{B} = 0$ 要求从两端面流出的磁通变化 $\pi r^2 B_z'\,\dd z$ 由侧面的 $2\pi r\,B_r\,\dd z$ 补上，于是 $B_r = -\tfrac{r}{2}B_z'$。这意味着：**只要轴上场沿 $z$ 变化，就一定有径向场**。硬边模型把 $B_z$ 画成方波，等于把这些径向场压成元件两端两个无限薄的"冲击"。

### 螺线管：先转起来，再被拉回

在入口端 $B_z' > 0$，$B_r$ 指向轴心；出口端 $B_z' < 0$，$B_r$ 背离轴心（对 $B_z > 0$）。粒子穿过入口边缘时，$F_\theta = qv_zB_r$ 给它一个角向速度；进入螺线管主体后，$F_r = qv_\theta B_z$ 把它拉向轴心——螺线管聚焦是边缘场和主场接力完成的。由 Busch 定理，在以 Larmor 频率旋转的坐标系中两个横向平面解耦，满足

$$
r'' + \left(\frac{B_z(z)}{2B\rho}\right)^{2} r = 0,\qquad
\theta_L = \int\frac{B_z}{2B\rho}\,\dd z,\qquad
\frac{1}{f} \approx \int\left(\frac{B_z}{2B\rho}\right)^{2}\dd z
$$

聚焦强度正比于 $B_z^2$，**与场的方向无关**；改变 $K_b$ 的符号只改变束流旋转的方向。用上面的束线验证：把 Kb 从 0.35 改成 −0.35，线性预览的 rms 曲线完全不变（束腰都在 $z = 0.62\ \mathrm{m}$，0.81 mm）。

### 四极场图

磁四极在轴附近 $B_y = G\,x$、$B_x = G\,y$，$k = G/(B\rho)$；正粒子在 $k > 0$ 时 $x$ 方向聚焦。场图四极一般按某个参考梯度（例如中心 1 T/m）归一化导出，此时 $K_b$ 就是实际梯度（T/m）。与螺线管不同，四极的力是 $B$ 的一次方，**$K_b$ 的符号决定极性**：$K_b < 0$ 时聚焦和散焦平面互换。有边缘场时常用等效长度 $L_{eff} = \int G(z)\,\dd z/G_0$ 与硬边四极比较。

### 偏转与校正成分

场图中若含有轴上横向磁场（偶极成分），粒子会被偏转。内核按场图积分，偏转自然计入；线性预览不计偏转，当估计偏角超过 1 mrad 时给出警告。场图在空间中是一个沿 $z$ 轴的直长方体，粒子偏离轴线后会逐渐走出场图覆盖的区域，因此场图适合描述小角度的偏转和校正；大角度二极铁请使用 `bend` 与 `edge`（见 [二极铁](#dipole)），校正线圈也可以用 [校正铁](#steerer) 描述。内核在场图中如何定义大偏转时的参考轨道，手册没有说明。

## 场图还是硬边 {#static-fields-equations}

### t-code 积分的方程

内核在场图元件中对每个粒子积分 Lorentz 方程

$$
\frac{\dd(\gamma m\boldsymbol{v})}{\dd t} = q\,\bigl(\boldsymbol{E}(\boldsymbol{r}) + \boldsymbol{v}\times\boldsymbol{B}(\boldsymbol{r})\bigr),\qquad
\boldsymbol{E} = K_e\,\boldsymbol{E}_{map},\quad \boldsymbol{B} = K_b\,\boldsymbol{B}_{map}
$$

时间步长由 input.txt 的 `steppercycle` 决定。静磁场不做功，粒子动能不变；静电场按上一节的能量守恒改变动能。

### 线性化与硬边等效

把场在轴附近展开到一阶，横向运动方程可以写成

$$
x'' + \frac{(\beta\gamma)'}{\beta\gamma}\,x' + \left(\frac{1}{B\rho}\frac{\partial B_y}{\partial x} - \frac{1}{E\rho}\frac{\partial E_x}{\partial x}\right)x = 0
$$

（这里没有写出螺线管的 $x$–$y$ 耦合项；有轴向磁场时用旋转坐标系或 4×4 矩阵，见 [螺线管](#solenoid)。）第二项来自静电场中动量的变化。若元件内动量变化可以忽略，把场按等效梯度 $G_{eff}$、等效长度 $L_{eff}$ 换成硬边元件，就回到矩阵模型：四极用 [四极铁](#quadrupole) 一章的厚透镜矩阵，螺线管用 $k = B_{eff}/(2B\rho)$、$C = \cos kL$、$S = \sin kL$ 的耦合矩阵。

上表里的 $B_{eff}$ 和 $L_{eff}$ 是这样选的：硬边螺线管与场图有相同的 $\int B\,\dd z$（旋转角相同）和 $\int B^2\,\dd z$（薄透镜焦距相同）。两个积分都对上了，为什么还会有差别？因为它们只是薄透镜极限下的量。焦距与元件长度可比时，束流尺寸在场内就在变化，场沿 $z$ 怎么分布开始起作用。

### 硬边等效有多准

在示例中比较两个 lattice（示例流强 0.184 mA，线性预览计入线性空间电荷，rms $x$）：漂移 0.05 m + 场图 `sol` + 漂移 0.3 m，与在相同中心位置放置等效的硬边 `solenoid`（$L = 0.136\ \mathrm{m}$）：

| | 场图 rms 束腰 | 硬边 rms 束腰 | $z = 0.7\ \mathrm{m}$ 处场图 / 硬边 |
|---|---|---|---|
| $K_b = 0.35$（$B_{eff} = 1.88\ \mathrm{T}$，$f/L_{eff} \approx 2$） | 0.811 mm @ 0.62 m | 0.828 mm @ 0.62 m | 0.845 / 0.857 mm |
| $K_b = 0.531$（$B_{eff} = 2.85\ \mathrm{T}$，$f/L_{eff} \approx 0.85$） | 0.285 mm @ 0.388 m | 0.311 mm @ 0.402 m | 2.73 / 2.42 mm |

弱聚焦时两者相差约 2 %，强聚焦时到 $z = 0.7\ \mathrm{m}$ 已差约 13 %。经验是：$f$ 比元件长度大几倍时硬边等效足够做初步设计；$f$ 与长度可比时，精确计算应使用场图。

下图是 $K_b = 0.531$ 等效硬边螺线管的示意场（由参数计算，硬边，不是场图数据），与上面的场图对比纵向分布的差别：

```avas-field
solenoid B=2.85 L=0.136 R=0.02
```

在螺线管实验中用这组等效参数，观察 Larmor 旋转角 $kL$（约 $62^\circ$）、厚透镜焦距（0.142 m）与薄透镜焦距（0.116 m）的差别，以及束腰位置随 B 的变化。再把 W 降到 0.05 MeV：薄透镜焦距按 $f \propto (B\rho)^2 \propto W$ 缩短约 30 倍（0.116 m → 3.8 mm），$kL$ 增大到约 6 rad，束流在螺线管内多次过焦，薄透镜近似完全失效——低能段要用弱得多的螺线管。

```avas-lab
solenoid L=0.136 B=2.85 W=1.527 d1=0.05 d2=0.3
```

> **想一想**：示例场图有噪声，为什么 $\int B_z\,\dd z$ 几乎不受影响，而 $\int B_z^2\,\dd z$ 系统性地偏大约 3 %？
>
> 答：把测得的场写成 $B + n$，$n$ 是平均为零的噪声。线性积分里 $n$ 正负抵消；平方积分里多出一项 $\int n^2\,\dd z$，它总是正的，不会抵消。所以由噪声场图算出的螺线管焦距偏短。

> **AVAS 约定**：线性预览把场图切成 4 mm 的薄片，每片做"边缘 + 半步螺线管主体 + 由轴附近横向梯度给出的薄透镜 + 半步主体 + 边缘"的处理。螺线管的径向边缘场由叠加后的轴上 $B_z$ 按 Maxwell 方程（$\partial B_x/\partial x + \partial B_y/\partial y = -\partial B_z/\partial z$）得出，放在每片两端，保证传输矩阵严格辛；场图的 $B_x$、$B_y$ 只提供无散的部分（四极、斜四极成分），因为带噪声的场图里这两个分量与 $B_z$ 并不一致；内核则直接在三维场中积分，二者都包含边缘场，后者还包含非线性项。

## 容易误解的地方 {#static-fields-pitfalls}

- **Kb 的符号**：螺线管的 Kb 符号只改变旋转方向，焦距不变；四极的 Kb 符号决定极性，反号后聚焦与散焦平面互换。
- **场图长度不是等效长度**：示例 `sol` 场图长 0.35 m，等效硬边长度只有 0.136 m。用场图长度和峰值场去建硬边模型，聚焦会被严重高估。
- **原始最大值不是峰值场**：`sol.bsz` 的原始最大值比 9 点平滑后的峰值高约 20 %；平方量（$\int B^2$）被噪声抬高约 3 %，线性量（$\int B$）基本不受影响，参见 [场图噪声](#field-maps-interpolation)。
- **"静电元件不改变能量"**：只有离开元件、回到原电势时动能才恢复；元件内部动能、速度和聚焦强度都在变，减速型元件中若 $q\Phi$ 超过动能，粒子会停下或被反射。
- **电刚度与磁刚度混用**：$E\rho \approx 2W/q$ 正比于动能，$B\rho = p/q$ 正比于动量。同一个静电元件在能量减半时强度加倍，磁元件只增大约 $\sqrt 2$ 倍。
- **"磁铁里没有径向场"**：只要轴上场沿 $z$ 变化就有 $B_r = -\tfrac{r}{2}B_z'$；硬边模型把它压缩成两端的冲击，并不是说它不存在。
- **大角度偏转**：不要用直的场图盒子描述大角度二极铁，见 [偏转成分](#static-fields-magnetic)。

## 在 AVAS 中 {#static-fields-in-avas}

### 语法与参数

```text
field  L  R  0  2  0  0  Ke  0   file      ! 静电场：.esx .esy .esz
field  L  R  0  3  0  0  Ke  Kb  file      ! 静磁场：.bsx .bsy .bsz
field  0.1   0.02  0  3  0  0  1  0.677098  sol_1     ! 手册示例
field  0.35  0.02  0  3  0  0  1  0.531     sol       ! 示例螺线管
```

```avas-params
field
```

- 场类型写 2（静电）或 3（静磁）。AVAS 没有静电透镜的矩阵模型元件，静电聚焦元件只能用类型 2 的场图描述；纯偏转也可以用电场校正铁（`steerer` 的类型 1）描述，见 [校正铁](#steerer)。
- **频率 `f` 必须写 0**；`phase` 写 0；`V3` 对静态场无意义，写 0。手册的规则是"不存在的参数写 0"。写成束流频率会让人误以为它是射频场。
- 静电场的电场单位为 MV/m，乘以 `Ke`；静磁场的磁场单位为 T，乘以 `Kb`。
- 对静磁场，手册示例中 `Ke` 写的是 1；场图没有电场分量文件时它没有作用对象（本章的束线写 0，效果相同）。对静电场，按手册规则 `Kb` 写 0。
- `file` 为场图文件名（不含扩展名），静电场需要 `.esx/.esy/.esz`，静磁场需要 `.bsx/.bsy/.bsz`，格式见 [场图](#field-maps)。
- `L` 应等于场图头部的长度；`R` 是损失判据的孔径半径。

> **AVAS 约定**：静磁场图四极的 `Kb` 符号就是极性；螺线管的 `Kb` 符号只改变旋转方向。界面的元件列表根据场类型把场图元件分为射频、静电、静磁三类；静磁场图的具体类型（螺线管、四极……）由场图文件名推测，显示时带"（推测）"，识别依据写在详情说明中——这只是显示用的推测，不是物理数据。

> **注意**：静磁元件的误差用 `err_quad_*`（静磁元件误差）命令描述，射频腔用 `err_cav_*`，参见 [误差与校正](#errors)。

### 典型取值

| 参数 | 元件 | 作用 | 示例 / 典型值 |
|---|---|---|---|
| `Kb` | 静磁螺线管 | 场强缩放，焦距 $\propto 1/K_b^2$ | 示例 0.531（$\int B\,\dd z = 0.387\ \mathrm{T\,m}$，$f \approx 0.12\ \mathrm{m}$）；本章束线 0.35（$f \approx 0.27\ \mathrm{m}$） |
| `Kb` | 静磁四极 | 梯度与极性 | 场图按 1 T/m 归一化时 $K_b = G$；常温四极一般在几十 T/m 以内 |
| `Ke` | 静电四极、单透镜 | 电场缩放 | 场图按 1 kV 电极电压导出时 $K_e$ = 电压 / kV；低能段电极电压常为几到几十 kV |
| `L` | 全部 | 元件长度 | 等于场图头部长度 |
| `R` | 全部 | 损失孔径 | 与真实孔径一致，不大于场图横向范围 |

由于聚焦强度 $\propto K_b^2$（螺线管）或 $\propto K_b$（四极），扫描 `Kb` 可以直接用参数扫描：`avas scan --input InputFile --target 元件名 --param Kb --values …`。

### 注意事项

- **场图截断**：场图两端的场应已衰减到可以忽略。若场图在边界处截断，粒子会受到一个虚假的边缘冲击；示例 `sol` 两端已降到峰值的约 0.3 %。
- **元件长度与场图长度不一致**：内核对两者不一致时的处理，手册没有说明；线性预览只使用 $[0, \min(L, L_{map})]$ 范围内的场。务必让 `L` 与场图头部一致。
- **重叠的场**：相邻元件的边缘场重叠时，不能简单地把两个场图首尾相接（重叠部分会被截掉），要用 [叠加场](#superpose)。
- **螺线管耦合**：螺线管使 $x$、$y$ 耦合并旋转束流；非圆束经过螺线管后 rms $x$、$y$ 不再独立，四极之后接螺线管时尤其要注意。
- **静电反射**：减速型静电元件中若 $q\Phi$ 超过动能，粒子会停下或被反射，线性预览会提示参考粒子在何处停止，并在那里结束；这类粒子无法通过元件。
- **大角度偏转**：静电偏转与大角度磁偏转都不适合用直的场图盒子描述，见 [偏转成分](#static-fields-magnetic)。
